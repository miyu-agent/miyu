用法：miyu [<命令>] [<选项>]

不带命令时打开默认界面。

对话：
  ask [<消息>]        发送消息并打印回复
  undo                撤销上一轮（别名：rewind）
  restore             恢复上一次撤销的内容
  redo [<消息>]       重做上一轮，可换成新消息
  compact [<要点>]    压缩上下文
  recap               总结当前会话
  rename <标题>       重命名会话

内容：
  memory <命令>       管理记忆
  kb <命令>           管理知识库
  schedule <命令>     管理定时任务

软件包：
  pkg <命令>          管理软件包
  mcp <命令>          登录或登出 MCP 服务

设置：
  config <命令>       查看和修改设置
  check [<文件>]      检查配置文件
  provider <命令>     管理供应商密钥
  setup               配置模型供应商

系统：
  service <命令>      管理后台服务
  sandbox <命令>      配置或移除沙盒用户（Windows）

选项：
  -h, --help     显示帮助
  -V, --version  显示版本

例子：
  miyu ask "这个项目是做什么的"
  miyu ask -c "测试怎么跑"
  miyu undo

运行 'miyu help <命令>' 查看命令的说明。
