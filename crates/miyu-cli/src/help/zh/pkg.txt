用法：miyu pkg <命令> [选项]

不写命令时运行 list。

命令：
  list                    列出已安装的软件包（别名：-Q）
  install <软件包>        安装软件包（别名：-U）
  remove <编号>           卸载软件包及其设置和状态（别名：-R）
  info <编号>             显示软件包信息（别名：-Qi）
  files <编号>            列出软件包的文件（别名：-Ql）
  owns <路径>             查找文件所属的软件包（别名：-Qo）
  check [编号]            检查已安装的文件有没有改动（别名：-Qk）
  pack <目录>             把软件包目录打包成 .miyu 文件
  update                  更新软件源索引（别名：-Sy）
  search [词…]            搜索软件源（别名：-Ss）
  upgrade                 升级已安装的软件包（别名：-Su）
  clean                   清理缓存里的旧版本包文件（别名：-Sc）

<软件包> 可以是：
  <目录>                  含 package.toml 的软件包目录
  <文件>                  .miyu 包文件
  <编号>                  从软件源安装，或装回卸载过的出厂软件包

pacman 写法：-S <编号>… 从软件源安装，-Syu 更新索引后升级。

选项：
      --format text|json  输出格式（默认 text）
      --yes, --noconfirm  安装或卸载前不确认
      --target <系统>     打包的目标系统
  -o, --out <目录>        打包的输出目录（默认当前目录）
  -h, --help              显示帮助
