用法：miyu core <命令> [<选项>]

管理在后台运行的核心。核心由界面和命令在需要时启动，一般不用手动管理。

命令：
  start   启动核心，就绪后返回；已经在运行时什么都不做
  status  显示核心的运行状态
  stop    让正在运行的核心停下，等它退出后返回；没有在运行时什么都不做

start 只启动核心，不打开界面，也不打开浏览器。status 在运行时还显示核心的版本
和数据根。

status 的退出状态：
  0  核心正在运行
  1  出错，例如连不上正在运行的核心
  3  核心没有在运行

选项：
      --format <text|json>  status 的输出格式（默认 text）
  -h, --help                显示帮助
