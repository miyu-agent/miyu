Usage: miyu mcp login <server>
       miyu mcp logout <server>

Commands:
  login <server>   Log in to a URL MCP server that needs browser authorization
  logout <server>  Delete the stored login

login prints the authorization address and tries to open a browser; once
authorized there, the token goes into the secrets file and the server
connects. If the browser is on another machine, paste back the full address
it lands on and press Enter. Waits up to 10 minutes. The core renews the
token before it expires.

Options:
  -h, --help  Print help
