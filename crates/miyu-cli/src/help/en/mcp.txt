Usage: miyu mcp login <server>
       miyu mcp logout <server>

login: log in to a URL MCP server that only accepts browser authorization (one
in your personal settings with a url and no token). Prints the authorization
address and tries to open a browser; once you agree there, the token goes into
the secrets file and the server connects by itself. If the browser is on
another machine, paste back the whole address it lands on and press Enter.
Waits up to 10 minutes. The core renews the token itself before it expires.

logout: delete the stored login; log in again to use the server.

Options:
      --system  As an admin: MCP servers belong to the whole machine
  -h, --help  Print help
