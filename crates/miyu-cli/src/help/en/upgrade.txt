Usage: miyu upgrade [<options>]

Upgrade Miyu itself. When it was installed by the install script, download
the new version, verify its signature and checksum, and replace it. When it
came from AUR or Homebrew, print the package manager command to use. When it
was unpacked by hand, print where to download it. Your data is not touched.

Miyu's own files in the folder the program lives in are replaced and anything
else is left alone, but resources/ is replaced as a whole each time, so keep
your own files out of the install folder. A core that is already running stays
on the old version until 'miyu core stop'; the next start uses the new one.

Options:
      --prerelease  Include pre-releases
      --yes         Upgrade without asking
  -h, --help        Print help
