Usage: miyu pkg [command] [options]

See which packages are installed; install, remove, check installed files.
Without a command it is list.
A package folder holds a package.toml; the folder name is the id.
A package file is a packed .miyu.

Commands:
  list                    List packages
  install <folder|file|id>
                          Install a folder or a package file; an id comes
                          from the package source, a shipped one is restored
  remove <id>             Remove a package with its settings and state
  info <id>               Show a package
  files <id>              List the files a package installed
  owns <path>             Show which package a file belongs to
  check [<id>]            Check installed files; all packages if none given
  pack <folder>           Pack a folder into a package file here
  update                  Fetch the latest index from the package source
  search [<words>…]       Search the package source
  upgrade                 Upgrade installed packages from the source
  clean                   Delete downloaded files not of installed versions

pacman options work too:
  -U, -R, -Q              install, remove, list
  -Qi, -Ql, -Qo, -Qk      info, files, owns, check
  -Sy, -Ss, -Sc, -Su      update, search, clean, upgrade
  -Syu                    update, then upgrade
  -S <id>                 Install from the package source

Options:
      --format text|json  list, info, files, owns, check: json for scripts
      --yes, --noconfirm  install, remove: do not ask first
      --system            install, remove, upgrade, clean, update: as an admin
      --target <target>   pack: pick one of the manifest's targets
  -o, --out <dir>         pack: where to write the file
  -h, --help              Print help
