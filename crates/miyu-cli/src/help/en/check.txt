Usage: miyu check [file] [options]

Check the files written by hand: the system config, the project config here,
the secrets file, persona.toml and prompts/examples.md in each persona
directory, every preset and every package manifest. Each problem is printed
with its file, line, reason and fix; the exit code is 1 when there are
errors. Last comes the semantic model and the indexing progress of memories
and knowledge bases, which are not counted as problems.

With a file, only that file is checked.

Options:
      --format text|json  Output format (default: text)
  -h, --help              Print help

Examples:
  miyu check
  miyu check ~/.miyu/personas/miyu/prompts/examples.md
