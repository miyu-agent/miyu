Usage: miyu service <command> [<options>]

Manage the user service that starts the core at boot or login: a systemd
user service on Linux, or desktop autostart where there is none; launchd on
macOS; a logon task on Windows.

Commands:
  enable   Install and enable the service
  disable  Disable and remove the service
  status   Show whether the service is installed and enabled

The service runs this miyu, with MIYU_HOME if set. For a system-wide service
(a dedicated user, /var/lib/miyu), follow packaging/README.md in the
repository.

Options:
      --format <text|json>  Output format (default: text)
  -h, --help                Print help
