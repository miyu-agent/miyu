## 施工单 M-6：预设能关掉脚本调工具

状态：已合（2026-10-23）。经过：项目主人 2026-10-23 问「这应该是一个软件包形式吧？可开关的功能？」，照推荐定成基础系统里的一个功能；又问关了以后工具说明怎么办，答「组工具面时就不接那一段」；核心主会话同一天排在 Y-2 中上后面，要关了的会话逐字节回到完全没有它时的样子。设计 `39-脚本调工具.md` 第三节第 7 条、MC15；图纸 `presets.md`「怎么走」第 5 条、`policy.md` 的 `ToolEntry`、`session/tools.md`「1g」、`tools/shell.md`「脚本调工具」第 10 条。

### 目的

M-1 到 M-4 合了以后，脚本调工具对每个会话都开着：只要工具面上有 `shell` 和一件能在脚本里调的工具，`shell` 的说明就接上怎么用的那一段、system 带那一句，命令里能经 `miyu call` 调。人能关的只有个人设置里按工具的 `clicall.*`，要整个关掉得一件一件关，换个预设也跟不过去。极简开发的预设是「只给 shell 和读写文件，发挥模型原本的能力」，它不该带这一段。

### 做法

1. **基础系统多一个功能 `clicall`「脚本调工具」**（`resources/packages/basesystem/package.toml`）：没有工具，同「项目指令」。名字、说明三种语言，给人看，不发给模型。
2. **组工具面时照预设**（`Agents::face`）：功能关着的（`agents/clicall.rs` 的 `on`，`PresetFile::opens_in`；没有预设的照开），每一件的 `clicall` 都当假。后面的事都跟着这一格走，不另改：
   - `shell` 说明那一段只在有能调的工具时接（施工 M-4 的 `clicall::describe`），所以不接；
   - system 那一句照工具面算（`clicall::tells`），所以不带；
   - 内核的 `Session::clicall_tools` 是空的，执行器不开通道，命令里 `miyu call` 退出码 2。
   拼出来和一件都不能调的目录拼的一字不差，测试直接比两份工具面。
3. **出厂的三个预设不用改**：全部功能 `unlisted = "on"`，常规开发整个基础系统开着，所以开着；极简开发 `unlisted = "off"`、只写了 `files`、`commands`，所以关着。
4. **中途换预设**（`actor/persona/face.rs` 的 `refaced`）：以前就有的工具照旧快照里的原样（施工 P-2 下），只有 `clicall` 这一格照新的预设。这一格不发给模型，工具说明一字不变。关了的当场调不成，以前接上的那一段照旧留着，同施工 T-1 上关后台运行时 `shell` 留着 `run_in_background`；打开的要新会话才接上那一段。不这么做的话，换成关着的预设也关不掉内置的那几件，只关得掉 MCP、脚本工具（它们照现在的登记）。

### 给她看的字

中途关掉以后，以前接上的那一段还在，她照旧说明去调，撞上退出码 2。那一句原来是 `miyu call only works inside a command Miyu runs.`，她明明就在 Miyu 跑的命令里，会以为是自己用错了地方（核心主会话审时提的）。命令行那头分不出「不在 Miyu 里」和「这个会话关了」：两种都没有那两个环境变量。所以改成一句把两种都说到：`miyu call only works inside a command Miyu runs, in a session where scripts can call tools.`，13 个 token 变 22 个。这句只在出错时出现，不进前缀。登记簿换了指纹，`miyu call --help` 的中英两份也补上「预设开着」。

### 字节

关着的会话：工具数组、system 和完全没有脚本调工具时一字不差（`agents/tests.rs` 的 `switched_off_the_face_is_the_same_as_without_tools_from_scripts`，同一个目录、一份照预设关、一份每件都不能调，整份 `ToolEntry` 比；system 那一句照 `tells`）。开着的会话一字不变：`on` 只在预设关着时把 `clicall` 拿掉，原来的路不动，请求样本 `docs/designs/samples/requests/` 和 `miyu-assemble`、`miyu-kernel` 的样本测试照旧过。

### 不做

- 不另做软件包：没有工具、不能单独装卸，离了 `shell` 没有意义（MC15 未选 A）。
- 不按场所、按人格关：预设已经能按会话挑，个人设置的 `clicall.*` 还能按工具关。
- 前台脚本要人确认时停下来等，是下一步 M-7（重开 MC4）。

### 头

不用改：`preset.get` 的功能表本来就照清单列，网页的预设页、终端的设置多出一行「脚本调工具」。合了以后照规矩告诉两个头。
