## 施工单 SG-1：软件包设置分组

状态：施工中（2026-11-10）。项目主人经语音会话要的。

### 为什么

包的设置页是平铺的：miyu-say 选了 MiniMax，MiMo、OpenAI 的几项照样全摊着。清单早就能写 `[settings.<组>.<名字>]`（施工 9-1 再补），可组这一层没交给头，也没有「照某一项的值显示」的写法，头只能一股脑全画。

### 做什么

1. 清单：组那张表 `[settings.<组>]` 可写 `name`（语言表，写法同项的 `name`）、`shown_when = { "<这个包的一项>" = "<值>" }`（值也可以是几个的列表）。键写这个包自己清单里的名字，不写前缀。只能指一个 `option`、不在这一节里，值都要是它的选项；写错的清单读不成，报新的 `bad_shown_when`（三种语言的字）。写了 `name` 的表，底下还有别的子表才算一组，以前的写法不变（`packages.md`「配置项」第 1 条）。
2. `config.schema`：组里的项带 `section`（组名）；这个包那一组带 `sections`：`[{ "id", "name", "shown_when"?: {"key": "<完整的键>", "is": [...]} }]`，照清单写的先后，名字照连接的语言、没写的是组名，`is` 总是列表。没分组的包两格都不写，字节不变（`config.md`「协议」）。
3. 不画的节只是不画：值照旧存、读、查，核心哪里都不看 `shown_when`。
4. 文档：参考 `config`、作者 `manifest` 中英，蓝图 `packages.md`、`config.md`。

### 验收

- `miyu-config`（`settings/tests/section.rs`）：名字、一个值和几个值的 `shown_when` 读对；指的项不在、别的包的键、写全了前缀、不是选项、在这一节里、值不是选项、空列表、不是表、两项，都报 `bad_shown_when`、报在那一行；没分组的包没有节。先红：改之前写了名字的组当成缺 `type` 的一项。
- 集成（`tests/package_sections.rs`）：`config.schema` 里组里的项带 `section`、包那一组带 `sections`（中文名、退到英文、退到编号，键写全，一个值的也是列表）；没分组的包那一组和原来一样、项没有 `section`；不画的节照旧写得进、读得到。先红：改之前这个包的清单读不成。
- 本机门禁全过。改协议，合了告诉 UI 和 im。
