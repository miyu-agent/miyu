## 施工单 N-3 下：免 key 的网页抓取兜底

状态：2026-10-19 在做。设计 `36-联网搜索.md` 第二节第 1 条最后一行（网页抓取最后兜底）、第五节 N-3（照旧版的几家重新实测、挑还能用的；项目主人要求顺手优化）；图纸 `docs/blueprint/tools/web_search.md`。

### 实测（2026-10-19，本机，两条查询）

| 结果页 | 结果 |
|---|---|
| DuckDuckGo HTML 版 | 头两次各 10 条；连问几次以后弹人机验证（`anomaly.js`、`cc=botnet`），之后一阵都挡 |

### 做了什么

1. `search.json` 多两家来源（DuckDuckGo、Bing，免 key），排在没配置时的顺序最后；多一格 `browser_user_agent`。
2. `search/scrape.rs`：照 HTML 建树（`htmd` 底下的 html5ever，不再像旧版那样手写字符串扫描，页面小改版不容易坏），照 class 找结果；链接解包（DuckDuckGo 的 `uddg=`、Bing 的 `u=a1` + base64url）；Bing 的摘录不要链接里的字（「阅读更多」）；一条都没认出、页面上有人机验证记号的当限额（进冷却，正好避开 DuckDuckGo 的封锁）。
3. `sources.rs`：两家 `GET`、带浏览器的 `User-Agent`；Bing 照查询里有没有中日韩文字挑市场（`zh-CN`、`en-US`）。
4. 设置的下拉多两个选项；`miyu-net` 加依赖 `base64`（本来就在依赖图里）。
