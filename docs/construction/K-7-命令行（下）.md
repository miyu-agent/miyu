## 施工单 K-7 下：命令行 `miyu kb`

状态：已完成（2026-10-13 写、合；19 第六节列了命令行的几个子命令，项目主人 2026-10-13 定建库叫 `miyu kb new`、加文档照附件上传）。

### 目的

在 shell 里管知识库：列、搜、读、建、改、加、删、挂、重建，不用手动建目录、写 `kb.toml`。走 K-7 上的 `kb.*`，不另起一套，照 `miyu memory` 的样子做。

顺带补 K-7 上漏的一处：五种新的拒绝（`kb_exists`、`document_exists`、`kb_read_only`、`folder_unavailable`、`trash_failed`）没写给人看的话，头和命令行只看得到「已拒绝。」。

### 蓝图改哪几节

- 新的一页 `docs/blueprint/cli/kb.md`（照 `cli/memory.md` 的格式）。
- `cli/main.md`：子命令列表、帮助页一种语言几页。
- `knowledge.md`：「在哪」「守着它的」、施工步子 K-7 下。
- `protocol.md`：五种拒绝的话（拒绝那一张表）。

### 定了的

1. 子命令（不写子命令是 `list`）：

   | 子命令 | 做什么 | 发什么 |
   |---|---|---|
   | `list` | 列出知识库 | `kb.list` |
   | `search <词>` | 搜 | `kb.search`，`--kb` 只搜一个 |
   | `read <库> <文档>` | 读一篇的一页 | `kb.read`，`--page` |
   | `new <库>` | 建一个库 | `kb.create`，`--name`、`--description` |
   | `edit <库>` | 改名字、说明 | `kb.update`，`--name`、`--description`（至少写一个） |
   | `add <库> <文件>…` | 把文件加进库 | 每个文件 `blob.put`（照本机路径），再 `kb.add`；路径是文件名，`--to <目录>` 放进库里的那个目录；`--replace` 换掉已经有的 |
   | `remove <库> <文档>` | 删一篇（进回收站） | `kb.remove` |
   | `mount <库> <目录>` | 挂现成的目录 | `kb.mount`，相对路径照当前目录接成绝对的；`--name`、`--description` |
   | `delete <库>` | 删整个库（进回收站；挂进来的不碰你的目录） | `kb.delete` |
   | `reindex <库>` | 重建索引 | `kb.reindex` |

2. 删的都不问：进回收站，找得回来（同 `miyu memory` 清空不问，2026-10-07 项目主人定的那条）。
3. 印的照人要的，不搬存储结构（2026-10-08 项目主人定的设计原则）：
   - `list`：一个库一行，编号、名字（和编号一样的不写）、几篇、说明；用不了的接上为什么。
   - `search`：一块一段，头一行是库、文档、标题路径或第几页，下面是这一块的字。
   - `read`：那一页的字，不止一页的末尾说第几页。
   - 别的一句话说做成了。
4. `--format text|json`：`list`、`search` 的 `json` 原样印核心回的那一串，给脚本。
5. 被拒绝：照核心的原话印在标准错误上，退出码 1。`folder_unavailable`、`trash_failed` 的原话后面接上核心给的那一句为什么。
6. 五种拒绝的话：
   - `kb_exists`：知识库已经有了。
   - `document_exists`：这一篇已经有了。
   - `kb_read_only`：挂进来的知识库是只读的。
   - `folder_unavailable`：这个目录挂不上。
   - `trash_failed`：挪不进回收站。
   - 英文照同样的意思写。

### 不做什么

- 终端界面、网页的知识库页：两个头的会话做。
- 加文件夹（整个目录拷进库）：要整个目录的请挂。
- `add` 一次传多个时，碰到失败的那一个就停（前面成了的不回滚），说清哪个没成。
