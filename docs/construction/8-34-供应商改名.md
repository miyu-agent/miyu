## 施工单 8-34：供应商改名

状态：合了（2026-10-22）。终端会话转来（2026-10-22）项目主人的话：「不能改的是 id，只能在创建的时候改……最好是能改，方便一些。」终端在供应商页的编号上给入口。图纸 `docs/blueprint/models.md`、`docs/blueprint/config.md`、`docs/blueprint/protocol.md`。

### 开工前查清的（编号存在哪些地方）

- 配置：`[providers.<编号>]` 连同 `.compat`、`.models.<模型>[.price]` 子表，系统配置、个人设置两层都能写。
- 引用它的配置项：`models.chat`、`models.vision`（引用），`models.embedding`（模型或者 `local`、`off`），`memory.organizer`（引用），`pools.<池>.models`（模型的列表），都是 `<供应商>/<模型>`。照配置清单的类型找（同 `dangling.rs` 查悬空的那一套），不手写一张表。
- 密钥：名字和编号无关（`{ secret = "<名字>" }`），跟着表走，不用动。
- 会话钉的模型：`session.created`、`session.policy_changed` 的 `model`，日志只追加，改不了。
- 派生数据：`state/models/learned.json` 的键 `<供应商>/<模型>`，`state/models/providers/<编号>.json`。用量账本照日志重算，不动。

### 定的（技术题，主会话定）

1. **方法** `provider.rename {"from", "to"}`，只给人（同 `secret.set`）。`to` 照编号的写法（小写字母开头，小写字母、数字、`-`、`_`，最多 32 个，不是 Windows 的保留名），不合的 `bad_params`；`from` 和 `to` 一样的 `bad_params`。合出来的配置里没有 `from` 的 `unknown_provider`；已经有 `to` 的 `provider_exists`。
2. **两层各改各的文件**：哪一层有 `[providers.<from>]` 就在那一层改名（两层都有的两层都改：个人那一层是叠在系统那家上的，同一家）；两层里引用 `<from>/<模型>` 的都换成 `<to>/<模型>`。每一层照 `config.set` 的规矩写（重读、先写临时文件再替换、撞上手改重来、记日志、推 `config.changed`）。表头照 `toml_edit` 的可改文档改名（子表跟着走），引用照 `config.set` 那一套只换那一个值。先改个人设置、再改系统配置；后一层写不成的，前一层已经改了的不撤，回那一层的错（同 `persona.set` 几份里写到一半的规矩），再调一次照剩下的改（已经改过的那一层里没有 `from` 了，只换引用）。
3. **会话**：`state/models/renamed.json` 记 `{"<旧编号>": "<新编号>"}`，连着改的拉平（a→b 以后又 b→c，记成 a→c、b→c）；改回去的（b→a）删掉 a 那一条。每轮开始照钉着的引用解析不出、供应商在这张表里的，换成新编号再解析，解析出来的照「退回默认」那条路告诉内核（`Replaced`，内核记 `session.policy_changed`，`model` 是新的，`replaced` 是旧的），记一行 `INFO model renamed`；换了也解析不出的照旧退回 `models.chat`。以后又有人建了旧编号的，照新建的那家算，表不看。
4. **派生数据**：`learned.json` 里 `<from>/` 开头的键换成 `<to>/`；`providers/<from>.json` 改名成 `<to>.json`（已经有的先删）。都在核心手里那一份上改，写盘照旧。
5. **开着的会话下一轮起照新编号**：第 3 条在回合开始时做，不用通知会话。

### 做了什么

- `miyu-config`：`rename::rename_table`（`toml_edit` 的可改文档换表名，`toml_edit` 多开 `display`）、`rename::retargeted`（照清单的类型找指着旧编号的项）。
- `miyu-models`：`Learned::rename_provider`、`Renamed`（`renamed.json`）。
- `miyu-session`：`Observed` 多 `renamed`，`ModelData::renamed`、`rename_provider`（`route/shared/renamed.rs`）；回合开始解析不出的先照改名换（`route/turn.rs`）。
- `miyu-endpoint`：`provider.rename`（`providers/rename.rs`），拒绝 `provider_exists`，只给人。
- 测试：`miyu-config` 三条、`miyu-models` 一条、`route_turn` 一条、端点 `provider_rename` 一条。变异 8 条全杀。
