## 施工单 F-8 六补修：她装包撞了名，工具结果说清撞了什么

状态：已合（2026-10-15，3a0f234e，CI run 38670542323）。终端的会话在通知 F-8 六补时发现：她用 `package` 工具装包撞了名，工具结果只给原因代码 `package_conflict`，她不知道撞了什么、改不了自己的包。

### 做了什么

1. 包的端口带上 `data.conflicts`（`PackageConflict`：哪一样、名字、包）。
2. `package` 装包、`packages` 看包文件夹撞了名的，照命令行那样写：`conflict.txt` 一行说装不上，`conflict-line.txt` 一处一行「- skill notes (in zkit)」。两句新字登记进 26 第十节和 `prompts.md`（14、8 个 token，照 o200k 量）。
