## 施工单 D-5 补：展示认音视频

状态：主会话做。网页的会话 2026-10-23 报，项目主人指出：她用 `show` 展示的 mp4、mp3 在网页上只能下载。

### 为什么

`show/kind.rs` 只认图片、PDF、svg、HTML、Markdown、UTF-8 文本，音视频落到 `application/octet-stream`，头只能当文件给下载。

### 做了什么

- `show/kind/media.rs`：照前 64 字节的文件头认浏览器放得了的七种（`video/mp4`、`video/webm`、`audio/mpeg`、`audio/flac`、`audio/wav`、`audio/mp4`、`audio/ogg`），排在 PDF 后面；文件头认不出的二进制再照后缀认。QuickTime、Matroska、AAC 的 ADTS 不认，照别的文件。
- `show` 的说明第一句写上视频、音频（2026-10-23 项目主人照推荐定：先改说明再实测，她不主动用 `show` 再在 system 加一句）：tools 数组变一次，计划内断一次缓存；按 o200k 估多 4 个 token。登记簿换指纹，`prompts.md` 重新生成。
- 图纸 `tools/show.md`「怎么走」第 4 条和说明的样本。

### 不做的

- `mov`、`mkv`：浏览器多半放不了。
- 终端怎么画音视频归终端的会话。

### 验收

1. `crates/miyu-basesystem/src/show/kind/tests.rs`：七种照文件头认得出；QuickTime、Matroska、ADTS 不认；认不出的二进制照后缀；文本照旧是文本。
2. `cargo xtask check` 全过。
3. 网页：她 `show` 一个 mp4、一个 mp3，正文里出播放器，不是下载。
4. 实测（合了以后，真模型）：画了图、下了视频、写了网页（HTML）、生成了文件这几种场景，看她会不会主动用 `show`；不会的再开一步在 system 加一句。
