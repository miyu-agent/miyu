## 施工单 X-12 上：脚本——读开头、找、怎么跑

状态：合了（a6634383，三台 CI run 1914；2026-10-12 主会话）。图纸 `docs/blueprint/skills.md`「脚本」第 1 到 3 条、「定了的」第 3、4 条。

### 目的

脚本当工具的底子：读开头注释、从包和家目录里找、一个脚本当一件工具跑起来。登记进工具目录、开关是 X-12 中，预算和 `miyu check` 是 X-12 下。

### 做了什么

1. **读开头**（`miyu-policy` 的 `script.rs`，纯逻辑）：照旧版的写法。文件开头连成一段的注释（`#`、`//`，第一行的 `#!` 也算在里面、没有键）是开头。认 `Description`（给模型，必须有）、`Display name`、`显示名称`、`描述`（给人）、`Timeout`（秒，没写的 60）、`Parameters`（下面几行拼成一份 JSON 为止，顶层得是对象）；冒号全角、半角都行；`Id`、`Group`、`Trust`、`Permission`、编码声明这些旧版留着的认、不用。工具名照文件名：去掉最后一个扩展名，不合 `[A-Za-z0-9_-]` 的换成 `_`，最多 64 个字。拿旧版出厂的几个脚本的开头对过。
2. **找**（`miyu-store` 的 `scripts.rs`）：先找属主家目录 `home/<账号>/scripts/`，再照包的编号找装了的包的 `scripts/`；同一个工具名先找到的赢；子文件夹、点开头的不算；不是字的、读不了的、开头写错的跳过、说为什么。
3. **一个脚本一件工具**（`miyu-basesystem` 的 `shell/script.rs`）：访问类别是执行，照跑命令的规矩进沙盒、问人（`Call.sandbox`）。
   - 照 `#!` 起：Unix 上照写的起；Windows 上取解释器的名字（`env` 的取它后面那个，`python3` 换成 `python`），没有 `#!` 的照扩展名（`.py`、`.ps1`、`.js`、`.cmd`/`.bat`）。
   - 参数是她给的那份 JSON，交给 `MIYU_ARGS_JSON`，也写进标准输入（同旧版）；工作目录是这一轮的；缓存目录 `MIYU_SCRIPT_CACHE_DIR` 在系统临时目录下 `miyu-scripts/<工具名>`；`PYTHONUTF8=1`；别的环境变量照 `shell` 的白名单。
   - 起进程、看门（核心崩了跟着没）、截输出、跑完了的几句（没有输出、退出码、信号、截断）和 `shell` 同一套：脚本放在 `shell` 的子模块里，直接用兄弟模块的东西，不往外开口子；起进程那一步多了「标准输入接一份字」，`shell` 照旧接空的。
   - 另两句（`software/basesystem/script/`）：到时整组杀掉（15 token）、起不来（18 token），登记。

### 定了的（主会话，技术题照推荐）

- **脚本工具放进 `miyu-basesystem`、挂在 `shell` 下面**：起进程那一套（进程组、看门、Windows 的杀进程树、输出解码和截断）是现成的、私有的，另开一个 crate 要么照抄、要么把它们公开出去，都比挂在下面差。
- **缓存目录放系统临时目录**：数据根在沙盒里是藏起来的；工作区那一级的沙盒本来就能写临时目录。只读那一级哪儿都写不了，照旧。
- **不用 `Id` 当工具名**：图纸写的是照文件名；旧版脚本的 `Id` 都和文件名一样。

### 验收

- 读开头：旧版的写法（全角、半角冒号，多行参数，认、不用的键，`//` 注释，`\r\n`）读得出；没写参数的当没有参数；写错的五种各说哪里不对；文件名换成工具名。
- 找：包里的、家目录的、同名、读坏了的清单、点开头的、子文件夹、不是字的、开头写错的。
- 怎么起：Unix、Windows 两种找法（纯函数，Linux 上也测 Windows 的）。
- 真跑：Python 脚本三个平台都跑，参数从环境变量、标准输入都拿得到、中文照原样、缓存目录和工作目录对；Unix 上退出码不是 0 的出错、到时整组杀掉、解释器不在的说起不来。
- 变异 11 个：10 个报红；「不跳 `#!` 那一行」活下来，查下来那一段本来就多余（那一行也是 `#` 开头、没有键），删了；`cargo xtask check` 八项；三台 CI。
