## 施工单 R-5 七补：内置语义模型换成 granite

状态：已完成（2026-10-18 写、施工、自己验收；提交 87283021，本机门禁八项，三台机器的 CI 和长跑全绿，run 39142773999；中间两次红在别的会话的测试上，修了以后重跑）。项目主人 2026-10-18 定：检索都用关键词加向量的混合，内置语义模型换成 granite-embedding-97m-multilingual-r2 的 4 位量化（计算精度 `accuracy_level=4`），照 R-5 三补放进可选的小程序包 `embed`、模型文件打进包里、出厂不装。第一步（R-5 六补）让小程序会切它的字节级 BPE；这一步换包、换出厂清单，把照模型的三个门槛给 granite 量好。剩下的是技术细节，照施工方案第一节第 1 条直接做。

### 目的

装了内置语义模型的人用上 granite：多语种、乱带的少、知识库找得准；联想、知识库的门槛照它量过，换上当天就照常工作。

### 定了的（技术细节）

1. **模型文件**：官方 revision `835ad140` 的 fp32 照 `tools/quantize_q4.py` 量化（MatMul 和词嵌入的 Gather 都是 4 位，一块 32 个、对称，激活 8 位整数算），61 MB，可逐字节重现；词表、合并照 `tools/bpe_files.py` 转。Release `models-granite-embedding-97m-multilingual-r2`（预发布，不标最新）：三个文件、Apache-2.0 的 `LICENSE`、写明来源和改动的 `NOTICE`、`SHA256SUMS`。
2. **出厂清单**换成 granite：`dims` 384、`[tokenizer]` 是 `bpe`、三个文件。bge 存下的向量照旧留着，换了模型照新的编号补（`recall.md` 第三条第 1 款）；门槛表里 bge 那一行也留着（还装着旧包的照旧用）。
3. **三个门槛**照原来定 bge 的判法在两份测评集上量，真数据（主人的旧记忆，仓库外）对一遍：记忆联想 0.85、知识库自动想起 0.86、知识库搜的下限 0.82。granite 的相似度整体高一截，不能照搬 bge 的数。
4. **记忆搜的下限不动**：现在照 bge 量的 0.40 是写死的常数，对 bge 只滤掉问句前 20 条里最低的 1.8%，对 granite 是 0%，行为几乎一样；它照模型、和合并的权重一起在混合重调那一步定。
5. **测试**：出厂清单那一条照 granite 写；真模型的对照（`real.json`）换成 granite 算的六句（含英文、日文），`make_bpe.py` 生成；用真模型的几个量尺照出厂清单取模型编号和文件，不再写死 bge。

### 施工结果（2026-10-18）

1. **量化可重现**：照 `quantize_q4.py` 重新量出来的和十月十八日测的那一份逐字节一样（SHA-256 `66dfce3a…`）；fp32 原件、`tokenizer.json` 的 SHA-256 和 Hugging Face 上 revision `835ad140` 的一样。Release 建好、下载回来六个文件 `SHA256SUMS` 全对。
2. **门槛**（详见两份 `eval.md`）：
   - 记忆联想：测评集上 0.84 平常的话带一句，0.85 起不带；0.85 带对的回合 64%（bge 0.60 是 45%）。真数据上 0.85 乱带 19%（bge 40%）、带了的里该带的 44%（bge 37%）、带对了 28%（bge 32%）。
   - 知识库自动想起：0.86 带的 89% 对、88% 的回合想起了，平常的话一句不带（bge 0.60 是 94%、88%）。
   - 知识库搜的下限：0.82 平常的话搜得出东西的和只走关键词一样六句，一个字都对不上的四句留三句（0.818 那一句挡掉）；0.81 多一句平常的话。
3. **测评集**：关键词加 granite 的 recall@5 84%（bge 81%），跨语言 60%（bge 20%）；换了说法的 hit@1 只有 8%（bge 42%），合并时向量那一路排得不分明，记进下一步。
4. **真核心冷启动**：刚起来就搜，第一次算出问句（核对三个文件 67 MB、拉起、算一句）285 到 290 毫秒，磁盘缓存冷的时候 541 毫秒（bge 是 70 毫秒上下）；八句问答两路合并全对（只走关键词四句）；补一百条 1.2 到 1.9 秒。
5. **蓝图里一处旧写法**：`recall.md` 原来写模型清单在「清单旁边的同名目录」里，F-8 上起包的文件就在包文件夹里，照改（拼验收用的包时照旧写法放错了，核心判成用不了，两个头的引导页那一步被跳过，查出来的）。
