## CL 命令行文案

状态：施工中（2026-10-29 开工）。

### 目的

`miyu` 印给人看的字全照设计 47 改：报错 `miyu: ` 打头、建议 `hint:` 另起一行、帮助页用动宾短语、统一用语，再加一道检查挡住写回去。项目主人 10-29 同意设计 47 第六节四条推荐：半角前缀、照 GNU 分级、总表不列子动作、不用「她」。

### 分步

| 步 | 做什么 |

| CL-1 | 设计 47 定稿（这一份和设计一起提交） |

### 蓝图改哪几节

- `docs/blueprint/cli/main.md`「参数写错时」、帮助页那一节，`cli/*.md` 里抄着帮助页、报错原文的地方，照改。
- 新加 `diagnostic.rs` 一行进 `cli/main.md`「在哪」。

### 不做什么

- 核心拒绝时的那句话（`仅主人可用。` 一类）的正文不改，命令行只给它加 `miyu: `、去句号（设计 47 第五节）。
- 终端界面、网页的界面字，给模型看的字。
- 退出码不变。

### 验收

- 每一步：本机门禁全过；改过的报错、帮助页的测试、样本照新写法；中英各挑几处在真终端里敲一遍看样子。
- CL-3 的检查退掉改动（写回一句带句号的报错）报红。

### 风险

- 测试里断言原话的地方多：照编译、测试报的一处处改，不批量替换。
- `miyu pkg install tui` 这类提示要等打包把终端放进软件源以后才跑得通：提示照设计写，打包那一步对齐。
