## 施工单 H-2：会话在项目里

状态：在做（2026-10-19 主会话）。设计 `38-项目.md` 第一节第 2、3 条、第二节第 2、4 条、第三节。

### 这一步做什么

1. 内核：`session.meta_changed` 多 `project`（项目编号，空的是移出来，同标题），`SetMeta` 命令多这一格，会话照日志算现在在哪个项目（`Session::project`，H-3 拼附加提示词用）。
2. 会话列表的索引多一列 `project`（版本 7：对不上的删了照日志重建），`session.list` 的一项、`sessions` 流多 `project`。
3. `session.set_meta` 多 `project`（`null` 移出来）：项目要在（`unknown_project`），会话要是本机的主会话（场所会话、子代理、分叉出来的都不是：分叉出来的也有父会话；不是的 `bad_params`，`data.field` 是 `project`）。
4. `session.create` 多 `project`：没写的人格、预设照项目的，建好了再记一条移进去，`events` 是 `[1, 2]`。
5. `project.delete` 先把里面的会话一个个移出来，回 `{"moved": N}`。

### 定了的（主会话）

- 事件里移出来记成空字符串，不是设计初稿写的 `null`：和标题「写空的是去掉」同一个写法，内核的命令和状态都是一个字符串；协议上照旧写 `null`（设计跟着改了）。
- 置顶不跟着项目变：拖进项目时取消置顶是界面的规矩，头另发 `pinned: false`。
- 建会话时移进项目用另一个命令编号（请求编号接 `/project`）：建会话那一条已经用了原来的。
