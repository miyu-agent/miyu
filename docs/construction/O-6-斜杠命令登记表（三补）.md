## 施工单 O-6 三补：斜杠命令改成登记表

状态：合了（2026-10-15，2b0bea87，CI run 38627618596）。`command.run`、`command.catalog` 认的是一张写死的枚举，名字、别名、跟不跟字、谁能用、怎么执行、回执的键都在中心一处；记忆想加一条清掉这个会话记忆的命令，就得改中心（记忆的会话 2026-10-14 提，项目主人看了认为是设计缺陷）。

### 这一步做什么

1. `commands/registry.rs`：一条命令一个 `Slash`（名字、别名、`summary` 和 `argument` 的字键、在不在后台答、身份以外谁能用、怎么执行），登记进 `Commands`，照名字排。`Core` 起来时登记好内置的。
2. 各自在管它的模块里写：核心自己的 `/clear`、`/stop`、`/workspace`（`commands/basic.rs`），记忆的 `/remember`、`/dream`（`memory/slash.rs`），长期目标的 `/goal`（`commands/goal.rs`）。
3. `command.run` 照登记表认、先判身份再问命令自己能不能用、执行、记 `command.ran`、写回执；`command.catalog` 照登记表列；在不在后台答照命令自己的 `later`。协议的形状不变，两个头不用改。
4. 名字和别名在同一个名字空间里，撞了是内置命令写错了，登记时就 `panic`。别名不一样的不算撞：`/reset-memory` 和 `/reset` 是两个词。
5. 图纸 `protocol.md` 的 `command.run` 第 11 条、「还没有的」一条。

### 定了的（主会话，技术题照推荐）

- 登记表放在 `miyu-endpoint` 里，内置模块照「加东西只登记，不改中心」各自登记；装配在 `commands::builtin` 一处。
- 扩展包能不能在清单里声明斜杠命令、命令怎么交给包的程序执行：留口子，等项目主人定。

### 验收

- 新测试：内置六条照名字排、别名找得到；名字撞别名、别名撞名字登记时就拦；`/clear-memory`（别名 `/reset-memory`）和 `/clear`、`/reset` 不撞。认命令、只有 `/dream` 在后台答。原来的协议测试一字没改，照样过。
- 手写变异：去掉撞名检查报红；去掉命令自己的「谁能用」，6 条集成测试报红。
- `cargo xtask check` 八项；三台 CI（run 38627618596）。
