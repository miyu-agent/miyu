## 施工单 X-39：MCP 服务的说明和提示词

状态：主会话审过（2026-10-21），审时的意见都写进下面了：说明只跟工具面一起变；外壳的结束标签防伪造；`assistant` 的照原文并进来；上限照 `APPEND_MAX` 的单位；斜杠名的形状照两个头认的定死。项目主人 2026-10-21 定重开「MCP 补齐 instructions、prompts」：`mcp.md`「先不接」那一条里的这两样拿出来做，资源（`resources/*`）、Tasks、MCP Apps、浏览器登录照旧不做。两处各一个提交（AGENTS.md「施工的规矩」第 2 条）。不碰路径、子进程、终端、Windows 特有的东西；改了提示词的组装，照 `26-提示词.md` 第十节登记新字。

### 为什么

- **说明**（`instructions`）：服务在握手、探的回应里交一段给模型看的说明，写它的工具什么时候用、怎么配合。适配器两个时代都已经读下来了（`Client::instructions`），核心没用。工具改成先加载以后（设计 25 W9，L-3 起默认），她只看得到工具名和一句说明，服务的说明正好告诉她什么时候去拿这个服务的工具（Claude Code 照这个理由在会话开头放服务的说明，每个截到 4096 个字）。
- **提示词**（`prompts/*`）：规范里给人选的模板（「user-controlled」，规范举的例子就是斜杠命令）。Claude Code 列成 `/<服务名>:<提示词名> (MCP)`，参数照空白切开、照声明的先后对上，取回来的直接进对话。Miyu 已经有模板命令（`slash.md`），MCP 的提示词是同一样东西换了来处。

### 之一：说明照扩展放在 system 尾部的那几段走（X-20）

1. **从哪来**：连上以后客户端交的 `instructions`（新时代在 `server/discover` 的回应里，旧时代在 `initialize` 的回应里），空白的当没有。写进目录缓存 `state/mcp/<服务名>.json`（同工具，多一格），照缓存先登记的那一回也有：会话照缓存先有工具，说明跟着工具走。
2. **放在哪**：不另开一块，照扩展经 `system.append` 放在 system 尾部的那几段（施工 X-20，`26-提示词.md` 第四节第 8 块，`miyu_session::appended`）：每个服务一段，键是 `mcp:<服务名>`（包的编号里没有 `:`，撞不上扩展的；服务名只有小写字母、数字、`-`，工具名的开头 `mcp__<服务名>__` 认得出是哪个服务）。那一段是核心的外壳（登记进 `26` 第十节，`core/mcp/instructions.txt`：一对标签，开头的带服务名）包着服务的原文（第三方的字不登记，同技能的说明、MCP 工具的说明）。原文不转义（它就是说明），但不许伪造出标签外的东西：截短以后，原文里出现外壳结束标签的，那一处的 `<` 写成 `\u003c`（同技能列表的转义写法），别的照原样。X-20 的扩展自己写外壳，核心不替它防；这里外壳是核心的，核心防。
3. **给谁**：同 X-20 照这一刻的工具面挑：工具面上有这个服务的工具（先加载的那种也算）才带；预设关了这个服务、不给这种会话的，工具不在面上，说明也不带。`appended::resolve` 认工具归哪一段时，`mcp__` 开头的照服务认，别的照包认。
4. **多长**：原文照 X-20 的上限 `APPEND_MAX` 截：4000 个字符（Rust 的 `char`，即 Unicode 码位，`system.append` 照 `chars().count()` 查的同一个数；Claude Code 是 4096），超了的截掉后面，不另加说明。
5. **什么时候换**：造会话时钉进快照。之后只跟工具面一起变：appended 在 system 里，变了整个前缀的缓存都断，所以某一轮工具面变了（服务后来才起来、它的工具这一轮第一次上工具面；服务关了、工具下了面）才照这一刻的说明换；工具面没变的一轮照快照里钉的，服务升级换了说明原文也不读。扩展经 `system.append` 放的照 X-20 原来的规矩（下一轮换上），不受这一条管。

（草稿里原来是另开一块、钉下不变；改成走 X-20：机制现成、审过，键、上限、照工具面挑、中途换都有了，核心不多一块。）

### 之二：提示词当斜杠命令

1. **列**：服务的本事里写了 `prompts` 的，列完工具接着 `prompts/list`（照 `nextCursor` 翻页，同工具；新时代带 `ttlMs` 的照工具那样过期了用到时再列，旧时代收 `notifications/prompts/list_changed` 再列：适配器把它和工具变了数成同一个，变了两样都再列）。不写进目录缓存：服务不在时提示词也用不了，菜单里不列。没有名字、参数没有名字的那一项不收（适配器那一层，名字照原样交上来）。
2. **名字**：`<服务名>:<提示词名>`，恰好一个 `:`（两个头的斜杠菜单照这个形状认：字母打头，字母、数字、`-`、`_`，中间一个 `:`；网页 cmd-colon 407deb1、终端同）。服务名本来就合；提示词名照工具名的办法清理：不合 `[A-Za-z0-9_-]` 的字（空白、斜杠、`:` 都算）换成 `_`，整个名字超过 64 个字符的截到 64 个（同工具名）。清理以后撞了同一个服务前面的那个的不登记，记进看管那一格的 `skipped`（X-37），`{"prompt": <原名>, "why": "name_taken"}`，`miyu check` 的 `mcp_tool_skipped` 一并说（提示词写成 `/<原名>`）。取的时候照原名问服务。不另认 `mcp__<服务>__<提示词>` 的写法：一样东西一个名字。
3. **菜单**：`command.catalog` 里排在模板后面、照名字排，一项 `{"name", "aliases": [], "summary", "argument"?}`：`summary` 照服务写的 `title`，没有的照 `description`，都没有的空着（服务的字不分语言）；`argument` 照声明的参数拼：必填的 `<名字>`、可选的 `[名字]`。只列这个会话（不写会话的照管理员）用得上的：服务在跑、列过了、预设开着、给这种会话。
4. **跑**：`command.run` 名字里有 `:` 的照这一条：找会话、认说话的人、判身份（同模板，`may_run`）、看预设和会话种类、找服务和提示词；参数照空白切开，照声明的先后一个一个对上，最后一个参数拿剩下的整段（只有一个参数的拿全部，比 Claude Code 一个参数一个词顺手）；没声明参数、人又跟了字的，照模板的规矩接在末尾。必填的没给的拒，说缺哪几个。`prompts/get` 照服务的 `timeout_ms` 等。
5. **取回来的**：`messages` 照先后并成这个人说的一句：`text` 照原文；`image` 存进会话属主的 blob、成图片块（同工具结果）；带文字的 `resource` 照文字；`resource_link` 写一行名字和链接；`audio`、二进制的 `resource` 照 `core/mcp/not-shown.txt` 写一行（同工具结果）。`assistant` 的那几条照原文并进来，前面不另加标记（会丢掉谁说的，Claude Code 也是这么并的）：Miyu 的模板命令只进人说的一句，不往历史里插她说的话。合起来是空的照内核拒 `empty_message`。之后同模板：`message.user` 带 `command: {"name", "text"}`，时间线上是人敲的那一行，展开的记在事件里（`slash.md`「模板」第 4 到 7 条）。
6. **出错**：服务不在跑、没列出这个提示词的 `command_unavailable`；服务回错（`-32602` 名字不对、缺参数这类）、回 `input_required`、超时的 `command_failed`，`said` 照原话。
7. **开关**：不另设功能，跟着服务的 `mcp-<服务名>` 走；`preset.get` 不另列。

### 不做什么

- 资源（`resources/*`、`@` 引用）、`completion/complete` 补全参数、Tasks、MCP Apps、浏览器登录：照旧不接。
- 提示词不进目录缓存、不在服务不在时列出来。

### 蓝图、文档改哪几处

- `mcp.md`：「怎么走」加两条（说明、提示词），「先不接」那一条去掉这两样，「守着它的」加测试；`slash.md`「是什么」加第三种（MCP 的提示词）、菜单和 `command.run` 的规矩。
- `26-提示词.md` 第四节第 8 块补一句（MCP 服务的说明也走这里）、第十节登记外壳；协议参考 `commands`（中英）的 `command.catalog`、`command.run`；作者文档 `mcp`（中英）一节「服务的说明和提示词」。

### 风险

- 说明是第三方的字、进 system：同技能的说明、MCP 工具的说明，她装了什么就看到什么；截到 4000 个字挡住太长的。
- 提示词的名字里有 `:`：头的命令补全照 `command.catalog` 的名字走，不另解析；两个头先确认 `:` 在输入框里不另作他用。
