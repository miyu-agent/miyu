## 施工单 TL-1：偏好思考语言

状态：搁置（项目主人 2026-10-26）。主会话派的（2026-10-26）：设置里加一个思考语言，先实测给模型看的字该怎么写、有没有用，再定做不做。图纸 `26-提示词.md` 第十节、`AGENTS.md`「给模型看的字克制、有账」。

### 为什么

回复语言（施工 P-9 补）只管她回的话。思考段（`reasoning_content`）的语言另有习惯：Miyu 的 system 是英文的，有的模型照它用英文想，人用中文问也一样，想看思考过程的人读起来费劲。

### 实测怎么做的（2026-10-26）

- 前缀照真核心：沙箱数据根上 `miyu ask` 录下第一轮的整个请求体（system 里有「关于你」、核心的几行、技能；人这边有事实块；带 24 个工具），称呼、更多描述、回复语言（简体中文）都填了。每种写法只改一处，换上测试题直接发给端点，不经核心，所以一种写法不用一个数据根。
- 两个场景，各 6 道题（查端口、Rust 借用报错、HashMap 和 BTreeMap、算时间、一行 shell、git 报错）：
  - Z：人用英文问，想让她用中文想；
  - E：人用中文问，想让她用英文想。
- 每格 12 次（6 道题各两遍，有几格补到 18、24 次）。
- 数思考段里目标语言的占比：去掉代码和路径，汉字一个字算一个，英文一个词算一个。占比 ≥80% 算「跟了」。
- 另看回复还是不是中文：所有写法都没把回复带偏。
- token 照同一道题比基线多出的 `prompt_tokens` 算，是 DeepSeek 的分词。
- 模型：
  - 用了 `deepseek-v4.1-flash` 和 `nemotron-3.5-super-vl`（NVIDIA 的推理模型）。
  - 第三家 `solar-mini4` 带上工具就不交思考段，没法数。
  - Claude、GPT 没测成：测试端点上 Claude 那一路余额用完了、另两路 key 过期，GPT 那一路账号被风控了。渠道恢复后用同一套测具补跑。

### 写法

| 编号 | 写在哪 | 原文（目标中文时） |
|---|---|---|
| 0 | 不加（基线） | — |
| A | `<user>` 里单独一行 | `preferred_thinking_language: 简体中文` |
| B | 并进回复语言那一行 | `preferred_reply_language: 简体中文 (thinking: 简体中文)` |
| C | system，`</user>` 后面一句英文 | `Think in 简体中文.` |
| D | 事实块 `<env>` 多一个属性 | `thinking_language="简体中文"` |
| S | system，`</user>` 后面一句英文，说得更死 | `Write your thinking in 简体中文, whatever language the user writes in.` |
| Q | system，`</user>` 后面一句中文 | `用中文思考。` |
| T | 人这句话后面，S 的原文 | 同 S |
| R | 人这句话后面，Q 的原文 | 同 Q |

T、R 是为了看位置到底有多大用：每轮都要再写一遍，不是能直接上的形状。

### 看出来的

1. 每个模型的思考语言自己有一套：
   - DeepSeek 在这套英文 system 下几乎总用英文想，人用中文问也一样（89%）。
   - nemotron 大体跟着人这句话的语言走，有一半时候跟回复语言。
2. 往「关于你」里写一行（A、B），或者放进环境块（D），两家都不认。
   - A 在 nemotron 上反而更少（41% 对 43%）：它把这一行当成关于人的资料，不是要它做什么。
3. 写成一句指令才有用，而且只对听话的模型有用：
   - nemotron 上，system 里一句从 43% 提到 65%～76%；放在人这句话后面到 92%。
   - DeepSeek 用中文写最多到 33%。它的思考段里写着 "They want me to think in Chinese (用中文思考)"，接着照样用英文想：它读懂了，只是不改。
   - 往它本来就用的语言拉（DeepSeek 想英文、nemotron 想中文）不用加。
4. 中文写的那句（Q）比英文的（C）短一半：4～6 对 6～8 个 token。nemotron 上两句差不多（72% 对 65%）。

技术上能做的形状：只在填了的时候往 system 里 `</user>` 后面接一句。这一句跟着会话快照走，新会话生效，前缀稳定，和回复语言那一行一样；没填的会话一字不变。每轮写在人这句话后面效果最好，可是每轮多几个 token，而且是往人这边的话里塞指令，不推荐。

1. 做不做：
   - （推荐）先不做，等 Claude、GPT 补测完再定。现在两家里有一家（DeepSeek，开发端点默认的模型）怎么写都拉不动，加上去等于对它白给 token。
   - 现在就做，用 S（system 里那句说得更死的英文，13～17 token）：DeepSeek 3/12、nemotron 13/18，是 system 里两家都最好的一句。
   - 现在就做，用 Q（`用中文思考。` 这种，按语言写原文，4～6 token）：nemotron 8/12，DeepSeek 0/12。
2. 如果做：

   - 默认空：不拼，不跟着回复语言走。数据上，跟回复语言走对 DeepSeek 没用，对 nemotron 是它本来就有一半时候在做的事。
