## 施工单 X-14 上：斜杠命令模板

状态：已合（2026-10-15，5feb5094，CI run 38668788358）。项目主人 10-15 定了包的斜杠命令两种都要（交给程序办的、展开成一段话发给 AI 的），谁能用、撞名、时间线怎么显示也定了（图纸 `docs/blueprint/slash.md`「已经定了的」七条）。这一步做展开成一段话的那一种。

### 做了什么

1. 照 Claude Code 的 custom slash commands：包的 `commands/<名字>.md`、自己放的 `home/<账号>/commands/<名字>.md`。开头可有可无（`description`、`argument-hint`，中文日文的说明在 `metadata` 的 `summary_zh`、`summary_ja`）；正文里 `$ARGUMENTS`、`$ARGUMENTS[N]` 换成参数，没写记号又跟了字的空一行接在末尾，不加标签（给模型的字非必要不加）；`$1`、`` !`命令` ``、`@文件` 不认。
2. `command.run` 登记表里没有的名字照模板认：先找会话、认说话的人，再找模板（认不出的照旧 `unknown_command`，群里的桥照它把 `/xxx` 当平常的话记下），再判身份（同内置那一关），再看预设（每条一个功能 `command-<名字>`）。展开的那段当这个人说的一句发出去（同 `session.send`，不插话）；回应 `said` 是空的，不记 `command.ran`。
3. `message.user` 多一格 `command {name, text}`：模型看展开的那段，时间线、撤销的回执、会话列表的预览照人敲的那一行。重做照原样的带着它，换了字的不带。
4. `command.catalog` 照名字和内置的排在一起，`preset.get` 每条列一个功能。内置的赢，自己放的盖住包里的，出厂的包先于家目录。

### 验收

- 内核 4 条、模板读写 6 条、找模板 5 条、视图 1 条、真核心 8 条（含场所会话那一关、认不出的照旧 `unknown_command`）。
- 门禁第一趟红在接入QQ 的 `slash_commands_in_a_group_answer_in_the_group`：先判身份再找模板，群里普通成员打 `/xxx` 从「认不出」变成「不能用」，桥不再把它当平常的话记下；改成先认再判身份，补了一条测试守着。
- 手写变异 18 个全抓住。
