## 施工单 DOC-20：文档的写法定成规矩，面向用户的文档照它改写一遍

状态：待验收（2026-11-19）。项目主人定：写文档这件事要有规范；现在的文档除了他手写的仓库首页和快速上手，都太口语化，面向用户的必须修正，内部文档这一回不修正。规范照他手写的两份和 Shorin ArchLinux Guide 的写法定，记进仓库的 `AGENTS.md`。同一天又定：文档页里不放指到另一种语言的链接，语言在仓库首页选好了。

### 改了什么

- `AGENTS.md` 加「文档的规矩」一节：文档放在哪、照谁的写法、一段怎么组织、句子怎么写、常用的说法、不要的写法、格式、内容、署名和项目主人写的内容。草稿和一段样稿先给项目主人看过，第三版认可。
- `docs/zh/`、`docs/en/` 下 36 页（中英各一份，快速上手是项目主人写的，不改）照规范逐页改写：
  - 省略成分的短句（「……的，……」「照……」「没……的」「不动」）写成完整的陈述句；每节开头补一句交代这一节做什么；命令前面有引出的话，后面说会看到什么。
  - 界面文字、选项、按键、程序输出从「」换成反引号，里面的字不变。
  - 口语的小标题换成名词或动宾短语（「装好了没有」→「确认安装成功」「出了问题」→「排查问题」）。标题只改字，个数、先后、层级不变；指到这些标题的 63 处链接照先后配对换成新锚点。
  - 用户手册里的内部说法「头」换成「界面」或具体的名字（配置键全表「生效」一列的「头重启后」→「界面重启后」）；开发者文档里留着，每页第一次出现时解释一句。
  - 「别的」统一成「其他」，「干活」「跑完」「照旧」这几个口语词换掉。
- 每页开头指到另一种语言的那一句（「英文版：…」「Chinese version: …」）去掉，74 处，连快速上手页头当初加的那一行。
- 改写时回程序里核对出的错处一并改正：
  - 命令行页：卸载软件包时删的只有状态，配置目录和配置文件里它的设置项留着，`--purge` 才一起删（原来写成「设置和状态一起删」）。
  - 配置键全表：自带资料里写了额度接口的有 OpenCode Go 和 DeepSeek（原来写只有 OpenCode Go）。
  - 系统托盘页：停核心最多等 70 秒（原来一处写一分钟、一处写 70 秒）；「不启动核心」那一句说清楚指的是为显示状态而连接的时候。
  - 开发者文档目录页：Apache-2.0 管的是 `reference/`、`authors/`（原来把 `dev/`、`guide/` 也写进去了，和蓝图 `licenses.md` 对不上）。
  - 引用的程序原话七处照字表改：`从 Miyu 导入…`、`整理没成（…）`、`超时，挪到后台了：…`、`Recursive deletes`、`No one can answer questions here.`、`Color mode`、`Enable 'clock' now? [Y/n]`；英文命令行页一句提示里写死的 `(web, gui)` 换成占位。

没改的：`docs/authors/`、`docs/reference/` 等并进 `zh/`、`en/` 的那一步一起改写；蓝图、设计、施工单不改。

### 怎么做的

规范和须知定好以后，分十一批派给 opus 子代理（一次两个），每批两到四页，中英一起改；须知写明只换写法不换内容、不许改变一句话的力度、标题只许改字。头两批是试改，回来查出一个通病（把「不要这样用」改软成「不推荐这样使用」），改回 10 处并把这一条写进须知，后面九批没有再出现。每批回来抽查：新加的「建议／推荐」逐句对原文、读一节看语气、权限和通讯平台名单这类讲判断的地方改前改后并排对。

### 核实

- 全量比对（72 页和改写前逐页比）：代码块去掉注释后逐字相同；每页链接指到的页相同；改写前反引号里的片段都还在；改写前「」里的字都还在（在反引号或「」里）；正文里的数字一个没少，多出来的 3 处是承接句里的（「每天早上 8 点」这类）和上面改正的 70 秒。
- 文档检查：中文 37 页、英文 37 页一页对一页（行数、标题层级、表格行列、代码块个数相等），986 个链接都指得到，没有指到另一种语言的。
- 别的仓库带锚点指过来的链接只有两处（表情包、渲染两个仓库的 README 指附加软件页），那两个标题没改。
- 改正的错处各自的出处：`crates/miyu-endpoint/src/packages/remove.rs`、蓝图 `cli/pkg.md`；`resources/models/profiles.toml`、`crates/miyu-models/src/quota.rs`；托盘仓库 `src/program.rs`；蓝图 `licenses.md`；核心、终端界面、精简版、迁移包各自的字表。
- 没有运行程序：这一步只换写法，命令和输出是前面各步实测过的，没有重跑。

### 留下的

- 工具页说提问时网页界面显示 `… 提问`、英文页说两个界面都显示 `… is asking`，网页界面那一半没在字表里找到原文，等界面实测时核对。
- 程序字表里一处不合规矩的英文，文档只能照抄，要改程序：表情包设置项 `Remind her to send stickers`（用了 her）。（原来还列了终端界面一句报错里的 `the remake's miyu`：那是手册抄的旧字，终端的字表早已改了，DOC-21 照字表改正了手册。）
- 作者教程并进开发者文档以后，Apache-2.0 管哪些目录要重新划（现在是按目录名划的），那一步之前请项目主人定。
