## 施工单 P-7：背景图的透明度和焦点

状态：合了（5ef76c7b，三台 CI run 1813；2026-10-11 主会话；网页的会话同一天转来，项目主人定：背景图的透明度每个人格各一份；背景图不裁，只选焦点，窗口变宽变窄都尽量露着那一处）。图纸 `personas.md`「主题色、背景图」第 2 条、`protocol.md`。

### 这一步做什么

1. `persona.toml` 的 `[appearance]` 多两项（`miyu-policy` 的 `persona/tables.rs`）：`background_opacity`（0 到 100 的整数）、`background_focus`（`[x, y]`，各 0 到 100 的整数）。逐项盖；写错的 `persona_invalid`，代码 `bad_background_opacity`、`bad_background_focus`，三种语言的字在 `core/human/*.json`。
2. `persona.set` 多 `background_opacity`、`background_focus`（`miyu-endpoint` 的 `personas/write.rs`）：值或 `{"unset": true}`；写错的、`changes` 里也改了同一项的 `bad_params`；只写它们的可以新建。`changes` 也认这两项：焦点是两个数的数组，`changes` 的值原来不收数组，这一处照「字、开关、数和它们的数组」收（`toml_changes.rs`）。
3. `persona.get`、`persona.list` 每格多这两格，没有的 `null`。
4. 默认值不在核心里填：头照自己的画（网页露 20、焦点居中）。

### 定了的（主会话，照网页的建议）

- 写法照 P-6 的 `seed`：值或 `{"unset": true}`，不另起方法。
- 核心不填默认值：没写的交 `null`，头各画各的。

### 验收

- `miyu-policy`：读成数、逐项盖、两头 0 和 100 都收；五种写错（超过 100、字、少一个、负数、多一个）带代码和位置。
- `miyu-endpoint` 的 `tests/persona_appearance.rs`：写、列、读、经 `changes` 改、`unset` 回到下面那一层的；六种写错的拒、什么都不写。
- 变异 6 个，都报红（上限放宽、焦点多一个也收、下面那层盖上面、和 `changes` 撞了也收、`changes` 不收数组、列表不带焦点）。
- `cargo xtask check` 八项；三台 CI。
- 合了告诉网页的会话：sha 和写法。
