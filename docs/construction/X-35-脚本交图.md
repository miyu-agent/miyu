## 施工单 X-35：脚本交图

状态：合了（2026-10-21，5a7a31cb）。扩展线的会话做，主会话审过、合进 main。项目主人 2026-10-20 定：脚本交图走一个目录（不改输出格式）。

### 目的

脚本能把图交给她，她直接看到，不用再 `read` 一次。旧版的 `bilibili` 抽帧这一类：现在帧写在缓存目录里，脚本的字叫她去调一件新版没有的工具。

每次调用，核心给一个空目录，路径放在环境变量 `MIYU_SCRIPT_IMAGES_DIR` 里。脚本把图拷进去就行，输出照旧是字：哪种语言都是一行拷贝，目录本身就是接口（仿 Linux）。

```python
shutil.copy(frame, os.environ["MIYU_SCRIPT_IMAGES_DIR"])
```

### 蓝图改哪几节

- `skills.md`「脚本」第 3 条「跑」：多一个目录。
  - 每次调用新建一个，放在 `MIYU_SCRIPT_CACHE_DIR` 旁边：随机名，`0700`，沙盒里能写，同缓存目录在系统临时目录里。
  - 建好先取真实路径（`canonicalize`）：macOS 的系统临时目录在链接下面（`/var` → `/private/var`），交给沙盒规格的、自己读的都用真实路径，不然只有 macOS 红（主会话审时提）。
  - 跑完照文件名排，只看这一层的普通文件，不跟链接：打开时就不跟（Unix 上 `O_NOFOLLOW`），不靠先看一眼再打开，两步之间能被换掉；读之前先看打开的那一个的大小，超过 5 MiB 的不读进内存（主会话审时提）。照 `miyu_tool::picture` 认格式（PNG、JPEG、GIF、WebP）、量尺寸、查上限（5 MiB、每边 8000），至多 4 张，交成图（`Done.images`），执行器存成 blob、接在字后面（同 `read`、MCP）。
  - 认不得的、超了上限的、多出来的不交，运行日志记一行 `WARN script image dropped tool=… file=… why=…`，给写脚本的人查；不给她另写一句（J12：证明不了不加不行，她看到的就是交上去的那几张）。
  - 读完整个目录删掉。
  - 退出码不是 0 的照样交，到时被杀的不看。
- 「守着它的」加测试一行。
- 作者文档 `scripts-skills`（中英）：「交图」一小节，带上面那一行例子。

### 不做什么

- 交别的文件（音频、PDF）；改输出格式；脚本开头多一行声明。
- 嵌套调用（`miyu call`）：照旧不交图，`images_dropped`（设计 39 第六节）。
- Windows 的沙盒：另一个会话在做，这里照它的规格放开同一个目录，不另写。

### 验收

1. 先写会红的测试：
   - 测试脚本往目录里拷两张图和一份文本：结果里两张图，照文件名排；文本那一个不交，结果的字照脚本印的原样。
   - 拷进 5 张的，只交前 4 张。
   - 目录里放一个指向图的链接，不跟。
   - 跑完目录没了。
   - 真沙盒（Linux）里跑也写得进。
2. 手写变异 15 个左右。
3. `cargo xtask check` 全过。

### 风险

- **系统临时目录别的用户也能写**：随机名、`0700` 建，建之前不存在才用。建不成的，这一次不给这个环境变量，脚本照常跑。
- **只读级别**：设计 11 A12 定了只读的沙盒连临时目录也写不了，脚本往这个目录里拷会失败，同缓存目录；照旧给环境变量，不另判级别。
- **目录里塞了很多文件**：只看前面若干个名字（照文件名排，至多 64 个），别的当没有，不往内存里一直读。

### 做下来的

- 和施工单原文不一样的一处：没给她另写「没给她看的」那一句（J12：证明不了不加不行，她看到的就是交上去的那几张），交不了的只在运行日志里记 `WARN script image dropped`；登记簿不动。
- 只读级别不另判：设计 11 A12 定了只读的沙盒连临时目录也写不了，脚本往这个目录里拷会失败，同缓存目录。
- 先在原来的 `script.rs` 上跑新测试，红了 5 个；换上新的全绿，真沙盒那一条也绿。
- 手写变异 13 个，12 个抓住。没抓住的「读完以后不查字节数」是等价的：超过 5 MiB 的在打开时看大小就挡下了，只有看完大小、读之前文件又变大才走得到它，测试造不出这种竞争。「不认格式」一开始没抓住（文本连尺寸都量不出，换哪种写法都挡），测试里补了一张量得出尺寸的 BMP，必须不交。
