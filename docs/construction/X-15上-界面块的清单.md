## 施工单 X-15 上：界面块的清单

状态：已合（2026-10-15，a8935a1b，CI run 38688243204）。设计 `33-界面扩展.md`（项目主人 10-15 定声明式），图纸 `widgets.md`「清单」。

### 做了什么

1. 清单 `[[widget]]`：`id`、`place`（`home`、`sidebar`、`status`、`page`）、`title`（侧边栏、整页必写）、`scope`（`session` 只给侧边栏）、`command`（只给整页）。只有扩展包能写，最多 16 块，要声明扩展能力 `widgets`；写错的 `bad_widget`，报在那一段。
2. 扩展能力多一个 `widgets`（表里第三个，排在 `commands` 后面），名字、说明三种语言。
3. `package.list` 每一项多 `widgets`：编号、位置、范围、标题（照连接的语言挑）、整页的命令名。
4. 整页的命令名和斜杠命令一个名字空间：装包查冲突、看一眼列出来、`miyu check` 和内置同名的报 `slash_builtin`；同一个包里和自己的 `[[slash]]`、别的整页撞了报 `bad_widget`。
