## 施工单 X-10 上：技能——找、读开头、列进 system、文件夹放开只读

状态：施工中（2026-10-12 主会话）。图纸 `docs/blueprint/skills.md`「技能」第 1 到 3 条、「定了的」第 1、4 条。

### 目的

她看得到装了的、自己放的技能，用得上时自己读 `SKILL.md`。技能不单独设工具，她用 `read` 读（`10-自带软件.md` 第三节）。

### 做了什么

1. **读开头**（`miyu-policy` 的 `skill.rs`）：照公开的 Agent Skills 格式。`---` 之间的 YAML 用 `yaml-rust2`（纯 Rust，三个平台一样）。名字 1 到 64 个字、只用小写字母、数字、单个 `-`，和文件夹同名；说明不能空，并成一行（`|` 写的多行说明照样一行列出来），超过 1024 个字截掉；`metadata` 里的 `display_name`、`summary` 给人看。写错了的说哪里不对（英文一句，运行日志、以后 `miyu check` 用）。文件开头的 BOM、行尾的 `\r` 不算。
2. **找**（`miyu-store` 的 `skills.rs`）：先找属主家目录 `home/<账号>/skills/<名字>/SKILL.md`，再照包的编号找装了的（清单读成了的）软件包的 `skills/<名字>/SKILL.md`（出厂的在资源目录，自己装的在家目录）。同名的先找到的赢（自己放的压过包带的，两个包撞了照编号留前一个）；后来的、开头写错的、读不了的跳过，交回为什么，会话层记一行运行日志。点开头的文件夹、没有 `SKILL.md` 的文件夹不算。照名字排。
3. **列进 system**（`miyu-session` 的 `skills.rs`，`core/skills/open.txt`、`line.txt`）：头一行，一个技能一行 `- 名字: 说明 (SKILL.md 的路径)`；三格照模板转义。system 第 4 块里排在知识库那一块前面（26 第四节）。工具面上没有 `read` 的、一个技能都没有的不列。造会话时找、拼好钉进快照（`skills`，没有的不写，以前造的快照字节不变），换人格重拼照旧快照的，会话中途不改（列表变了的走回合尾巴，X-11）。
4. **文件夹放开只读**：边界表多一片 `Shelf`（数据根里单独放开只读的目录，排在数据根前面），权限策略照它放行读、拒绝写（哪一级都拒，完全放开也拒）。造会话、载入时照这一刻找到的技能各算一次（`Guard::with_shelves`）。只碰得到自己工作区的会话（群会话这些）也读得到，写照拒。
5. 协议端点造会话、派子会话、载入时把这一刻装了的软件包交给会话（`Create::installed`、`Load::installed`）。
6. `guard.rs` 到了行数上限：要问人的那几条（提的放行规则、给头看的说明、放行过的管不管得到）挪进 `guard/asking.rs`，没改逻辑。

### 定了的（主会话，技术题照推荐）

- **这一步只放开文件工具**：沙盒里的命令（`cat`、技能里带的脚本）读技能文件夹要三套沙盒（Linux 的 Landlock、macOS 的 Seatbelt、Windows 的另一个用户）各开一个口子，拆成 X-10 中。出厂的技能在资源目录里，本来就不藏；藏着的只有家目录里放的、自己装的包带的。
- **不设个数上限**：每个技能自动算一个功能、预设里能关（X-11），超了预算由 `miyu check` 报（X-13）。
- **YAML 用 `yaml-rust2`，进纯逻辑层的白名单**（01 第九节规则 3）：读开头是纯解析（字进、读好的样子出），放在 `miyu-policy` 能不碰磁盘做单元测试；格式的写法多（引号、折叠、多行、`metadata` 嵌套），自己写容易漏。纯 Rust、不碰 I/O、默认功能关掉，带进来的 `hashlink` 保插入顺序；MIT 或 Apache-2.0。
- **说明照模板转义**（同知识库那一块）：引号、尖括号写成 `"` 这种，伪造不了标签；真模型照样读得懂。
- **路径写绝对路径**，Windows 上反斜杠换成 `/`（转义会把反斜杠写成两个，她照抄就对不上）。

### 量了的

两份字照开发端点（magpie 网关的 `clinepass/cline-pass/deepseek-v4.1-flash`）量：头一行 13，一个技能一行 44（路径占一半多），登记在 26 第十节。

### 真模型走了一遍

沙箱数据根，家目录里放两个技能：`release-notes`（照本项目的格式写发布说明：标题行、两节固定标题、每条不超过 20 个字、固定的结尾一行）、`pdf-processing`。开发端点上开三个会话：

| 说的 | 她做的 |
|---|---|
| 「帮我把这两个改动写成发布说明……版本 0.3.0。」 | 第一步就读 `release-notes/SKILL.md`，照格式写：`## v0.3.0 · 2026.10.12`、`### 新东西`、`### 修好了`、结尾那一行都对 |
| 同一个会话接着问「1+1 等于几？」 | 直接答 2，没读技能 |
| 「Draft a changelog entry for: fixed a crash on startup.」 | 第一步读 `release-notes/SKILL.md`，没给版本照技能写 `v-next` |
| 「work 目录里有个 report.pdf，怎么把里面的文字提出来？」 | 第一步读 `pdf-processing/SKILL.md`，答的命令照技能里写的 |

日志里没有密钥；沙箱核心停了。

### 验收

- 读开头：公开格式的几种写法（引号、`>` 折叠、`|` 多行、BOM、`\r\n`）、写错的十几种各说哪里不对、超长说明截断。
- 找：包里的、家目录的、同名、读坏了的清单、点开头的、没有 `SKILL.md` 的、开头写错的。
- 边界表：放开的那一片、旁边的数据根照旧不能碰。
- 会话层：列进 system 末尾、读放行、写拒绝（工作区、完全放开两级）、旁边的数据根照拒；群会话读得到、写不了；载入以后照样读得到、system 一字不变；换人格技能那一块照旧；没有 `read` 的不列。
- 端点：真核心造会话、换一份核心像重启过，两次都读得到。
- 变异 17 个；`cargo xtask check` 八项；三台 CI。
