## 施工单 R-22 再补：`/dream` 的回执省掉 0、写用时

状态：施工中（2026-10-20）。

### 目的

项目主人 2026-10-20 看了 `/dream` 的回执（终端的会话转来）：「0 条的就不用显示了」「没有时间」。两个头照核心交的回执原话显示，只改核心。

### 做了什么

- 回执能带几段（`crates/miyu-endpoint/src/commands.rs` 的 `Said` 多 `lists`）：每段是一句，照连接的语言拼好，用 `commands/joiner`（中文「，」、英文「, 」、日文「、」）连起来填进模板。有的项是 0 不写时，不用把每种组合开成一个键。
- `/dream`（`crates/miyu-endpoint/src/memory/slash.rs`）：检查几条照写；改了的、作废的是 0 的不写；都是 0 的写「没有要改的」；摘要换了的多一段（叫停的不说）；末尾写这一趟用了多久，照运行状态行的读秒（`miyu_view::clock`：`12s`、`1m 05s`、`1h 02m 05s`）。没有要整理的、一批都没合完就叫停的也写用时。`commands/dreamed-summary` 并进 `commands/dreamed`。
- 字：`core/human` 三种语言改 `commands/dreamed*`，加 `commands/dreamed/{given,revised,retired,unchanged,summary}`、`commands/joiner`。
- 图纸：`memory.md` 第七条第 9 款、`protocol.md` 的 `/dream`、`cli/memory.md`（命令行 `miyu memory dream` 还是原来那句，跟不跟着改等项目主人定）。

### 验收

1. `cargo xtask check` 八道全过。
2. `crates/miyu-endpoint/src/memory/tests.rs` 的 `the_dream_receipt_leaves_out_zeros_and_says_how_long_it_took`：各种组合、三种语言逐字比；0 的照写、不写「没有要改的」、渲染时不拼几段的三个变异都报红。
3. 终端里 `/dream`：回执照新的说法，末尾有用时。
