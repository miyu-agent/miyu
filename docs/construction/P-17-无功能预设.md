## 施工单 P-17：「无工具」换成能编辑的出厂预设「无功能」

状态：项目主人 2026-10-26 提，主会话照推荐定，扩展线做。前提：ENV-1 合了（「用户身份」`env-profile` 能关，2026-10-26 合进 main）。

### 口径（项目主人 2026-10-26，主会话转）

1. 「无工具」改成能编辑，改名「无功能」。
2. 「无功能」就是预设功能菜单里能开关的全关掉的那份预设：工具、环境那几块、技能、脚本、MCP、命令，以后新装的也关。人可以在它上面打开几样。
3. 验收：选「无功能」以后菜单里每一项都显示关着；项目主人在无人格、无工具的会话里问出来的八样一样都不出现。

### 为什么

「无工具」（施工 P-16 下）不是文件，是 `preset.list` 末尾拼出来的一项（编号 `null`，内部空编号，快照记 `no_tools`、不记 `PresetPin`）：
- 头里改不了它；
- 没有 `PresetPin`，`Shown::of` 当它全开，环境那几块、「关于你」、记忆照样进请求。项目主人在终端的上下文明细里看到「自带 57」，问那是什么。

### 实测（2026-10-26，当时的 main 加 ENV-1，无人格、无工具，称呼「小林」，o200k）

| 块 | token | 菜单里的开关 |
|---|---|---|
| system：「关于你」`<user>` | 11（随称呼、更多描述、回复语言变长） | `env-profile` |
| system：本机路径那一句 | 24 | `env-workdir` |
| system：`You run in miyu-agent 0.0.0.` | 13 | `env-harness` |
| 事实：`<env time timezone cwd>` | 52（cwd 长度不定） | `env-time`、`env-workdir` |
| 事实：`<permission level>` | 6 | `env-permission` |
| 事实：`<session id>` | 25 | `env-session` |
| 事实：`<model …>` | 约 26（测试的核心没配模型，照模板估） | `env-model` |
| 事实：`<memories>` | 25（一条；项目主人那边 7 条） | 记忆包的功能 |

- 「自带 57」是 system 那三块：项目主人写了称呼和更多描述，「关于你」比测试里长，加上两行核心说明（24+13）。
- 八样每样都有开关，没有要另问项目主人的。权限规则、本机系统两行跟着工具面，一件工具都没有时本来就不拼。

### 定论（主会话 2026-10-26）

1. 出厂多一份真预设 `resources/presets/none.toml`：名字三语，`unlisted = "off"`，什么都不开。它就是一份普通预设，能编辑，改了写家目录那一层。
2. 列表里拼出来的那一项去掉。协议上 `session.create` 的 `preset: null`、快照的 `no_tools` 照旧认（以前的会话）；新开的选「无功能」就是编号 `none`。
3. 模型那一行的 `preset="none"`：来自 `stamp_preset`，没有 `PresetPin` 时写死 `none`；不改。选了「无功能」整行都不带。
4. `preset.list` 少了 `null` 那一项、多了 `none`，是协议形状改动：合完通知两个头（终端那张预设表要能编辑这一项）。

### 做了什么

- `resources/presets/none.toml`：无功能 / Nothing / 機能なし，说明「不开启任何功能。」三语，图标 `circle-off`，`unlisted = "off"`。
- 端点 `presets.rs`：去掉 `none()` 和 `preset.list` 末尾那一项；给人看的字 `preset-none/*` 三语一起删。
- 测试：`preset_nothing.rs`（新）；`preset_none.rs` 的列表那条改成「不再拼 `null`、最后是 `none`」；`presets.rs`、`persona_avatar.rs` 的列表跟着改；`miyu-store` 出厂预设那条加 `none`。
- 文档：图纸 `presets.md`（出厂表、名字说明、「无功能」一节，「无工具」标不再列）、`protocol.md` 的 `preset.list`，协议参考 `personas.md`、`sessions.md` 中英两份。

### 不做的

- 不迁移：还没发版。人自己写过 `none.toml` 的，照分层盖住出厂那份（原来 P-16 怕撞，现在这就是编辑）。
- 「无工具」内部那一套（空编号、`no_tools`、`session.configure` 交 `null`）不删：以前的会话、以前的头还在用。要不要删另提清单。

### 验收

1. `crates/miyu-endpoint/tests/preset_nothing.rs`：
   - 以前的无工具（`preset: null`）照旧带：关于你、环境、cwd、权限、会话编号、记忆、本机路径、harness 版本；
   - 选 `none` 的一件工具都没有、八样都没有，快照不是 `no_tools`，`Shown` 全关；
   - 量尺 `measure_the_no_tools_session`（`MIYU_P17_OUT=… --ignored`）导出第一次请求，拿 o200k 逐段数。
2. `preset_none.rs`、`presets.rs`、`persona_avatar.rs`：列表里没有 `null`，最后一项是 `none`。
3. `miyu-store` 的 `the_shipped_presets_read_cleanly`：`none` 什么都不写，名字、说明三语。
4. 变异各红一次：`none.toml` 写成 `unlisted = "on"`、列表照旧拼 `null`。
5. `cargo xtask check` 全过，Windows 版 clippy 过。
