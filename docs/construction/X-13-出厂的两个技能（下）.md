## 施工单 X-13 下：出厂的两个技能

状态：施工中（2026-10-12 主会话）。图纸 `docs/blueprint/skills.md`「定了的」第 5 条，设计 `31-软件包.md` 第六节第 2 条。

### 目的

她照包的样子写技能、脚本，用 `package` 装上（F-10 下上）。出厂带两个技能教她怎么写：她平时只看到两行说明，用到才读正文。

### 做了什么

1. **出厂包 `authoring`**（`resources/packages/authoring/`）：只带技能、没有程序、没有开关（X-13 上的 `bundle`）。两个技能各算一个功能（`skill-skill-creator`、`skill-package-creator`），预设里能关。
   - `skill-creator`：技能是什么、放在包的哪里、`package.toml` 最少写什么；开头怎么写（`description` 加双引号，裸的「冒号加空格」会让 YAML 读不成，F-10 下上真模型撞上的）；正文怎么写；`packages` 检查（看 `skipped`）、`package` 装、改了再装一次。
   - `package-creator`：脚本的开头注释（`Description`、`Parameters`、`Timeout`、给人看的几格）、参数从 `MIYU_ARGS_JSON` 和标准输入来、标准输出是结果、在沙盒里跑；MCP 服务的 `[[mcp]]`；检查和装。
2. **技能给人看的名字照语言**（`miyu-policy` 的 `skill.rs`）：格式的 `metadata` 只收字到字的表，语言写进键里：`display_name`、`summary` 算 `en`（别的语言没写时退回它），`display_name_zh`、`summary_zh`、`_ja` 是另两种。`preset.get` 照连接的语言挑（同脚本）。X-10 上先只读一种，这一步定下几种语言的写法。
3. **登记簿的门禁扫到包带的技能、脚本**（`xtask/src/ledger.rs`）：`resources/packages/` 原来整个当数据跳过，现在各包的 `skills/`、`scripts/` 照查（清单照旧不查）。两份 `SKILL.md` 登记在 26 第十节：列进 system 的那一行 56、68 个 token，正文 667、741。
4. 测试跟着改：出厂技能列进每个工具面上有 `read` 的会话的 system 末尾，几处比 system 结尾、功能表、放开只读的文件夹的测试照新的写。

### 定了的（主会话，技术题照推荐）

- **两个技能放进单独的出厂包 `authoring`**，不放进基础系统：能整个卸掉；名字给人看的是「写技能和包」。
- **技能名照旧版**：`skill-creator`；写脚本和写包合成一个 `package-creator`（她自己的脚本只能装成包，家目录不另开口子）。
- **说明照公开格式写成一行英文、带几个人会说的中文词**：每次请求都带，越短越省；两行合计 124 个 token，加头一行 13。

### 真模型走了一遍

沙箱数据根、开发端点（magpie 网关的 `clinepass/cline-pass/deepseek-v4.1-flash`），驱动遇到确认请求答「允许这一次」：

| 说的 | 她做的 |
|---|---|
| 「帮我做一个技能：以后我说「记一下 ……」，你就把那件事追加到工作区的 notes.md 里，每条前面带上今天的日期。做好以后装上。」 | 第一步读 `skill-creator`；在工作区写 `quick-notes/package.toml`、`skills/quick-notes/SKILL.md`（`description` 加了引号）；`packages` 看文件夹，预览里有 `skills: ["quick-notes"]`、没有 `skipped`；`package` 装，问人的卡片带着同一份预览，允许以后装上 |
| 「记一下：明天下午三点去取快递。」 | 读刚装上的 `quick-notes`，照它追加一行 `- 2026-10-12 明天下午三点去取快递` 到 `notes.md` |

对照 F-10 下上那一次（没有这两个技能）：她翻了出厂包和仓库里的图纸才写出来，说明没加引号，技能读不成。日志里没有密钥；沙箱核心停了。

### 验收

- 读开头：给人看的几格照语言读，不带后缀的算 `en`，空的不记。
- 端点：功能表里有两个技能、名字照连接的语言；会话 system 里列着它们；放开只读的文件夹里有它们。
- 门禁：包带的技能没登记的报出来（改之前这一条过得去：整个 `packages/` 跳过）。
- 变异 4 个全报红（中文名算成英文、功能表不挑语言、门禁照旧跳过包、门禁连后台页也查）；头一稿的「门禁连清单也查」是等价变异（文件接上 `skills` 不会是目录），换成了后台页那一个。
