## 施工单 X-7：长期目标的续轮

状态：合了（422630a1，三台 CI run 1853；2026-10-12 主会话）。图纸 `goal.md`「照旧版留下的」第 1、2、4、5、6、7 条，「在新的架构里怎么放」第 2、3 条。

### 这一步做什么

1. 内核收一个改目标的命令 `Goal`（`miyu-kernel` 的 `session/goal.rs`）：设（原文、上限）、改、停、接着跑、结束（结局、原因），照现在的目标判，合的记对应的那一条 `goal.*`、不合的拒：已经有一个没结束的再设 `goal_exists`；没有目标的改、停、接着跑、结束 `no_goal`；停着的再停 `goal_paused`，跑着的接着跑 `goal_running`；原文是空白的 `empty_message`。`/goal` 命令、`goal` 工具（X-8）都走它。
2. 授权：载入会话时，目标照日志还跑着的，内核记一条 `goal.paused`（`by` 内核，没有 `cause`），核心重启以后不自己开轮，等人 `/goal resume`（照常记 `goal.resumed`）。跑着的一定是这次运行里设下、接着跑的，会话层不另记授权。
3. 续轮：actor 每办完一封信回到主循环时（`actor.rs` 的 `run`）看一眼：目标跑着、会话空着（内核的 `vacant`：没有回合、没在重启、没在等子代理）、收件箱是空的（人优先）、没在等人开口：交内核一个说话的命令，`by` 是长期目标这个模块（`goal`），正文是续轮消息。内核照平常开一轮，不加新的回合种类。
4. 等人开口：续轮开的一轮一件工具都没调就结束了，停下不再开，直到人说一句话（`message.user`，`by` 是人）。
5. 到了轮数上限：目标跑着、会话空着，第几轮已经到了上限，记 `goal.ended {outcome: blocked}`（原因是英文的一句，写明到了上限），不再开。
6. 目标跑着的会话不闲够了退下（`actor/life.rs` 的「还有事」多一条）：退下再载入就停了。
7. 续轮消息（`resources/core/goal/round.txt` 第一轮完整版、`round-again.txt` 之后每轮的短版，照搬旧版的英文措辞）：开头一句说清是人用 `/goal` 交代、闲着时自己开的轮；目标原文、第几轮（有上限的写「第几轮，共几轮」）；规矩（这一轮做一步实在的；只说在等的轮不开，做不下去就报卡住；派了子代理就结束这一轮，回报会叫醒；做完了验过再报完成）；两条写好的结束调用 `goal {"action":"complete"}`、`goal {"action":"blocked","reason":"…"}`。短版自包含，压缩以后不指向丢掉的旧文。登记进 `26-提示词.md` 第十节，量 token。
8. 会话状态的 `goal`：跑着、在等人开口的写 `waiting`；载入时记成停着的照日志就是 `paused`。
9. 图纸 `goal.md`、`kernel/session.md`（命令、原因码）、`protocol.md`（原因码的字）、`view.md`（`waiting`）、`session/actor.md`（续轮、退下）。

不在这一步：`/goal` 命令、`goal` 工具、收尾轮、规则行（X-8）；她用工具报卡住要先连着做满 3 轮自动轮（X-8，工具那一头判）。

### 定了的（主会话，技术题照推荐）

- 续轮消息挪进这一步（图纸原来排在 X-8）：续轮发出去的就是它，X-7 单独合进去也是完整的一段；命令、工具、收尾还是 X-8。
- 授权落成「载入时把还跑着的记成停着」：起先打算照这次运行里落了盘的设、接着跑另记一个授权，写的时候发现重启以后目标照日志还跑着，`/goal resume` 会被内核当成「跑着的接着跑」拒掉、人就接不回来；记成停着以后日志说的就是实情，头上照日志显示停着，`resume` 照常走。
- 「收件箱里没有人的话」照收件箱空不空判：有一封没办的就先不开，办完再看一遍，人的话总在续轮前面。起先放在 `drain` 收尾时看，整套测试一起跑时偶发卡住：头要会话状态的信正好排在收件箱里就不开，办那封信又不经过 `drain`，之后不再看，续轮停在第 0 轮（实际用时网页每落一批就要一次状态，会常撞上）。挪到主循环开头，每办完一封都看；`tests/goal_rounds.rs` 多一条一直要状态的测试守它，退回原来的放法当场红。
- 等人开口只看续轮开的那一轮：人开的那一轮她只是回话、没调工具很正常，不该因此停下。
- 到了上限由会话层记 `goal.ended`（`by` 是模块 `goal`）：轮数是会话层照日志算的，内核不数。

### 验收

- 内核：`Goal` 命令五种各记对应的事件；五种拒绝各有例子；空白原文拒。
- 会话层（真 actor、假模型）：设了、空着就开续轮，续轮消息的第一轮是完整版、之后是短版；续轮里调了工具的接着开，没调工具的停下等人，人说一句以后接着开；停了不开；到上限记卡住、不再开；有排着的人的话先办人的；载入以后不开，`resume` 了才开；授权着的不退下。
- 会话状态：`waiting`、没授权的 `paused`。
- 变异 14 个：13 个报红（设的原文空白也收、停着的还能停、载入不停下、停着的载入时也记、等人也开、调了工具反而等、人开口也不停等、哪一轮都算续轮、头上不显示等人、跑着的也退下、上限多一轮、头一轮也发短版、改了不重发完整版）；1 个等价（同一轮发两次：只在续轮被内核拒时用得上，封存另判了，会话空着时内核不拒发话，这条路走不到，留着兜底）；`cargo xtask check` 八项；三台 CI；本地先跑长跑随机（改了排队、加了命令）。
