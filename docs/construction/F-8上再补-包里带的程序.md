## 施工单 F-8 上再补：包里带的程序

状态：写好了，等门禁和三台 CI（2026-10-11 主会话）。起草给第三方作者的说明时查出来的。

### 查清楚的

设计 `31-软件包.md` 第二节的包的样子里，带程序的包（扩展、小程序）把程序放在包文件夹的 `bin/` 下。可代码找程序只找 `miyu` 真实位置旁边的（`miyu_store::packages::locate`，施工 9-2 起），设计 30 第六节第 1 条也还这样写。`miyu pkg install` 把包文件夹拷进家目录，程序跟着进了 `packages/<编号>/bin/`，核心却在 `miyu` 旁边找：别人做的扩展装上就是「程序不在，当没装」，只有随 Miyu 一起装、放在 `miyu` 旁边的几个能用。

顺带查出一处：程序是装的时候才拷进来的，拷的那一刻核心要是正好在起别的子进程（命令、别的扩展），子进程在换成自己的程序以前也攥着写它的句柄；装完马上拉起，Linux 回 `ETXTBSY`（Text file busy），看管照「起不来」直接停下，不再重试。测试里同样的事撞过（`tests/support/extensions.rs` 的 `Program` 改硬链接就是为它），以前只有测试会拷了就跑，现在装包也会。

### 这一步做什么

1. `locate(程序, 包文件夹, 主程序)`：先找包文件夹的 `bin/<程序>`（Windows 加 `.exe`），再找主程序旁边的；包文件夹是相对路径的不找 `bin/`（那是照当前目录找）。`Found::program` 照这个包的文件夹找。
2. 用到的几处都带上包文件夹：扩展拉起、程序在不在（列表的 `status`、开关、当没装的功能和配置项）、包的检查、内置语义模型的小程序、`miyu <子命令>` 转交、打开界面、`miyu web`。
3. 扩展拉起时程序正被开着写的，隔 50 毫秒再试，最多 20 次（`supervise.rs` 的 `spawn_settled`）。
4. 命令行没找到程序时说的两句改成不提「旁边」：程序可能该在包里，也可能该在 `miyu` 旁边，说「没找到」「重装它的软件包」。
5. 图纸：`packages.md`（在哪、转交、入口、守着它的、起草时定的）、`extensions.md`（原因、拉起、守着它的）、`package-pages.md`、`protocol.md`、`cli/main.md`、`recall.md`、`core.md`、`web-module.md`、`web-ui.md`；设计 30 第六节第 1 条。

### 定了的（主会话，技术题照推荐）

- 两层一个找法，`bin/` 在前、`miyu` 旁边在后。没选「家目录的包只找 `bin/`」：家目录里放清单、程序放 `miyu` 旁边的开发办法（现在的测试也这样）照旧能用；同一个包两处都有的，包自己带的更具体。两种都不找 `PATH`，冒充不了。
- 升级只换了程序、清单没变的也会重起：装包本来就是先停下原来的、换文件、再照开关拉起（`manage.rs` 的 `from_path`），不靠比清单。
- 小程序（内置语义模型）拉起不另加重试：它起不来记一次失败，下次用时再起，本来就会再试。

### 验收

- 单测：`a_program_is_found_in_the_package_bin_then_beside_main`（哪儿都没有、只有旁边的、包里的先、相对的包文件夹不找 `bin/`）；`a_head_runs_the_program_its_package_brings`。
- 集成：`packages_programs.rs` 的 `a_package_brings_its_own_program`（真核心装上一个程序只在包 `bin/` 里的扩展：在跑、列表里在跑、预设里它的功能算装了、装上的文件里有它的程序）；`a_busy_program_starts_once_it_is_let_go`（只在 Linux：程序开着写时不记成起不来，放开以后在跑）。真二进制：`a_package_command_runs_the_program_in_its_bin`。
- 变异（都红）：不找 `bin/`（四处测试各自红）、相对的也找 `bin/`、拉起不重试、按编号找包文件夹交回空的、列表的状态不带包文件夹、当没装不带包文件夹。
- `cargo xtask check` 八项；三台 CI。
- 走查（2026-10-11 主会话，沙盒数据根、本地假模型服务）：照作者说明（`docs/authors/README.md`）原样抠出清单和 Python 程序拼成包，`miyu pkg install --yes` 装上（`pkg files` 列出 `bin/miyu-hello`）；`extension.enable` 带 `approve` 打开，在跑，列表的状态是在跑；会话里假模型调 `hello_greet`，它看到的工具结果是 `Hello, Ann!`；`miyu hello` 转交给包里的程序（印用法、退出码 2，照例子写的）。
