## 施工单 X-42 下补：远程也能登录

状态：主会话 2026-10-22 排、定了做法，插在 X-44 补前面；Y-1 下上把 `mcp.login` 放进了只给本机的那张表，这一步拿出来（core2 同意，那几个文件它手上的活不碰）。

### 目的

远程连进来的人（从手机、别的机器经网页软件连回来的）也要能登录 MCP 服务。核心本来就只交回授权页的网址、不开浏览器（开浏览器的是头），回调听核心那台机器的 `127.0.0.1`：远程的头在它自己那边打开授权页，授权完跳到打不开的地址，照 X-42 下的 `mcp.login_finish` 贴回来。所以 `mcp.login` 不该是「本机才能用的」。

### 改哪几处

- `connection/reach.rs` 的 `local_machine_only` 拿掉 `mcp.login`；`tests/local_machine.rs` 那张「本机才能用」的单子跟着拿掉它。
- 蓝图 `protocol.md` 本机才能用的那一条、`mcp.md` 第八条第 2、13 条，协议参考 `connection`、`packages`（中英）：`mcp.login` 不在本机才能用的里面；`mcp.login`、`mcp.login_finish`、`mcp.logout` 写成「只给人，远程的也行」（原来写的「只给本机的人」是 Y-1 以前「只给人、不给扩展」的说法）。

### 验收

1. 先写会红的测试：远程连进来的连接调 `mcp.login` 拿到授权页，照 `mcp.login_finish` 贴回跳到的地址，服务连上；`mcp.logout` 照样能调。
2. `cargo xtask check` 全过；本机跑 Windows 的 clippy；只改一张表和文档，不过三台 CI。
