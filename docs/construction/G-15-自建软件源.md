## G-15 自建软件源

状态：已完成（2026-10-29）。

### 目的

不靠 GitHub 也能发一个软件源：`miyu-index folder` 把一个文件夹里的 `.miyu` 收成索引、签名、用静态网页服务发出去，用的人照第三方源加进配置。项目主人 10-29 在虚拟机里以新用户身份试，终端、网页还没进官方源装不上，要一个本地的源把装包的流程也测一遍；todolist 里「允许自建软件源，像 pacman 那样」同一件事。顺带补上装进数据根的包找不到主程序的缺口（网页软件要拉起核心）。

### 蓝图改哪几节

- 设计 37 第五节：自建软件源一条。
- 作者说明、参考的扩展一节：环境多 `MIYU_PROGRAM`（主程序的真实位置），命令行转交子命令、核心拉起扩展都设。
- `packages.md`：`[ui] pages_dir` 改成相对包文件夹（网页那种才写，`"pages"`）。

### 不做什么

- 不做 `miyu-index serve`：任何静态网页服务都能发，测试用 `python3 -m http.server` 就够。
- 不改官方源的收录（`build`）：只把读一个包文件的那段抽出来两边共用。
- 推荐包在装的时候提不提（`recommends`），这一轮只记下缺口，另开一步。

### 验收

- `crates/miyu-source/src/collect/folder/tests.rs`：几个包、一个包几种系统并成一条、同一个编号第二个版本和读不成的不收并记一笔、文件夹没有的报错。
- 实测：宿主机上用测试钥匙收终端、网页、im、赞助几个包，`python3 -m http.server` 发在 `192.168.122.1`；虚拟机里加这个源，`miyu pkg update`、`search`、`install tui` 走通，网页在核心没在跑时 `miyu web` 拉得起核心。
- 本机门禁。
