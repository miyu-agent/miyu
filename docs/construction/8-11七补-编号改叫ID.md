## 施工单 8-11 七补：自定义一家问的「编号」改叫「ID」

状态：已合（2026-10-14，f8bf03a3，CI run 38517238365）。项目主人 2026-10-14 在终端引导里看自定义一家的表单时说「编号」像 1234567，问过叫「名称」，因为这一格只能小写字母开头、只用小写字母、数字、`-`、`_`（配置里的键，模型写成 `local/…` 前面那一截），叫「名称」会让人想写中文，定了叫「ID」。图纸 `docs/blueprint/cli/setup.md`「怎么走」第 4 条。

### 做了什么

1. `miyu setup` 自定义那一家试通以后问「ID（直接回车用 local）：」，写法不对的说「<敲的> 不能当 ID：小写字母开头，只用小写字母、数字、- 和 _，最长 32 个字」。英文本来就是 ID。
2. 终端、网页的引导和设置页同一格同一天改叫 ID（终端 7d2fc4a，网页 step/custom-id 35cc93e）。
3. 命令行帮助里通用的 `<编号>` 占位（会话、记忆、`--provider`）不动：那是另一回事。

### 验收

- `crates/miyu-cli/tests/setup_custom.rs` 照新字。三台 CI 过。
