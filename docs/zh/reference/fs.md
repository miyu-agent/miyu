# 文件：`fs.*`

> <sub>本文档由 Anthropic 的 Claude Fable 5.2 生成。</sub>

这一页是给头（连接核心的界面程序，例如终端界面、网页界面）使用的本机文件操作：补全路径、查找文件、把路径换成真实的位置、分块读取一份文件。

| 方法 | 做什么 |
|---|---|
| [`fs.list`](#fslist) | 列出一层目录，用于在输入框里补全路径 |
| [`fs.find`](#fsfind) | 在一个目录里模糊查找文件 |
| [`fs.realpath`](#fsrealpath) | 把一个路径换成真实的位置 |
| [`fs.read`](#fsread) | 分块读取一份本机文件 |

**谁能调用**：人可以调用；扩展需要有 `fs.read` 能力。

**边界**：在 Miyu 的数据目录（默认是 `~/.miyu`）里，只有工作区 `workspace/` 可以列出、查找和读取，其他位置返回 `path_forbidden`。`fs.realpath` 只告诉你位置、不读取内容，所以不检查边界。

**路径的写法**：写绝对路径，或者以 `~`、`~/…` 开头的路径（接在系统的家目录后面）。

## `fs.list`

**参数**

| 名字 | 类型 | 说明 |
|---|---|---|
| `cwd` | 字符串，必写 | 相对的路径接在它后面。 |
| `dir` | 字符串，默认 `""` | 已经输入的那一截目录：以 `~` 开头的接在家目录后面，绝对路径按原样使用，其他的接在 `cwd` 后面。 |
| `prefix` | 字符串，默认 `""` | 名字的开头。 |

**回应**是 `{"items": [...], "partial"}`。每一项的字段如下：

| 名字 | 说明 |
|---|---|
| `path` | 在列表上显示的写法，目录后面带 `/`。 |
| `full` | 绝对路径，使用当前平台的写法。 |
| `dir` | 是不是目录。 |
| `size` | 文件的字节数，目录没有这一项。 |
| `marks` | `path` 里和 `prefix` 对上的那几个字的位置（第几个字）。 |

核心用名字的开头去对 `prefix`，不区分大小写；以点开头的名字只在 `prefix` 以 `.` 开头时才列出。目录排在前面、文件排在后面，各自按名字排序。最多返回 50 条，超出的部分截掉，此时 `partial` 是 `true`。

```json
→ {"jsonrpc":"2.0","id":"f1","method":"fs.list","params":{"cwd":"~/src/miyu","dir":"src/","prefix":"ma"}}
← {"id":"f1","jsonrpc":"2.0","result":{"items":[{"dir":false,"full":"/home/me/src/miyu/src/main.rs","marks":[4,5],"path":"src/main.rs","size":2048}],"partial":false}}
```

**出错**：`path_unreadable`（路径不存在、不是目录，或者没有权限）；`path_forbidden`。

## `fs.find`

**参数**

| 名字 | 类型 | 说明 |
|---|---|---|
| `cwd` | 字符串，必写 | 在哪个目录里查找。 |
| `query` | 字符串，默认 `""` | 用户输入的字。 |
| `fresh` | 布尔，默认 `false` | 打开列表时写 `true`：如果清单已经建好 10 秒以上，就重新建一份。 |
| `wait` | 布尔，默认 `false` | 如果清单还在建，就等建完再回答（在后台回答，不挡住其他请求）。 |

**回应**：和 `fs.list` 相同，另外有 `building`：它表示清单还在建，这一次只根据已经建好的那一部分回答。

1. 核心在 `cwd` 里建一份文件清单：它遵守 `.gitignore`，跳过隐藏目录、`node_modules`、`target`，不跟随链接；最深 8 层，最多 20000 个，收满时 `partial` 是 `true`。`path` 是相对 `cwd` 的路径，用 `/` 连接。
2. 只有输入的字按先后顺序都出现在 `path` 里（不区分大小写），这个文件才会列出；落在文件名里的、在一段开头的、连在一起的排在前面，文件名正好等于输入的字的排在最前。最多返回 50 条。

**出错**：和 `fs.list` 相同。

## `fs.realpath`

**参数**：`path`（必写）；`cwd`：只有 `path` 是相对路径时才需要。

**回应**：`{"path": <真实的位置>}`。遇到链接时顺着找到它指向的本体；还没有建出来的那几段，按原样接在最后一层存在的目录后面。

**出错**：`bad_params`（路径是相对的，却没有给 `cwd`）；`path_unreadable`（任何一层都不存在、链接指向不存在的地方，或者没有家目录）。

## `fs.read`

**参数**：`path`（必写，不能是相对路径）；`offset`（默认 0）；`length`（默认 512 KiB，最多 512 KiB，写 0 时只查询大小）。

**回应**：`{"data", "size"}`，和 [`blob.get`](blob.md#blobget) 相同。路径上的任何一层链接都不跟随。

**出错**：`bad_params`（路径是相对的；或者 `length` 超过 512 KiB）；`path_unreadable`（文件不存在、不是普通文件，或者没有权限）；`path_forbidden`。
