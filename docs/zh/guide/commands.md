# 斜杠命令

> <sub>本文档由 Anthropic 的 Claude Fable 5.2 生成。</sub>

这一页列出在输入框里输入 `/` 之后可以使用的全部命令：每条命令做什么、带什么参数，以及在终端界面、网页界面、通讯平台中哪里可以使用。和会话有关的几条命令（撤销、压缩、导出等）在 [会话](sessions.md) 里有详细的说明。

## 输入命令

- 在输入框里输入 `/`，输入框上方会弹出命令列表。列表会随着你的输入筛选，名字或别名的开头和输入一致的命令排在前面。用 `↑` `↓` 选择，用 `Tab` 补全，用 `Enter` 执行。
- 参数写在命令名后面，中间空一格，例如 `/compact 保留接口的改动`。
- 如果输入的名字不在列表里，会交给核心识别。如果核心也不认识这个名字：终端界面会说明为什么不能执行；在网页界面里，如果名字后面还带着文字，整句会当作一句普通的话发给 AI。如果 `/` 后面的内容不像命令名（命令名以英文字母开头，只包含英文字母、数字、`-` 和 `_`），例如 `/你吃了吗`、`/home/me`，就从一开始当作普通的话处理。
- `/help` 会列出按键和全部命令。

命令分为两类：

- 核心的命令：包括核心登记的命令、软件包提供的命令和你自己添加的命令。它们在终端界面、网页界面和通讯平台上都可以使用，终端界面和网页界面的命令列表里都会列出它们。
- 界面自己的命令：只在某一个界面里有，见下面的「终端界面的命令」和「网页界面的命令」。

如果两类命令里有同名的（例如 `/clear`、`/stop`、`/context`、`/workspace`），界面会按照自己的方式执行，命令的说明使用核心的说明。

## 核心的命令

核心登记了下面这些命令：

| 命令 | 别名 | 参数 | 做什么 | 详见 |
|---|---|---|---|---|
| `/clear` | `/reset` | | 清空上下文，会话本身保持不变 | [会话](sessions.md) |
| `/stop` | | | 打断当前这一轮，排队的消息保留下来但不发送，同时停止这个会话的后台命令、子代理和循环 | [会话](sessions.md) |
| `/workspace` | | `<路径>` | 更换这个会话的工作目录。不带路径时显示当前的工作目录。只有你本人可以使用 | [会话](sessions.md) |
| `/context` | | `[<数值> \| unset]` | 带数值时设置这个会话的上下文上限，例如 `128k`、`1m`；`unset` 或 `off` 去掉上限；不带参数时显示当前的上限和压缩线 | [会话](sessions.md) |
| `/todo` | | `[clear]` | 列出待办；带 `clear` 时清空待办 | [会话](sessions.md) |
| `/remember` | | `<内容>` | 记下一条记忆 | [记忆](memory.md) |
| `/dream` | | `[stop]` | 立即整理记忆；带 `stop` 时停止整理 | [记忆](memory.md) |
| `/clear-memory` | `/reset-memory` | | 清除这个会话记下的记忆 | [记忆](memory.md) |
| `/goal` | | `[[--rounds <轮数>] <目标> \| pause \| resume \| clear]` | 不带参数时查看进度；带目标时设定长期目标，如果已经有目标就修改它，`--rounds` 指定最多运行几轮；`pause` 暂停，`resume` 继续，`clear` 清除 | [让 AI 自己接着干](automation.md) |
| `/loop` | | `[[<间隔>] <要说的话> \| off]` | 每隔一段时间说一次这句话，间隔写成 `5m`、`2h` 这样；不写间隔时，由 AI 决定下一次在什么时候；什么都不写时，由 AI 自己决定做什么、什么时候做；`off` 停止这个会话的循环。如果只写了间隔、没有写要说的话，会回复这条命令的用法 | [让 AI 自己接着干](automation.md) |

`/todo`、`/remember`、`/dream`、`/clear-memory`、`/goal`、`/loop` 属于各自的软件包：如果软件包没有安装，或者会话的预设没有开启对应的功能，命令列表里就不会列出这条命令。

在网页界面里，如果新会话还没有开始，输入核心的命令不会开始这个会话，而是当场回复一句提示。`/goal <目标>`、`/loop <要说的话>` 是例外，它们和第一句话一样，会先开始会话。只输入 `/loop` 不会开始会话，会提示 `请输入要循环说的话`；如果要开启自主循环，需要先说一句话开始会话，再输入这条命令。

## 软件包和你自己添加的命令

下面几种命令也算作核心的命令，在命令列表里和上面的命令排在一起：

| 来源 | 写法 | 输入之后 |
|---|---|---|
| 命令模板：数据根（默认是 `~/.miyu`，Windows 上是 `%USERPROFILE%\.miyu`）下的 `root/commands/<名字>.md`，也就是 `~/.miyu/root/commands/<名字>.md`，或者软件包的 `commands/` 目录下 | `/<名字> 参数` | 模板的正文会当作你说的一句话发给 AI |
| 扩展声明的命令（清单里的 `[[slash]]`） | `/<名字> 参数` | 由扩展的程序处理，回复一段文字给你看 |
| MCP 服务的提示词 | `/<服务名>:<提示词名> 参数`，例如 `/github:review-pr 123` | 取回的内容会当作你说的一句话发给 AI。只能在本机的会话里使用 |
| 扩展带的整页 | `/<名字>` | 打开那一页 |

如果 `~/.miyu/root/commands/` 里的模板和软件包里的模板同名，使用你的模板；如果和上面核心登记的命令同名，使用核心的命令。每条模板、每个 MCP 服务都在预设里单独开关，如果预设没有开启，输入之后会提示 `预设「…」未启用 /…。`。模板和扩展命令的写法见 [扩展 Miyu](extending.md)。

## 设置谁能使用命令

在通讯平台上，谁能使用一条核心的命令由 `commands.<命令名>.access` 决定。设置页上没有这一项，需要用 `miyu config set` 修改：

| 值 | 谁能使用 |
|---|---|
| `admin` | 你本人，以及你在通讯平台后台页的群卡上填进 `允许使用管理员命令的用户` 的人。平台自己的群主、群管理员不算在内，见 [接入通讯平台](heads/im.md) |
| `anyone` | 所有人都可以使用 |
| `off` | 停用，所有人都不能使用，输入之后会提示 `/<名字> 已停用。` |

如果没有设置这一项，就使用命令自带的设置（扩展在 `[[slash]]` 里写的设置）；如果命令也没有自带的设置，就是 `admin`。在终端界面和网页界面里，说话的都是你本人，所以只有 `off` 会产生影响。

例如：

```sh
miyu config set commands.clear.access anyone       # 群里所有人都能使用 /clear
miyu config set commands.remember.access off       # 停用 /remember
```

修改之后立即生效。这一项只对核心的命令有效，界面自己的命令不受它影响。

## 在通讯平台里使用命令

在通讯平台上给 AI 发送以 `/` 开头的消息时，核心会先把它当作命令识别，核心不认识的消息会当作普通的话发给 AI。在通讯平台里只能使用核心的命令（也就是上面「核心的命令」里的命令，以及模板和扩展的命令；MCP 的提示词不能使用），谁能使用由 `commands.<命令名>.access` 决定。终端界面和网页界面自己的命令（例如 `/undo`、`/compact`、`/new`）在通讯平台里没有。平台上的细节见 [接入通讯平台](heads/im.md)。

## 输入框里的其他写法

除了 `/` 开头的命令，输入框里还有下面几种写法：

| 写法 | 在哪里可用 | 做什么 |
|---|---|---|
| `$<技能名>` | 终端界面、网页界面 | 点名一个技能：输入 `$` 会弹出技能列表，选中的技能的正文会跟着这句话一起交给 AI。一句话里可以点名几个技能 |
| `@<路径>` | 终端界面、网页界面 | 弹出文件列表，从中选择文件。图片这类文件会作为附件，其他文件和目录会以路径的形式写进话里，见 [会话](sessions.md) |
| `!<命令>` | 终端界面 | 在输入框里第一个字输入 `!` 会进入运行命令的模式，按回车会在会话的工作目录里直接运行这条命令，不经过权限确认，也不在沙盒里运行；命令和输出会一起交给 AI。每条命令最多运行 120 秒，不能带附件。输入框为空时按 `Backspace` 或 `Esc` 回到平常的模式 |
