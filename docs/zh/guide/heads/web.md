# 网页界面

> <sub>本文档由 Anthropic 的 Claude Fable 5.2 生成。</sub>

这一页介绍怎样在浏览器里使用 Miyu：页面上每一块是什么、能用来做什么。想把网页界面部署到服务器上、放到反向代理后面，可以看 [常驻和服务器](../service.md)。

## 打开网页界面

在终端里运行：

```sh
miyu web
```

网页界面由程序 `miyu-web` 提供，下面称它为“网页软件”。如果网页软件没有在运行，`miyu web` 会先在后台启动它（核心没有运行时也会一起启动），再交给系统的浏览器打开。终端里会输出一行 `已在浏览器中打开：<网址>`，然后命令马上返回，不会占着终端。关掉浏览器以后网页软件仍然在运行，所以收藏的地址可以直接打开。默认地址是 `http://127.0.0.1:8300`。

交给浏览器时使用的命令：Linux 上是 `xdg-open`，macOS 上是 `open`，Windows 上是 `cmd /C start "" <网址>`。如果这个命令无法启动，或者在 3 秒内出错退出，就算作没有交给浏览器，终端会输出 `miyu: 无法打开浏览器，请手动打开上面的地址`，网址仍然输出在这一行上面。

`miyu web` 可以使用以下参数：

| 参数 | 作用 |
|---|---|
| `--port <端口>` | 这一次监听的端口，只在网页软件没有运行时有效，出厂值是 `8300`。 |
| `--print` | 不打开浏览器，只输出地址。 |
| `--format <text\|json>` | 输出的格式；使用 `json` 时也不打开浏览器。 |
| `--reset` | 带一次性码打开网页界面，用来重设访问密码。 |
| `--logout` | 让所有浏览器都重新登录。 |
| `--package <编号>` | 直接打开 `软件后台` 里这个软件包的页面。 |
| `--session <编号>` | 直接打开这个会话。 |
| `--settings [<分页>]` | 直接打开设置页；写 `access` 会打开 `通用` 里的 `访问`。 |
| `-h`、`--help` | 输出帮助。 |

还有其他几种打开网页界面的方法：

- 如果安装了系统托盘，点击托盘菜单里的 `打开网页界面` 即可；在 Linux、Windows 上，左键点击托盘图标也可以打开。详细的见 [系统托盘](applet.md)。
- 如果浏览器的地址栏里有 `安装`，可以把网页界面安装成一个单独的窗口，窗口的名字是 Miyu。

端口的规则如下：

- 如果没有设置过端口，8300 被占用时会依次尝试 8301 到 8309，使用第一个空闲的端口。如果这些端口都被占用，或者你设置的端口被占用，会报错 `端口 8300 已被占用`，此时用 `--port` 换一个端口即可。
- 要固定端口，设置 `web.port`；要修改监听地址，设置 `web.listen`。详细的见下面的「访问和安全」。

网页软件启动以后会一直运行，没有人使用时也不会退出。如果想节省资源，可以设置 `web.idle_seconds`：既没有浏览器连接、也没有在传输图片和视频这类文件的状态连续持续这么多秒以后，网页软件会自己退出，下次运行 `miyu web` 时再启动。出厂值是 `0`，表示一直不退出；打开了局域网访问时也不会退出。设置页上不显示这一项，需要用命令修改，例如：

```sh
miyu config set web.idle_seconds 600
```

如果只想关掉网页界面、让核心继续运行，运行 `miyu web stop`。想查看网页界面是否在运行、在哪个地址，运行 `miyu web status`。这两条命令不连接核心，详细的见 [命令行](../cli.md#miyu-web)。如果网页软件在前台运行（例如在服务器上按照 [常驻和服务器](../service.md) 启动的 `miyu-web serve`），按 `Ctrl+C` 即可停止；在 Linux、macOS 上，它收到 `SIGTERM` 时也会停止。

### 在手机和其他设备上使用

打开局域网访问（见「访问和安全」）以后，手机、平板可以用这台电脑的地址打开网页界面，输入访问密码登录即可。窗口宽度小于 836 像素时，页面会切换成窄屏布局：

- 左栏会收起，左上角有一个菜单按钮 `展开侧栏`，点击后左栏从左边滑出来，手指向左划可以收起。
- 右侧边栏会盖在对话上面，顶部有关闭按钮，手指向右划可以收起。
- 平时要悬停才出现的按钮（你的消息下面的复制、编辑，一轮末尾的复制、重做，左栏的多选）会一直显示。
- 通过局域网用 `http` 打开的页面，浏览器不提供剪贴板的接口，复制失败时会提示 `复制不了，请长按选中文字后复制`。

## 第一次打开

第一次打开网页界面时，新手引导会盖住整个页面，一屏是一步。顶部的一排小格是步骤条；按 `Enter` 进入下一步，点击 `上一步` 返回上一步，在右上角可以切换明暗。

1. 欢迎：页面上显示 `Miyu`，点击 `开始`。
2. 界面语言：选择中文、English、日本語，或者 `跟随系统`。
3. 模型：在 `选择模型供应商` 里选一家供应商、填写密钥，点击 `测试连接`，再选择默认模型。具体怎么填写见 [模型](../models.md)。
4. 人格：在 `创建人格` 里填写名称、头像和具体提示词。这一步可以点击 `跳过`，跳过以后不使用人格。
5. 外观：在 `配置外观` 里选择明暗、主色、配色方案和主题。如果上一步跳过了人格，这一步也会跳过。
6. 关于你：在 `AI 怎么认识你` 里填写 `称呼` 和 `更多描述（可选）`，上面还有一行 `回复语言（可选）`。如果都空着，按钮会显示为 `跳过`。
7. 预设：在 `选择预设` 里点击一个预设；选择 `自定义` 可以自己勾选功能。
8. 语义模型：在 `是否开启内置语义模型` 里，选择 `是（推荐）` 会下载并安装语义模型，选择 `否` 则只使用关键词检索。如果软件源里没有这个软件包、本机也没有安装，就没有这一步。
9. 其他设备：在 `在别的设备上用` 里，选择 `开放` 时要先设置访问密码，设置好以后会显示其他设备使用的地址和二维码；选择 `不开放` 时只有这台电脑能打开网页界面。如果页面不是通过 `miyu web` 打开的，就没有这一步。
10. 完成：页面列出选好的模型、人格和预设，点击 `▶ 开始聊天` 进入一个新会话。

如果是从其他设备登录、并且第一次设置访问密码，第一步是 `密码`，之后从界面语言开始接着走。

走完引导后会写入 `ui.welcomed = true`，之后终端界面和网页界面都不再出现引导。更换界面语言后页面会重新载入，并从这一步继续；如果中途关掉页面，下次会从头开始。如果想再走一遍引导，运行：

```sh
miyu config set ui.welcomed false
```

然后刷新页面即可。人格、预设和外观以后都可以在设置页里修改。

## 页面布局

宽屏时页面分成三列：左栏、对话区和右栏。

### 左栏

左栏从上到下依次是：

- 头像和名字：显示正在查看的会话所用的人格，名字下面显示 `在线`、`连接中` 或 `离线`。点击头像可以打开这个人格的编辑卡片。
- `新建会话`、`全部会话`、`项目` 三行。如果有软件包添加了入口，下面会多一行 `更多`，点击后弹出菜单。
- `置顶`、`项目`、`会话` 三栏，点击栏头可以收起或展开。`会话` 按时间分组：最近、近 7 天、近 30 天、30 天前；终端集成打开的会话单独成为一组 `终端集成`，导入的存档单独成为一组 `存档`。这一栏最多列出 20 个会话，点击下面的 `查看全部` 可以进入全部会话页。
- 最底下一行：齿轮按钮打开设置，旁边的按钮切换浅色和深色。

每个会话占一行，左边的标记表示它现在的状态：正在运行的会话显示转圈；另外还有 `等你确认` 和 `已中断，等待输入` 两种状态；有没看过的内容时显示一个圆点。子代理的会话挂在派出它的会话下面，已经结束的子代理会话会收起成 `已完成 N 个`。

鼠标悬停在一行上时，右边会出现 `⋮`，菜单里有：置顶（或取消置顶）、移到项目、移出项目（只有项目里的会话才有）、复制会话编号、重命名、导出…、删除。点击删除会直接删掉会话，不会再确认。

- 多选：鼠标悬停在 `会话` 栏头上会出现多选按钮，点击后每一行前面换成勾选框，按住 `Shift` 点击可以连续选择，栏头会换成 `已选 N 个` 和全选、删除、退出按钮。按 `Esc` 退出多选。
- 拖动：按住一个会话拖到 `置顶` 栏里即可置顶，拖回下面就取消置顶，拖到一个项目上可以移进这个项目。拖动时按 `Esc` 取消。
- 宽度：按住左栏的右边沿拖动可以改变宽度，双击可以恢复出厂的宽度。宽度记在这台设备上。
- 收起：左上角的按钮可以收起、展开左栏。收起以后，把指针移到窗口的左边沿，左栏会浮出来。

### 对话区

- 左上角是会话标题，项目里的会话会在标题前面显示项目名。点击标题会出现一张卡片，列出会话编号（点击可以复制）、人格、预设和工作区。点击人格或预设那一行可以更换，更换之前会先确认，并且会先压缩上下文；人格那一行的笔按钮打开人格的编辑卡片；点击工作区那一行可以更换工作目录。
- 子代理的会话会在标题前面逐层显示上面几层会话，点击可以进入那一层；输入框正上方有 `回到「…」`，点击可以回到派出它的会话。
- 中间是时间线，详细的见下面的「时间线」。向上滚动以后，底部会出现 `回到底部`。
- 对话区右边有一条跳转条：你发的每一句话对应一条短横线，指针靠近时会列出每一句，点击哪一句就滚动到哪一句。
- 右上角是右栏的开关 `展开右栏`。
- 对话这一列的左右两个边沿都可以拖动来改变宽度，双击可以恢复出厂的宽度。

空会话（还没有发出第一句话）的输入框上面有 `选择人格`、`选择预设`、`设置工作区` 三个按钮，不点击时使用默认值。如果默认的预设或人格不能使用，输入框会锁住并显示 `请选择预设` 或 `请选择人格`，选择以后才能输入。

选择工作目录时（例如 `设置工作区`、项目的 `工作区目录`），网页界面会在这台电脑上打开系统的选择文件夹对话框，同一时间只打开一个：

| 系统 | 使用的对话框 |
|---|---|
| Linux | 依次尝试 `zenity`、`kdialog`；如果都没有安装，或者连接不上显示，就退回页面自己画的文件夹浏览器。 |
| macOS | 使用 `osascript` 的选择文件夹对话框；打开失败时退回页面自己画的文件夹浏览器。 |
| Windows | 使用 PowerShell 的选择文件夹对话框，它会显示在其他窗口上面。 |

### 右栏

点击右上角的开关可以打开右侧边栏，里面是一张张卡片：

| 卡片 | 列出的内容 | 点击后 |
|---|---|---|
| 待办 | AI 列出的待办事项，已完成的收起在 `已完成 N 项` 里。 | |
| 后台任务 | 这个会话的后台命令和子代理，子代理再派出的会挂在下面；有 `停止` 和 `全部停止` 按钮。 | 后台命令可以 `看输出`；子代理会在主区域打开它的会话。 |
| 文件修改 | 这个会话修改过的文件，可以搜索。 | 查看这次改动的差异，可以用 `上一个文件`、`下一个文件` 切换，用 `放大看` 放大查看。 |
| 展示文件 | AI 用 `show` 给你看过的文件。 | 在右栏里打开（预览工作区）。 |
| 定时任务 | 挂在这个会话上的定时任务。 | |

窗口不够宽时，右栏会盖在对话上面，点击右栏外面或按 `Esc` 可以收起。卡片的先后顺序、开关，以及每张卡片最多显示几行，在设置页 `软件包` 里 `网页` 那一段的 `右侧边栏` 里修改。右栏的左边沿可以拖动来改变宽度。

预览工作区是在右栏里查看文件的地方，它的顶部一行有：

- `预览`、`源码` 切换（两种都有时才显示）。
- 标题，点击后列出展示过的全部文件。
- 复制、下载、最大化、关闭按钮；从右侧边栏点进来时，左上角是返回按钮。

Markdown 按照回答的排版方式显示，代码带行号和语法高亮，HTML 在隔离的框里直接运行、不联网，图片可以用滚轮缩放、拖动，PDF 使用浏览器自带的阅读器。如果安装了带界面块的扩展，顶部会多出 `工作区`、`面板` 两个标签，面板里是扩展放进来的内容。

在设置页 `软件包` 里停用右侧边栏以后，右上角会换成 `预览工作区` 的开关；有新的展示文件时，这个按钮上会出现一个圆点。

## 输入框

在输入框里可以使用以下按键：

| 按键 | 作用 |
|---|---|
| `Enter` | 发送。AI 回答时也可以发送，消息会先排队，可以在状态行上 `撤回`。 |
| `Shift+Enter`、`Ctrl+J` | 换行。 |
| `Esc` 两下（1.5 秒内） | AI 回答时打断回答；空闲时清空输入框，之后在输入框为空时按 `↑` 可以找回。在整理记忆的会话里是停止整理。 |
| `↑`、`↓` | 翻看发过的消息。 |
| `Ctrl+R` | 打开输入历史列表，可以搜索；在列表里按 `Tab` 查看全文，按 `Enter` 填进输入框。 |
| `Ctrl+S` | 先把输入框里的这句话存起来；输入框为空时再按一次可以取回。Mac 上也是 `Ctrl+S`，`⌘S` 不起作用。 |
| `Tab`、`Shift+Tab` | 切换权限级别。命令、`@`、`$` 列表打开时，`Tab` 由列表使用。 |
| `/` | 焦点不在任何输入框里时，把焦点放回输入框。 |
| `Backspace` | 光标在最前面时，删掉最后一个附件。 |
| `Ctrl+,`（Mac 上是 `⌘,`） | 打开设置。 |

命令、文件、技能、会话、历史这几种列表的用法都一样：按 `↑` `↓` 选择，按 `Enter` 选定，按 `Esc` 关闭。

`Ctrl+,` 和 `⌘,` 按照打开网页界面的设备区分：Mac、iPhone、iPad 上的浏览器使用 `⌘,`，其他设备使用 `Ctrl+,`。在软件包整页里的表单中，`Ctrl+S` 和 `⌘S` 都是保存。

### 斜杠命令

在输入框里输入 `/` 会弹出命令列表，列表随着输入筛选，按 `Tab` 补全，按 `Enter` 执行。最常用的命令如下：

| 命令 | 作用 |
|---|---|
| `/new` | 新建会话。 |
| `/sessions` | 打开会话列表，可以带上搜索词。 |
| `/stop` | 打断这一轮，并停掉这个会话的后台命令、子代理和循环。 |
| `/undo` | 撤销最后一轮。 |
| `/redo` | 撤掉最后一轮，用原来的话重新来一次。 |
| `/compact` | 立即压缩上下文。 |
| `/model` | 更换这个会话的模型。 |
| `/persona`、`/preset` | 更换人格、预设。 |
| `/workspace` | 更换工作目录。 |
| `/settings` | 打开设置页。 |
| `/help` | 查看按键和全部命令。 |

全部命令见 [斜杠命令](../commands.md)。

### @ 文件和 $ 技能

在输入框里可以用 `@` 引用文件，用 `$` 选择技能：

- 输入 `@` 会弹出文件列表，从会话的工作目录里查找。按 `Tab` 进入目录，按 `Enter` 选定。图片这类文件会作为附件，其他文件会在输入框里写成一块 `[文件名]`，发送时换成路径。按退格键会整块删除。
- 输入 `$` 会弹出技能列表，选中的技能会和这句话一起交给 AI，一句话里可以选几个技能。

### 附件

- 可以把文件拖进窗口、在输入框里粘贴，或者用 `@` 选择。在触屏设备上，输入框里有一个回形针按钮 `添加附件`。
- 一次最多添加 10 个附件；每个最大 20 MiB，图片最大 5 MiB，并且每边不超过 8000 像素。
- 如果文件超过上限，网页界面会在这台电脑上查找原文件。找到后只把路径交给 AI，输入框里那张卡片会标上 `仅路径`；没有找到时标上 `未找到`，点击它可以填写完整路径。
- 查找原文件时按照名字、大小和修改时间来识别：先查找会话的工作区，再查找家目录下的下载、桌面、文稿、影片、图片、音乐，最后查找整个家目录；以点开头的文件夹、`node_modules`、`target`、macOS 的资源库和 Windows 的 `AppData` 不会进入，查找到时限为止。在装了 `plocate` 的 Linux 上和 macOS 上，会先查询系统现成的索引（`plocate`、Spotlight），马上就能返回结果，外接磁盘上的文件也找得到。Windows 上没有索引可以查询，只能一层层查找，找不到时就是 `未找到`。
- 数据根（默认是 `~/.miyu`，Windows 上是 `%USERPROFILE%\.miyu`）里的文件不能作为附件。

详细的见 [会话](../sessions.md#给-ai-文件和图片)。

### 输入框下面的一行

输入框下面的一行有这些内容：

| 位置 | 内容 | 点击后 |
|---|---|---|
| 左边 | 权限级别，显示 `⏵⏵ 开放权限` 或 `⏸ 只读`。 | 切换到另一个级别，详细的见 [权限和沙盒](../permissions.md)。 |
| 左边 | 模型名。 | 打开更换模型的菜单，菜单分 `模型`、`模型池` 两页，按 `Tab` 切换；如果模型有思考程度，指针指向它时会向右展开 `思考程度`。 |
| 中间 | `N 个后台任务`，只有在有任务运行时才显示。 | 列出后台命令和子代理，可以停止它们。 |
| 右边 | 一个圆环、累计 token（括号里是缓存命中率）和花费。 | 打开一个浮窗，分成上下文、累计消耗、花费三段。 |

圆环表示上下文占了窗口的多少。正在压缩、压缩失败或者超出窗口时，这一格会变成红色，并显示 `正在压缩上下文`、`上下文压缩失败` 或 `上下文超出窗口`。扩展的界面块也可能出现在右边。

输入框上面也有一行：左边是运行状态行（AI 正在做什么、用了多久、重试的情况），右边是长期目标和循环的下次运行时间。待办显示在这一行的上面。

## 时间线

时间线是对话区中间显示对话内容的地方。你的消息是靠右的气泡。AI 的每一轮是一块：顶部是人格的头像和名字，下面依次是过程、回答和收尾的一行。

- 过程：一步占一行，思考时显示 `正在思考` 或 `已思考`，每个工具一行，带一个图标。正在进行的这一轮是展开的，做完以后收成一行摘要，点击可以查看每一步。
- 点击一步可以展开细节：参数和结果；命令会显示命令本身和输出；修改文件会显示差异，增加和删除的内容用不同的颜色标出。文件太大或者不是文字文件时，显示 `文件太大，不显示差异` 或 `不是文字文件，不显示差异`。
- 如果脚本里调用了工具，那一步下面会显示 `脚本调用的工具 · N 次`，点开可以逐个查看。
- 子代理：派出子代理的那一步带一个机器人图标；子代理交回报告时，时间线上会记一行 `子代理已提交报告 · <标题>`，点开可以查看报告。后台命令结束时也会记一行，点开可以查看命令和输出。
- 压缩上下文、清空上下文时各记一行，分别是 `上下文已压缩` 和 `上下文已清空`。

回答的显示方式：

- 使用 Markdown 排版：标题、列表、表格、公式、脚注。代码块带语法高亮，右上角有 `复制代码`。
- mermaid 代码会画成图。
- 回答里单独占一行的图片、视频、音频地址会显示成卡片。点击图片可以放大，下面有下载、复制图片、在右栏打开（只有 AI 展示过的图片才有）、在新标签页打开几个按钮。
- 单独占一行的网页链接会显示成链接卡片，一条回答最多显示三张。

时间线上的按钮：

- 你的消息：鼠标悬停时下面会出现 `复制` 和 `编辑`。编辑时直接在气泡里修改，按 `Enter` 发送、按 `Esc` 取消，这一轮会按照新的内容重新来一次。
- AI 的一轮：收尾的一行显示时间、端点/模型、用时、用量和输出速度，后面是 `复制` 和 `重做`。
- 编辑和重做只在最新的一轮上有，AI 正在回答时没有。

### 确认和提问

AI 需要你确认一件事，或者向你提问时，整个输入框会变成一个抽屉；输入框里已经写好的字会保留，回答完以后回到输入框。

确认：第一行写着要做的事（例如 `运行命令`、`写入 N 个文件`、`安装或卸载软件包`），受保护的命令会标上 `高危命令`。下面有两个选择：

1. `允许本次`
2. `不允许`：可以在下面的 `理由（可选）` 里写一句理由，AI 能看到它。

用 `↑` `↓` 选择，按 `Enter` 确定。如果有超时，会显示 `… 后自动拒绝`。

提问：标题是 `… 提问`，每题一页，按 `←` `→` 切换题目。单选题选中就算回答；能多选的题按 `Space` 勾选。选择 `输入其他答案` 可以自己写答案，按 `N` 可以加上 `补充`。最后一页是 `确认`，在这一页按 `Enter` 即 `提交`。

按两下 `Esc` 或点击 `取消` 会关上抽屉，并打断这一轮。已经回答过的内容会留在时间线上。

## 项目

项目可以把会话分成一组，并为组里新建的会话预先设定工作目录、人格、预设和一段附加提示词。只有网页界面有项目功能。

### 新建项目

1. 点击左栏 `项目` 栏头的 `+`（或者点击全部会话里 `项目` 那一页的最后一张卡片 `新建项目`）。
2. 在 `新建项目` 里填写以下内容：

   | 项 | 说明 |
   |---|---|
   | 名称 | 必填，最多 40 个字。 |
   | 说明 | 最多 80 个字，显示在项目卡片上。 |
   | 颜色 | 从十二种颜色里选一种，或者点击 `+` 自己选择。 |
   | 工作区目录 | 项目里新建的会话在这个目录里工作；不选择时是 `默认工作区`。 |
   | 人格、预设 | 选择 `默认` 时使用设置里的默认值。 |
   | 附加提示词 | 项目里的每个会话都会带上这段提示词，最多 8000 个字。 |
   | 留言 | 开关 `能和项目外的会话互相留言`，默认关闭。 |

3. 点击 `创建`。

### 项目里的会话

- 新建：鼠标悬停在项目那一行上会出现 `⋯`，点击 `在项目里新建会话`；也可以进入项目页点击 `在项目里新建`。新会话使用项目的工作区、人格和预设，左上角显示 `项目名 / 新会话`。
- 把已有的会话放进项目：拖到左栏的项目上，或者点击 `⋮` → `移到项目`。移出项目：点击 `⋮` → `移出项目`，或者拖回下面的会话里。只有你在本机打开的主会话能放进项目，子代理的会话和通讯平台上的会话不能放进去。
- 移进项目的会话，人格、预设和工作目录保持不变。附加提示词按照会话当前所在的项目，在每一轮开始时带上；移出项目以后就不再带上。
- 在项目里的会话中输入 `/persona`、`/preset`，会提示 `这个会话在项目里，人格和预设由项目定`。
- 留言关闭时，项目里的会话只能看到同一个项目里的会话，也只能给它们发消息。打开以后，也能和项目外的会话互相留言。

左栏里每个项目占一行，点击后会在原地展开它的全部会话。项目收起、并且里面有正在运行的会话时，项目名前面会显示 `(N)`。

### 修改和删除

- 修改：点击项目那一行的 `⋯` → `项目设置`，或者点击项目页右上角的 `项目设置`。表单和新建时一样，改完点击 `保存`。
- 删除：点击 `⋯` → `删除项目`，再点击 `确认删除`；或者在 `项目设置` 左下角的 `删除项目` 上点两下。项目里的会话会一起删除，无法找回。

项目页（点击左栏的 `项目`，再点击一张项目卡片）：顶部的 `‹ 全部项目` 用来返回，下面是标题和说明，`此项目里新建会话的默认配置` 一块列出工作区目录、人格、预设、附加提示词和留言，再下面是项目里的会话。

## 全部会话

点击左栏的 `全部会话` 或 `查看全部` 可以打开全部会话页，它会占据对话区的位置。如果核心支持项目，顶部会分成 `会话`、`项目` 两页。

`会话` 页上有这些内容：

- 顶部：搜索、`多选`、`新会话`、`导入会话…`。
- 筛选：`全部`、`运行中`、`未读`。右边是 `按最近活动`，点击后切换成 `按创建时间`。
- 列表按时间分组。项目里的会话不在这里列出，要进入项目页查看。
- 多选的用法和左栏相同：可以勾选、按 `Shift` 连续选择、全选和删除。
- 点击 `导入会话…` 可以选择一个导出的 `.zip`，导入的会话放在最后一组 `存档` 里。存档只能查看，打开时会显示 `这是存档，只能看，不能接着聊`。导出的方法见 [会话](../sessions.md)。

按 `Esc` 可以关闭这一页。

## 设置

设置页是页面正中的一个弹窗，可以用左栏底部的齿轮、`/settings` 或 `Ctrl+,` 打开。`/config` 会直接进入 `模型`，`/pkg` 进入 `软件包`，`/market` 进入 `下载软件`。顶部可以搜索设置项。每改一项都会立即保存。

| 页 | 内容 |
|---|---|
| 通用 | 外观（主题、配色方案，见下面的「外观」）；显示、新会话、会话、命令、终端集成会话；`访问`。 |
| 用户 | 头像；`个人资料`：称呼、更多描述。 |
| 隐私与安全 | 权限和受保护的命令，详细的见 [权限和沙盒](../permissions.md)。 |
| 模型 | `供应商`、`默认模型`、`模型池` 三个分页，详细的见 [模型](../models.md)。 |
| 用量 | 用量和花费，可以按天、按模型、按会话、按用途查看；时间范围有今天、7 天、30 天、全部和自定义。 |
| 预设、人格 | 新建、修改、删除预设和人格，详细的见 [人格和预设](../personas-presets.md)。 |
| 记忆 | 查看、修改、整理 AI 记住的事，详细的见 [记忆](../memory.md)。 |
| 知识库 | 搜索、查看原文、添加文档、挂载文件夹，详细的见 [知识库](../knowledge.md)。 |
| 定时任务 | 查看、新建、停止、删除定时任务，详细的见 [让 AI 自己接着干](../automation.md)。 |
| 技能、脚本、MCP | 列出已安装的技能、脚本和 MCP 服务；MCP 页可以 `添加服务`。技能、脚本页的 `打开目录` 会用这台电脑的文件管理器打开对应的文件夹：Linux 用 `xdg-open`，macOS 用 `open -R`（在访达里选中它），Windows 用 `explorer`；打不开时改成复制路径。 |
| 下载软件 | 软件源里的软件包，可以搜索、安装、升级，详细的见 [软件包](../packages.md)。 |
| 软件包 | 已安装的软件包，每行一个开关；最后一段 `网页` 是网页界面自己的组件。 |
| 软件后台 | 带有自己页面的软件，点击可以打开对应的页面。 |
| 高级 | 压缩、核心、运行日志、模型目录、冷却、软件源这类设置，每组一行，点进去修改。 |

设置页 `软件包` 最后的 `网页` 一段列出了网页界面自己的组件，例如 `右侧边栏`、`系统通知`、`右边的跳转条`、`mermaid 图`。每个组件都有开关，有设置项的可以点进去修改。这些开关只记在这台设备的这个浏览器里。

## 外观

外观设置在设置页 `通用` 的最上面，分成两组：

- 主题：`吉祥物` 一行可以选择 `无`、`Deniro`，或者外观包带的吉祥物。安装了其他主题时会多一行 `主题`，用下拉菜单选择形状和材质（圆角、阴影、边框、字体），出厂的是 `默认主题`。如果打开了其他的时间线、回答显示样式，会多一行 `输出样式`。
- 配色方案：`明暗` 可以选择 `跟随系统`、`浅色` 或 `深色`；下面每张卡片是一个配色方案；`主色` 从候选颜色里选择。

出厂带有以下配色方案：

| 配色方案 | 颜色的来源 |
|---|---|
| 自动（出厂） | 如果这个会话的人格有主色，就使用人格的主色；没有的话使用桌面壁纸的颜色；都没有时使用默认配色。 |
| 跟随人格 | 使用人格自己选的主色；没有选时从头像里取色。 |
| 跟随壁纸 | 使用这台电脑桌面壁纸的颜色，换壁纸后当场跟着变化。在其他设备上打开时没有这一项。 |

左栏底部的按钮也可以切换浅色和深色。

`跟随壁纸` 会先查找 matugen 生成的那一份颜色（Linux 上是 `$XDG_CACHE_HOME/miyu/matugen.json`，没有设置这个变量时是 `~/.cache/miyu/matugen.json`；macOS 上是 `~/Library/Caches/miyu/matugen.json`；Windows 上是 `%LOCALAPPDATA%\miyu\matugen.json`）；找不到时，会按照这台电脑的桌面查找壁纸图片：

| 系统 | 读取壁纸的位置 |
|---|---|
| Linux | KDE、GNOME、XFCE、Cinnamon、MATE 的桌面设置（根据 `XDG_CURRENT_DESKTOP` 识别，Unity、Budgie、Pantheon 按照 GNOME 的方式读取）；awww、swww、hyprpaper（Hyprland 下）、swaybg、wpaperd、waypaper；在 X11 下还识别 feh、nitrogen。 |
| macOS | 系统保存壁纸设置的文件；读取不到时询问 System Events，第一次会弹窗询问是否允许，不允许就读取不到。HEIC 格式的壁纸会用系统的 `sips` 转换成 JPEG。 |
| Windows | 注册表 `HKCU\Control Panel\Desktop` 里的 `WallPaper`；读取不到时（例如使用幻灯片放映），使用 Windows 转换好的那一张 `%APPDATA%\Microsoft\Windows\Themes\TranscodedWallpaper`。 |

视频壁纸读取不到。为了跟上壁纸的变化，跟随壁纸会监视壁纸图片和保存设置的文件，一有改动就重新取色（Linux 用 inotify，macOS 用 FSEvents，Windows 用 ReadDirectoryChangesW）。hyprpaper、swaybg 这类只通过命令换壁纸、不写文件的程序监视不到，换成另一个壁纸程序时也监视不到；这两种情况下，会在浏览器窗口重新获得焦点时再查找一次。

背景图可以跟着人格设置：在人格的编辑卡片里的 `背景图` 选择一张图片，使用这个人格的会话，对话区就会铺上这张图。

出厂的主题只有 `默认主题`。另外还带有一个 `像素风` 主题，默认停用，需要在设置页 `软件包` 的 `网页` 一段里打开，再到 `主题` 里选择。软件源里有社区制作的网页外观包（以 `webui-theme-` 开头），安装以后会出现在 `主题` 和 `配色方案` 里，安装方法见 [软件包](../packages.md)。安装或卸载外观包以后，页面会提示 `外观「…」有变化，刷新页面后生效`。

输入 `/gallery` 会打开 `皮肤样张`：这是一个只存在于这一页的会话，把各种元素都摆了出来，更换主题时可以对照着看。

## 访问和安全

在这台电脑上用 `miyu web` 打开，或者直接打开 `http://127.0.0.1:<端口>` 时，不需要密码。从其他设备访问时需要访问密码。

访问设置在设置页 `通用` 最下面的 `访问` 卡片里（`miyu web --settings access` 会直接打开这里）：

- `局域网访问` 开关，旁边显示 `已开启` 或 `仅本机`。如果还没有设置访问密码就打开开关，会先弹出 `设置访问密码`，设置好以后点击 `设置并打开`。
- 开关打开时，下面还有几行：
  - `监听地址和端口`：`0.0.0.0` 表示这台电脑的所有地址，也可以只填其中一个地址。本机和局域网打开时都使用这里的端口。修改以后网页界面会当场切换过去，端口变化时会提示 `端口换成了 …，这个页面照旧连着`。
  - `访问密码`：点击 `设置` 或 `修改`。在其他设备上修改时，要先填写 `当前访问密码`。
  - `在别的设备上打开`：显示二维码和地址，可以点击 `复制`；其他网卡上还有地址时，点击 `更多地址` 查看。用手机扫码、输入访问密码就能进入。如果在 macOS 上其他设备打不开，按照提示到 `系统设置 → 网络 → 防火墙 → 选项` 里允许 `miyu-web` 的传入连接。

局域网访问使用明文 HTTP，只在你信得过的网络里打开它。在其他设备上关掉局域网访问时，那台设备会当场断开。

其他设备上的登录页是 `登录 Miyu`：输入访问密码；勾选 `自动登录` 后，这个浏览器 30 天内不用再输入，不勾选时，关掉标签页以后就要重新输入。如果忘了访问密码，在安装 Miyu 的电脑上运行 `miyu web --reset`；要让所有浏览器重新登录，运行 `miyu web --logout`。

以下功能只能在安装 Miyu 的那台电脑上使用，在其他设备上用不了：

- 用 `@` 选择文件，为会话或项目选择工作目录。
- 打开文件夹的按钮，在其他设备上会换成复制路径。
- 配色方案 `跟随壁纸`。
- 超过附件上限、只交路径的文件。
- 知识库挂载文件夹，添加运行本机命令的 MCP 服务。

系统托盘菜单里的 `局域网访问` 和 `在手机上打开…` 做的是同一件事，详细的见 [系统托盘](applet.md)。监听地址和端口的配置键，以及 SSH 端口转发、反向代理的限制，见 [常驻和服务器](../service.md#从其他电脑和手机打开网页界面)。

## 通知

AI 做完一轮、有问题等你回答、或者需要你确认时，浏览器会弹出系统通知：

- 正在查看的会话，只有这个标签页不在前台时才弹出通知；其他会话在前台时也会弹出，但不发出声音。
- 通知的标题是会话所用人格的名字，没有人格时显示 `Miyu`；正文是 `<会话标题> · 回答完了`、`… · 等你回答` 或 `… · 等你确认`。点击通知会回到那个会话。
- 每次新开会话的定时任务运行结束时，会弹出 `定时任务跑完了` 或 `定时任务没跑完`。
- 子代理的会话和一次性的会话不弹出通知。
- 系统托盘在运行时，没有在网页界面里打开的会话由托盘弹出通知，网页界面只为这个标签页里打开的会话弹出通知。

第一次在输入框里发送消息时，浏览器会询问一次是否允许通知。如果不想要通知，在浏览器里拒绝，或者在设置页 `软件包` 的 `网页` 一段里关掉 `系统通知`。关掉标签页以后网页界面不再弹出通知；如果想继续收到通知，需要安装系统托盘。

## 软件包添加的内容

软件包可以往网页界面里添加几样东西，安装并启用后就会出现，停用后就会消失：

- 后台页：软件包自己的一整个页面，列在设置页的 `软件后台` 里，点击即可打开。页面顶部有一条窄栏，左边是 `返回`；网址带有 `#package=<编号>`，可以收藏，也可以在新标签页里打开。运行 `miyu web --package <编号>` 可以直接打开它。
- 界面块：扩展放进来的一小块文字和按钮（例如天气、构建状态），出现在新会话的首页、右栏的 `面板`、输入框下面一行的右边，或者单独占一整页。扩展的程序没有运行时显示 `未运行`。
- 外观：主题、配色方案、吉祥物，详细的见上面的「外观」。

这些内容的制作方法见 [往界面上放东西](../../dev/ui-surfaces.md)。

## 常见问题

| 看到的提示 | 解决方法 |
|---|---|
| `端口 8300 已被占用` | 用 `miyu web --port <端口>` 换一个端口，或者修改 `web.port`。 |
| `miyu: 无法打开浏览器，请手动打开上面的地址` | 按照输出的地址自己打开；没有桌面的机器使用 `miyu web --print`。Linux 上交给浏览器依靠的是 `xdg-open`，没有安装时需要装上。 |
| `连不上网页软件`、`网页软件没有在运行。` | 网页软件没有在运行（被 `miyu web stop` 或托盘的 `停止` 停掉了、电脑重启过，或者设置了 `web.idle_seconds` 后空闲退出了），在终端里运行 `miyu web` 即可。 |
| `连了很久还没连上。…` | 如果这台设备开着代理或 VPN，关掉它们，或者把这个地址设置成直连。 |
| `核心版本过旧` | 升级核心，再刷新页面。 |
| `访问密码错误` | 重新输入；如果忘了密码，在安装 Miyu 的电脑上运行 `miyu web --reset`。 |
| `尝试次数过多，N 秒后再试` | 等提示里写的秒数过去再试。 |
| `还没设访问密码` | 在安装 Miyu 的电脑上运行 `miyu web --settings access` 设置好密码，再从这里登录。 |
| `这个链接已用过或已过期：在终端里再运行一次 miyu web` | 按照提示操作即可；带票据的链接 60 秒内有效，并且只能使用一次。 |
| `登录已失效，请重新输入访问密码` | 重新输入访问密码。 |
| `在这台电脑上本来不用输入密码，这次没连上核心…` | 在终端里运行 `miyu web` 查看原因。 |
| `外观「…」有变化，刷新页面后生效` | 刷新页面即可。 |
| `复制不了，请长按选中文字后复制` | 通过局域网用 `http` 打开的页面无法使用剪贴板，需要长按选中文字再复制。 |

网页界面的日志在 `~/.miyu/var/log/webui/web.log`。其他问题见 [出了问题怎么查](../troubleshooting.md#网页界面无法打开)。
