# 终端界面

> <sub>本文档由 Anthropic 的 Claude Fable 5.2 生成。</sub>

这一页是在终端里使用 Miyu 的完整说明：屏幕上每一部分是什么、每个按键的作用、怎么把界面调成自己顺手的样子，以及怎么在 shell 的提示符后面直接和 AI 对话。

## 打开终端界面

在终端里运行 `miyu` 或 `miyu tui` 就可以打开终端界面。直接运行 `miyu` 时，打开的是设置里 `默认界面`（`ui.head`）指定的界面，出厂设置就是终端界面。如果核心没有在运行，会先启动核心。

```text
miyu tui [--resume <编号> | --page <页> | config]
```

| 写法 | 做什么 |
|---|---|
| 不带参数 | 按照 `启动时打开`（`ui.startup`）的设置，开一个新会话或者接着最近的那个会话 |
| `--resume <编号>` | 打开这个会话，编号要写完整；如果打不开，就报错退出 |
| `--page config`、`config` | 只打开设置页，不进入会话；在设置页的菜单上按 `Esc` 退出 |
| `--page oobe` | 重新走一遍首次引导 |
| `-h`、`--help` | 输出帮助 |

如果页名认不出来，会照常打开首页。终端界面由软件包 `tui` 提供，如果卸载了，可以用 `miyu pkg install tui` 装回来。

可以用下面几个环境变量调整终端界面：

| 变量 | 做什么 |
|---|---|
| `MIYU_COLOR` | 强制指定色深：`truecolor`（或 `24bit`）、`256`、`16`、`none` |
| `NO_COLOR` | 设成任意非空的值就不显示颜色，只保留加粗、斜体这类修饰 |
| `MIYU_TUI_IME=0` | 不替你切换输入法（见下面的「输入法」） |

如果只想在这一次打开时带上环境变量，运行：

```bash
MIYU_COLOR=truecolor miyu
```

```powershell
$env:MIYU_COLOR = 'truecolor'
miyu
```

在 PowerShell 里这样设置的环境变量，在这个窗口里会一直有效。

## 对终端的要求

终端界面的一部分功能要终端支持才能用。下表列出 Miyu 怎么判断终端是否支持，以及不支持时会怎样：

| 需要什么 | 怎么判断 | 缺了会怎样 |
|---|---|---|
| 真彩色 | `COLORTERM` 是 `truecolor` 或 `24bit`；`TERM` 里带有 `kitty`、`wezterm`、`alacritty`、`ghostty`、`foot`；`TERM_PROGRAM` 是 `iTerm.app`、`WezTerm`、`ghostty`、`vscode`。Windows 上没有设置 `TERM` 的也算支持 | 如果 `TERM` 带有 `256color`，换成最接近的 256 色，否则换成 16 色；如果 `TERM` 是空的或者是 `dumb`，不显示颜色 |
| Nerd Font | 不会自动判断，首次引导里会问你看到的是图标还是方块 | 图标显示成方块、问号。可以改用普通字符：运行 `/icons`，或者在设置页的 `外观 → 图标` 里修改 |
| 鼠标 | 程序会接管鼠标 | 终端自己的选区用不了，拖选、复制由 Miyu 自己完成（见「鼠标」） |
| 图片 | 打开时询问一次终端，最多等 2 秒，能识别 kitty、sixel、iTerm2 三种协议 | 图片、公式、Mermaid 图都显示成源码 |
| 键盘协议 | 支持 kitty 键盘协议的终端能报告 `Shift+Enter`、`Ctrl+Enter` | 换行要改用 `Alt+Enter` 或 `Ctrl+J`，不能用 `Shift+Enter` |
| 前台、后台 | 终端会报告窗口获得、失去焦点 | 在报告不了焦点的终端里，回答完成后不弹通知（kitty 除外） |

在 Linux 控制台（`TERM=linux`）里，如果没有设置过图标，默认使用普通字符；如果没有设置过主题，默认使用纯 ASCII 的那一套主题。如果界面语言是中文或日文，会提示一次 `Linux 控制台显示不了中文：可在设置里把界面语言换成英文`。

在 Windows Terminal 里（通过环境变量 `WT_SESSION` 判断，在 Windows Terminal 里运行 WSL 也算），输入框空着时不显示轮换的提示，首页的那一行提示也不显示。

### tmux、SSH、herdr

在 tmux、herdr 里使用，或者通过 SSH 连接到其他机器使用时，有以下几点不同：

- 复制通过终端的 OSC 52 完成，所以通过 SSH 连接时也能复制到你本地的剪贴板。如果终端不支持 OSC 52，就复制不进去，也不会报错。
- `Ctrl+V` 读取的是运行 Miyu 的那台机器的剪贴板。通过 SSH 连接时，要粘贴本地剪贴板里的内容，需要使用终端自己的粘贴（kitty 是 `Ctrl+Shift+V`）。
- 在 tmux、herdr 里，通知交给系统弹出（终端自己的通知传不出去）。
- 在 tmux 里无法询问终端的颜色，所以配色跟随终端时只使用终端的 16 色。如果想要真彩色的那一套配色，需要打开 tmux 的透传（passthrough）。
- 如果同一个界面有时在能显示图片的终端里看、有时在不能显示的终端里看（例如在 herdr 里用手机连进来），可以运行 `/images off`，让这一次运行先不显示图片，运行 `/images on` 恢复显示。这两条命令不修改配置。

## 首次引导

第一次打开终端界面时，连上核心以后整个屏幕都是首次引导。走完引导后会写下 `ui.welcomed`，以后不再出现。如果中途按 `Ctrl+C`，程序会退出，并且不记录为走完，下次会从头开始。如果想再走一遍，运行 `miyu tui --page oobe`。

欢迎页上写着 `欢迎使用 Miyu` 和 `花一分钟配置模型和人格`，按 `Enter` 开始。最上面一行显示进度：语言、操作方式、图标、模型、货币、人格、配色方案、关于你、预设。每一步都可以按 `Esc` 回到上一步。

1. 界面语言：第一行是 `跟随系统（…）`，下面是中文、English、日本語。选择以后界面会立即切换。
2. 你喜欢的操作方式：可以选择 `方向键`（↑↓ 上下移动，直接打字搜索）或 `Vim`（j/k 上下移动，按 / 搜索），选择结果写进 `tui.keys`。
3. 图标：这一步会问 `你看到的是图标，还是方块或乱码？`。选择 `图标` 会使用 Nerd Font 图标，选择 `方块或乱码` 会使用普通字符，选择结果写进 `tui.icons`。
4. 选择模型供应商：选择一家供应商，填写密钥，点击 `测试连接`（会发送一条测试请求，消耗少量额度），连接成功后选择模型。列表里还有 `更多供应商…` 和 `自定义…`（填写地址和接口类型：OpenAI 兼容、Anthropic、OpenAI Responses）。如果已经配置过模型，会问你 `使用` 还是 `更换`。这一步不能跳过。供应商、密钥、模型的详细说明见 [模型](../models.md)。
5. 希望金额以什么货币显示：列表里有二十种常见的货币，最后一行 `其他…` 可以填写三个字母的货币代码。选择结果写进 `usage.currency`，花费会按照近期的汇率换算成这种货币。
6. 创建人格：可以填写名字（必填）、简单描述、头像、具体人格提示词、示范对话、人设提醒短语。比较长的几项按 `Enter` 进入编辑窗口，按 `Ctrl+G` 用外部编辑器编写；Windows 上没有外部编辑器这个选项，需要在编辑窗口里编写或者粘贴进去。选择 `下一步` 会创建这个人格并设成默认人格；选择 `跳过` 不创建人格。详细的见 [人格和预设](../personas-presets.md)。
7. 配色方案：可以选择明暗（自动、深色、浅色）和配色（自动、跟随头像、跟随壁纸、终端配色），光标移到哪一种，界面就会立即变成哪一种。如果人格没有头像，会多一项 `形象`，可以选择显示或不显示吉祥物（`开启会提高 CPU 占用，拖慢启动速度`）。选择跟随头像、跟随壁纸时，会多一项 `主色`。另外还有一项 `铺底色`。如果上一步跳过了人格，这一步也会跳过。
8. AI 怎么认识你：这一步有 `AI 用什么语言回复`、`AI 怎么称呼你`、`更多描述（可选）` 三项，都可以不填，也可以选择 `跳过`。
9. 选择预设：每个预设显示成一块，按空格查看详情，按 `Enter` 选定并设成默认预设；最后一块是 `自定义`，可以自己取名、勾选功能。
10. 是否开启内置语义模型：只有软件源里有语义模型的软件包时才会出现这一步。选择 `是` 会立即下载并安装，选择 `否` 只使用关键词检索。详细的见 [记忆](../memory.md)。
11. 完成：页面上写着 `模型 … · 人格 … · 预设 …`，按 `Enter` 开始对话。紧接着打开的新会话会直接使用这里选定的人格和预设。

以后想修改这些设置，都可以在设置页（`/settings`）里修改。

## 屏幕布局

空会话显示的是首页：输入框在屏幕中间，上面是首页的几项内容（如果打开了 `首页显示形象`，还会显示头像或吉祥物）。发出第一句话以后，屏幕会变成下面这样：

```text
┌─────────────── 主列 ───────────────┐│┌── 侧边栏 ──┐
 正文顶上（往上翻时钉着你说的那句话）  ││ 头像
                                     ││ 会话名、#短编号
 时间线                               ││ 工作区
                                     ││ 上下文
 输入框上面（待办、运行状态、排队的话）  ││ 用量
 ╭ 输入框 ──────────────────────╮     ││ …
 ╰──────────────────────────────╯     ││
 底栏：权限级别 · 模型      用量        ││
```

| 位置 | 显示什么 |
|---|---|
| 时间线 | 你说的话、AI 的回答，以及 AI 每一步做了什么（见「阅读时间线」） |
| 正文顶上 | 往上翻页、你说的那句话已经滚出屏幕时，顶上会钉住一行，显示那句话，点击它可以跳回去 |
| 输入框上面 | 待办；AI 回答时的运行状态行（`思考中`、`回答中` 和用时）；排着队的话；连不上核心时用红字写出原因；临时的提示 |
| 输入框 | 你输入的文字。输入框最多长到 8 行，超出的部分在框里滚动 |
| 底栏 | 左边是权限级别（`⏵⏵ 开放权限`、`⏸ 只读`）、模型和供应商、思考程度；右边是速度和用量那一格（例如 `◔ 128.4k · ¥0.42`）。有后台命令时，中间会多一个按钮 `N 个后台命令`。窗口变窄时，先去掉右边的格子，再把权限级别收成只剩图标、模型只显示名字的最后一段，最后去掉供应商名 |
| 侧边栏 | 窗口宽度达到 120 列以上、并且不在首页时，侧边栏出现在右边，宽 38 列。侧边栏可以滚动，也可以拖选文字 |

### 侧边栏的部件

侧边栏由下面几个部件组成，出厂时按这个顺序排列：

| 部件名 | 显示什么 | 点击的作用 |
|---|---|---|
| `avatar` | 人格的头像，人格没有头像时显示吉祥物。这个部件受 `侧边栏显示形象`（`tui.mascot_sidebar`，出厂关闭）控制；关闭时，如果人格有头像，仍然会显示头像 | |
| `session` | 会话名，下面是 `#短编号`，再下面是人格和预设 | 点击短编号复制完整的会话编号 |
| `cwd` | `工作区`：这个会话的工作目录 | |
| `context` | `上下文`：已经用了多少 / 窗口有多大 · 百分比 | |
| `usage` | `用量`：一共多少 token、输入和输出各多少、缓存命中率、压缩了几次、缓存断裂了几次、花费 | |
| `loops` | 这个会话上挂着的循环（`/loop`） | |
| `jump` | `跳转消息`：这个会话里你最近说的几句话，新的在下面，当前正在看的那句前面有箭头。显示的条数由 `tui.sidebar_jumps`（出厂 `8`）决定 | 点击一句话跳到那里 |
| `files` | `文件修改`：这个会话修改过的文件，一行一个，后面写着增加和删除的行数，最多 8 个。没有修改过文件时不显示 | 点击一行打开 `/files` 页面，并选中这个文件 |
| `recent` | `最近会话`：一行一个会话。行首是黄色的 `?` 表示在等你确认或回答，转圈表示正在运行，圆点表示已经做完但你还没看，箭头表示当前的会话。显示的个数由 `tui.sidebar_sessions`（出厂 `8`）决定 | 点击一行切换到那个会话 |

如果安装了带界面块的软件包，它的块会接在这几个部件后面。

### 选择显示的部件

侧边栏、底栏、输入框上面、正文顶上各有一个部件列表。这些列表在设置页里没有，需要用 `miyu config edit` 手动修改系统配置 `~/.miyu/etc/config.toml`（数据根默认是 `~/.miyu`，Windows 上是 `%USERPROFILE%\.miyu`）：

| 键 | 出厂的部件 |
|---|---|
| `tui.side` | 上表中的九个部件 |
| `tui.footer` | 左段 `level`、`model`，右段 `usage` |
| `tui.above` | `todo` |
| `tui.top` | `prompt` |

每个部件写成一个行内表：`part` 是部件名；`shown = false` 表示隐藏（出厂是 `true`，即显示）；`rows` 是最多显示几行（`0` 表示不限制，底栏只有一行，不看这一项）。写进列表的部件按照写的顺序排列，没有写到的部件按照出厂的顺序接在后面。如果部件名认不出来，这个部件不会显示，并提示一次 `挂载位里有不认识的部件：…`。

```toml
[tui]
# 最近会话放最上面、最多 5 行；不要头像
side = [{ part = "recent", rows = 5 }, { part = "avatar", shown = false }]
# 底栏不写模型
footer = [{ part = "model", shown = false }]
```

保存以后，界面会立即按照新的配置重新绘制。如果只是想少显示几个会话或几句话，修改 `tui.sidebar_sessions`、`tui.sidebar_jumps` 就可以了，设成 `0` 表示不显示那一块。

## 按键

下面按使用场景列出按键。如果有列表或框打开着，按键会先交给它处理；随时可以运行 `/help` 查看按键和全部命令。

### 输入框里

在输入框里打字时，可以使用这些按键：

| 键 | 做什么 |
|---|---|
| `Enter` | 发送；如果输入的是命令，就执行命令。框里只有空白时不发送 |
| `Shift+Enter`、`Alt+Enter`、`Ctrl+J` | 换行 |
| `↑`、`↓` | 在输入框里上下移动；在第一行再按 `↑`、在最后一行再按 `↓`，会翻阅输入历史。如果框里原来就有文字，只翻阅以这些文字开头的历史 |
| `Ctrl+R` | 打开输入历史列表 |
| `←`、`→`、`Home`、`End` | 移动光标，`Home`、`End` 移到这一行的开头和结尾；按住 `Shift` 时是选中文字 |
| `Ctrl+←`、`Ctrl+→` | 按词移动光标，按住 `Shift` 时是选中文字 |
| `Ctrl+A` | 回到输入框的开头 |
| `Ctrl+W`、`Alt+Backspace`、`Ctrl+Backspace` | 删除前一个词 |
| `Backspace`、`Delete` | 删除一个字 |
| `Ctrl+C` | 有选中的文字时复制它；没有选中文字、但框里有字时清空输入框，并提示 `已清空 · ↑ 恢复`，在输入框空着时按 `↑` 可以把文字拿回来 |
| `Ctrl+S` | 暂存：把框里的文字存起来，并清空输入框；再按一次取回。如果暂存区和输入框里都有文字，两边互换 |
| `Ctrl+V`、`Alt+V` | 读取剪贴板并粘贴，剪贴板里的图片、复制的文件会变成附件（见「输入框的几种写法」）。在 Windows Terminal 里粘贴图片要用 `Alt+V` |
| `Ctrl+Shift+V` | 终端自己的粘贴，粘贴进来的全部是文字 |
| `Ctrl+G` | 用外部编辑器编写这一句话：使用 `$VISUAL`，没有设置时使用 `$EDITOR`，都没有设置时使用 `vi`。保存并退出编辑器后，文字会回到输入框。Windows 上没有这个功能，按下去不起作用；长的话可以直接在输入框里写（用 `Shift+Enter`、`Alt+Enter`、`Ctrl+J` 换行），或者粘贴进来 |
| `Esc` | 取消选中的文字；用 `/edit` 编辑上一句话时，取消编辑。`Esc` 不会清空输入框 |
| `Ctrl+D` | 输入框空着时退出程序 |

### 时间线

查看时间线时，可以使用这些按键：

| 键 | 做什么 |
|---|---|
| `PgUp`、`PgDn` | 往上、往下翻半屏。往上翻以后，新出现的文字不会把你正在看的位置挤走 |
| `Ctrl+End` | 回到最底部，并跟随最新的内容。往上翻时，右下角会显示 `跳转到底部（Ctrl+End）↓`，有新内容时它会变亮 |
| `Ctrl+L` | 清屏：把屏幕上的内容顶上去，往上翻仍然能看到。AI 正在回答时不能清屏 |
| `/jump` | 列出你在这个会话里说过的话，按 `Enter` 跳过去，那句话会出现在屏幕的第一行 |
| `Ctrl+C` | 在正文里拖选了文字时，复制选中的文字。按 `Esc` 取消选区 |

展开、收起时间线上的一个步骤需要用鼠标点击。

### AI 在回答时

AI 正在回答时，下面这些按键的作用和平时不同：

| 键 | 做什么 |
|---|---|
| `Enter` | 照常发送。这句话会排进队列，等这一轮结束后接着发送。排着队的话显示在输入框上面，点击其中一条可以把它撤回到输入框 |
| `Esc` `Esc` | 按一下会提示 `再按一次 Esc 中断`，1.5 秒内再按一下会打断这一轮，排着队的话接着发送。如果 AI 还没有开始做事、也没有排着队的话，打断后会撤销这一轮，你说的那句话放回输入框 |
| `Ctrl+C`（输入框空着时） | 打断这一轮，排着队的话不发送，退回到输入框 |
| `Ctrl+Enter` | 如果输入框里有字，先把它排进队列，然后立即打断这一轮，排着队的话马上发送。AI 没有在回答时，作用和 `Enter` 相同 |
| `Ctrl+L` | 不能清屏，会提示 `回答进行中，无法清屏` |

AI 在整理记忆时，按两下 `Esc` 可以停止整理。在查看子代理时，或者主会话空闲、但还有子代理在运行时，在输入框空着时按两下 `Esc` 会停掉子代理，按 `Ctrl+C` 也会停掉它们。

### 确认框和提问框

AI 需要你确认一个步骤、或者向你提问时，输入框的位置会换成一个框，这时全部按键都交给这个框处理：

| 键 | 做什么 |
|---|---|
| `↑`、`↓`（`j`、`k`） | 选择 |
| `1` 到 `9` | 直接选择第几项 |
| `Enter` | 确定、提交 |
| 空格 | 在可以多选的题目里勾选、取消勾选 |
| `←`、`→`（`h`、`l`）、`Tab`、`Shift+Tab` | 在几道题目之间切换 |
| `n` | 在提问里填写补充说明；在确认里把光标移到 `不允许`，填写理由 |
| `Ctrl+J`、`Ctrl+K`、`Ctrl+↑`、`Ctrl+↓` | 滚动查看将要运行的命令或预览 |
| `Ctrl+V` | 粘贴一张图片：在提问里，图片附在当前这道题上；在确认里，只有选中 `不允许` 时才接收图片 |
| `Backspace` | 没有在写字时，删除这一页的最后一张图片 |
| `Esc` `Esc` | 取消 |

在写字时，`Enter` 是保存，`Shift+Enter`、`Alt+Enter`、`Ctrl+J` 是换行，`Esc` 是退出编辑。确认框上的三个选项、等待多久后自动拒绝，见 [权限和沙盒](../permissions.md#确认框)。

### 列表和弹出的框

`/` 命令列表、`@` 文件列表、`$` 技能列表、输入历史、`/sessions`、`/model` 这些列表和框里，可以使用这些按键：

| 键 | 做什么 |
|---|---|
| `↑`、`↓`，`Ctrl+K`、`Ctrl+J` | 选择 |
| `Enter` | 执行、选定 |
| `Esc` | 关闭 |
| 打字 | 在命令列表、`@` 列表、`$` 列表里，接着打字就是筛选；在输入历史、会话列表、模型列表里，打字是搜索 |
| `Tab` | 在命令列表里补全命令名；在 `@` 列表里进入这个目录 |

在不能打字的框里（`/help`、`/theme`、`/language`、`/effort`、`/usage`、`/status`、`/tool-list`、`/context`、`/export`、后台面板、选择人格和预设的框），直接按 `j`、`k` 也能上下移动。下面几个框有自己的按键：

| 框 | 键 |
|---|---|
| `/sessions` 会话列表 | 空格勾选，`Ctrl+A` 全选，`Ctrl+P` 置顶或取消置顶，`Ctrl+D` 删除（需要按两下） |
| `/status`、`/tool-list` | `c` 复制全部内容 |
| `/context` 上下文明细 | `Enter` 展开，`c` 复制 |
| `/usage` | `Tab`、`←`、`→` 切换页面，`t` 在 token 和花费之间切换 |
| 后台面板 | `Enter` 展开或收起一条命令的输出，`x` 停掉这条命令 |
| 新会话选择人格、预设的框 | `e` 编辑选中的人格或预设；这个框打开时，`Ctrl+C`、`Ctrl+D` 会退出程序 |
| `/files` 页面 | `↑`、`↓`（`j`、`k`）切换文件，`PgUp`、`PgDn`、空格滚动差异，`Home`、`End` 跳到开头和结尾，`Esc` 或 `q` 返回 |

### 全局

下面这些按键在任何时候都可以使用：

| 键 | 做什么 |
|---|---|
| `Tab`、`Shift+Tab` | 在开放权限和只读之间切换。命令列表、`@` 列表、`$` 列表打开时，`Tab` 交给列表处理，`Shift+Tab` 仍然可以切换。权限级别的说明见 [权限和沙盒](../permissions.md) |
| `↓`（输入框空着时） | 把焦点移到底栏的后台按钮和子代理状态行上。然后用 `↑`、`↓`、`←`、`→` 移动，按 `Enter` 打开后台面板或者切换到那个子代理的会话，按 `x` 停掉选中的子代理，按 `Esc` 回到输入框 |
| `Ctrl+Z` | 把程序挂起到后台，运行 `fg` 恢复。Windows 上没有这个功能 |
| `Ctrl+D` | 输入框空着时退出程序；也可以运行 `/exit` 退出 |

在查看子代理的会话时，如果这个子代理已经停止或者已经报告完成，在输入框空着时按 `Esc` 可以回到主会话。

### Vim 按键模式

把 `tui.keys` 设成 `vim` 以后（在设置页的 `通用 → 交互 → 按键模式` 里修改，或者在首次引导的第二步选择 `Vim`），下面几个地方会换成另一套按键：

| 在哪 | 方向键（`arrows`，出厂） | Vim（`vim`） |
|---|---|---|
| 会话列表、模型列表、输入历史列表、`/jump` | 直接打字搜索，`↑`、`↓` 选择 | `j`、`k` 选择；按 `/` 开始搜索，搜索时用 `Ctrl+J`、`Ctrl+K` 选择，按 `Enter` 收起搜索框（筛选结果保留），按 `Esc` 取消搜索；没有在搜索时，按 `Esc` 先清除保留的筛选，再按一次才关闭 |
| `@` 文件列表、`$` 技能列表 | 按 `Esc` 关闭列表 | 按 `Esc` 进入 `在列表里选`：`j`、`k` 选择，`h`、`l` 移动输入框里的光标，`/` 筛选，`Enter` 插入，再按 `Esc` 关闭 |

其他地方的按键在两种模式下都一样。

### 输入法

在 Linux 上使用 fcitx5 输入法时，如果你在列表里按 `j`、`k` 这类不是用来打字的键，Miyu 会先把输入法切换成英文，回到打字时再切换回来；终端不在前台时不会切换。如果不想要这个功能，在打开终端界面时设置 `MIYU_TUI_IME=0`。这个功能只支持 fcitx5（环境变量 `XMODIFIERS`、`GTK_IM_MODULE`、`QT_IM_MODULE` 里写着 fcitx 时才会生效，用 `fcitx5-remote` 切换），macOS、Windows 上的输入法不会替你切换。

## 鼠标

终端界面接管了鼠标，在不同的位置可以用鼠标做这些事：

| 在哪 | 能做什么 |
|---|---|
| 时间线 | 点击一段内容或一个步骤，展开或收起它；拖选文字，松开鼠标就会复制（选区会保留，按 `Ctrl+C` 还能再复制一次）；点击链接、路径，用系统的程序打开；点击 Mermaid 图，用程序打开大图；滚轮滚一格移动三行 |
| 时间线右边的那一列 | 把指针放上去会出现滚动条，可以拖动，也可以点击 |
| 输入框 | 点击放置光标，拖动选中文字，双击选中一个词；点击附件块、文件块，用系统的程序打开那个文件 |
| 排着队的话 | 点击一条，把它撤回到输入框 |
| 正文顶上钉着的那句话 | 点击跳回那句话 |
| 底栏 | 点击用量那一格打开 `/context`；会话卡住时，点击 `压缩` 和运行 `/compact` 的效果相同；点击后台按钮打开后台面板 |
| 侧边栏 | 用滚轮滚动；拖选文字后按 `Ctrl+C` 复制；点击短编号、最近会话、跳转消息、文件修改的效果，见上面的部件表 |
| 列表、框 | 把指针放上去就会选中，点击一下执行，用滚轮滚动 |
| 确认框、提问框 | 把指针放上去就会选中，点击一下等于按 `Enter` |

点击链接、路径、附件块时，Miyu 会交给系统打开：Linux 用 `xdg-open`，macOS 用 `open`，Windows 用 `rundll32.exe url.dll,FileProtocolHandler`。只会打开 `http`、`https`、`file` 链接和本机上已经存在的文件。

AI 用 `show` 给你看的文件、Mermaid 的大图，会先交给这种文件的默认程序打开，没有默认程序时交给浏览器：

| 系统 | 默认程序 | 浏览器 |
|---|---|---|
| Linux | 用 `xdg-mime` 查询这种文件的默认程序，用 `gio launch` 启动它；没有 `gio` 时用 `gtk-launch`，再没有就用 `xdg-open` | 使用 `$BROWSER`；没有设置时依次尝试 `firefox`、`chromium`、`chromium-browser`、`google-chrome`、`google-chrome-stable`、`brave-browser`、`microsoft-edge` |
| macOS | `open` | 先用 `$BROWSER`，再用 `open -a Safari` |
| Windows | 交给系统（`rundll32.exe`）处理，因为无法判断有没有能打开它的程序，所以交出去就算打开了 | `$BROWSER` |

如果都打不开，卡片上会写 `没有能打开它的程序：…` 和文件的路径。

## 输入框的几种写法

除了直接打字，输入框还支持下面几种写法：

| 写法 | 做什么 |
|---|---|
| `/命令` | 输入 `/` 会弹出命令列表，边输入边筛选 |
| `@` | 引用文件或目录：输入 `@` 加几个字会弹出文件列表，按 `Tab` 进入目录，按 `Enter` 把它变成一个块。输入 `/` 可以按目录查找 |
| `$` | 点名使用技能：输入 `$` 加名字会弹出技能列表，一句话里可以点名几个技能 |
| `!` | 第一个字符输入 `!` 会进入运行命令的模式，框里提示 `输入要跑的命令`，按回车后核心会直接运行这条命令，不经过 AI，最多运行 120 秒。这种模式下不能带附件。框空着时按 `Backspace` 或 `Esc` 回到平常的模式 |
| 把文件拖进终端 | 如果拖进来的全部是本机上已经存在的文件、目录，图片、PDF、音频、视频会变成附件（`[图片 1]`），其他的变成文件块（`[名字]`、`[目录/]`），发送时换成路径 |
| 粘贴图片 | 按 `Ctrl+V`（Windows Terminal 里按 `Alt+V`）把剪贴板里的图片变成附件；在文件管理器里复制的文件，处理方式和拖进来的文件相同（macOS 上不接收，见下文） |
| 粘贴大段文字 | 超过 10 行或 800 个字的文字会变成一个块 `[已粘贴 N 行]`，发送时换回原文 |

附件最大 20 MiB。如果当前模型不接收这种附件，会改成发送文件路径，并提示 `当前模型不支持…，已改为文件路径`。超过 1 MB 的一句话会转成文字附件发送。

`Ctrl+V` 读取剪贴板时使用这些命令：

| 系统 | 文字 | 图片 | 复制的文件 |
|---|---|---|---|
| Linux | 在 Wayland 下先尝试 `wl-paste`，再尝试 `xclip`、`xsel` | 在 Wayland 下装了 `wl-paste` 时用它读取，否则用 `xclip` | 和图片相同 |
| macOS | 系统自带的 `pbpaste` | 系统自带的 `osascript` | 不接收：在访达里复制的文件粘贴不进来 |
| Windows | Windows PowerShell（`powershell`） | 和文字相同 | 和文字相同 |

每个命令最多等待 1 秒；Windows 上启动 PowerShell 比较慢，最多等待 3 秒。如果都读取不到，会提示 `无法读取剪贴板：请使用终端的粘贴（kitty 为 Ctrl+Shift+V）`。

## 阅读时间线

时间线记录了这个会话里发生的所有事情：

- AI 在一轮里做的每一步各占一行，显示图标、工具名和简短的参数。命令、思考、编辑会带几行预览：思考进行中时，滚动显示最新的 `tui.timeline_thought_rows`（出厂 `15`）行；命令预览显示 `tui.timeline_preview_rows`（出厂 `10`）行。如果打开了 `tui.timeline_expand_thought`、`tui.timeline_expand_command`、`tui.timeline_expand_edit` 中的某一项，对应的那一种默认显示全文。
- 点击一个步骤会展开它，可以看到它的输出、编辑的差异；查询记忆、知识库的结果，展开后是一条条的内容。再点击一次就会收起。
- 一轮结束后，这一轮的步骤会折叠成一行，例如 `执行了 2 条命令 · 3 次思考 · 48s`，如果编辑过文件，后面还会写增加和删除的行数。点击这一行可以展开。如果不想折叠，关掉 `tui.timeline_fold`。
- 一轮结束时有一行收尾，写着时刻 · 供应商/模型 · 用时，后面接着速度、这一轮的用量和缓存命中率。
- 差异：运行 `/files` 会打开 `文件修改` 页面，一边是修改过的文件列表（宽窗口时在右边，窄窗口时在上面），另一边是选中的文件的完整差异。
- 回答里的本机路径、网址可以点击，点击后用系统给这种文件指定的程序打开。AI 用 `show` 给你看的文件会写着文件种类和 `点击打开`。
- 图片、块级公式、Mermaid 图在支持图片协议的终端里会画成图片，点击 Mermaid 图会用程序打开大图；终端显示不了的，会显示源码。运行 `/images off` 可以让这一次运行先不画图。
- 子代理：底栏上面每个子代理占一行，显示它的状态，按 `↓` 选中、按 `Enter` 可以切换到它的会话查看。
- 后台命令：底栏中间显示 `N 个后台命令`，点击它，或者选中后按 `Enter`，会打开后台面板，可以查看输出、停掉命令。命令完成时，时间线上会记一行 `后台命令完成 · …`。
- 用量：底栏右边的用量格显示上下文环、累计 token（包括子代理）和花费；侧边栏的 `上下文`、`用量` 两部分显示得更详细。运行 `/usage` 可以查看这台机器上按天、按模型统计的用量。
- 从别处来的消息（其他会话、子代理、你在其他界面发的话）会记一行 `从 … 收到消息`。

## 外观

### 配色

运行 `/theme` 会打开配色框，光标移到哪一种配色，界面就立即变成哪一种；按 `Enter` 把选择写进 `tui.theme`，按 `Esc` 换回原来的配色。

| 选项 | 值 | 颜色从哪里来 |
|---|---|---|
| 自动 | `auto`（出厂） | 依次检查：如果人格有头像或主题色，就跟随头像；如果找得到桌面壁纸，就跟随壁纸；如果能查询到终端的颜色，就使用终端配色；都没有时使用 Tokyo Night |
| 跟随头像 | `persona` | 从正在查看的这个人格的头像里提取主色，生成一套配色；如果人格自己设置了主色，就使用它。人格提供不了颜色时，这一项不列出 |
| 跟随壁纸 | `wallpaper` | 先找 matugen 生成的配色，没有时从桌面壁纸图片里提取主色。更换壁纸后配色会自动跟着变。找不到壁纸时，这一项不列出 |
| 终端配色 | `terminal` | 跟随终端自己的配色。如果终端支持真彩色、并且能查询到终端的颜色，就从终端的 16 色里挑选主色生成一套配色，否则直接使用终端的 16 色。这种配色不铺底色 |

Tokyo Night 只在 `自动` 什么都找不到时作为兜底，配色框里不列出它，但手动写 `tui.theme = "tokyonight"` 也能识别。程序自带四份配色文件：`tokyonight-night`、`tokyonight-day`（自带颜色），`terminal`、`terminal-light`（使用终端的颜色）。

跟随头像、跟随壁纸、终端配色有几个候选主色时，可以在设置页的 `外观 → 配色方案 → 主色` 里挑选。跟随壁纸、终端配色挑选的主色写进 `tui.theme_seed`；跟随头像挑选的主色写回那个人格。

明暗（`tui.theme_mode`）：选择自动时跟随终端的底色，查询不到时当作深色；也可以选择一直使用深色或浅色。

铺底色（`tui.theme_background`，出厂打开）：整个界面铺上配色的底色。终端配色不铺底色，设置页里也不列出这一项。

### 图标、主题、语言

- `/icons` 在 Nerd Font 图标和普通字符两套之间切换，只对这一次运行有效。如果想一直使用，需要设置 `tui.icons`（设置页的 `外观 → 图标`）。
- 主题（`tui.look`）控制框线、记号和文字的修饰：不设置时使用默认主题；写 `ascii` 使用自带的纯 ASCII 主题，界面上的符号、图标都会换成 ASCII 字符（汉字、字母不变），`tui.icons`、`/icons` 选择的图标要换回其他主题才会使用；如果安装了其他终端主题包，写它的编号。主题包的安装方法见 [软件包](../packages.md)。
- `/language`：第一行是 `自动（跟随系统：…）`，下面是中文、English、日本語。选择结果写进 `ui.language`。切换以后，新绘制的文字使用新的语言，已经在时间线上的内容不变。

### 外观和行为的配置键

全部的 `tui.*` 配置键见 [配置键全表](../config-keys.md#终端)。和外观、行为有关的有：

| 键 | 默认 | 设置页 | 作用 |
|---|---|---|---|
| `tui.theme` | `auto` | 外观 → 配色方案 → 配色 | 配色 |
| `tui.theme_mode` | `auto` | 外观 → 配色方案 → 明暗 | 明暗 |
| `tui.theme_background` | `true` | 外观 → 配色方案 → 铺底色 | 是否铺底色 |
| `tui.theme_seed` | — | 外观 → 配色方案 → 主色 | 跟随壁纸、终端配色时使用的主色，格式是 `#rrggbb` |
| `tui.look` | — | 外观 → 主题 | 主题包 |
| `tui.icons` | `nerd` | 外观 → 图标 | `nerd` 或 `plain` |
| `tui.mascot` | — | 外观 → 形象 | 使用哪一只吉祥物，不设置时使用自带的 |
| `tui.mascot_home` | `false` | 外观 → 形象 | 在空会话的输入框上方显示头像或吉祥物 |
| `tui.mascot_sidebar` | `false` | 外观 → 形象 | 在侧边栏顶上显示头像或吉祥物 |
| `tui.keys` | `arrows` | 通用 → 交互 | 按键模式 |
| `tui.auto_pick` | `false` | 通用 → 新会话 | 新会话直接使用默认的人格和预设，不弹出选择框 |
| `tui.timeline_fold` | `true` | 通用 → 时间线 | 一轮结束后折叠步骤 |
| `tui.timeline_limit_live` | `true` | 通用 → 时间线 | 进行中的步骤只显示最新的几行 |
| `tui.history_rows` | `0` | 通用 | `Ctrl+R` 历史列表显示几条，`0` 表示跟随窗口高度 |
| `tui.history_preview_rows` | `6` | 通用 | 历史列表下面的预览显示几行，宽窗口时预览在右边 |

也可以用命令修改，例如：

```sh
miyu config set tui.theme terminal
miyu config set tui.icons plain
```

修改后立即生效。

## 设置页

运行 `/settings`（`/config` 是同一条命令）会打开整屏的设置页，按 `Esc` 一层层退回，在主菜单上按 `Esc` 回到对话。如果想不进入会话、直接打开设置页，运行 `miyu tui config`。

| 页 | 包含的设置 |
|---|---|
| 通用 | 显示（界面语言、启动时打开）、新会话（默认人格、默认预设、开局只读、自动选择人格和预设）、会话、终端集成会话；以及终端界面自己的时间线、交互、侧边栏条数、历史列表 |
| 外观 | 主题、配色方案、形象、图标 |
| 供应商和模型 | 分成三页：供应商、默认模型、模型池，详细的见 [模型](../models.md) |
| 用户 | 个人资料：称呼、回复语言、更多描述 |
| 隐私与安全 | 权限、受保护的命令，详细的见 [权限和沙盒](../permissions.md) |
| 人格 | 创建、修改、删除人格，详细的见 [人格和预设](../personas-presets.md) |
| 预设 | 创建、修改、删除预设 |
| MCP | MCP 服务的状态，以及登录、登出。只有配置了 MCP 服务时才列出这一页 |
| 软件包 | 分成下载软件、已安装、软件后台三页；在已安装的软件包上按 `Enter` 进入它自己的设置，详细的见 [软件包](../packages.md) |
| 高级 | 压缩、核心、运行日志，以及软件包放进这一页的设置，例如技能、平台账号 |

在一页里，用 `↑`、`↓` 选择，按 `Enter` 修改，按 `d` 恢复默认值，按 `D` 把这一组恢复默认值，按 `Esc` 返回。人格提示词这类比较长的设置项，按 `Enter` 进入编辑窗口，按 `Ctrl+G` 用外部编辑器编写（查找编辑器的方式和输入框里的 `Ctrl+G` 相同）；Windows 上没有外部编辑器这个选项，需要在编辑窗口里编写或者粘贴进去。

## shell 集成

安装 shell 集成以后，在 shell 的提示符后面输入一句话、按回车，就是在和 AI 对话。回答会按照时间线的样子输出在 shell 里，不会进入全屏界面。

### 安装和卸载

可以使用下面这些命令：

```sh
miyu shellhook install            # 按照你正在使用的 shell 安装
miyu shellhook install --shell zsh
miyu shellhook status             # 查看安装进了哪几个 shell
miyu shellhook doctor             # 检查是否安装成功、能否连上核心、终端颜色、剪贴板
miyu shellhook uninstall          # 关闭：从 shell 里移除
```

`--shell` 可以写 `fish`、`bash`、`zsh`、`pwsh`（PowerShell 7）、`powershell`（Windows 自带的 5.1）。不写 `--shell` 时，按照这台机器的系统判断：

| 系统 | 不写 `--shell` 时怎么判断 |
|---|---|
| Linux | 根据上一层进程判断，判断不出来时根据 `SHELL` 判断 |
| macOS | 只根据 `SHELL` 判断 |
| Windows | 如果设置了 `SHELL`，就根据它判断；没有设置时，根据 PowerShell 加进 `PSModulePath` 的用户模块目录判断，区分出 5.1 和 7 |

如果判断不出来，会报错 `认不出是哪种 shell：用 --shell 加 fish、bash、zsh、pwsh 或 powershell 指定`。`--program <路径>` 指定 shell 里调用的程序，不写时使用这个程序旁边的 `miyu`。

安装的位置：

| shell | 写进哪里 |
|---|---|
| fish | `~/.config/fish/conf.d/miyu-shellhook.fish`（如果设置了 `XDG_CONFIG_HOME`，就在它下面），写入整个文件 |
| bash | 在 `~/.bashrc` 里写入一段带记号的内容 |
| zsh | 在 `~/.zshrc`（如果设置了 `ZDOTDIR`，就在它下面）里写入一段带记号的内容 |
| pwsh、powershell | 向 PowerShell 查询它自己的 `$PROFILE.CurrentUserCurrentHost`，在那个文件里写入一段带记号的内容。需要 PSReadLine |

安装进去的只有一行，每次 shell 启动时都会重新输出脚本，所以升级 Miyu 以后新开的 shell 会自动使用新的脚本。已经开着的 shell 里会提示 `这个终端里的集成还是旧的，重开终端用新的`。再安装一次只会替换原来的那一段。如果 fish 的文件不是 shellhook 写的，安装时不会修改它。

如果 PowerShell 的执行策略是 `Restricted` 或 `AllSigned`，PowerShell 不会加载启动文件，安装时会输出 `PowerShell 的执行策略是 Restricted，不加载启动文件，装了也不生效：在 PowerShell 里执行 Set-ExecutionPolicy -Scope CurrentUser RemoteSigned 再开新窗口`（提示里写的是实际的执行策略）。按照提示运行：

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

### 使用方法

1. 新开一个 shell。
2. 输入一句话，按回车。如果第一个词是普通的词、又不是任何命令，这一行会交给 AI；如果是命令，就照常执行。如果输入了多行，先检查第一个命令是否存在，判断不出来时交给 Miyu 判断。找不到命令时，这一行也会交给 AI。
3. 查看回答。需要确认或者回答问题时，提示符下面会弹出和全屏界面一样的框。按 `Ctrl+C` 可以打断。

| 键 | 做什么 |
|---|---|
| `Ctrl+J` | 在命令行里换行，用来输入多行的话 |
| `Ctrl+V` | 读取剪贴板：图片、复制的文件会变成块（`[图片 1]`），大段的文字会变成 `[已粘贴 14 行]`。在 PowerShell 里也可以用 `Alt+V` |

斜杠命令也可以在 shell 里输入，或者写成 `miyu shellhook <名字>`（例如 `miyu shellhook model`）。`/model`、`/theme`、`/effort`、`/sessions`、`/persona`、`/preset` 会在提示符下面打开一个框供你选择，`/model`、`/theme`、`/effort` 后面也可以直接写名字。`/settings` 会打开全屏的设置页。`/tui` 会用全屏界面打开这个终端的会话。`/exit`、`/language` 在 shell 里不起作用。

AI 启动的后台任务完成后，会在你回到提示符时输出出来。如果任务在提示符等待输入时完成：fish、zsh 会立即输出；bash 要等你下一次按回车，PowerShell 要等下一次绘制提示符（按回车或 `Ctrl+C`）时才输出。

### 终端集成会话

每个终端窗口各有一个会话，叫做终端集成会话，在会话列表里标着 `终端集成`。只打开终端不会创建会话，真正说了话才会创建。设置页的 `通用 → 终端集成会话` 里有三项设置：

| 键 | 默认 | 作用 |
|---|---|---|
| `terminal.persona` | 跟随 `persona.default` | 新开的终端集成会话使用哪个人格 |
| `terminal.preset` | 跟随 `preset.default` | 新开的终端集成会话使用哪个预设 |
| `terminal.idle_new_after` | `180` | 如果距离上一次说话已经闲置超过这么多分钟，下一句话会开一个新会话，并提示 `上次说话是 … 前，为了防止缓存失效导致额外花费，已开启新会话`。设成 `0` 表示不开新会话 |

在 shell 里运行 `/persona`、`/preset` 修改的也是这两项设置。

## 通知

终端不在前台时，如果回答完成、出了错、在等你确认、在等你回答，Miyu 会弹出一条通知，并响一声。通知的标题是这个会话的人格名字，如果人格有头像，通知会带上头像。如果是其他会话做完了、或者其他会话在问你，即使终端在前台也会弹出通知，但不响。

| 在哪 | 怎么弹出通知 |
|---|---|
| kitty | 使用 kitty 自己的通知，点击可以跳回窗口；窗口在前台时 kitty 自己不弹出 |
| iTerm2、WezTerm、ghostty（根据 `TERM_PROGRAM` 是 `iTerm.app`、`WezTerm`、`ghostty` 判断） | 使用终端自己的通知 |
| 其他终端，以及 tmux、herdr 里 | 使用系统通知，见下表 |

系统通知和提示音，在三个平台上分别使用：

| 系统 | 系统通知 | 提示音 |
|---|---|---|
| Linux | `notify-send` | 依次尝试 `pw-play`、`paplay`、`canberra-gtk-play`、`aplay` |
| macOS | `osascript` | `afplay` |
| Windows | 没有：走到系统通知这一步时，什么都不弹出 | 没有 Windows 的播放程序，所以不响 |

在 Windows 上，只有上表前两行那种自己能识别通知序列的终端（例如 WezTerm）才能弹出通知。Windows Terminal 不在这个名单里，Miyu 不会给它发送通知。

在 herdr 里由 herdr 负责响声。通知和提示音没有可以设置的开关。

## 多个会话

同时使用多个会话时：

- 打开终端界面时是开新会话还是接着最近的会话，由 `启动时打开`（`ui.startup`）决定，详细的见 [会话](../sessions.md)。
- 新会话开始时，先选择人格，再选择预设，选好了才能打字。如果不想每次都选，打开 `tui.auto_pick`。
- 运行 `/sessions` 打开会话列表，会话按 `最近`、`近 7 天`、`近 30 天`、`30 天前`、`存档` 分组。在侧边栏的 `最近会话` 里点击一行也能切换。
- 其他会话在等你确认或回答时，不会在当前会话里弹出框，而是提示 `「标题」在问你 · /resume 切过去`；会话列表里那一项标着 `在问`，侧边栏里那一行的行首是黄色的 `?`。切换过去以后，框就会弹出来。
- 其他会话做完一轮后，侧边栏里那一行会出现一个圆点，切换过去以后圆点消失。

## 和 herdr 一起用

在 herdr 的窗格里打开终端界面时：

- Miyu 会把工作中、等你回复、空闲这几种状态报告给 herdr，显示在 herdr 的侧栏上。
- 切换会话时，Miyu 会自动报告恢复命令 `miyu tui --resume <编号>`。herdr 重启以后，每个窗格会接回各自的会话。运行 `/new` 会清掉旧的恢复命令。如果只关闭 herdr 的客户端，Miyu 仍然在运行。
- 恢复命令要求你输入的那个命令名能在 PATH 上找到，找不到时不报告。写在命令前面的临时环境变量（例如 bash 里的 `MIYU_HOME=… miyu`）herdr 不会保存，如果需要这些变量，写一个固定这些变量的启动脚本，放进 PATH。

## 缓存里的文件

终端界面的崩溃记录、交给编辑器的草稿这类文件放在缓存目录里。缓存目录是整台机器共用的，不会随着 `MIYU_HOME` 改变：

| 系统 | 缓存目录 |
|---|---|
| Linux | `$XDG_CACHE_HOME/miyu`（如果 `XDG_CACHE_HOME` 没有设置、或者不是绝对路径，就是 `~/.cache/miyu`） |
| macOS | `~/Library/Caches/Miyu` |
| Windows | `%LOCALAPPDATA%\Miyu\cache` |

缓存目录里终端界面使用的文件：

| 在哪 | 是什么 |
|---|---|
| `tui/crash.log` | 崩溃记录：时刻、版本、报错和调用栈，每次崩溃都接在后面写入 |
| `tui/edit/` | 按 `Ctrl+G`、修改提示词时交给编辑器的临时文件 |
| `tui/pasted/<进程号>/` | 从剪贴板粘贴进来的图片。界面退出时删除；如果程序崩溃后留下了文件，Linux、macOS 上会在下次打开终端界面时清理，Windows 上不会清理，需要的话手动删除 |
| `tui/sounds/` | 提示音 |

## 排查问题

| 看到的现象 | 怎么办 |
|---|---|
| 图标是方块、问号 | 字体里没有 Nerd Font 的图标。安装一个 Nerd Font，或者运行 `miyu config set tui.icons plain` |
| 框线、转圈显示成乱码 | 运行 `miyu config set tui.look ascii`，换成纯 ASCII 的主题 |
| 颜色发灰、不对 | 检查 `COLORTERM`、`TERM` 能不能识别出真彩色，如果不能，设置 `MIYU_COLOR=truecolor`；或者在设置页的 `外观 → 配色方案` 里更换配色、明暗 |
| 图片、公式显示成源码 | 终端不支持 kitty、sixel、iTerm2 图片协议，需要换一个支持的终端；或者是之前运行过 `/images off`，运行 `/images on` 恢复 |
| 按 `Shift+Enter` 把消息发出去了 | 终端无法报告 `Shift+Enter`，换行要用 `Alt+Enter` 或 `Ctrl+J` |
| `无法读取剪贴板：请使用终端的粘贴（kitty 为 Ctrl+Shift+V）` | Linux：安装 `wl-paste`（Wayland 下）、`xclip`、`xsel` 中的一个；粘贴图片、复制的文件需要 `wl-paste` 或 `xclip`。macOS：读取剪贴板用的是系统自带的 `pbpaste`，读取不到时使用终端自己的粘贴。Windows：读取剪贴板需要启动 Windows PowerShell（`powershell`），3 秒内没有读完就算读取失败，这时使用终端自己的粘贴 |
| 提示 `已复制 … 个字符`，剪贴板里却没有内容 | 终端不支持 OSC 52，所以复制不进去。需要换一个支持 OSC 52 的终端 |
| `核心未运行：设置 MIYU_CORE_BIN 指向 miyu`、`连不上核心：…` | 用 `miyu` 或 `miyu tui` 打开，不要直接运行 `miyu-tui`；如果还是不行，见 [排查问题](../troubleshooting.md#核心无法启动或无法连接) |
| 在 shell 里说的一句话被发送了两遍 | 运行 `miyu shellhook status`，它会提示旧版的 `conf.d/miyu.fish` 也还在，删掉这个文件 |
| 终端界面崩溃，提示 `调用栈已保存到 …` | 崩溃记录在缓存目录下的 `tui/crash.log`，见上面的「缓存里的文件」 |

如果安装了 shell 集成，先运行 `miyu shellhook doctor`，它会逐条告诉你哪里有问题、怎么修复。
