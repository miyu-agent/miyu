# AI 能用的工具

> <sub>本文档由 Anthropic 的 Claude Fable 5.2 生成。</sub>

AI 读文件、运行命令、联网，都是通过调用工具完成的。这一页列出出厂自带的每一件工具：它做什么、只读下还能不能用、有什么限制，以及怎么关掉其中一件。

## 工具的来源

AI 能用的工具有下面几种来源：

- 出厂软件包自带的工具：见下面的全表。
- 你安装的软件包、扩展带的工具：见它们各自的说明。通讯平台的 `qq_*`、`tg_*` 见 [接入通讯平台](heads/im.md)；表情包的 `meme_*`，以及 `render_image`、`ocr` 这些工具见 [附加软件](addons.md)。
- 脚本：数据根（默认是 `~/.miyu`，Windows 上是 `%USERPROFILE%\.miyu`）的 `~/.miyu/root/scripts/` 里，一个文件就是一件工具，工具名就是文件名。脚本的写法见 [放文件就能用的](../dev/scripts-skills.md)。
- MCP 服务：工具名是 `mcp__<服务名>__<工具名>`，工具名里字母、数字、`_`、`-` 以外的字符会换成 `_`，整个名字最长 64 个字符。声明了资源的服务还会多出两件工具 `mcp__<服务名>__list_resources`、`mcp__<服务名>__read_resource`，用来列出和读取它的资源。接入 MCP 服务的方法见 [扩展 Miyu](extending.md)。

一个会话里有哪些工具，由这个会话的预设决定（见 [人格和预设](personas-presets.md)）。除此之外还有几道筛选：

- 记忆的三件工具只在开启了记忆的会话里才有；知识库的搜索、阅读、编辑、删除工具只在能查到至少一个知识库时才有，`kb_save` 则一直都有，方便建立第一个知识库。
- `subagent` 只提供给本机的会话，子代理派出的子代理不再有这件工具；`ask_user` 只提供给本机、有人看着的主会话；`sessions` 只提供给本机的主会话；`send_message`、`todowrite`、`session_usage` 只提供给本机的会话。
- 通讯平台上的会话还有另外的限制，见 [接入通讯平台](heads/im.md)。

查看这个会话现在有哪些工具，可以使用：

- 终端界面：输入 `/tool-list`，会按内置、软件包、MCP、脚本分组列出工具名。按 `c` 复制，按 `Esc` 关闭。
- 网页界面：点击对话区左上角的会话标题，再点击 `预设` 那一行右边的笔（`编辑这个预设`）打开预设，就能看到开启了哪些功能和工具。

## shell

`shell` 工具的行为如下：

- 使用哪个 shell：由系统决定，核心启动时查找一次，没有配置可以修改。不读取你的 shell 启动文件（`.bashrc`、`.zshrc`、PowerShell 的 `$PROFILE` 都不读取）。工具说明里会告诉 AI 使用的是哪一种 shell，AI 按照这种 shell 的写法来写命令：

  | | 使用哪个 | 怎么查找 | 告诉 AI 的名字 |
  |---|---|---|---|
  | Linux | bash | 使用 `PATH` 里的 `bash`，找不到时使用 `/bin/bash`。 | `bash` |
  | macOS | zsh | 固定使用 `/bin/zsh`，不从 `PATH` 里查找。 | `zsh` |
  | Windows | PowerShell 7，没有时使用 Windows PowerShell 5.1 | 先使用托盘安装包（`.msi`）带的那一份，再查找 `PATH` 里的 `pwsh.exe`，都没有时使用 `%SystemRoot%\System32\WindowsPowerShell\v1.0\powershell.exe`。 | `PowerShell 7` 或 `Windows PowerShell 5.1` |
- 在哪里运行：在这个会话的工作目录里运行。每次调用都会从工作目录启动一个新的 shell，上一次的 `cd` 和变量不会带过来。如果工作目录被删除或者移走了，任何命令都无法运行，工具会回答 `工作目录已不存在`，换一个工作目录就可以了（见 [会话](sessions.md)）。
- 环境变量：把核心的环境变量整份传过去，但会去掉名字里含有 `KEY`、`SECRET`、`TOKEN`、`PASSWORD`、`PASSWD`、`CREDENTIAL` 的变量（不区分大小写），以及以 `MIYU_` 开头的变量。另外还会设置 `GIT_TERMINAL_PROMPT=0`、`PAGER=cat`、`GIT_PAGER=cat`、`NO_COLOR=1`、`TERM=dumb`：这样 git 需要密码时会直接失败，输出也不会分页、不会带颜色。
- 超时：AI 没有指定时等待 120 秒，最多可以指定 600 秒。到时间还没运行完的命令，如果预设开启了 `后台运行`，就会挪到后台继续运行，时间线上会记录 `超时，已转到后台运行：…`；如果没有开启，或者命令开头就是 `sleep`（Windows 上是 `Start-Sleep`），整组进程都会被停掉，时间线上会记录 `超过 … 秒，已停止`。
- 停止命令：超时停止或者你叫停时，Linux、macOS 上会杀掉命令的整个进程组，Windows 上会用 `taskkill /T /F` 杀掉整棵进程树。命令自己运行完退出以后，Linux、macOS 上它留在进程组里、还没有退出的子进程也会一起被杀掉；Windows 上不会杀掉，留下的进程会继续运行。
- 后台运行：预设开启了 `后台运行` 时，AI 可以一开始就把命令放到后台，马上拿到一个任务编号（例如 `j1`），命令运行完会自动回报。后台命令最多运行 `jobs.max_running`（默认 `30m`，可以设置为 `1m` 到 `2h`），到时间就会被停掉。AI 还可以让后台命令每输出一行就马上交给它，用来盯着日志。
- 干等：前台 `sleep`（Windows 上是 `Start-Sleep`）两秒或以上的命令不会运行，工具会回答 `不允许在前台用 sleep 等待`：后台的任务完成后会自己回报，不需要干等。
- 输出太长：给 AI 看的输出最多 30000 个字，超出时保留开头和结尾各一半，中间注明省略了多少。如果要看完整的输出，可以让 AI 把输出写进文件再读取。
- 危险命令：开放权限下，有几类命令会先问你，有几类会被直接拒绝，见 [权限和沙盒](permissions.md#要确认的命令)。Windows 上按 PowerShell、cmd 的写法识别，见 [Windows 上的写法](permissions.md#windows-上的写法)。

## trash

`trash` 删除的东西会进入系统的回收站：Linux 上是 freedesktop 规范的回收站，macOS 上是废纸篓，Windows 上是回收站。如果要找回，从系统的回收站里还原即可。用 `/undo` 撤回那一轮不会把删除的东西放回来。

## show

AI 可以用 `show` 把它做出来或找到的图片、网页、文档、音频和视频直接展示给你。同一个路径再展示一次时，会替换掉原来那一份。

- 终端界面：时间线上会出现一张卡片或者一张图片，点击后用系统的程序打开；HTML 和 PDF 到达时会自动打开一次。如果没有能打开它的程序，会显示 `没有能打开它的程序` 和文件路径；在 Windows 上，终端界面把文件交给系统去打开，分辨不出有没有能打开它的程序，交出去就算已经打开。如果文件后来被修改了，会显示 `文件已更改`；如果被删除了，会显示 `文件已不存在`。
- 网页界面：文件会放进右边的 `预览工作区`，最后展示的排在前面；音频和视频在时间线里直接播放；无法识别的文件只能下载。

`show.system_hint`（默认 `true`）开启时，系统提示词里会有一句话，提醒 AI 用 `展示` 把这些东西展示给你看。关掉这个选项对新会话生效，可以运行：

```sh
miyu config set show.system_hint false
```

## ask_user

AI 向你提问时，终端界面上会显示 `… 在问`，网页界面上会显示 `… 提问`，下面是题目和选项。按 `↑`、`↓` 选择，多选题按 `Space` 勾选，按 `Enter` 提交；每道题都可以选择 `输入其他答案`，按 `n`（网页界面是 `N`）可以加一段补充说明；有几道题时，按 `←`、`→` 切换题目；连按两下 `Esc` 取消。其他会话在问你时，终端界面上会提示 `「…」在问你 · /resume 切过去`。

AI 会一直等你回答，不受确认框的超时设置 `permission.confirm.timeout` 限制。没有人能回答的会话（子代理、`miyu ask`、通讯平台）没有这件工具。

## advisor

AI 卡住时，可以用 `advisor` 把问题交给旗舰池（`flagship`）里的模型，等它回答完再接着做。旗舰模型只能看到 AI 写给它的问题，看不到这个会话的内容。AI 可以接着上一次的问题继续问下去。旗舰池默认是空的，往里面添加模型的方法见 [模型](models.md)。

## subagent

AI 用 `subagent` 另开一个会话派出子代理，子代理在后台工作，做完以后把报告送回来。AI 可以给子代理选择模型池和人格（只列出 `subagent = true` 的人格），也可以让子代理接着这个会话的对话继续做（fork），或者只允许它读取、不允许修改。子代理的预设和权限沿用派它的会话，子代理不会记录记忆。详细的见 [让 AI 自己接着干](automation.md)。

## 关闭工具

可以用下面几种方法关掉工具：

- 在预设里关掉：在设置页的预设里把那个功能或那件工具关掉，或者在预设文件里写 `[features]`、`[tools]`。详细的见 [人格和预设](personas-presets.md)。
- 关掉整个软件包：在设置页的 `软件包` 里关掉那个软件包的 `启用` 开关，它带的工具就都没有了。在命令行里可以运行：

  ```sh
  miyu config set packages.base-net.enabled false
  ```

- 技能、脚本、MCP 服务还有总开关 `features.<功能编号>`（例如 `features.mcp-github`），总开关只对默认全部开启的预设起作用；如果预设里写了开关，就以预设为准。

这些修改都从下一轮开始生效。

## 只读下的工具

切换到只读以后：

- `write`、`edit`、`trash`、`kb_save`、`kb_edit`、`kb_delete` 不执行，时间线上会记录 `只读模式，未执行`。
- `shell` 和脚本在沙盒里运行，任何位置都写不进。三个平台的沙盒有什么不同，见 [权限和沙盒](permissions.md#三个平台)。
- MCP 服务里没有标成只读的工具，每次使用前都会先问你。
- 其他工具照常使用。
