# 配置键全表

> <sub>本文档由 Anthropic 的 Claude Fable 5.2 生成。</sub>

这一页列出核心登记的每一个配置键，以及随核心出厂的终端界面、网页界面的键。怎么修改、改在哪里、改了为什么没有生效，可以看[配置](config.md)。

这些键都写在系统配置 `~/.miyu/etc/config.toml` 里（数据根默认是 `~/.miyu`，Windows 上是 `%USERPROFILE%\.miyu`）。只有 `permission.start_read_only` 还可以写进项目配置。

## 阅读表格

「类型」一栏的写法如下：

| 类型 | 写法 |
|---|---|
| 开关 | `true`、`false` |
| 整数、小数 | 写一个数。要求小数的地方也可以写整数 |
| 选项 | 「能写」一栏里的一个值，要带引号 |
| 多选 | 「能写」一栏里的几个值，写成数组 |
| 字 | 带引号的一行文字，不能是空的；「能写」一栏写了最多几个字 |
| 几行字 | 可以换行的文字 |
| 英文字 | 一行文字，其中中日韩的文字不能超过一半 |
| 时长 | 带引号的正整数，后面跟 `s`、`m`、`h`；不跟单位时表示秒，例如 `"30m"` |
| 名字 | 以小写字母开头，只包含小写字母、数字、`-`、`_`，最长 64 个字符 |
| 网址 | 以 `http://` 或 `https://` 开头；也可以写成 `{ env = "变量" }` |
| 模型引用 | `"供应商/模型"` 或 `"@池"` |
| 密钥引用 | `{ secret = "名字" }` 或 `{ env = "变量" }`，见[配置](config.md#密钥) |
| 列表 | 一个数组，每一项的类型是括号里写的那一种 |

「默认」一栏里的「—」表示没有默认值：不写就是没有设置，说明里写了没有设置时会怎样。

「生效」一栏的意思如下：

| 写的 | 意思 |
|---|---|
| 立即 | 修改后马上使用新的值 |
| 下一轮 | 已经打开的会话从下一轮开始使用新的值 |
| 新会话 | 以后新开的会话使用新的值，已经打开的会话不变 |
| 界面重启后 | 终端界面、网页界面下次启动时才读取新的值 |
| 核心重启后 | 核心下次启动时才读取新的值 |

键里尖括号的那一段是你自己起的名字：`<编号>` 以小写字母开头，只包含小写字母、数字、`-`、`_`，最长 32 个字符；`<模型>` 使用供应商那边的叫法，长度是 1 到 128 个字节；`<工具名>`、`<功能编号>` 的长度是 1 到 128 个字符，不能包含 `.`。如果名字里有 `.`、`:`、`/`，这一段要加上双引号，例如 `[providers.ollama.models."qwen3:8b"]`。

## 界面

这一组键管界面的语言、启动时打开哪个会话、打开哪个界面，以及金额的币种，对应设置页的 `通用 → 显示`。

| 键 | 类型 | 默认 | 能写 | 说明 | 生效 | 项目配置 |
|---|---|---|---|---|---|---|
| `ui.language` | 选项 | `"auto"` | `auto`、`zh`、`en`、`ja` | 终端界面、网页界面和命令行显示给你看的文字使用哪种语言。`auto` 表示跟随系统。 | 立即 | 不能 |
| `ui.startup` | 选项 | `"new"` | `new`、`recent` | 打开终端界面或网页界面时，是新建一个会话，还是接着最近的那个会话。 | 界面重启后 | 不能 |
| `ui.head` | 名字 | `"tui"` | 界面软件包的编号 | 直接运行 `miyu`、`miyu config` 时打开哪个界面。 | 界面重启后 | 不能 |
| `usage.currency` | 字 | `"USD"` | 3 个字，例如 `CNY` | 用量的金额换算成哪种币种显示。 | 立即 | 不能 |

## 新会话

| 键 | 类型 | 默认 | 能写 | 说明 | 生效 | 项目配置 |
|---|---|---|---|---|---|---|
| `persona.default` | 名字 | — | 人格的编号 | 新会话默认使用哪个人格。没有设置时，新会话不使用人格。 | 新会话 | 不能 |
| `preset.default` | 名字 | `"full"` | 预设的编号 | 新会话默认使用哪个预设。 | 新会话 | 不能 |
| `permission.start_read_only` | 开关 | `false` | | 新会话一开始就是只读，见[权限和沙盒](permissions.md)。 | 新会话 | 只能写 `true` |

## 终端集成会话

终端集成会话是你在 shell 里直接和 Miyu 说话时进入的会话，它会一直延续下去。这一组键对应设置页的 `通用 → 终端集成会话`。

| 键 | 类型 | 默认 | 能写 | 说明 | 生效 | 项目配置 |
|---|---|---|---|---|---|---|
| `terminal.persona` | 名字 | — | 人格的编号 | 新开的终端集成会话使用哪个人格。没有设置时跟随 `persona.default`。 | 新会话 | 不能 |
| `terminal.preset` | 名字 | — | 预设的编号 | 新开的终端集成会话使用哪个预设。没有设置时跟随 `preset.default`。 | 新会话 | 不能 |
| `terminal.idle_new_after` | 整数 | `180` | `0` 到 `525600`，分钟 | 如果距离上一次说话已经闲置超过这个时间，你的下一句话会开一个新会话，旧的会话会保留。`0` 表示不开新会话。 | 立即 | 不能 |

## 权限

这一组键决定哪些命令要先问你，对应设置页的 `隐私与安全`。每一项的细节见[权限和沙盒](permissions.md)。`permission.confirm.git`、`delete`、`power`、`pipe_to_shell`、`container` 五个开关在三个平台上都有效；Windows 上按 PowerShell、cmd 的写法识别，见 [Windows 上的写法](permissions.md#windows-上的写法)。

| 键 | 类型 | 默认 | 能写 | 说明 | 生效 | 项目配置 |
|---|---|---|---|---|---|---|
| `permission.confirm.git` | 开关 | `true` | | 破坏性的 git 操作会先问你。 | 下一轮 | 不能 |
| `permission.confirm.delete` | 开关 | `true` | | 递归删除会先问你。 | 下一轮 | 不能 |
| `permission.confirm.power` | 开关 | `true` | | 关机、重启会先问你。 | 下一轮 | 不能 |
| `permission.confirm.pipe_to_shell` | 开关 | `true` | | 下载下来直接执行的命令会先问你。 | 下一轮 | 不能 |
| `permission.confirm.container` | 开关 | `true` | | 容器要使用宿主的设备、进程或网络命名空间时会先问你。 | 下一轮 | 不能 |
| `permission.confirm.timeout` | 整数 | `300` | `0` 到 `86400`，秒 | 等你确认的时间超过这个值就自动拒绝。`0` 表示一直等。 | 下一轮 | 不能 |

## 命令、工具和功能开关

这一组键管斜杠命令、工具和功能的开关。设置页里没有这几项，需要用 `miyu config set` 或者手动修改配置文件。

| 键 | 类型 | 默认 | 能写 | 说明 | 生效 | 项目配置 |
|---|---|---|---|---|---|---|
| `commands.<命令名>.access` | 选项 | — | `admin`、`anyone`、`off` | 通讯平台上谁能使用这条斜杠命令：你和群管理员、所有人，或者停用。没有写时使用命令自带的设置，命令也没有设置时是 `admin`。见[斜杠命令](commands.md)。 | 立即 | 不能 |
| `features.<功能编号>` | 开关 | — | | 一个技能、脚本或 MCP 服务是否打开。功能编号写成 `skill-<名字>`、`script-<工具名>`、`mcp-<服务名>`。这个键只对 `unlisted = "on"` 的预设起作用；如果预设里对这一项写了开或关，以预设为准。没有写时由预设决定。 | 下一轮 | 不能 |
| `clicall.tools.<工具名>` | 开关 | — | | AI 能不能在命令里用 `miyu call` 调用这个工具。没有写时以工具自己登记的为准。 | 下一轮 | 不能 |
| `clicall.mcp.<服务名>` | 开关 | — | | AI 能不能在命令里用 `miyu call` 调用这个 MCP 服务的工具。如果单个工具另外写了设置，以那个工具的设置为准。 | 下一轮 | 不能 |
| `packages.<编号>.enabled` | 开关 | — | | 这个软件包是否打开，和软件包页上的开关是同一个。用 `miyu config set` 修改它，就是打开或关闭这个软件包；这个值不会写进配置文件，手动写进 `config.toml` 的值不会被识别。 | 立即 | 不能 |

| 键 | 类型 | 默认 | 能写 | 说明 | 生效 | 项目配置 |
|---|---|---|---|---|---|---|
