# 快速上手

英文版：[English](../../en/guide/quickstart.md)。

## 快速安装

快速安装会帮你装上 Miyu 的整合包，包含核心、基本功能、终端界面（`tui`）、网页界面（`webui`）和系统托盘（`applet`）。Mac 和 Linux 还会装上极其轻量的`litemiyu`备用和救急。

> Agent 最好有两个，一个坏了还有另一个。

不同的操作系统安装包不同，请选择自己使用的操作系统

- Windows：到[发行版页面](https://github.com/miyu-agent/miyu-applet/releases)下载 `.msi` 安装包。
- Linux：到同一个发行版页面下载 `.deb` 或 `.rpm`；或者用一条安装命令：`curl -fsSL https://raw.githubusercontent.com/miyu-agent/miyu/main/packaging/install.sh | sh`。
- MacOS：用 Homebrew，依次运行 `brew tap miyu-agent/miyu`、`brew install miyu-agent`、`brew install --cask miyu-applet`；或者到同一个发行版页面下载 `.dmg`。
- Arch Linux 可以从 AUR 安装：`paru -S miyu-agent`。

每种装法的细节、升级和卸载见[安装、升级、卸载](install.md)。

### 可选：自定义安装

如果你使用是 Linux 或者 MacOS，可以仅安装核心，然后使用 `miyu pkg` 命令自选要安装东西，例如只想要网页界面的情况下就使用 `miyu pkg install webui`，终端界面对应的包是`tui`。通过`miyu pkg --help`命令查看具体使用方法。

## 第一次启动

快速安装后，Miyu 会出现在你的软件菜单中，启动后会在系统托盘中看到 Miyu 的图标，右键图标可以看到操作菜单，选择`打开网页界面`即可打开 `webui`。如果你想使用 TUI，可以直接终端运行 `miyu` 或者`miyu tui`命令。如果你仅安装了核心和 `webui`，可以在终端运行 `miyu web` 命令打开 `webui`。

第一次启动会进入新手引导，点击`开始`之后会进入以下几步：

### 界面语言

决定了界面用什么语言显示，选择第一项`跟随系统（自动）`时为了视觉上的考量，部分内容依旧以英文展示。

### 选择模型供应商

配置一个 AI 供应商并选择模型，支持自定义。

###  创建人格

“人格”代表着使用过程中和你对话的 AI 是谁，决定了 AI 的记忆。不同的会话可以选择不同的人格。

为你的的 AI 取一个`名称`，设置一个`头像`，编写一段`具体提示词`详细说明 AI 的设定。如果想要约束 AI 的说话方式，可以设置几对 `示例对话`，如果想要避免 AI 在长对话时偏离人格设定，可以使用`人设提醒短语`功能。

当然，你也可以选择跳过，以`无人格`使用，记忆功能依旧正常。

### AI 怎么认识你

你可以在这里对自己进行一些描述，设置你期望的`回复语言`，你的`名称`，用提示词详细描述你，或者你想要 AI 注意的事情。

当然你也可以选择跳过。

### 选择预设

”预设“ 代表着开启哪些功能，Miyu 自带了一些预设，你也可以创建你自己的`自定义预设`。每个会话可以单独设置预设，也可以在会话途中切换预设。

### 是否开启内置语义模型

语义模型可以大幅提高检索能力，提高记忆和知识库的检索质量。如果你不是什么二十年前的老古董机器，推荐开启。

### 向局域网开放

> 仅 webui

`webui` 可以选择向局域网开放，同一个局域网的其他设备可以访问部署了 Miyu 的机器。配合`tailscale`、`easytier`之类的虚拟组网程序，可以在外出时也能访问 `webui`。

### 无缝集成到终端

> 仅 tui

可以选择安装 shellhook 到 `bash`、fish、zsh 之类的 shell 中，安装后终端就是 Harness 本身，可以直接打字对话，可以直接运行 Harness 命令，并且不影响 shell 的正常使用。

## 软件包

引导结束之后就可以正常使用基本功能进行 Agent 工作了。基本功能大多以内置软件包的形式提供，你还可以安装额外的软件包增加 Miyu 的功能。

### 安装和卸载

`webui`点击左侧边栏下方的齿轮图标打开设置页，进入`下载软件`页面；`tui`在输入框运行`/config`进入设置菜单的`软甲包`页面；还可以使用`miyu pkg`命令，具体使用方法用`miyu pkg --help`查看。

 ### 调整配置

扩展软件包的配置主要有两处。进入已安装的软件包页面找到安装好的软件包，进入那个软件包的详情页就可以看到它的配置项目。软件包还可以自带一个后台面板，除了从软件包的详情页跳转，设置菜单的`软件后台`页面也收集了这些后台面板，可以快捷跳转。

### 制作自己的扩展

如果你想要创建并上传自己的软件包，可以阅读：[写一个 Miyu 软件包](../../authors/README.md)，或者从[软件包模板](https://github.com/miyu-agent/miyu-package-template)开始。

## 接入通讯平台

Miyu 的官方软件源中自带了一套开箱即用的 IM 接入功能。

安装`接入通讯平台`（`miyu-im`）这个软件包后进入软件后台。除了从`tui`或者`webui`进入后台，也可以运行 `miyu im web`命令打开后台。在主页点击`新建连接`就可以看到支持的接入平台和接入方式，跟着引导一步步做就可以了。新建连接后在 `会话设置`页点击`新建`按钮新建会话卡片，可以设置 AI 在各个群聊/私聊中的具体行为。

## 使用技巧

### 模型池

Miyu 内置了三个档位的模型池，你也可以自定义模型池。如果有合适的模型，推荐设置一下`轻量池`和`旗舰池`，`轻量池`默认用于给会话取名，`旗舰池`可以用于`advisor`功能，AI 可以使用`advisor`功能向旗舰模型寻求帮助。

### 自主循环

以`/loop`开头的提示词可以让 AI 进入自主循环，AI 会以合适的节奏自主完成用户布置的任务。
