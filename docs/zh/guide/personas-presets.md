# 人格和预设

> <sub>本文档由 Anthropic 的 Claude Fable 5.2 生成。</sub>

每个会话都使用一个人格和一个预设。这一页讲人格和预设各自负责什么，怎么选择、切换和设置默认值，以及怎么自己编写。

## 人格和预设的作用

人格和预设负责的是两件不同的事：

- **人格**决定 AI 是谁、怎么说话：人设、示范对话和人设提醒短语，都会拼进发给模型的系统提示词。也可以不使用人格，这时 AI 只带着 Miyu 自己的那段系统提示词。
- **预设**决定这个会话打开了哪些功能：哪些工具、技能、脚本、MCP 服务、斜杠命令模板可以使用，往对话里注入哪些环境信息。每个会话都必须有一个预设。

人格和预设分开选择，可以随意搭配。人格的记忆跟着人格走：使用同一个人格的会话共用一份记忆，不使用人格的会话共用另一份，详细的见 [记忆](memory.md)。如果会话的预设没有打开 `人格记忆`，这个会话既不保存记忆，也不召回记忆。

## 出厂的预设

Miyu 出厂带有下面四个预设：

| 界面上的名字 | 编号 | 打开了什么 | 什么时候使用 |
|---|---|---|---|
| 全部功能 | `full` | 已安装的全部打开，以后新安装的也会打开 | 默认使用的就是它 |
| 常规开发 | `dev` | 基础系统、注入环境信息、任务和定时三组，网络搜索，人格记忆，以及写技能和写软件包的两个技能。其他的都不打开，以后新安装的也不打开 | 写代码，并且不需要扩展、MCP 服务这些额外的东西 |
| 极简开发 | `minimal` | 只有读文件、新建文件、编辑文件、运行命令四个工具，以及环境信息的八项 | 想让 AI 按模型自己擅长的方式工作，工具越少越好 |
| 无功能 | `none` | 什么都不打开，以后新安装的也不打开 | 只聊天；或者以它为基础，自己打开几项 |

出厂的默认预设是 `full`。

## 出厂的人格

Miyu 出厂带有一个人格 `软件工程师`（编号 `software-engineer`），由出厂软件包 `软件工程师人格`（`base-persona-engineer`）提供。这个人格用来写代码，它的人设要求先用最简单的办法、用独立的依据验证结果、做完并验证过就结束、说话简洁。AI 派出子代理时可以选择这个人格。

出厂时没有设置默认人格：如果新会话没有选择人格，就不使用人格。删除这个人格就是卸载提供它的那个软件包；想要找回来，把 `base-persona-engineer` 重新安装回来即可（见 [软件包](packages.md)）。

## 为新会话选择人格和预设

不同的地方选择人格和预设的方法不同：

- 首次引导：在 `创建人格` 这一步新建一个人格（可以跳过），新建的人格会成为默认人格；在 `选择预设` 这一步选择的预设会成为默认预设，也可以在这一步用 `自定义` 新建一个预设。
- 终端界面：新建会话时，输入框的位置会先出现 `请选择人格`，再出现 `请选择预设`，两个都选完才能打字。人格框的第一行是 `无人格`。用 `↑`、`↓` 选择，`Enter` 确定，`e` 编辑光标所在的那一个，`a` 新建；在预设框里按 `Esc` 可以回到人格框重新选择。光标一开始停在上一个会话使用的那一个上。如果不想每次都被询问，可以在设置页打开 `通用 → 新会话 → 自动选择人格和预设`（`tui.auto_pick`），新会话就会直接使用默认的人格和预设。
- 网页界面：空会话的输入框上方有 `选择人格`、`选择预设` 两个按钮，不点击时使用默认设置。如果默认的预设用不了（文件写错了，或者被删除了），输入框会被锁住，显示 `请选择预设`，选择一个预设以后才能打字。
- 命令行：使用 `miyu ask --persona <人格>`、`--no-persona`、`--preset <预设>`，值写的是编号。这几个参数只对新建的会话有效，不能和 `-c`、`-s` 一起写。例如：

  ```sh
  miyu ask --persona software-engineer --preset dev "看看这个仓库的测试为什么慢"
  ```

- 定时任务：`miyu schedule add` 同样接受 `--persona`、`--no-persona`、`--preset`，作用于每次新建的会话；这几个参数不能和 `--session` 一起写。详细的见 [让 AI 自己接着干](automation.md)。
- 通讯平台上的会话使用哪个人格和预设，由平台那边的规则决定，见 [接入通讯平台](heads/im.md)。在网页界面里，项目中新建的会话使用项目设置的人格和预设。

## 在会话中切换

已经开始的会话也可以更换人格和预设：

- 终端界面：输入 `/persona` 或 `/preset`，在弹出的框里选择。如果 AI 正在回答，选择框不会打开，并提示 `回答进行中：先打断，或者等它做完`。
- 网页界面：点击对话区左上角的会话标题，在菜单里点击 `人格` 或 `预设`，选择一个，再点击 `确认`（如果还没有可以压缩的对话，就不会询问，直接切换）。也可以输入 `/persona`、`/preset`。项目里的会话由项目决定人格和预设，输入这两个命令会提示 `这个会话在项目里，人格和预设由项目定`。

切换时，Miyu 会先用旧的人格把前面的对话压缩成摘要，从下一轮开始使用新的人格或预设。换了人格以后，从这一轮开始，记忆保存进新人格的那一份，以前保存的记忆留在原来的人格那里。换预设不会改变记忆开不开，记忆开不开始终按照新建会话时的设置。子代理的会话不能切换人格和预设。

## 默认值

新会话默认使用的人格和预设由下面几个配置键决定：

| 键 | 作用 | 设置页上的位置 |
|---|---|---|
| `persona.default` | 新会话默认使用哪个人格。不设置时，新会话不使用人格；如果指向的人格已经不存在，也当作没有设置，`miyu config set` 和 `miyu check` 会发出警告 | `通用 → 新会话 → 默认人格` |
| `preset.default` | 新会话默认使用哪个预设，出厂设置是 `full`。如果指向的预设不存在，新建会话时会报错，不会悄悄换成其他预设；`miyu config set` 仍然会接受这个值，但会多输出一行警告，`miyu check` 也会警告 | `通用 → 新会话 → 默认预设` |
| `terminal.persona` | 终端集成会话新建时使用哪个人格。终端集成会话是你在 shell 里直接和 Miyu 说话时进入的会话。不设置时跟随 `persona.default` | `通用 → 终端集成会话` |
| `terminal.preset` | 和上一项相同，决定使用哪个预设。不设置时跟随 `preset.default` | `通用 → 终端集成会话` |

值要写编号。修改以后对之后新建的会话生效，已经开着的会话不变。例如：

```sh
miyu config set persona.default software-engineer
miyu config set preset.default dev
```

## 自己编写人格

人格是数据根（默认是 `~/.miyu`，Windows 上是 `%USERPROFILE%\.miyu`）里的一个文件夹 `~/.miyu/root/personas/<编号>/`。编号就是文件夹的名字：必须以小写字母开头，只能包含小写字母、数字、`-` 和 `_`，最长 64 个字符。编号不能是 `con`、`nul`、`aux`、`prn`、`com1` 到 `com9`、`lpt1` 到 `lpt9` 这些 Windows 的保留名，三个系统上都不接受。

```text
~/.miyu/root/personas/captain/
├── persona.toml          # 名字、说明，还有几样设置
├── avatar.png            # 头像，可以没有
├── background.jpg        # 背景图，可以没有
└── prompts/
    ├── persona.md        # 人设
    ├── examples.md       # 示范对话
    └── reminders.md      # 人设提醒短语
```

每个文件都可以没有，一个空文件夹也算一个人格。把文件夹放进去以后，新建的会话就能选择这个人格。

`persona.toml` 的写法如下：

```toml
[persona]
name = "老船长"                  # 名字，不能是空的
summary = "说话像老水手的助手"     # 简单描述，给你自己看，模型不看
subagent = true                 # AI 派子代理时能不能选它

[knowledge]
bases = ["sea-charts"]          # 用这个人格时只查得到这几个知识库

[appearance]
seed = "#2f6f9f"                # 主题色
background_opacity = 40         # 背景图露出多少，0 到 100
background_focus = [50, 30]     # 背景图对准哪一处，横、竖各 0 到 100
background_blur = 10            # 背景图模糊多少，1 到 100
```

| 项 | 说明 |
|---|---|
| `persona.name` | 名字。也可以写成 `{ zh = "…", en = "…", ja = "…" }`，界面会按照界面语言选择对应的名字 |
| `persona.summary` | 一句简单描述，写法和 `name` 相同，可以是空字符串 |
| `persona.subagent` | 写 `true` 时，AI 派出子代理时可以选择这个人格，名字和简单描述会一起给模型看。不写时不能选择 |
| `knowledge.bases` | 一组知识库的编号，只能查到列出来的知识库；写 `[]` 就一个都查不到。不写时全部都能查到 |
| `appearance.seed` | 格式是 `#rrggbb`，终端界面和网页界面会根据它生成配色。不写时从头像里取色 |
| `appearance.background_opacity` | 0 到 100 的整数 |
| `appearance.background_focus` | 两个 0 到 100 的整数 |
| `appearance.background_blur` | 1 到 100 的整数，不写时不模糊 |

Miyu 只认这几张表和这几项，写了其他会报错。

`prompts/` 里的几个文件：

- `persona.md`：人设，写这个人格是谁、怎么说话、怎么对待你。它会原样放在系统提示词的最前面，用什么语言写都可以。
- `examples.md`：示范对话，放在系统提示词之后、对话之前。以 `user:` 开头的行是你说的话，以 `assistant:` 开头的行是 AI 的回答；没有开头标记的行接在上一句的后面，空行不算。示范对话必须从 `user:` 开始，一问一答交替，并以 `assistant:` 结束：

  ```text
  user: 今天天气怎么样？
  assistant: 风平浪静，适合出海。

  user: 帮我看看这段代码
  assistant: 拿来吧，老船长瞅瞅。
  ```

- `reminders.md`：人设提醒短语，是一小段提醒 AI 不要出戏的话。如果预设打开了 `人设遵循提醒`，AI 每 3 轮会再看一遍这段话，系统提示词的末尾还会另外加一句话，要求 AI 调用完工具以后也保持人设。如果不想要这个功能，可以删掉这个文件，或者在预设里关掉 `人设遵循提醒`（出厂的 `常规开发` 和 `极简开发` 就没有打开它）。

头像放在 `avatar.png`、`avatar.jpg` 或 `avatar.webp`，背景图放在 `background.png`、`background.jpg` 或 `background.webp`。如果在界面里更换，头像最大 1 MiB，宽和高都不超过 1024；背景图最大 5 MiB，宽和高都不超过 4096。

修改了文件以后，新建的会话会使用新的内容；已经开着的会话会在下一轮开始时换上新的人设、示范对话和人设提醒短语。如果文件写错了，可以用 `miyu check` 检查，它会说明哪个文件的第几行错在哪里；开着的会话如果遇到写错的文件，会继续使用原来的内容。

## 自己编写预设

预设是一个文件 `~/.miyu/root/presets/<编号>.toml`，编号就是文件名，写法和人格的编号相同。下面是一个「只读代码审查」预设，它只打开读文件、找文件、搜内容这几个功能，再把工作目录告诉 AI：

```toml
# ~/.miyu/root/presets/review.toml
[preset]
name = "代码审查"
summary = "只能读文件、找文件、搜内容"
icon = "search"
unlisted = "off"

[features]
read = true
glob = true
grep = true
env-workdir = true
```

`[preset]` 这一张表的各项：

| 项 | 说明 |
|---|---|
| `name` | 名字，写法和人格的名字相同 |
| `summary` | 一句说明，给你自己看，不会发给模型 |
| `icon` | 图标，写 [Lucide](https://lucide.dev) 里的图标名 |
| `unlisted` | 没有写到的功能打不打开：`on` 是打开，`off` 是关闭。以后新安装的功能也按照它来。不写时是 `on` |

其他几张表：

| 表 | 写法 | 作用 |
|---|---|---|
| `[features]` | `<功能编号> = true` 或 `false` | 一个功能打不打开 |
| `[software]` | `<软件包编号或组名> = true` 或 `false` | 整个软件包、整个组打不打开 |
| `[tools]` | `<工具名> = false` | 在打开的功能里单独关掉一个工具。只能写 `false` |
| `[limits]` | `unattended_steps = <正整数>` | 没有人看着时，一轮最多请求几次模型，不写时是 `500`。它作用于通讯平台上的会话、定时任务新建的会话、`miyu ask`，以及有人看着的会话里不是由你发起的那几轮（例如定时任务、长期目标接着运行的轮次） |

一个功能打不打开，按照下面的先后顺序决定：先看 `[features]` 有没有写它；再看 `[software]` 有没有写它所在的软件包；再看 `[software]` 有没有写这个软件包所在的组；都没有写时，按照 `unlisted` 决定。写了没有安装的功能不会报错。

功能编号如下：

| 什么 | 编号 |
|---|---|
| 出厂的工具 | 多数和工具名相同，例如 `read`、`shell`、`subagent`。不同的有：`web_search` 是 `web-search`，`web_fetch` 是 `web-fetch`，`send_message` 和 `sessions` 是同一个功能 `sessions`，`remember`、`memory_search`、`forget` 是 `memory`，五个 `kb_*` 工具是 `knowledge`，三个 `cron_*` 工具是 `schedule`，`schedule_next` 是 `loop`。全表可以看 [AI 能用的工具](tools.md) |
| 不带工具的出厂功能 | 环境信息 `env-time`、`env-workdir`、`env-permission`、`env-session`、`env-model`、`env-harness`、`env-machine`、`env-profile`；自动注入 AGENTS 文档 `project-docs`；命令行调用工具 `clicall`；人设遵循提醒 `roleplay` |
| 技能 | `skill-<技能名>` |
| 脚本 | `script-<工具名>` |
| MCP 服务 | `mcp-<服务名>` |
| 斜杠命令模板 | `command-<命令名>` |

`[software]` 里可以写的组：

| 组名 | 界面上的名字 | 组里包含 |
|---|---|---|
| `basesystem` | 基础系统 | 读文件、新建文件、编辑文件、找文件、搜内容、删到回收站、运行命令、后台运行、命令行调用工具、子代理、求助旗舰模型、提问、展示给用户、跨会话消息、翻查本会话、用量查询、软件包 |
| `tasks` | 任务和定时 | 待办清单、长期目标、定时任务、循环任务 |
| `environment` | 注入环境信息 | 环境信息的八项、自动注入 AGENTS 文档 |
| `persona` | 人格 | 人格记忆、人设遵循提醒 |
| `research` | 查资料 | 网络搜索、知识库 |

如果只想在出厂预设的基础上改一点，只写改了的部分即可。例如在全部功能里关掉网络搜索，文件名是 `full.toml`：

```toml
# ~/.miyu/root/presets/full.toml
[features]
web-search = false
```

修改了文件以后，新建的会话会使用新的内容；已经开着的会话从下一轮开始换上。可以用 `miyu check` 检查有没有写错。

### 设置页里的总开关

在设置里，每个技能、脚本、MCP 服务都有一个开关，记录在 `features.<功能编号>` 里（例如 `features.mcp-github`）。这个开关只对 `unlisted = "on"` 的预设起作用；如果预设里对这一项写了打开或关闭，就以预设为准。`unlisted = "off"` 的预设里，没有写到的功能仍然是关闭的。

## 在界面里新建和修改

人格和预设也可以在界面里新建和修改：

- 终端界面：使用设置页（`/settings`）主菜单里的 `人格` 和 `预设` 两项。在列表里按 `a` 新建，填写名字，编号可以留空，由 Miyu 自动生成；按 `Enter` 打开一个进行修改。人格可以修改名字、简单描述、是否允许子代理选择、头像、具体人格提示词、示范对话和人设提醒短语；修改提示词时，按 `Enter` 进入编辑窗口填写，或者按 `Ctrl+G` 交给外部编辑器（使用 `$VISUAL`，没有设置时使用 `$EDITOR`，都没有设置时使用 `vi`）；Windows 上没有外部编辑器这个选项，需要在编辑窗口里填写或者粘贴进去。预设可以修改名字、描述，以及每个功能、每个工具的开关，用 `Space`、`Tab` 或 `Enter` 切换，用 `Ctrl+A` 全部切换；每改一项就保存一项。在窗口里按 `d` 是删除；对于你修改过的出厂人格、预设或软件包带来的人格、预设，按 `d` 是恢复出厂设置。在新会话的选择框里按 `e`、`a`，也会进入同样的窗口。
- 网页界面：使用设置里的 `人格` 和 `预设` 两个页面，可以新建、修改和删除。在开着的会话里，点击左上角的会话标题，`人格` 那一行的笔形图标就是 `编辑这个人格`。

在界面里修改出厂的或者软件包带来的人格、预设时，修改会保存到你自己那一层，只记录你改了的部分。删除的人格会进入回收站，保留 7 天；删除的预设找不回来。

## 三层的叠加规则

人格和预设都有三层，从下往上依次是：

1. 出厂的：随 Miyu 一起安装的。
2. 软件包带来的：已安装的软件包里的 `personas/` 和 `presets/`。
3. 你自己的：`~/.miyu/root/personas/` 和 `~/.miyu/root/presets/`。

如果同一个编号在几层里都有，上层会覆盖下层：人格的 `persona.toml` 和预设的 `[preset]` 逐项覆盖，写了的项替换掉下层的，没有写的项沿用下层的；人格 `prompts/` 里的文件、头像和背景图，同名的整个替换掉；预设的 `[features]`、`[software]` 逐个覆盖。删掉你自己那一层，就会恢复成下层的样子。如果软件包带来的和出厂的编号相同，使用出厂的；如果几个软件包带来了同一个编号，只使用其中一个，`miyu check` 会报出被覆盖的那几份。

软件包也可以带人格和预设，制作方法可以看 [放文件就能用的](../dev/scripts-skills.md)。

## 排查问题

| 看到的现象 | 怎么办 |
|---|---|
