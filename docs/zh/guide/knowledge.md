# 知识库

> <sub>本文档由 Anthropic 的 Claude Fable 5.2 生成。</sub>

知识库是你交给 AI 查阅的一批文档，例如笔记、手册、设定集、PDF。这一页讲怎么创建知识库、AI 什么时候会去查，以及怎么更新和删除。

知识库和记忆不一样：知识库是你提供的资料，按原样存放，AI 查的时候读的是原文；[记忆](memory.md) 是 AI 在对话里自己记下的一条一条的话。

AI 查知识库用的工具由出厂软件包 `base-knowledge` 提供，它在界面上的名字是 `知识库`。知识库里的文件属于你自己：即使没有安装这个软件包，也照样可以用 `miyu kb` 管理它们。

## 创建知识库

创建一个知识库并试着搜索，按下面三步操作：

1. 新建一个空的知识库，或者把现成的目录挂载进来：

   ```bash
   miyu kb new notes --name "学习笔记" --description "日语语法和单词"
   miyu kb mount handbook ~/Documents/handbook --name "团队手册"
   ```

   ```powershell
   miyu kb new notes --name "学习笔记" --description "日语语法和单词"
   miyu kb mount handbook $HOME\Documents\handbook --name "团队手册"
   ```

2. 往新建的知识库里添加文件：

   ```bash
   miyu kb add notes ~/Downloads/grammar.md ~/Downloads/kanji.pdf
   ```

   ```powershell
   miyu kb add notes $HOME\Downloads\grammar.md $HOME\Downloads\kanji.pdf
   ```

3. 试着搜索一下：

   ```sh
   miyu kb search て形
   ```

知识库的编号必须以小写字母开头，只能包含小写字母、数字、`-` 和 `_`，最长 64 个字符，并且不能是 `con`、`nul`、`com1` 这类 Windows 保留名。如果编号写错了，会报 `知识库编号无效`。

## 支持的文件

知识库可以收下面这几种文件：

| 文件 | 扩展名 | 怎么切成段 | 最大 |
|---|---|---|---|
| Markdown | `.md`、`.markdown` | 按标题切 | 4 MiB |
| 纯文本 | `.txt` | 按段落切 | 4 MiB |
| PDF | `.pdf` | 按页切 | 64 MiB |
| 网页 | `.html`、`.htm` | 转换成文字，再按标题切 | 64 MiB |

- 文字文件必须是 UTF-8 编码。
- PDF 和网页要靠 `miyu-extract` 提取文字，它和 `miyu` 放在同一个目录里（Windows 上是 `miyu.exe` 旁边的 `miyu-extract.exe`）；如果没有 `miyu-extract`，这些文件会被跳过。扫描出来的、只有图片的 PDF 里没有文字，也会被跳过。
- 子目录里的文件同样会收进来。以点开头的文件和目录，以及链接，不会收进来。其他扩展名的文件也不会收进来。
- 用 `miyu kb add` 添加时，一个文件最大 20 MiB。

收不进来的文件不会影响其他文件。`miyu kb list <库>` 会在那一篇文档后面写明原因，例如 `（无法读取：文件过大）`。

## 添加和挂载的区别

把文件添加进知识库，和把目录挂载成知识库，有下面这些区别：

| | `miyu kb new` + `add` | `miyu kb mount` |
|---|---|---|
| 文件在哪里 | 复制进 `~/.miyu/root/kb/<编号>/`（数据根默认是 `~/.miyu`，Windows 上是 `%USERPROFILE%\.miyu`） | 留在原来的目录里，知识库只记录挂载的是哪个目录 |
| 原文件修改以后 | 知识库里的不会跟着变，需要再运行一次 `add --replace` | 下一次搜索、列出时跟着变 |
| 添加、删除文档 | 可以，用 `add`、`remove`；AI 也可以写入 | 不可以，知识库是只读的，你和 AI 都不能修改 |
| `delete` | 把整个知识库目录移进系统回收站 | 只取消挂载，目录本身保持不变 |

挂载的目录要写成绝对路径，或者以 `~/` 开头；在 Windows 上，以 `~\` 开头也可以。

你也可以直接往 `~/.miyu/root/kb/<编号>/` 里放文件、改文件；在 `~/.miyu/root/kb/` 下面新建一个目录，只要目录名符合编号的写法，就相当于新建了一个知识库。下一次搜索、列出时，Miyu 会根据文件更新索引：新增的和修改过的文件重新读取，删除的文件从索引里去掉，没有变化的文件保持不变。

## miyu kb

`miyu kb` 是管理知识库的命令：

```text
miyu kb [<子命令>] [<选项>]
```

不写子命令时运行的是 `list`。选项写在子命令的前面或后面都可以。

| 子命令 | 做什么 | 成功时输出 |
|---|---|---|
| `list` | 列出知识库，一行一个：编号、名字、有几篇文档；软件包带来的知识库会写 `来自 <包名>`，打开了自动想起的会写 `自动想起`，最后是说明 | |
| `list <库>` | 列出知识库里的文档 | |
| `search <词>…` | 搜索全部知识库，最多列出 10 段 | |
| `read <库> <文档>` | 读取一篇文档的一页。一页是 32 KiB，PDF 按它自己的页来分 | |
| `new <库>` | 新建一个空的知识库 | 已创建 … |
| `edit <库>` | 修改名字、说明，打开或关闭自动想起 | 已修改 … |
| `add <库> <文件>…` | 把文件复制进知识库 | 已添加 <库>/<文档> |
| `remove <库> <文档>` | 删除一篇文档，把它移进系统回收站 | 已移到回收站：… |
| `mount <库> <目录>` | 把现成的目录挂载成只读的知识库 | 已挂载 …：N 篇 |
| `delete <库>` | 删除整个知识库 | 已删除 …，移到回收站：… |
| `reindex <库>` | 删掉索引，根据文件重新建立 | 已重建 … 的索引：N 篇 |

| 选项 | 做什么 |
|---|---|
| `--kb <库>` | `search` 只搜索这一个知识库 |
| `--page <页>` | `read` 读取第几页，不写时是第 1 页 |
| `--name <名字>` | 用于 `new`、`edit`、`mount`：显示的名字，不写时使用编号 |
| `--description <说明>` | 用于 `new`、`edit`、`mount`：用一句话说明这个知识库是什么 |
| `--auto` | 用于 `new`、`edit`、`mount`：打开自动想起 |
| `--no-auto` | 用于 `edit`：关闭自动想起 |
| `--to <目录>` | `add` 时把文件放进知识库里的这个子目录 |
| `--replace` | `add` 时替换已有的同名文档 |
| `--format <text\|json>` | `list`、`search` 的输出格式 |

`<文档>` 要写成知识库里的相对路径，和 `list <库>` 输出的写法一样。例如：

```bash
miyu kb read notes grammar.md --page 2
miyu kb add notes --to 语法 --replace ~/Downloads/grammar.md
miyu kb edit notes --auto
miyu kb search --kb handbook 报销
```

```powershell
miyu kb read notes grammar.md --page 2
miyu kb add notes --to 语法 --replace $HOME\Downloads\grammar.md
miyu kb edit notes --auto
miyu kb search --kb handbook 报销
```

## AI 什么时候查知识库

在打开了知识库功能的会话里：

- 系统提示词里会列出 AI 能查的知识库：编号、名字和说明。因为 AI 靠名字和说明判断什么时候该去查，所以名字和说明要写清楚。
- AI 会自己用 `kb_search` 搜索，用 `kb_read` 一页一页地读原文。
- 对于打开了自动想起的知识库，不用等 AI 自己去查：你说的话提到了哪一段，就会把哪一段带上。

如果一个会话一个知识库都查不到，AI 就拿不到 `kb_search`、`kb_read`、`kb_edit`、`kb_delete`，只能拿到 `kb_save`，这样 AI 仍然可以建立第一个知识库。

### 自动想起

在你发起的每一轮里，Miyu 会根据你这一轮说的话，从打开了自动想起的知识库里查找：

- 如果你的话里出现了某一节标题的最后一级（例如标题是「语法 › て形」时的「て形」），就带上这一节。
- 如果你的话和某一段的意思相近，就带上这一段。这需要语义模型，见下面的「语义搜索」。

每一轮最多带 3 段。每一段的内容是它的位置（知识库、文档、标题）加上开头的 120 个字，整块不超过 600 字节；如果需要全文，AI 会自己用 `kb_read` 去读。在一段上下文里已经带过的段落不会再带；这个数和记忆的联想合在一起计算，一段上下文（压缩以后重新计算）最多带 40 段。

自动想起默认是关闭的。可以用 `miyu kb edit <库> --auto`、`--no-auto` 打开或关闭，也可以在网页界面的知识库页上，用卡片上的 `自动联想` 开关。

### 给一节加别名

在 Markdown 一节标题下面的第一行写上关键词，这一节就多了几个可以触发自动想起的名字。例如：

```markdown
## 守灯人

关键词：灯塔的姑娘、Eileen、看灯的人

守灯人住在岬角的灯塔里……
```

- 这一行要以 `关键词`、`keys` 或 `キーワード` 开头（不区分大小写），后面跟着 `：` 或 `:`。
- 关键词之间用 `、`、`，`、`,`、`；` 或 `;` 隔开。
- 标题和关键词至少要有 2 个字才有效。
- 这一行不会带给 AI。

## AI 写入知识库

AI 可以用下面三个工具写入知识库：

| 工具 | 做什么 |
|---|---|
| `kb_save` | 新建一篇文档，或者接在一篇文档的后面。如果知识库还不存在，就新建这个知识库 |
| `kb_edit` | 把一篇文档里的一段文字替换掉，被替换的原文在文档里只能出现一次 |
| `kb_delete` | 把一篇文档移进回收站 |

- AI 只能写 Markdown 和纯文本，写完以后的文件不能超过 4 MiB。
- 挂载进来的知识库和软件包带来的知识库，AI 都写不了。
- AI 不能删除整个知识库。
- 在开放权限下，AI 用读写文件的工具也能读到、改动 `~/.miyu/root/kb/` 里的文档，改动过的文档会根据文件内容更新索引；在只读下，AI 只能读到这些文档。

如果不想让 AI 写入知识库，可以任选下面一种做法：

- 在预设的 `[tools]` 里关掉这三个工具：

  ```toml
  [tools]
  kb_save = false
  kb_edit = false
  kb_delete = false
  ```

- 在只读的会话里，这三个工具不会执行，见 [权限和沙盒](permissions.md)。

## 哪些会话能查哪些知识库

可以按下面的范围控制会话能查到哪些知识库：

| 范围 | 怎么写 |
|---|---|
| 全部会话 | 默认能查到全部知识库：你新建的、挂载的，以及已安装的软件包带来的 |
| 使用某个人格的会话 | 在人格文件 `persona.toml` 的 `[knowledge]` 里写 `bases = ["notes"]`，就只能查到列出来的知识库；写成 `[]` 就一个都查不到，也不能新建知识库 |
| 使用某个预设的会话 | 在 `[features]` 里写 `knowledge = false`，五个工具都没有，也不会自动想起 |

例如：

```toml
# ~/.miyu/root/personas/captain/persona.toml
[knowledge]
bases = ["sea-charts", "handbook"]
```

新建了知识库、修改了人格以后，下一次就会按照新的设置生效。人格和预设的写法可以看 [人格和预设](personas-presets.md)。

## 语义搜索

搜索知识库时会同时按关键词和意思两种方式查找，再把结果合在一起排序。按意思查找需要语义模型，也就是 `models.embedding`，默认使用本机的 `embed` 软件包（`miyu pkg install embed`，见 [附加软件](addons.md)、[模型](models.md#三个用途)）。

- 如果没有安装，或者设置成了 `off`：搜索只按关键词查找；自动想起只认标题和关键词。
- 如果设置的是远程模型：搜索按两种方式查找，计算向量用的文字会发给那一家供应商；自动想起不会按意思带上内容，只认标题和关键词。

索引在下面这些时候建立：

- 关键词索引：在搜索、列出、挂载目录、重建索引，以及 AI 使用知识库工具时，会根据文件把这个知识库的索引补全。
- 向量：搜索过以后在后台补全；对于打开了自动想起的知识库，用到时也会在后台补全。还没有补全向量的段落只能通过关键词找到。

`miyu check` 会在末尾输出索引的进度，例如 `知识库：handbook 30/42` 表示这个知识库的 42 段里有 30 段已经有了向量。这些输出怎么看，详细的见 [出了问题怎么查](troubleshooting.md#先运行-miyu-check)。

## 软件包自带的知识库

软件包也可以带知识库，安装以后就能查到，列表里会写 `来自 <包名>`。这种知识库是只读的：你只能打开或关闭它的自动想起（记录在 `~/.miyu/etc/kb.toml` 里），以及重建它的索引。卸载软件包时，它带来的知识库也会一起删除。如果你自己有一个编号相同的知识库，会使用你自己的那一个。

软件源里现成的知识库有 `kb-shorinwiki`，运行下面的命令即可安装：

```sh
miyu pkg install kb-shorinwiki
```

想自己做一个，可以看 [放文件就能用的](../dev/scripts-skills.md#知识库)。

## 界面

知识库可以在网页界面里管理，终端界面里只能用命令：

- 网页界面：设置里的 `知识库` 页面。页面顶上可以搜索；每个知识库是一张卡片，卡片上有 `自动联想` 开关；点进卡片可以列出文档、查看原文；你自己新建的知识库可以 `加文件`、`加文件夹`、把文件拖进来、删除文档；页面上还有 `新建空库`、`挂一个现有文件夹`、`重建索引`、`删除`。
- 终端界面没有知识库页，需要使用 `miyu kb`。

## 存放位置

知识库相关的文件存放在下面这些位置：

| 位置 | 是什么 |
|---|---|
| `~/.miyu/root/kb/<编号>/` | 一个知识库：里面是文档，以及一份 `kb.toml` |
| `~/.miyu/var/cache/index/kb/` | 索引，根据文件计算出来，可以用 `reindex` 重建 |
| `~/.miyu/etc/kb.toml` | 对于软件包带来的知识库，记录你改过的自动想起开关 |

`kb.toml` 可以手写，四项都可以不写：

```toml
name = "学习笔记"             # 名字，不写时使用编号
description = "日语语法和单词"  # 用一句话说明
auto = true                  # 自动想起，不写时是关闭的
mount = "~/Documents/notes"  # 挂载的目录；写了这一项时，文档在那个目录里
```

在 Windows 上，`mount` 要写 Windows 的路径，并且使用 TOML 的单引号字符串，里面的 `\` 原样保留，例如 `mount = 'D:\notes'`。

如果写了其他的项，或者写法不对，这个知识库会当作没有 `kb.toml` 来使用，`miyu kb list` 里会显示错误信息。

备份知识库、把知识库搬到另一台电脑，可以看 [数据和备份](data.md)。

## 排查问题

| 看到的现象 | 怎么办 |
|---|---|
| `无法添加 X：不支持的格式` | 知识库只收上面表里的几种文件 |
| `挂进来的知识库是只读的。` | 挂载的知识库不能添加、删除文档，需要到原来的目录里修改 |
| `随软件包来的知识库是只读的，只能开关自动想起。` | 软件包带来的知识库只能打开或关闭自动想起，以及重建索引 |
| `这个目录挂不上。` | 目录不存在，或者读取不了 |
| 文档后面写着 `缺少 miyu-extract` | PDF 和网页提取不了文字，`miyu-extract` 必须和 `miyu` 放在同一个目录里 |
| AI 不去查知识库 | 用 `miyu kb search` 试着搜索；检查人格的 `[knowledge]`，以及预设有没有打开知识库；给知识库写清楚名字和说明 |
