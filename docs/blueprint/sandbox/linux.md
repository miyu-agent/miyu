## 沙盒：Linux

### 是什么

Linux 上助手怎么照规格收紧自己。各平台共用的（规格、助手的命令行、退出码、探测）在 `sandbox.md`。

只用 Landlock（施工 5-2 起；5-3 改成只管写，照 DeepSeek 的 dsh 的 `landlock-run`）：它在内核里，不要任何特权，也不要命名空间。整盘能读，只管写；藏起来的（数据根）读写都不行。Landlock 只能放行，不能在放行的范围里再挖掉一块，所以「除了藏起来的都能读」是从根目录一级级放行、唯独通向藏起来的那条路不放做出来的。不要命名空间、不要 AppArmor（2026-09-29 项目主人定）。

### 在哪

| 代码 | 管什么 |
|---|---|
| `crates/miyu-sandbox/src/bin/miyu-sandbox/linux.rs` | `mechanisms`、`run`：照规格收紧（写着 `mount` 的换成 bubblewrap），再换成命令 |
| `crates/miyu-sandbox/src/bin/miyu-sandbox/linux/bwrap.rs` | 用 bubblewrap 的挂载收紧（施工 5-16）：找可信的 bwrap、真起一次验、照规格拼挂载、挂好以后在里面再跑一次助手 |
| `crates/miyu-sandbox/src/bin/miyu-sandbox/linux/landlock.rs` | 建 Landlock 的规则集、加规则、收紧自己 |
| `crates/miyu-sandbox/src/bin/miyu-sandbox/linux/reads.rs` | 读怎么放：从根目录一级级往下，绕开藏起来的 |

### 对外的样子

**探测时报的手段**：内核有 Landlock、至少是第 2 版的（第 2 版起才管得了跨目录的改名、链接；更老的一律不许，很多工具会坏），报 `landlock`；没有的报空。

**怎么放**：

| 什么 | Landlock 怎么放 |
|---|---|
| 读 | 列目录、执行：从根目录往下都放。读文件：从根目录一级级往下放，通向藏起来的那条路上的目录只放它们旁边的，藏起来的本身不放 |
| `write` | 这个内核的 Landlock 管得到的全部文件操作：读、写、建、删、改名、链接、截断、设备的 ioctl，内核 7.1 起还有连那里的 Unix 套接字 |
| `/dev/null` | 总能写 |
| `hidden` | 不放：读不了内容，写不了。列目录的权限从根目录往下带，名字看得到 |
| `reveal`（施工 X-10 中） | 每一条再放读（同读文件那一种）：Landlock 的规则互相叠加，藏起来的那一片没放，这里补上一块；写照旧不放 |

- 规格以外的都能读，写不了、删不了、改不了名，命令起的子进程一样。收紧以前已经打开的（标准输入、输出、错误）照旧能用。
- 规格里写的路径不在的，跳过。
- 一级级放行时，那几级目录里的链接跳过，不跟过去：跟过去就可能放行到藏起来的里面。
- 藏起来的落在某一条 `write` 里（施工 5-15，2026-10-20 项目主人定；原来拒绝执行）：写也照读的走法一级级绕开（`reads.rs` 的 `around`）：从那一条 `write` 起往下走，通向藏起来的那条路上的目录本身不放（不能在里面新建、删除、改名，所以藏起来的挪不出去、换不掉），里面已有的文件单个放写，别的整个放，链接跳过；藏起来的就是那一条本身的，什么都不放。正式装机（数据根是 `~/.miyu`）放开 `~` 时每条命令约 1.3 ms，同默认的会话子目录（约 1.8 ms，那时读要绕开的私密目录多）差不多（2026-10-20 本机量，release 的助手，`/usr/bin/true` 300 次的 p50）。能写的落在藏起来的里面（工作区在数据根里）：照样能写，它有自己的一条规则。
- 收紧的时候设 `no_new_privs`：沙盒里的 setuid 程序（例如 `sudo`）拿不到更高的权限。
- 连系统服务的套接字拦下（2026-09-29 项目主人定：能替命令在沙盒外读写的系统服务照样挡）：Landlock 第 9 版（内核 7.1）起，`write` 以外路径上的 Unix 套接字连不上（D-Bus、Docker 都是）；第 6 版（6.12）起，沙盒外建的抽象套接字也连不上。更老的内核拦不住。沙盒里要 ssh-agent 的 `git push`、桌面通知这类会失败。
- 规格的 `sockets`（施工 M-3）：每个加一条只放行连它的规则（`ResolveUnix`）；管不了连套接字的旧内核本来就不拦。用挂载收紧的，落在藏起来的里面的挂回来（`--bind`），里面那一次的规格带上它们。

**收紧不成的那一句**（`sandbox.md` 定的写法：`miyu-sandbox: cannot confine: <原话>`，退出 125，不跑命令），原话是下面之一：

| 原话 | 什么时候 |
|---|---|
| `landlock is not available: <原话>` | 内核没有 Landlock，或者不到第 2 版 |
| `cannot open <路径>: <原话>` | 规格里的路径、一级级放行时碰到的目录在，但打不开 |
| `landlock: <原话>` | 加规则、收紧自己出了错 |

### 怎么走

1. **`run`**：
   1. 规格写着 `mount` 的（施工 5-16）：换成 bubblewrap（`bwrap.rs`），见第 3 条；没有能用的 bwrap 的说 `cannot confine: bubblewrap is not available`、退出 125、不跑，不悄悄退回 Landlock。没写的往下（施工 5-15 起不再查「藏起来的落在能写的里面」，写照第 4 条一级级绕开）。
   2. 建规则集：第 2 版的全部文件操作必须管得住，管不住就拒绝；更新的版本多出来的（截断、设备的 ioctl、连路径上的 Unix 套接字）能管就管；抽象套接字的范围（第 6 版起）能管就管。
   3. 读：根目录放「列目录、执行」。再从根目录起一级级走：这一级目录里的每一样，是藏起来的，跳过；是通向藏起来的那条路上的目录，走进去接着看；是链接，跳过；别的放「读取文件」（它下面都带上）。没有藏起来的，就是根目录整个放「读」。打开了却查不了它是什么的（断开的 FUSE 挂载，`fstat` 报 ENOTCONN 这类），跳过这一条：它本来就读不了，不跳过的话整个规则集加不上、沙盒起不来（施工 5-4 补）。
   4. 每条 `write` 加「全部」的规则，`/dev/null` 加「写」的规则。打不开的：不在的跳过，别的拒绝。
   5. 设 `no_new_privs`，收紧自己（助手这时只有一个线程）。
   6. 换成命令（`unix.rs`）。
2. **`mechanisms`**：建一个要求第 2 版文件操作的规则集，建得成就报 `landlock`。只建不收紧，探测的进程不受影响。Landlock 能用、bubblewrap 也能用的再报 `bwrap`（施工 5-16）：只在 `/usr/bin`、`/bin`、`/usr/local/bin` 找，跟链接以后要是属于 root、组和别人都写不了的普通文件（不照 `PATH`：沙盒里的命令写得了 `~/.local/bin`，放个假的进去以后每条命令都等于没关）；找到了在临时目录里照正式的挂载真起一次（能写的 `w`、它里面藏起来的 `w/h`），里面藏起来的是空的、写进去报错、能写的写得进，都对才算（起得来不等于挂上了）。
3. **挂载**（施工 5-16，2026-10-20 项目主人定：有就用、不自带）：`--ro-bind / /`、`--dev-bind /dev /dev`、`--die-with-parent`；不在藏起来的里面的 `write` 照原样可写挂回；`hidden` 是目录的盖一层空的 tmpfs、是文件的拿 `/dev/null` 盖；藏起来的里面的 `write`（工作区在数据根里）可写挂回、`reveal` 只读挂回；最后藏起来的那几层 `--remount-ro`，写进去报只读，不会写进一层用完就丢的内存。不在的跳过。挂好以后在里面跑 `miyu-sandbox run --spec <里面的规格> -- <命令>`：里面的规格只留 `write`（藏、放开只读已经由挂载办了），照第 1 条以下用 Landlock 收紧，系统服务的套接字照旧拦。进程多一层 bwrap（一直在，约 2.3 MB），同一个进程组，整组杀照旧。本机量（2026-10-20，release 的助手，`/usr/bin/true` 300 次的 p50）：放开 `~` 时挂载约 2.4 ms，只用 Landlock 约 1.2 ms。

### 已知的限制

- **能改工作区外已有文件的时间戳**（2026-10-07 主会话实测）：Landlock 不管改时间戳（`utimensat`），所以 `touch` 一个能写的范围以外、已经有的文件会「成功」，只改了修改时间，内容没动；往里写、追加、新建都照样挡下。实测经助手跑 300 次往家目录新建，全挡下。她因此可能以为「写成了」：`touch` 的退出码是 0。要挡就得另加系统调用过滤（seccomp），先记下不做（2026-10-07 项目主人没反对，主会话定）。
