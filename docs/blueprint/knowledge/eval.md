## 知识库自动想起的测评集

### 是什么

一份放进仓库的测评集和一个随时能重跑的量尺（施工 K-6 上，2026-10-13）：量知识库的自动想起（19 N5，K-6 下）该照什么挑、门槛定在哪。同记忆的测评集（`memory/eval.md`），只是量的是「这一轮该不该带上这一段」，不是搜得准不准。

测评集是虚构的：一个叫雾港的港口城的世界观（人物、地点、规矩、历史），17 段，每段一个标题，正好是自动想起最该用的那种「一提到就该想起来」的内容（19 N5）。人名、地名都是编的。

### 在哪

| 东西 | 管什么 |
|---|---|
| `crates/miyu-session/tests/fixtures/kb-eval/world/*.md` | 世界观：四篇，`##` 一段一个标题 |
| `crates/miyu-session/tests/fixtures/kb-eval/queries.toml` | 问句：48 句，四种 |
| `crates/miyu-session/tests/kb_eval.rs` | 规矩查一遍；量尺 |

### 格式

`queries.toml` 每条 `[[query]]`，多写别的格读不进：

| 格 | 规矩 |
|---|---|
| `kind` | 四种之一，见下 |
| `text` | 不空，照人在聊天里真会说的话写（自动想起拿的就是这一轮人说的话） |
| `expect` | 该想起的那几段，写成「文档:标题」（标题路径的最后一段，照知识库的切法算）：都在、不重；`none` 的是空的，别的不空 |

| 种类 | 是什么 |
|---|---|
| `name` | 话里提到了那一段的名字（「艾琳今天去哪了」） |
| `paraphrase` | 没提名字，换了说法（「那个守灯的姑娘怕什么」） |
| `chat` | 聊天里顺口带到的（「外面打雷了，艾琳没事吧」） |
| `none` | 平常的话，一段都不该想起 |

整份：问句 40 句以上，`none` 占两成以上，四种都有。

### 怎么量

```text
MIYU_EMBED_MODEL_DIR=<Release models-bge-small-zh-v1.5 的文件> \
  cargo test -p miyu-session --test all measure_the_kb_eval_set -- --ignored --nocapture
```

1. 临时数据根里建一个库，四篇拷进去，照文件补；一段一块。
2. 几种挑法，每句挑出带哪几段：
   - **标题名**：话里出现了某一段标题的最后一段（两个字以上）。
   - **关键词搜得到**：只走关键词搜，前 3 块（照 `kb_search` 的那一路）。
   - 设了 `MIYU_EMBED_MODEL_DIR` 的（同 `memory/eval.md`）：补齐向量，每句算问句的向量，照意思找前 3 块：
     - **照意思**：相似度过门槛的（0.50 到 0.70 量五档）。
     - **标题名加照意思**：两样合起来。
3. 照种类印一张表，列是：带了东西的占几成（`none` 的看这一格，该是 0）、带了的里该带的占几成、这一轮至少带对一段的占几成、平均带几段。最后一行 `all` 是有答案的三种合在一起。另印平常的话最像的那一段多像，有答案的该带的那一段多像。
4. 断言结果不断言耗时：一段一块、补齐了向量。

### 基线

2026-10-13，本机 Ryzen 9 7940H、Linux x86_64，模型是 Release 的 bge-small-zh-v1.5（8 位量化）。

| 挑法 | 平常的话带了东西 | 带了的里该带的 | 这一轮带对了（有答案的） | 点名的带对了 | 换了说法的带对了 |
|---|---|---|---|---|---|
| 关键词搜得到（前 3 块） | 43% | 37% | 91% | 93% | 83% |
| 标题名 | 0% | 100% | 53% | 100% | 0% |
| 照意思，门槛 0.55 | 0% | 78% | 82% | 79% | 83% |
| 照意思，门槛 0.60 | 0% | 93% | 74% | 71% | 75% |
| 照意思，门槛 0.65 | 0% | 100% | 59% | 57% | 58% |
| 标题名加照意思 0.55 | 0% | 79% | 91% | 100% | 83% |
| **标题名加照意思 0.60** | **0%** | **94%** | **88%** | **100%** | **75%** |
| 标题名加照意思 0.65 | 0% | 100% | 79% | 100% | 58% |

- 平常的话最像的那一段：0.358 到 0.493，没有一句过 0.50。
- 该带的那一段多像：点名的 0.43 到 0.77，换了说法的 0.53 到 0.74，顺口带到的 0.53 到 0.76。

看得出的几件，K-6 下照它做：

- 关键词搜得到就带的不行：平常的话四成多也搜得到东西，带的里六成多不相干（同记忆的测评集，两字切分里「什么」「怎么」到处都有）。
- 标题名准得很：点名的全想得起，一句闲聊都不带；换了说法的全想不起，要照意思那一路补。
- 合起来门槛 0.60（同记忆的联想，`memory.md` 第四条第 2 款）：闲聊一句不带，带的 94% 对，88% 的回合想起了该想的。0.55 多想起 3 成点、带错的多一倍；0.65 一段都不错，换了说法的只剩六成。

### 定了的

2026-10-13 项目主人看了这张表定：自动想起「关键词也算」照**标题名**算（话里提到了某一段标题的名字才带），再加照意思那一路，门槛 0.60。普通的关键词搜得到不算。`models.embedding` 关着、算不出的只剩标题名这一路（点名的照样想得起）。
