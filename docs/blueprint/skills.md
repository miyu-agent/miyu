## 技能和脚本

### 是什么

- **技能**：一个文件夹，里面一份 `SKILL.md`（开头几行写名字和一句说明，正文教她怎么做一类事），可以带参考资料、脚本。她平时只看到技能的名字和一句说明，用得上时自己读正文（`10-自带软件.md` 第三节：技能不单独设工具，用 `read` 读）。
- **脚本**：一个可执行文件，开头的注释写说明、参数，接进来就是她的一件工具（旧版 Miyu 的做法，实测好用：旧版出厂 17 个，番剧、天气、各家搜索、抖音下载这类）。

已经定了的（不在这里重定）：

- 技能、脚本和别的软件一样是装好的软件，不住在预设里；每个技能、每个脚本自动算一个功能，预设里能逐个开关（`16-人格与预设.md` Y7，`30-插件框架.md` 第三节）。
- 从哪来：软件包里的 `skills/<名字>/SKILL.md`、`scripts/<文件>`；本机自己放的在家目录里，同名的自己放的赢（`31-软件包.md` 第五节）。自己做出来的在做出它的那个预设里打开（16 第三节）。
- 技能的列表在 system 的「技能与知识库」那一段，排在核心和软件包的几行后面（`26-提示词.md` 第三节）；技能正文是她读进来的工具结果，压缩以后照「用过的技能」重建（`09-压缩.md` 第四节，`10-自带软件.md` 的 `file.read` 效果）。

状态：图纸（2026-10-11 主会话写；项目主人 2026-10-10 定了技能要先过一遍设计，2026-10-11 照推荐定了下面「定了的」五条）。施工 X-10 上做完（2026-10-12）：找、读开头、列进 system、文件夹放开只读（文件工具）；X-10 中做完（同一天）：沙盒里的命令也读得到（规格的 `reveal`，Linux、macOS；Windows 的沙盒还没收紧）；X-10 下做完（同一天）：读了 `SKILL.md` 的效果标上技能，压后另算一组重读回来（`compaction.md` 第九条第 3 条）。X-11 上做完（同一天）：每个技能算一个功能 `skill-<名字>`，造会话、载入时照预设筛，`preset.get` 列出来能开关。X-11 下做完（同一天）：回合开始照这一刻再找一遍，放开的文件夹跟着换，列表变了的在尾巴交一份新的（`<skills-changed>`）。X-12 上做完（同一天）：读脚本的开头注释、找脚本、脚本当一件工具怎么跑。X-12 中做完（同一天）：核心起来时、装卸包以后整份登记进工具目录，每个脚本一个功能 `script-<工具名>`，预设开关，`preset.get` 列出来。X-12 下做完（同一天）：`miyu check` 报跳过的脚本、技能和撞名没登记上的脚本，进沙盒的脚本读得到它自己；脚本多大都收（项目主人同一天改定）。X-13 上做完（同一天）：只写 `[package]` 的包是只带技能、脚本的 `bundle`，没有开关；装之前的预览列出包带的技能、脚本。X-13 中做完（同一天）：`miyu check` 说清同名的被谁盖住（`script_covered`、`skill_covered`），作者说明补上技能、脚本。X-13 补做完（同一天）：装之前的预览报读不成的技能、脚本（`skipped`）。X-13 下做完（同一天）：出厂包 `authoring` 带 `skill-creator`、`package-creator`，技能给人看的名字照语言（`display_name_zh` 这些）。

做法上定的（施工 X-10 上，主会话照推荐定）：

- 列出来的那一块造会话时钉进快照（`skills`，没有的不写），换人格重拼也照旧；放开只读的文件夹造会话、载入时照这一刻找到的各算一次。
- 名字、说明、路径照模板转义（同知识库那一块）：说明里的引号、尖括号写成 `\u0022` 这种，伪造不了标签。路径在 Windows 上反斜杠换成 `/`。
- 不设个数上限：每个技能自动算一个功能、预设里能关（X-11），超了预算由 `miyu check` 报（X-13）。
- 只碰得到自己工作区的会话（群会话这些）也读得到开着的技能文件夹，写照拒。

### 技能

1. **写法**：照公开的 Agent Skills 格式（Anthropic 起的头，现在 Claude Code、Codex、Gemini CLI、Cursor 这些都认）：`SKILL.md` 开头的 YAML 写 `name`（小写字母、数字、`-`，和文件夹同名）、`description`（给模型看，英文，说清是什么、什么时候用，可以带人会说的几个中文触发词）；正文随意。给人看的名字、一句说明放在格式自带的 `metadata` 里（`display_name`、`summary` 算英文，`display_name_zh`、`summary_zh`、`_ja` 是另两种：格式的 `metadata` 只收字到字的表，语言写进键里，施工 X-13 下）：给模型的和给人的分开两格（旧版吃过一格两用的亏，设置页中英混杂）。别的格子照格式认、不用。
2. **她看到的**：system 里技能那一段一行一个：名字、一句说明、`SKILL.md` 的路径。只列这个会话的预设里开着的。说明超过 1024 个字的截断（格式的上限）。
3. **读**：她用 `read` 读那个路径，读技能文件夹里别的文件（参考资料）也一样。技能文件夹在数据根里，文件工具平时碰不到（`11-权限与沙盒.md`），开着的技能文件夹单独放开只读（`session/guard.md` 加一条），不问人。技能里带的脚本照她跑命令的规矩跑（沙盒里能读这个文件夹）。
4. **用过的技能**：她读了某个技能的 `SKILL.md`，执行器在效果里记上（`10-自带软件.md` 的 `file.read`），压缩以后照它重读回来（09 第四节）。
5. **会话中途列表变了**（装了、卸了、她自己写了一个）：见「定了的」第 2 条。

### 脚本

1. **写法**：照旧版的开头注释，旧版的 17 个照搬就能用：

   ```python
   #!/usr/bin/env python3
   # Display name: Bangumi
   # 显示名称：番剧信息
   # Description: Bangumi airing calendar and subjects: what airs today, search, details.
   # 描述：查番组计划的放送日历与条目。
   # Timeout: 60
   # Parameters:
   # { "type": "object", "properties": { "query": { "type": "string" } } }
   ```

   `Description` 给模型（英文），`描述`、`显示名称` 给人（双槽，同技能；`显示名称`、`Display name` 也是时间线上这件工具的名字，派它那一刻记进结果，施工 9-8 六补）；`Parameters` 是参数的 JSON Schema，没写的当没有参数；`Timeout` 是秒，没写的 60。
2. **她看到的**：一件工具，名字是文件名（去掉扩展名，不合 `[A-Za-z0-9_-]` 的换成 `_`），说明、参数照开头注释。说明、参数多大都收，不按大小挡（2026-10-12 项目主人定）。开头写错的、同名被压掉的不登记，`miyu check` 报出来。
3. **跑**：照开头的 `#!` 起程序（Windows 上照扩展名找解释器）；参数是一份 JSON，交给环境变量 `MIYU_ARGS_JSON` 和标准输入（同旧版）；工作目录是会话的工作区；另给它一个能写缓存的目录（`MIYU_SCRIPT_CACHE_DIR`）。输出照命令的输出交回，退出码不是 0 的算出错。访问类别是执行：照跑命令的规矩进沙盒、问人（`session/guard.md`）；进沙盒的单独放开脚本这一个文件只读（在数据根里的，沙盒本来藏着）。
4. **技能里的脚本**不算工具，不进工具面：由技能正文写怎么跑（她用跑命令的那件工具跑）。

### 定了的（2026-10-11 项目主人照推荐定）

1. **照公开的 Agent Skills 格式**：网上现成的技能放进文件夹就能用；给人看的名字、说明放在格式自带的 `metadata` 里。
2. **会话中途技能列表变了**：在这一轮的尾巴上追加一份新的完整列表，system 里那一段不改，前缀缓存不掉（旧版 Miyu、dsh 都这样）。
3. **脚本当工具**：每个脚本一个开关，群里没有跑命令工具的会话也能用；代价是每个脚本占一份工具面。多大都收，不按大小挡（2026-10-12 项目主人改定，原先定的是超了预算不收）。
4. **本机自己放的目录**：`home/<账号>/skills/`、`home/<账号>/scripts/`。
5. **出厂带两个技能**：写技能的、写脚本和写包的。旧版的 17 个脚本放进软件源，不随出厂带。
6. **「基础功能」也开这两个技能**（2026-10-12 项目主人照推荐定，施工 P-8）：每次请求多 137 个 token；不开的话她要写技能时看不到，在本机目录里翻了三十多秒（F-10 下下真模型走查）。
7. **卸掉了的包，历史里技能那一步的名字退回技能名**（2026-10-12 项目主人照推荐定）：同工具的显示名一个规矩，日志只记事实，给人看的名字照现在装着的查（`view.md` 的 `skill`）。
