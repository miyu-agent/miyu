## 长期目标：交代一件要做很久的事，她自己一轮轮做下去

### 是什么

人用 `/goal <目标>` 交代一件要做很久的事。会话闲下来，核心替她开下一轮（续轮），她每轮往前做一步；做完了调 `goal` 报完成，做不下去报卡住，再写一段收尾给人。旧版 Miyu 做过，实测好用；这一份照旧版的行为、按新的架构放（证据在旧版的 `crates/miyu-engine/src/tools/goal/`、`crates/miyu-hosts/src/web/goal_driver.rs`，代码注释里记着每一条是哪次实测出来的）。

包：内置包 `goal`（`30-插件框架.md` 第二节的表），一个功能「长期目标」；预设「基础功能」默认开（`16-人格与预设.md` 第四节）。

状态：施工中（2026-10-11 主会话写；项目主人同一天定了下面「定了的」四条）。X-6（事件、账本、会话层照日志算的样子、会话状态的 `goal`）、X-7（改目标的命令、续轮、等人开口、到上限算卡住、载入时停下、续轮消息）做了；X-8 上（包和工具 `goal`、收尾、续轮消息说是谁设的）施工中，X-8 下是 `/goal` 命令。

### 照旧版留下的

1. **只在闲着时开续轮**：没有回合在跑、没有排着的人的话。人优先：自动轮不插在人前面。
2. **一轮下来一个工具都没调，停下等人开口**。最常见的是「我在等你确认」，再开下去只会把同一句话重复几十遍，每遍都花钱。人说了话（哪一轮都算）就接着跑。
3. **报卡住要先连着做满 3 轮自动轮**：不然第一轮遇到点麻烦就宣布卡住，长任务退化成「起个头就收工」。人说停随时停。
4. **核心重启以后不自己接着跑**，要人 `/goal resume` 再授权：一次崩溃重启不能让机器在没人看着的时候自己开轮。
5. **续轮消息照搬旧版的措辞**（`26-提示词.md` 第六节定了照搬）：开头一句说清是人用 `/goal` 交代的、闲着时自己开的轮（旧版实测：没有来历的一段祈使句被模型当成注入拒了）；第一轮完整版，之后每轮一段短版，短版自包含（目标原文、规矩、两条写好的结束调用），压缩以后不指向丢掉的旧文。
6. **轮数默认不限**（旧版 09-11 去掉了上限），`/goal` 时可以写上限，到了算卡住。
7. **派了子代理就结束这一轮**：它们报回来时叫醒她（现有的机制），不空转一轮光说在等。

### 在新的架构里怎么放

1. **目标记在会话日志里**：真相只有日志（`07-存储.md` 第一节），不另开库。几种事件：`goal.set`（目标原文、轮数上限、谁设的）、`goal.changed`（改了原文或上限）、`goal.paused`、`goal.resumed`、`goal.ended`（完成、卡住带原因、人清掉）。第几轮、连着几轮自动轮、在不在等人，都从日志算；载入时重放回来。格式另在 `03-事件模型.md` 登记。
2. **续轮谁开**：会话的 actor，每送完一批看一眼（和「空了告诉我」同一处，`actor/watchers.rs` 的 `after_batch`）。目标在跑、这次运行里授权过、会话空着（内核的 `vacant`：没有回合、没在重启、没在等子代理）、收件箱里没有人的话、没在等人开口：交内核一个说话的命令，`by` 是长期目标这个模块，正文是续轮消息。内核照平常开一轮，不加新的回合种类。
3. **授权只在内存里**：`/goal <目标>`、`/goal resume` 时授权，核心重启以后没有。授权着的会话不闲够了退下（`protocol.md`「会话表」第 9 条那几样「还有事」里加一条），不然退下再载入就断了。施工 X-7 落成：载入会话时，目标照日志还跑着的，内核记一条 `goal.paused`（`by` 内核），日志说的就是实情，`/goal resume` 照常记 `goal.resumed`；跑着的一定是这次运行里设下、接着跑的，不另记授权。
4. **工具 `goal`**（施工 X-8 上，`tools/goal.md`）：她用它自己设目标（`set`，当场算授权过）、报完成（`complete`）、报卡住（`blocked`，带原因）、看现在的目标（`get`）。结束调用的两条写在续轮消息里，参数填好，她不用回忆格式。报卡住的「先做满 3 轮」只管续轮开的那一轮（人开的那一轮人在，说停就停，旧版同样）：照会话状态的 `round` 数，不到 3 的拒，说这是第几轮、至少几轮。工具经端口交给会话的 actor，actor 交内核 `Goal` 命令（`by` 是这次调用），拒的原因原样回给她。续轮消息里「谁设的」照 `goal.set` 的 `by` 分两种：人用 `/goal` 设的，她自己用工具设的（照搬「人设的」会让她以为是人交代的）。
5. **收尾**（施工 X-8 上改）：续轮开的那一轮里报了完成、卡住，那一次调用的结果就是收尾的说法（写收尾给人：做了什么、怎么验的、产出在哪；卡住的说做到哪、卡在哪、要人做什么；这一次自动运行里不再调工具；措辞照搬旧版），她接着在同一轮写。不另开收尾轮、不在 system 里常驻一行规则：收尾一个目标只用一次，常驻每次请求都带（`26-提示词.md` 第六节，同一天改）；旧版也是在同一轮里接着收尾。人开的那一轮里报的只说记下了。到了轮数上限由核心记卡住，不收尾（旧版同样）。
6. **命令**（核心的命令，`commands.rs`）：`/goal <目标>` 设一个并授权；`/goal` 看进度；`/goal pause`、`/goal resume`、`/goal edit <目标>`、`/goal clear`。已经有一个没结束的，`/goal <新目标>` 拒、说用 `edit` 或先 `clear`。
7. **头上看得到**：会话状态多一格 `goal`：目标、第几轮、上限、状态（跑着、停着、等人、卡住、完成）、卡住的原因；变了推 `view.status`（`view.md`）。续轮的那条消息在时间线上照「她自己开的轮」画，不当人说的话。
8. **场所会话先不开**：群里、私聊里的 `/goal` 回不支持（旧版也只在本机的会话里跑）。

### 定了的（2026-10-11 项目主人）

1. **她能自己开目标，不做限制**：哪一轮里都能开（不只在人发起的那一轮），用 `goal` 工具开、开了当场算授权过（第 3 条）。改、停、继续、清掉照推荐只走 `/goal`。
2. **轮数默认不限**（照推荐）：`/goal` 时可以写上限；头上一直显示第几轮、这个目标花了多少。
3. **核心重启以后要人重新授权**（照推荐）：照日志知道有个目标在跑，但不自己接着开轮，等人 `/goal resume`；机器重启后不会没人看着自己跑起来。
4. **群聊、私聊的会话先不能用**（照推荐）。
