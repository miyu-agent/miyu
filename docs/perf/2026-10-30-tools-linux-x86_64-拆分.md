## 对照拆开

回答写完到量尺收到 `turn.ended` 7.55 / 16.67（回合结束落了盘、同步了才推）；收到 `turn.ended` 到读全下一个请求头 2.12 / 2.51（量尺再说一句、核心收下、组装、发出：底子）；另记收到 `turn.ended` 到 `session.send` 的回应 10.22 / 19.44（这一句同步了才回，请求常常先到）。p50 / p95，毫秒。
