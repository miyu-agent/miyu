## 对照拆开

回答写完到量尺收到 `turn.ended` 1.11 / 2.72（回合结束落了盘、同步了才推）；收到 `turn.ended` 到读全下一个请求头 1.38 / 1.77（量尺再说一句、核心收下、组装、发出：底子）；另记收到 `turn.ended` 到 `session.send` 的回应 2.97 / 3.96（这一句同步了才回，请求常常先到）。p50 / p95，毫秒。
