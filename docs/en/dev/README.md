# Developer documentation

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

For developers who want to extend Miyu, connect to it, or change its code. The docs live in three places: `authors/` holds tutorials for writing packages, `reference/` is the protocol reference, and `dev/` covers the architecture and contributing code. Find what you want to do below. Chinese version: [中文](../../zh/dev/README.md).

The docs in these places each come in Chinese and English, and the Chinese is the authoritative text. `reference/`, `authors/`, `dev/` and the user guide `guide/` are under Apache-2.0 (`LICENSES/Apache-2.0.txt` at the repository root), so what you write from them can use any license. Packages, extensions and heads that only talk to Miyu over the protocol are separate works, and the core's AGPL does not reach them.
