# Developer documentation

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

This part is for developers who want to extend Miyu, connect to it, or change its code. The docs live in two places: `dev/` (this folder) holds the tutorials, plus the architecture and how to contribute code; `reference/` is the protocol reference. Find what you want to do in the table below, and it tells you which page to read:

| I want to | Read |
|---|---|
| Write a skill, a script tool, or a slash command template | [Things that work as files](scripts-skills.md) |
| Connect an existing MCP server | [MCP servers](mcp.md) |
| Write an extension with tools | [Writing an extension](extensions.md); for the details of every method see [Protocol reference: Extensions](../reference/extensions.md) |
| Write a model driver | [Writing an extension: writing a model driver](extensions.md#writing-a-model-driver) |
| Make a package and publish it to a package source | [Writing a Miyu package](packages.md); for every field of the manifest see [The manifest](manifest.md) |
| Put your own things on the terminal UI or the web UI | [Putting things on the screen](ui-surfaces.md) |
| Write a theme or a skin | [Writing themes and appearance](themes.md) |
| Write a new head (a head is an interface program that connects to the core, such as the terminal UI or the web UI) | [Writing a head](head.md) |
| Write a plugin for a chat platform | [Writing plugins for chat platform access](https://github.com/miyu-agent/miyu-im/blob/main/docs/authors/README.md) in the `miyu-im` repository |
| Write an extension with the Python or Rust development kit | [miyu-agent/miyu-sdk](https://github.com/miyu-agent/miyu-sdk) |
| Look up a protocol method's params, reply and errors | [Protocol reference](../reference/README.md) |
| Understand which processes, crates and repositories make up Miyu | [Architecture](architecture.md) |
| Propose a change to the core or a head | [Contributing](contributing.md) |

The docs in both places come in Chinese and English, and the Chinese text is authoritative. `dev/` and `reference/` are under the Apache-2.0 license (the full text is in `LICENSES/Apache-2.0.txt` at the repository root), so what you write by following them can use any license. Packages, extensions and heads that talk to Miyu only over the protocol are separate works, and the core's AGPL does not reach them.
