# Errors

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

When the core refuses a request, the response looks like this:

```json
{"error": {"code": -32010, "data": {"reason": "session_not_found"}, "message": "Session not found."}, "id": "c7", "jsonrpc": "2.0"}
```

- `code`: JSON-RPC's own errors use the standard codes (the first five rows of the table below); Miyu's own errors all use `-32010`.
- `data.reason`: the reason code for programs, and the field your program should branch on. Some errors carry more fields, which are listed in the tables below.
- `message`: one sentence for people, in the connection's language (before the handshake and when the handshake is refused, it is in English or in the language given in that `hello`). Don't branch on it.

## General

| `reason` | `code` | When |
|---|---|---|
| `parse_error` | -32700 | What arrived is not JSON |
| `line_too_long` | -32010 | A line is over 1 MiB: the core refuses only that line, and the connection stays open; `data.limit` is the limit, and `id` is the one the core could find at the start of the line |
| `invalid_request` | -32600 | What arrived is JSON but not a request |
| `unknown_method` | -32601 | There is no such method (methods of optional packages that weren't compiled in also return this error) |
| `bad_params` | -32602 | The params can't be read, have the wrong type or are malformed; each method's "Errors" lists its own cases |
| `internal_error` | -32603 | Something went wrong inside the core (the disk, a broken file…); the reason is recorded in the core's log |
| `hello_first` | -32010 | Another method was called before the handshake |
| `local_only` | -32010 | An extension called a method that is for people only; or the way of logging in is wrong |
| `local_machine_only` | -32010 | The method works only on the machine running the core: a remote connection called a method that reads local files or takes local paths (see "Local machine only" in [Connection](connection.md)) |
| `not_a_provider`, `not_an_extension` | -32010 | The method is only for extensions the core launched, and another connection called it |
| `needs_approval` | -32010 | Capabilities the extension needs aren't approved yet, or the method it called needs a capability its manifest doesn't declare, or a tool in `provide` sets `runs_commands` while the package doesn't have `tools.commands` approved; the missing capabilities are in `data.capabilities` |

## Connecting and logging in

The errors of this kind are `protocol_mismatch`, `bad_token`, `bad_code`, `bad_login`, `bad_password`, `password_not_set` (no access password has been set yet), `login_throttled` (all of these close the connection after answering), `setup_first`; `not_permitted` (returned when a confined session installs, removes or upgrades packages through its port); and `bad_ticket` when the ticket for `login.redeem` doesn't exist, has expired or was already used. For details see [Connection](connection.md).
