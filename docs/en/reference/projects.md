# Projects: `project.*`

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

A project is a group of sessions (similar to Projects in ChatGPT or the Claude web app). It has a name, a color, and the defaults for new sessions (working directory, persona, preset), plus extra instructions and a messaging switch. Projects are stored in `projects.json`. A project here is not the project config of a code repository (`.miyu/config.toml`, `untrusted_project` in replies).

| Method | What it does |
|---|---|
| [`project.list`](#projectlist) | Lists all projects |
| [`project.create`](#projectcreate) | Creates a project |
| [`project.update`](#projectupdate) | Changes some fields, or clears some fields |
| [`project.delete`](#projectdelete) | Deletes a project |

**Who can call**: only people can call these methods; when an extension calls them, it gets `local_only`. If a head (an interface program that connects to the core, such as the terminal interface or the web interface) wants to follow changes, it can subscribe to the `projects` stream (see [Connection](connection.md)); after that the core pushes `projects.changed` (see [Pushes](pushes.md)).

## An item

| Name | Meaning |
|---|---|
| `project` | The project id, a UUIDv7 made by the core. |
| `name` | The project name, 1 to 40 characters long, with no leading or trailing spaces. |
| `description` | The project description, at most 80 characters. |
| `color` | The project color, written as `#rrggbb`. |
| `workspace` | The working directory for new sessions in the project, written the way people see it. |
| `persona` | The persona id for new sessions; `null` means no persona; when the field is absent, the configured default is used. |
| `preset` | The preset id for new sessions; when the field is absent, the configured default is used. |
| `prompt` | Extra instructions, at most 8000 characters. |
| `open` | When `true`, sessions in the project may message sessions outside the project; the field is omitted when `false`. |
| `created` | When the project was created. |

Fields that were never set are omitted.

## `project.list`

**Params**: none. **Result**: `{"projects": [<item>…]}`, oldest first.

## `project.create`

**Params**: the fields in the table above except `project` and `created`; `name` is required, and a field given as an empty string counts as not given. **Result**: `{"project": <id>}`.

## `project.update`

**Params**: `project` (required), the fields to change, and `unset`: an array of the names of fields to clear (`description`, `color`, `workspace`, `persona`, `preset`, `prompt`). Fields given a value get the new value, fields given an empty string are cleared, and fields listed in `unset` go back to being unset. **Result**: `{}`.

## `project.delete`

**Params**: `project`. **Result**: `{"moved": <sessions moved out>}`. The core first writes a `session.meta_changed {"project": ""}` for each session in the project, moving them out one by one; the sessions themselves are not deleted.

## Errors

| `data.reason` | When |
|---|---|
| `bad_params` (`-32602`) | `data.field` names the field that is wrong: the name is empty, too long or padded with spaces; the description or the instructions are too long; the color is not `#rrggbb`; the working directory is blank; or `unset` lists a field that cannot be cleared, or a field that is also given a value. |
| `unknown_project` | There is no such project. |
| `unknown_persona`, `persona_invalid`, `unknown_preset`, `preset_invalid` | The persona or preset does not exist or is broken; this is checked when a project is created or updated. |
| `internal_error` (`-32603`) | `projects.json` cannot be read or written. |
