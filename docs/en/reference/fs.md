# Files: `fs.*`

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

This page covers the local file operations for heads (interface programs that connect to the core, such as the terminal interface or the web interface): completing paths, finding files, resolving a path to its real location, and reading a file in chunks.

| Method | What it does |
|---|---|
| [`fs.list`](#fslist) | Lists one directory level, for path completion in the input box |
| [`fs.find`](#fsfind) | Fuzzy-finds files in a directory |
| [`fs.realpath`](#fsrealpath) | Resolves a path to its real location |
| [`fs.read`](#fsread) | Reads a local file in chunks |

**Who can call**: people can call these methods; extensions need the `fs.read` capability.

**Boundary**: inside Miyu's data directory (by default `~/.miyu`), only the workspace folder `workspace/` can be listed, searched and read; anything else returns `path_forbidden`. `fs.realpath` only reports a location and doesn't read the contents, so it doesn't check the boundary.

**Paths**: write an absolute path, or a path starting with `~` or `~/…` (joined to the system's home directory).

## `fs.list`

**Params**

| Name | Type | Notes |
|---|---|---|
| `cwd` | string, required | Relative paths are joined to it. |
| `dir` | string, default `""` | The directory part typed so far: one starting with `~` is joined to the home directory, an absolute one is used as it is, and anything else is joined to `cwd`. |
| `prefix` | string, default `""` | The start of the name. |

**Response** is `{"items": [...], "partial"}`. Each item has these fields:

| Name | Notes |
|---|---|
| `path` | How the list shows it; directories end in `/`. |
| `full` | The absolute path, in the current platform's form. |
| `dir` | Whether it is a directory. |
| `size` | The file's size in bytes; directories don't have it. |
| `marks` | The positions (character indexes) in `path` that matched `prefix`. |

The core matches the start of each name against `prefix`, ignoring case; names starting with a dot are listed only when `prefix` starts with `.`. Directories come first and files after them, each sorted by name. At most 50 entries are returned; the rest is cut off, and `partial` is then `true`.

```json
→ {"jsonrpc":"2.0","id":"f1","method":"fs.list","params":{"cwd":"~/src/miyu","dir":"src/","prefix":"ma"}}
← {"id":"f1","jsonrpc":"2.0","result":{"items":[{"dir":false,"full":"/home/me/src/miyu/src/main.rs","marks":[4,5],"path":"src/main.rs","size":2048}],"partial":false}}
```

**Errors**: `path_unreadable` (the path doesn't exist, isn't a directory, or there is no permission); `path_forbidden`.

## `fs.find`

**Params**

| Name | Type | Notes |
|---|---|---|
| `cwd` | string, required | The directory to search in. |
| `query` | string, default `""` | What the user has typed. |
| `fresh` | boolean, default `false` | Pass `true` when opening the list: if the index was built more than 10 seconds ago, it is rebuilt. |
| `wait` | boolean, default `false` | If the index is still being built, the answer waits until it is done (it is answered in the background). |

**Response**: the same as for `fs.list`, plus `building`, which means the index is still being built and this answer covers only the part built so far.

1. The core builds a file index of `cwd`: it honors `.gitignore`, skips hidden directories, `node_modules` and `target`, and doesn't follow links; it goes at most 8 levels deep and holds at most 20000 entries, and `partial` is `true` when it is full. `path` is relative to `cwd`, joined with `/`.
2. A file is listed only when every typed character appears in its `path` in order (ignoring case); matches in the file name, at the start of a segment, and consecutive matches rank higher, and a file name equal to the query comes first. At most 50 entries are returned.

**Errors**: the same as for `fs.list`.

## `fs.realpath`

**Params**: `path` (required); `cwd`: only needed when `path` is relative.

**Response**: `{"path": <real location>}`. Links are followed to their target; the parts that don't exist yet are appended, as written, to the last level that exists.

**Errors**: `bad_params` (the path is relative but no `cwd` was given); `path_unreadable` (no level exists, a link points nowhere, or there is no home directory).

## `fs.read`

**Params**: `path` (required, and it can't be relative); `offset` (default 0); `length` (default 512 KiB, at most 512 KiB; 0 asks for the size only).

**Response**: `{"data", "size"}`, the same as for [`blob.get`](blob.md#blobget). No link anywhere on the path is followed.

**Errors**: `bad_params` (the path is relative, or `length` is over 512 KiB); `path_unreadable` (the file doesn't exist, isn't a regular file, or there is no permission); `path_forbidden`.
