## 旗舰顾问

一件内置工具 `advisor`：她遇到难题时，把问题交给旗舰池里的模型，拿回建议接着做。用便宜的模型干平常的活，卡住了才请贵的模型出主意，用小钱换来大模型的判断。

状态：定稿（2026-11-10）。项目主人 2026-11-10 在发版前 check 第 30 条写的需求：旗舰池里有可用模型才生效，不然调了只回「旗舰模型没设」这类报错；顾问会话可以照参数接着上一次聊，默认每次新开；顾问没有工具，系统提示词专门写；她发给顾问的话当成用户消息，不放进系统提示词，免得每次断缓存。下面的形状 core1 定（第三节），工具名待项目主人验收时确认（第三节第 1 条）。施工 ADV-1 到 ADV-3，首个正式版之前做。

### 一、要什么

1. 她在会话里调 `advisor`，带上问题，同步等回答（不是子代理那种后台跑、跑完报告），回答当工具结果交回。
2. 顾问是旗舰池（`@flagship`，显示名「旗舰池」）里的模型。池里没有可用的模型时，工具照样在工具面上（工具面会话内字节恒定），调了只回一句报错：旗舰池里没有模型，叫人去配。
3. 顾问没有工具、没有人格，系统提示词是专门的一份（资源 `core/advisor/system.txt`），讲清楚它是顾问、只看得到问题里写的、给建议不替她做。
4. 她的问题作为用户消息发给顾问；系统提示词不随问题变，前缀稳定，接着聊的时候缓存照用。
5. 默认每次新开一个顾问会话；写了 `continue: true` 的接着这个会话上一次的顾问会话聊（顾问看得到上一次的问答）。上一次没有的，照新开。

### 二、为什么这么做

- **同步、不后台**：她要拿到建议才能接着做，和 `ask_user` 一样等着；后台跑的子代理是派活，不是问主意。
- **顾问会话是一个子会话**：照子代理的那套造（施工 7-5 起的 `sessions`、`spawn` 端口），种类记成 `advisor`，没有工具、钉着旗舰池。这样用量、花费照常记进账本、算进这个会话的 `usage_tree`，时间线上看得到这一步，接着聊就是往同一个子会话再说一句。不另造一种存储。
- **旗舰池没有模型照样列着工具**：要是按有没有模型增删工具，工具面就会在会话中途变，缓存整个作废（AGENTS 1.3）。
- **问题当用户消息**：放进系统提示词的话，每次问的不一样，前缀从系统提示词那里就断了。

### 三、形状（core1 2026-11-10 定）

1. **工具名** `advisor`，出厂包 `miyu-base-advisor`（同 `miyu-base-subagent` 的分法，主人能在软件包页关掉）。主人 todolist 里早先写过 `get_advice`，验收时问一句定哪个。
2. **参数**：`question`（字符串，必写），`continue`（布尔，默认 `false`）。说明照工具说明的规矩（每参数一句、三句以内）：
   - 工具：`Ask a stronger model for advice when you are stuck. It sees only your question, so include the context it needs.`
   - `continue`：`true: continue your last advisor conversation in this session.`
3. **结果**：顾问的回答原文；末尾不加东西。报错：
   - 旗舰池没有可用模型：`No model is set in the flagship pool.`
   - 顾问请求失败（供应商报错、超时）：照子代理失败的说法交回原因。
4. **顾问的系统提示词**（`core/advisor/system.txt`，英文、短，登记进设计 26 的登记簿、量 token）：说明它是给另一个 AI 出主意的顾问，只看得到问题里写的，回答要具体、可照做，不知道的直说要什么信息。
5. **记在哪**：子会话的种类 `advisor`；`session.list` 不列（同子代理，主会话的时间线上能点进去看）；`continue` 找的是这个会话最近一次 `advisor` 子会话。
6. **限额**：顾问的回答最多照旗舰模型的输出上限；一次调用的时限照子代理的出厂值。没人看着的场所（QQ 等）照样能调（只是问模型，不碰本机）。

### 四、施工

| 步 | 名字 | 做什么 |
|---|---|---|
| ADV-1 | 顾问子会话 | `spawn` 端口加同步的一种：造种类 `advisor` 的子会话（无工具、无人格、钉 `@flagship`、系统提示词 `core/advisor/system.txt`），说一句等到她答完，交回回答；`continue` 照最近的那个接着说；旗舰池没有可用模型直接交回报错 |

| ADV-3 | 头 | 时间线里顾问那一步能点进去看问答；归 UI 的会话 |
