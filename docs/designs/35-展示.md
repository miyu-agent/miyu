## 展示（`show`）

2026-10-17 项目主人定：基础系统加一件 `show`，「把这个给人看」。取代 10-15 拆开的 `show_image` 和「产物」包两样，一件工具管所有种类，怎么显示由界面照文件种类定。

状态：2026-10-17 项目主人过目通过。第一、二节是核心，第三节是三个头，第五节是施工拆分。

### 一、她这边

1. **一件工具**：`show {path, title?}`，基础系统里，功能「展示」（预设能关）。说明照 Claude Code 工具的写法，三句以内：

   ```text
   Shows a file to the user: an image, video, audio, HTML page, Markdown, PDF, code or any other file.
   The user sees it in their interface; you get no content back.
   Showing the same path again replaces what was shown.
   ```

   参数：`path`「The file to show.」，`title`「A short title. Default: the file name.」。
2. **只给人看**：结果只回一句 `Shown to the user.`（登记），文件的内容、图都不进上下文。她要自己看用 `read`。
3. **路径照 `read` 的规矩**：执行前的链照读来查（工作区以外的问人、只读的数据根碰不到、沙盒里藏起来的看不见），读的时候安全打开，同附件（施工 C-9 的 `attach.rs`）。
4. **多大**：不限（施工 SW-1，2026-11-12 项目主人定，原来同附件的上限 20 MB：录好的视频展示不了）。
5. **哪些会话有**：都有。本机的会话、子会话（子会话展示的东西人在子会话的时间线里看到）、场所会话（接入QQ 发出去，第三节）。

### 二、核心这边

1. **不拷**（施工 SW-1，2026-11-12 项目主人定；原来读到的内容存成 blob）：只记文件的真实路径、展示那一刻的大小和修改时间。本机的头照路径读硬盘，远程的头照会话加调用编号经核心分段读（`session.shown`），核心只读记下的那个路径，大小、修改时间变了的拒（`file_changed`），没了的拒（`file_gone`）。她以后改了、删了那个文件，展示过的那一张就读不到了。
2. **记进会话**：`tool.result` 的效果多一种 `file.shown`（`03-事件模型.md` 第三节，给头看、不给模型）：

   | 格 | 是什么 |
   |---|---|
   | `path` | 换成真实位置以后的绝对路径：同一个路径再展示一次，头照它换掉那一张 |
   | `name` | 文件名 |
   | `media_type` | 照内容认的种类（`miyu_tool::attachment::kind`，同附件）：`image/png`、`application/pdf`、`text/html`、`text/markdown`、`text/plain` 这些 |
   | `title` | 她写的标题，没写的没有这一格 |
   | `size` | 字节数 |
   | `modified` | 展示那一刻的修改时间（施工 SW-1） |

3. **种类怎么认**：先照内容（图片、PDF 的文件头），再照后缀（`.html`、`.htm` 是 HTML，`.md` 是 Markdown，认得出语言的代码后缀照 Markdown 渲染器的语言名记在 `language`），都不是的是 UTF-8 能读的算文本、读不了的算文件。头照 `media_type` 和 `language` 选显示法。
4. **视图投影**：会话的视图里，这一次调用的工具卡带上 `shown`（上面那几格），头不用自己去翻效果；内容照第 1 条读。
5. **撤销**：撤掉这一轮，展示也跟着从视图里没了（效果随结果走）。不碰文件：展示本来就只读。

### 三、各个头怎么显示（照项目主人 10-17 说的）

| 种类 | 网页 | 终端 | 接入QQ |
|---|---|---|---|
| 图片 | 对话里缩略图，点了浮起一层透镜式的预览，下面四个按钮：下载、复制图片、在右栏打开、在新标签页打开 | 直接画出来，点图本身用程序开大图 | 发成图片 |
| HTML | 右栏渲染，能切源码 | 当场开一次，留一张卡片，点卡片再开 | 发成文件 |
| Markdown | 右栏渲染，能切源码 | 卡片，点开用程序看 | 发成文件 |
| PDF | 右栏看 | 当场开一次，留卡片 | 发成文件 |
| 代码、文本 | 右栏带高亮 | 卡片，点开用程序看 | 发成文件 |
| 别的文件 | 卡片，能下载 | 卡片，点开用程序看 | 发成文件 |

- 右栏就是旧版 Miyu 网页的 artifact 面板：同一个路径再展示一次刷新那一张，右栏能在这个会话展示过的几样之间切。右栏看图能用滚轮缩放（2026-10-17 项目主人定）。
- 终端里 Markdown、代码、文本不画在对话里（2026-10-17 项目主人定：长的画在对话里不好看），一律卡片：文件名、种类、大小、几行。
- 终端「用程序开」都照同一个退路（2026-10-17 项目主人定）：先交给系统给这种文件定的默认程序；没有的交给浏览器（浏览器看得了 PDF、HTML，Markdown、代码、文本照原文显示）；浏览器也没有的，卡片上写「没有能打开它的程序」，再给出副本的完整路径，能复制。图片的看图程序同一个退路。
- 终端里 mermaid 的图同一个点法：点图本身开大图，去掉图下面「点击查看大图」那一行字。
- 终端「当场开一次」：收到一次新的展示就开（2026-10-17 项目主人定：不判人在不在看，show 了就开）；补发、翻历史里的是展示过的，不再开。打开要的是本机的文件：终端照记下的路径直接开（施工 SW-1 以前照 `blob.read` 取到临时目录再开）。
- 接入QQ 照场所会话的回复发出去，发不了文件的群（权限、大小）回一句发不了，这一张不算发出去。

### 四、不做的

- 不给她看渲染出来的样子（截图回传）：那是另一件事，要的时候再说。
- 不做「产物」的版本历史：同一个路径只留最新的那一张，旧的还在日志里，界面不列。
- 不收网址：她要给人看网页，写进回复里就是链接。
