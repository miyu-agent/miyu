# AI 能用的工具

> <sub>本文档由 Anthropic 的 Claude Fable 5.2 生成。</sub>

AI 读文件、跑命令、联网，都是调工具。这一页列出出厂的每一件工具：做什么、只读时还能不能用、有什么限制，和怎么关掉某一件。

## 工具从哪来

- 出厂软件包带的：下面的全表。
- 你装的软件包、扩展带的：见各自的说明。通讯平台的 `qq_*`、`tg_*` 见 [接入通讯平台](heads/im.md)；表情包的 `meme_*`，`render_image`、`ocr` 这些见 [附加软件](addons.md)。
- 脚本：数据根（默认 `~/.miyu`，Windows 上是 `%USERPROFILE%\.miyu`）的 `~/.miyu/root/scripts/` 里一个文件一件工具，工具名照文件名。怎么写见 [放文件就能用的](../authors/scripts-skills.md)。
- MCP 服务：工具名是 `mcp__<服务名>__<工具名>`，工具名里字母、数字、`_`、`-` 以外的字换成 `_`，整个名字最长 64 个字符。声明了资源的服务另有两件 `mcp__<服务名>__list_resources`、`mcp__<服务名>__read_resource`，列出、读它的资源。怎么接见 [扩展 Miyu](extending.md)。

一个会话里有哪些，由它的预设定（见 [人格和预设](personas-presets.md)）。另有几道筛：

- 记忆的三件只在记忆开着的会话里有；知识库的搜、读、改、删只在查得到至少一个知识库时有，`kb_save` 一直有，好建第一个库。
- `subagent` 只给本机的会话，子代理的子代理不再有；`ask_user` 只给本机、有人看着的主会话；`sessions` 只给本机的主会话；`send_message`、`todowrite`、`session_usage` 只给本机的会话。
- 通讯平台上的会话另有限制，见 [接入通讯平台](heads/im.md)。

看这个会话现在有哪些：

- 终端：敲 `/tool-list`，按内置、软件包、MCP、脚本分组列出名字。`c` 复制，`Esc` 关。
- 网页：点对话区左上角的会话标题，「预设」那一行右边的笔（「编辑这个预设」）打开预设，看开了哪些功能和工具。

「只读时」一格说切到只读以后这件工具怎样，权限见 [权限和沙盒](permissions.md)。「界面上叫」是时间线上显示的名字。

### 文件

| 工具 | 界面上叫 | 做什么 | 只读时 | 出厂包 | 限制 |
|---|---|---|---|---|---|
| `read` | 读取 | 读文本文件，带行号；读图片交给模型看；读目录列出里面有什么 | 照常 | `base-read` | 一次最多 2000 行或 2000 项，一行超过 2000 个字截掉，一次最多 64 KiB。认 UTF-8 和带 BOM 的 UTF-16，开头 8 KiB 里有 NUL 字节的当二进制、不读。图超过 5 MiB 或一边超过 8000 像素的先缩小，文件超过 64 MiB 的不读 |

## shell

- 用哪个 shell：照系统定，核心起来时找一次，没有配置能改。不读你的 shell 启动文件（`.bashrc`、`.zshrc`、PowerShell 的 `$PROFILE` 都不读）。工具说明里告诉 AI 用的是哪一种，AI 照它的写法写命令：

  | | 用哪个 | 怎么找 | 告诉 AI 的名字 |
  |---|---|---|---|
  | Linux | bash | `PATH` 里的 `bash`，找不到用 `/bin/bash` | `bash` |
  | macOS | zsh | 固定用 `/bin/zsh`，不照 `PATH` 找 | `zsh` |
  | Windows | PowerShell 7，没有的用 Windows PowerShell 5.1 | 先用托盘安装包（`.msi`）带的那一份，再找 `PATH` 里的 `pwsh.exe`，都没有的用 `%SystemRoot%\System32\WindowsPowerShell\v1.0\powershell.exe` | `PowerShell 7` 或 `Windows PowerShell 5.1` |
- 在哪跑：这个会话的工作目录。每次调用都从工作目录起一个新的 shell，上一次的 `cd`、变量不带过来。工作目录被删了、挪走了，命令一条都跑不了，答「工作目录不存在了」，换个工作目录就好（见 [会话](sessions.md)）。
- 环境变量：照核心的环境整份带过去，去掉名字里有 `KEY`、`SECRET`、`TOKEN`、`PASSWORD`、`PASSWD`、`CREDENTIAL` 的（不分大小写），和 `MIYU_` 开头的。另设 `GIT_TERMINAL_PROMPT=0`、`PAGER=cat`、`GIT_PAGER=cat`、`NO_COLOR=1`、`TERM=dumb`：git 要密码时直接失败，不翻页、不上色。
- 超时：AI 不写的等 120 秒，最多能写 600 秒。到时还没跑完的，预设开着「后台运行」就挪到后台接着跑，时间线上记「超时，挪到后台了」；没开的、开头就是 `sleep` 的，整组停掉，记「超过 … 秒，停掉了」。
- 停掉：到时停掉、你叫停时，Linux、macOS 上杀掉命令的整个进程组，Windows 上用 `taskkill /T /F` 杀掉整棵进程树。命令自己跑完退出后，Linux、macOS 上它留在组里还没退的子进程也一起杀掉；Windows 上不杀，留下的照样在跑。
- 后台跑：预设开着「后台运行」时，AI 能一开始就把命令放到后台，马上拿到一个任务编号（例如 `j1`），跑完自动回报。后台命令最多跑 `jobs.max_running`（默认 `30m`，能写 `1m` 到 `2h`），到了停掉。AI 还能让后台命令每输出一行就叫醒它，用来盯着日志。
- 干等：前台 `sleep`（Windows 上是 `Start-Sleep`）两秒以上的命令不跑，答「不许前台用 sleep 干等」：后台的任务办完会自己回报。
- 输出太长：给 AI 看的最多 30000 个字，多了留开头和结尾各一半，中间写省了多少。要看全的，让 AI 把输出写进文件再读。
- 危险命令：开放权限下有几类先问你、几类直接拒，见 [权限和沙盒](permissions.md#要确认的命令)。这些规则只认 bash、zsh 的写法，Windows 上的 PowerShell 命令一条都不查，见 [Windows 上不认](permissions.md#windows-上不认)。

## trash

删的东西进系统的回收站：Linux 照 freedesktop 的回收站，macOS 的废纸篓，Windows 的回收站。要找回，从系统的回收站里还原。`/undo` 撤销那一轮不会把它放回来。

## show

AI 把做出来、找到的图片、网页、文档、音视频直接给你看。同一个路径再展示一次，换掉原来那一份。

- 终端：时间线上一张卡片或者一张图，点了用系统的程序打开；HTML、PDF 到的时候自动打开一次。没有能打开的程序时写「没有能打开它的程序」和路径；Windows 上终端把文件交给系统去开，分不出有没有能打开它的程序，交出去就算开了。文件后来改了写「文件已变」，删了写「文件已不在」。
- 网页：放进右边的「预览工作区」，最后展示的在前；音视频在时间线里直接播；认不出的文件只能下载。

`show.system_hint`（默认 `true`）开着时，系统提示词里有一句提醒 AI 把这些东西用「展示」给你看。关掉对新会话生效：

```sh
miyu config set show.system_hint false
```

## ask_user

AI 问你时，终端上写「… 在问」，网页上写「… 提问」，下面是题和选项。`↑`、`↓` 选，多选题 `Space` 勾选，`Enter` 提交；每道题都能「输入其他答案」，`n`（网页是 `N`）加一段补充；题有几道的 `←`、`→` 换题；连按两下 `Esc` 取消。别的会话在问你时，终端上提示「「…」在问你 · /resume 切过去」。

AI 一直等你答，不受确认框的超时 `permission.confirm.timeout` 管。没人能答的会话（子代理、`miyu ask`、通讯平台）没有这件工具。

## advisor

AI 卡住了，把问题交给旗舰池（`flagship`）里的模型，等它答完接着做。旗舰模型只看得到 AI 写给它的问题，看不到这个会话。AI 能接着上一次的问下去。旗舰池出厂是空的，往里放模型见 [模型](models.md)。

## subagent

AI 另开一个会话派子代理，子代理在后台做，做完报告送回来；AI 能给它选模型池、人格（只列 `subagent = true` 的人格），或者让它接着这个会话的对话做（fork），或者只许它读不许改。子代理的预设、权限照派它的会话，不记记忆。详见 [让 AI 自己接着干](automation.md)。

## 关掉一件工具

- 在预设里关：设置页的预设里把那个功能或那件工具关掉，或者在预设文件里写 `[features]`、`[tools]`。见 [人格和预设](personas-presets.md)。
- 整个软件包关掉：设置页「软件包」里那个包的开关，记在 `packages.<编号>.off`，你的会话里就没有它的工具了：

  ```sh
  miyu config set packages.base-net.off true
  ```

- 技能、脚本、MCP 服务另有总开关 `features.<功能编号>`（例如 `features.mcp-github`），只对默认全开的预设起作用，预设里写了开关的照预设。

改了都从下一轮起生效。

## 只读时

切到只读以后：

- `write`、`edit`、`trash`、`kb_save`、`kb_edit`、`kb_delete` 不执行，时间线上记「只读模式，未执行」。
- `shell` 和脚本在沙盒里跑，哪里都写不了。三个平台的沙盒有什么不一样见 [权限和沙盒](permissions.md#三个平台)。
- MCP 服务里没标只读的工具，每次先问你。
- 别的照常。
