# 记忆

> <sub>本文档由 Anthropic 的 Claude Fable 5.2 生成。</sub>

AI 会记住你和它聊过的事，下次开会话还想得起来。这一页讲它记什么、什么时候记和想起、怎么看和改、怎么不让它记。

记忆由出厂软件包 `base-memory`（界面上叫「人格记忆」）提供，装好就开着。

## 记忆长什么样

一条记忆是一句话，最多 120 个字，有一个编号，写成 `m` 加序号，例如 `m12`。每条属于一类：

| 类 | 网页上叫 | 记什么 |
|---|---|---|
| `user` | 关于用户 | 关于你的事 |
| `feedback` | 对 AI 的要求 | 你要 AI 怎么做 |
| `episode` | 发生过的事 | 一起经历的事 |
| `reference` | 资料位置 | 长期有效的事实、资料在哪 |
| `person` | 认识的人 | 关于别的某个人的一件事，带着这个人是谁（名字或平台编号，例如 `qq:10086`） |

一条可以另带一行关键词，逗号隔开，最多 200 个字。关键词只用来搜到它，AI 看不到这一行。

除了一条条的记忆，还有两样，都是整理时写的：

- 对你的了解：一段摘要。
- 认识的人的卡：一人一张，最多 400 个字，照「认识的人」那一类的记忆合成。

AI 也能搜同一个人格以前的对话（只搜你开的那几轮）。

## 跟着人格走

每个人格一份记忆，用这个人格的会话共用。不用人格的会话共用另一份。

- 会话中途换了人格的，从换的那一轮起记进新人格那一份，以前记的留在原来那一份，不搬。
- 子代理不记也不想起。

## 什么时候记

| 谁记 | 怎么记 |
|---|---|
| 自动 | 会话闲下来以后，AI 把上次以后聊的内容里值得记的记下来。AI 在那一轮里已经自己记过、忘过的，那一轮不再看 |
| AI | 调 `remember` 工具。能改一条：新的一条换掉旧的 |
| 你 | 在本机的会话里敲 `/remember <内容>`，记成「关于用户」一类，回「记下了：…」 |
| 你 | `miyu memory add`，或网页记忆页上的「记一条」 |

自动记要满足：

1. 上次自动记以后，AI 至少答了 `memory.extract_turns`（默认 2）轮。
2. 会话闲了 `memory.extract_idle`（默认 30 分钟）。

一直闲不下来的会话（群里一直有人说话），上次以后结束了 `memory.extract_max_turns`（默认 20）轮，或者最早没记的那一轮过了 `memory.extract_max_wait`（默认 1 小时），就不等闲，在后台记。

自动记用日常池（`normal`）里的模型；池是空的，或者成员都在冷却、出错的，用会话自己的模型。池怎么配见 [模型](models.md#池便宜的干杂活贵的干正事)。

## 什么时候想起

| 什么时候 | 带上什么 |
|---|---|
| 会话第一轮、压缩以后第一轮 | 常驻的一块：对你的了解，加上它以后新记的，新的在前，不超过 3000 字节。放不下的，最后一行说还有几条，让 AI 用 `memory_search` 去搜 |
| 通讯平台上，别人开口的一轮 | 这个人的卡，一段上下文里只带一次 |
| 你开的每一轮 | 联想：照你这一轮说的话找，最多 3 条，不超过 500 字节，一段上下文里（压缩以后重新算）最多带 40 条，和知识库的自动想起合起来算。关键词和意思两样都对得上才带，宁可不带 |
| AI 自己要找时 | `memory_search` 工具：搜记忆、认识的人、以前的对话 |

联想要语义模型（`models.embedding`，见 [模型](models.md#三个用途)）：默认用本机的 `embed` 软件包（见 [附加软件](addons.md)）。没装的、写了 `off` 的、换成了远程模型的，不联想；常驻那一块、卡、`memory_search` 照常。没装的、写了 `off` 的，`memory_search` 只按关键词找。

想起了哪几条，时间线上不显示。看得到的：

- 终端：`/context` 的上下文明细里，「常驻记忆」「召回的记忆」各占多少 token；`/status` 里「回忆 N 次 · 记住 N 条」是 AI 调 `memory_search`、`remember` 的次数。
- AI 调记忆工具，时间线上照常有一行。

## 整理

整理是把新记的和相关的旧记忆放在一起理一遍：

- 重复的作废，留下一条。
- 被后来的推翻的作废。
- 用不着的作废。
- 改写不准的：存成新的一条，旧的作废。
- 写一段新的「对你的了解」。
- 照「认识的人」那一类合出每个人的卡。
- 没有关键词的补上关键词。
- 顺带重看最多 20 条旧记忆。

作废的能找回；整理不清空。

什么时候整理：

- 自动：自动记下了新的以后，离上次整理过了 `memory.merge_every`（默认 16 小时）就在后台整理。从没整理过的马上整理。
- 会话里敲 `/dream`：先把这个会话还没记的记了，再整理到没有剩下的。回执是「整理完成：…」，说检查、修改、作废了几条，摘要换没换，用了多久。
- `miyu memory dream`：整理默认人格那一份，或者 `--persona`、`-s` 指的那一份。
- 网页记忆页上的「整理」。

停下：会话里敲 `/dream stop` 或 `/stop`；终端里连按两次 `Esc`；`miyu memory dream` 按 `Ctrl+C`；网页点「停止整理」。整理好的那几批留着，正在整理的那一批下次再来。

整理用日常池（`normal`），同自动记。每份记忆留最近 `memory.dream_keep`（默认 20）次整理的过程，网页记忆页的「整理记录」里能看。

## 看和改

### 命令行

```text
miyu memory [<子命令>] [<选项>]
```

不写子命令的是 `list`。不写 `--persona`、`-s` 的，用默认人格（`persona.default`）那一份；没设默认人格的报「记忆不可用。」。不用人格的会话那一份写 `--persona _none`。

| 子命令 | 做什么 |
|---|---|
| `list` | 列出最新的 50 条，一条一行：编号、日期、正文 |
| `search <词>…` | 搜，最多 10 条，最相关的在前 |
| `add <内容>…` | 记一条，印「已添加 m…」 |
| `edit <编号> [<内容>…]` | 改正文：存成新的一条，旧的作废，印「已修改，新编号 m…」。只改 `--keywords`、`--who` 的不写内容 |
| `forget <编号>` | 作废一条 |
| `clear session [<会话>]` | 清掉一个会话记下的。不写会话的照 `-s`，再没有的是上一次 `miyu ask` 的会话 |
| `clear me` | 清空这一份记忆，连卡和对你的了解 |
| `dream` | 现在就整理 |
| `cards` | 列出认识的人的卡 |

| 选项 | 做什么 |
|---|---|
| `--persona <编号>` | 用这个人格的记忆。不能和 `-s` 一起写 |
| `-s`、`--session <编号>` | 用这个会话用的那一份 |
| `--forgotten` | `list`、`search`、`cards` 连作废的一起列 |
| `--class <user\|feedback\|episode\|reference\|person>` | `list` 只列这一类；`add` 记成这一类，不写是 `user` |
| `--why <原因>` | `forget` 写为什么 |
| `--keywords <词>` | `add`、`edit`：关键词，逗号隔开；`edit` 写空的是去掉 |
| `--who <是谁>` | `add`、`edit`：认识的人那一类说的是谁。`add --class person` 必须写 |
| `--format <text\|json>` | `list`、`search` 的输出格式 |

```sh
miyu memory search 咖啡
miyu memory add --keywords 编辑器,vim 写代码用 Neovim
miyu memory add --class person --who 小林 小林是做前端的同事
miyu memory edit m12 --keywords 饮料,早餐
miyu memory forget m15 --why 已经换工作了
miyu memory --persona captain list --class feedback
```

清掉的找不回来；作废的在网页记忆页上能「找回」。参数全表见 [命令行](cli.md#miyu-memory)。

### 网页

设置里的「记忆」页，在会话里敲 `/memory` 直接打开。终端没有记忆页。

- 顶上选哪一份记忆：一个人格一份，「无人格」一份。
- 「记忆」页签：搜（内容、关键词），按类别筛，「显示作废的」；点开一条改内容和关键词、作废、找回；「记一条」；「清空」（同 `clear me`，找不回来）；「整理」「整理记录」。
- 「认识的人」页签：看、搜、改每个人的卡，「认识一个人」新写一张。

## 不让它记

| 范围 | 做法 |
|---|---|
| 一次 `miyu ask` | `miyu ask --no-memory "…"`：新开的会话不想起也不记。不能和 `-c`、`-s` 一起写 |
| 用某个预设的会话 | 预设里关掉「人格记忆」：`[features]` 写 `memory = false` |
| 全部 | `miyu pkg remove base-memory`。记下的留在数据根里，装回来（`miyu pkg install base-memory`）就还在 |
| 一条 | 让 AI 忘掉（它调 `forget` 作废），或 `miyu memory forget <编号>` |
| 一个会话记下的 | 在那个会话里敲 `/clear-memory`（别名 `/reset-memory`），不问，回「清掉了这个会话记下的 N 条记忆。」。或者 `miyu memory clear session <会话>` |
| 一整份 | `miyu memory clear me`，或网页的「清空」 |

开不开记忆在开会话时定，之后换预设不变。`/remember`、`/dream`、`/clear-memory` 只在开着记忆的会话里能用；预设没开的，敲了说「预设「…」未启用记忆。」。

预设的写法见 [人格和预设](personas-presets.md)。

清一个会话的只清出处全在这个会话里的：你自己记的（`/remember`、`miyu memory add`）没有出处，不清；别的会话里也说过的，不清；卡不动。

## 设置

在设置页（`/settings`）「软件包」里人格记忆的设置项改，或者写进 `~/.miyu/etc/config.toml`。改了下一轮生效。

| 键 | 默认 | 能写 | 管什么 |
|---|---|---|---|
| `memory.extract_idle` | `"30m"` | `1m` 到 `1h` | 会话闲了多久自动记 |
| `memory.extract_turns` | `2` | `1` 到 `100` | 上次自动记以后至少几轮才记 |
| `memory.extract_max_turns` | `20` | `2` 到 `500` | 一直闲不下来的会话，攒满几轮就不等闲 |
| `memory.extract_max_wait` | `"1h"` | `10m` 到 `24h` | 一直闲不下来的会话，最早没记的那一轮过了多久就不等闲 |
| `memory.merge_every` | `"16h"` | `1h` 到 `720h` | 隔多久自动整理一次 |
| `memory.dream_keep` | `20` | `0` 到 `1000` | 留最近几次整理的过程，`0` 是整理完就删 |

```toml
[memory]
extract_idle = "10m"
merge_every = "24h"
```

## 通讯平台上的会话

记忆不按群、按人分开：同一个人格在哪个群、和谁私聊，用的都是这一份，哪儿都想得起全部。记下时另记着是在哪个场所、哪个群（记下那一刻的群名）说的。群里的人有了「认识的人」那一类的记忆，整理时给他合一张卡，他开口的那一轮带上。

`/remember`、`/dream`、`/clear-memory` 只在本机的会话里能用。通讯平台的会话用哪个人格、怎么设，见 [接入通讯平台](heads/im.md)。

## 存在哪

| 位置（数据根默认 `~/.miyu`，Windows 上是 `%USERPROFILE%\.miyu`） | 是什么 |
|---|---|
| `~/.miyu/root/memory/<人格编号>/` | 这个人格的记忆日志，不用人格的那一份是 `_none` |
| `~/.miyu/var/cache/index/recall/` | 搜索用的索引，照日志和会话算出来的 |

记忆日志只往后追加：改一条是新写一条，作废、清空也是另写一行，原文一直在日志里。别手改这些文件，用 `miyu memory` 或网页记忆页。

备份、搬到另一台机器见 [数据和备份](data.md)。

## 哪些内容会发给模型供应商

- 想起来的记忆、卡进上下文，随每次请求发给会话用的模型。
- 自动记、整理是另发请求给日常池的模型（或会话的模型）做的，要发去那一段对话、相关的记忆。发之前遮掉配置里引用的密钥原文和常见的 key 写法。
- `models.embedding` 写了远程模型的，记忆和对话的字发给那一家算向量。本机的 `embed` 不出这台机器。

## 出了问题

| 看到的 | 怎么办 |
|---|---|
| `miyu memory` 报「记忆不可用。」 | 没设默认人格。写 `--persona <编号>`，不用人格的那一份写 `--persona _none` |
| `/remember` 说「预设「…」未启用记忆。」 | 这个会话的预设没开人格记忆。换一个开着的预设开新会话，或者在预设里打开 |
| 「人格记忆未安装。」 | `miyu pkg install base-memory` |
| 「正在整理记忆。」 | 这一份正在整理，等它完 |
| 「记忆过长：N 字，上限 120 字」 | 一条写短一点，或拆成几条 |
| AI 从来不联想 | `miyu check` 看末尾的语义模型那几行；没装的 `miyu pkg install embed` |
