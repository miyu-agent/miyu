# 推演人生

> <sub>本文档由 Anthropic 的 Claude Fable 5.2 生成。</sub>

推演人生给一个人格开一个专门的会话，叫人生会话：AI 照人格的人设、记得的事、新闻和真实的时间，一次次自己醒来，写下这个人格此刻在做什么，再定下次几点醒。这一页讲怎么开、怎么看、怎么停，和它花多少。

## 和普通会话有什么不同

人生会话是一个普通的会话，有三处不同：

- 用隐藏的预设 `life`（推演人生）开。网页里选预设的地方不列它，终端的选择框照列。它开着下面七个出厂软件包，没有命令和文件工具：

  | 软件包 | 界面上叫 | 在人生会话里做什么 |
  |---|---|---|
  | `base-env` | 注入环境信息 | 交给 AI 环境信息，包括现在的时间 |
  | `base-net` | 联网搜索 | `web_search`、`web_fetch`，看新闻、天气。搜索怎么配见 [联网搜索和抓网页](web-search.md) |
  | `base-memory` | 人格记忆 | `remember`、`memory_search`、`forget` |
  | `base-loop` | 循环任务 | `schedule_wakeup`，AI 定下次几点醒 |
  | `base-life` | 结束人生 | `end_life`，AI 自己结束这段人生 |
  | `base-roleplay` | 人设遵循提醒 | 提醒 AI 别出戏 |
  | `base-history` | 翻查本会话 | `history`，翻以前写过的 |

- 没人敲字也自己跑：到点由核心叫醒，一次醒来就是一轮。
- 能用 `end_life` 自己结束。这件工具只在还没结束的人生会话里有，拿 `life` 预设开的别的会话没有。

一个人格同时只有一段在过的人生；不同的人格各开各的。

## 开始之前

- 会话要带人格。`/life` 管的是你敲它的那个会话现在的人格的人生；不带人格的会话回「这个会话没有人格，没有人生会话。」。出厂的人格是 `software-engineer`，自己写一个见 [人格和预设](personas-presets.md#自己写一个人格)。
- 联网搜索要配好，AI 才看得到新闻。
- 在人格文件夹 `~/.miyu/root/personas/<编号>/`（数据根默认 `~/.miyu`，Windows 上是 `%USERPROFILE%\.miyu`）里写 `prompts/life.md`，告诉 AI 这条人生怎么过（下一节）。不写也能开，用出厂的那一段。

人生会话用开的那一刻的默认模型。

## 写 prompts/life.md

每次醒来，AI 先读到一段固定的说明（这是人生会话、记下的会进记忆、怎么定下次醒），接着是 `prompts/life.md` 的全文，再空一行接上次醒来留给自己的话（没留的不接）。

这个人格是谁写在 `persona.md` 里；`life.md` 只写日子怎么过：

```markdown
<!-- ~/.miyu/root/personas/captain/prompts/life.md -->
照你的人设、最近发生的事、新闻和真实的时间天气，决定你此刻在做什么，只写这一刻，不补过去，也不演将来。
白天每隔一两个小时醒一次，周末多睡一会儿，夜里睡整觉。
睡前写一篇当天的日记，用 remember 记下一两件想留下的自己的事。搜到的新闻不用记。
```

- 每次醒来那一刻现读，改了下一次醒来就用新的。
- 没有这个文件、文件是空的、人格读不出来的，用出厂的一段（英文，意思同上面的例子）。
- 人格有几层的（出厂、软件包带的、你的），用最上面那一层的 `life.md`，整份换掉，不拼接。

## 开、看、停

在终端或网页里，对带着这个人格的会话敲：

| 命令 | 做什么 | 回执 |
|---|---|---|
| `/life` | 看这个人格的人生会话 | 在跑的说下次几点醒（照核心这台机器的时区，到分钟），正醒着的说醒着；暂停着的回「人生会话已暂停，用 /life resume 继续。」；没有的、上一段已经结束的回一段说明，**不开** |
| `/life new` | 开一段新的人生，马上醒第一次 | 说已开始；已经有一段在过的，先把它结束（和 `/life kill` 一样，记忆清掉），再开新的，回执里说上一段已结束 |
| `/life pause` | 暂停：到点不醒 | 同 `/life` |
| `/life resume` | 继续：马上醒一次，之后照 AI 定的醒。上次留给自己的话还在 | 同 `/life` |
| `/life kill` | 结束这段人生 | 「人生会话已结束，留下的记忆已清掉，会话保留为只读。」 |

- 终端里敲了就做，不问。`/life new` 遇到在过的人生会直接结束它。
- 网页里 `/life new`、`/life kill` 发出去之前先弹一张卡问一句：「重新开始一段人生？」「结束这段人生？」，点「结束并重新开始」「结束人生」才发；「取消」、`Esc`、点卡片外面都不发。`/life`、`pause`、`resume` 不问。
- 网页收到回执时，回执说的是哪个人生会话，就打开那个会话；正看着它的不跳。
- 没有可停、可续、可结束的人生时，`pause`、`resume`、`kill` 回「这个人格没有人生会话。」。
- 后面跟别的字的，回「用法：/life [new | pause | resume | kill]」。
- 只有你本人能用。通讯平台上的会话里没有这条命令。

打开人生会话看时间线，就是 AI 每次醒来写的东西，标题照常自动起。你也可以在里面说话，AI 把你在里面说的、做的当成真发生过的事。

- 终端：人生会话在会话列表里和别的会话放在一起。
- 网页：左栏、「全部会话」、`/sessions` 都不列人生会话。点左栏「更多 → 推演人生」，弹出一张卡，一个人生一行：人格名、AI 写的「现在在做什么」、状态（「进行中 · 下次醒 14:05」「已暂停」「已结束」）。点一行打开那个会话。正看着人生会话时，左栏「更多」那一行亮着。设置页「软件包」的「网页」那一段关掉「推演人生」，「更多」里就没有这一项，人生会话照样不进左栏，敲 `/life` 照样能打开它。

### 在网页的人格设置里开

网页设置的「人格」页打开一个人格，有一行「推演人生」开关；首次引导「创建人格」那一步也有。

- 拨开：先问一句，说明会自己醒来、每次醒来是一次模型请求、会自己记事、关掉算暂停。确认了才开：没有人生的、上一段已结束的开一段新的，暂停着的继续。
- 拨关：暂停，不问。
- 开关当场生效，不用点「保存」，也不写进人格文件。首次引导里人格还没建，拨开只先记下，点下一步建好人格以后再开。
- 开关右边一行写状态：「进行中 · 下次醒 14:05」「已暂停」「上一段已结束」，后面接 AI 最近写的「现在在做什么」。有人生会话的，旁边有「打开」。
- 开关开着时，下面露出「推演方法」一格，写的就是这个人格的 `prompts/life.md`（见上面「写 prompts/life.md」）。空着用出厂的那一段，格里的灰字就是它。跟着「保存」存；清空了存，就是去掉你写的那一份。
- 「推演方法」下面一格「人生会话上下文窗口」，同样开关开着才露：人生会话最多带多少 token，写的是人格 `persona.toml` 里的 `[life]` `context`。空着用出厂的数，格里的灰字写着它。要写正整数，`100,000` 这样带逗号的也认；写错了点「保存」，格下面写「要写一个正整数（token）」。跟着「保存」存，存了当场管这个人格没结束的人生会话，见下面「花费」。

## 每次醒来

1. 核心到点叫醒人生会话，交给 AI 上面那段话。
2. AI 照时间、记忆、搜到的东西写这一刻在做什么，可以记记忆、搜网页、翻以前写的。
3. AI 调 `schedule_wakeup` 定下次多久以后醒（最短 60 秒），写一句现在在做什么，可以给下次的自己留句话。

- AI 这一轮没定的，从这次醒来起一小时后再醒。AI 不能用 `schedule_wakeup` 停掉人生，要停用 `/life pause`。
- 醒来时 AI 还会看到上次醒来以后这个人格在别的会话里新记下的记忆。
- AI 写的那句「现在在做什么」，会在同一个人格别的会话（本机的、通讯平台上的、分叉出来的，派出去的子代理除外）下一轮开头交给 AI，同一句不重复交。人生暂停时不交。
- 叫醒靠核心。核心没开着时不醒；核心再起来时，错过的只补醒一次，然后照常。要它一直过下去，让核心常驻，见 [常驻和服务器](service.md)。

## 记忆

人生会话记下的记忆进这个人格的那一份，和这个人格平常的记忆放在一起，别的会话想得起来。会话闲下来后的自动记忆照常做。

结束以后，出处全在这个人生会话里的记忆都清掉，恢复不了；以前对话的搜索里也搜不到这个会话了。出处里也有别的会话的，留着。新开的一段人生想不起旧的那一段。

## 结束

两种结束，做的事一样：

- 你敲 `/life kill`，或者 `/life new` 结束了旧的。正在跑的那一轮当场打断。
- AI 调 `end_life` 自己结束，必须写遗言。那一轮照常说完。时间线上这一步记作「结束这段人生」。

结束以后：

- 不再醒，接不回来。
- 会话留着，只能看，不能接着说话：终端里说话会报「会话已封存」，网页的输入框锁住，写「这段人生已经结束，只能看」。时间线照常能翻，AI 自己结束的，遗言在最后。
- 这段人生的记忆清掉，见上一节。

再开新的用 `/life new`。

## 花费

每次醒来都是一轮模型请求，不管你看不看。人生会话算没人看着的会话，每一轮最多请求 `500` 次模型，规矩见 [让 AI 自己接着干](automation.md#没人看着时)。

- 上下文上限：开的时候照人格 `persona.toml` 里的 `[life]` `context` 设，没写的设成 100000 token（模型要的最少比这大的，照最少的设）。上限越大，每次醒来带的越多、花得越多。三处能改：
  - 正在跑的这一段：在人生会话里敲 `/context`，例如 `/context 64k`。醒来不会改回去。
  - 网页人格页的「人生会话上下文窗口」：存了以后，这个人格没结束的人生会话（在跑的、暂停的）当场换成新的数，以后开的也照它。和 `/context` 改的，后改的算数。
  - 以后开的：在人格的 `persona.toml` 里写，例如：

    ```toml
    [life]
    context = 64000
    ```

    手改这个文件不动已经开着的人生会话，以后新开的才照它。
- 每轮请求次数：在你的预设层盖一份 `life`，只写这一项：

  ```toml
  # ~/.miyu/root/presets/life.toml
  [limits]
  unattended_steps = 50
  ```

  开着的人生会话下一轮起换上。

- 看花了多少：终端 `/usage`，网页设置里的「用量」页能按会话看，见 [模型](models.md#用量和花费)。
- 花费没有自动的上限。不想要了就 `/life pause` 或 `/life kill`。

## 出了问题

| 看到的 | 怎么办 |
|---|---|
| 「这个会话没有人格，没有人生会话。」 | 换一个带人格的会话敲 `/life` |
| `/life new` 报定时任务满了（`too_many_schedules`） | 所有定时任务加起来最多 200 个。人生会话已经开好、算暂停着；删掉几个定时任务，再 `/life resume` |
| 很久没醒 | 敲 `/life` 看是不是暂停了；核心是不是开着 |
| AI 写的和新闻对不上 | 检查 [联网搜索和抓网页](web-search.md) 配好没有 |

写头的人要的 `life.*` 方法见 [人生会话的协议](../reference/life.md)。
