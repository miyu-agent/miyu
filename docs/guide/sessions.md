# 会话

> <sub>本文档由 Anthropic 的 Claude Fable 5.2 生成。</sub>

和 AI 的每一段对话是一个会话。这一页讲怎么开新会话、接着以前的聊、指定干活的目录、退回上一轮、处理满了的上下文，以及改名、导出、导入、删除。

会话的数据放在数据根（默认 `~/.miyu`，Windows 上是 `%USERPROFILE%\.miyu`）里，每个会话一个编号，写法是 UUID：`0198c2a4-7e1b-7c3d-9a2f-4b5c6d7e8f90` 这样 8-4-4-4-12 位的十六进制。终端、网页上常显示它的最后 8 位，叫短编号。

## 开一个新会话

终端：

1. 敲 `miyu`。直接敲 `miyu` 打开设置里「默认界面」（`ui.head`）指的那个界面，出厂是终端。标准输入、标准输出不是终端时（脚本、管道里），只印帮助，退出码 `2`。
2. 先在框里选人格，再选预设，选了才能打字。人格和预设是什么见 [人格和预设](personas-presets.md)。
3. 敲第一句话，回车。

打开界面时开新会话还是接着最近那个，看设置页「通用 → 显示 → 启动时打开」（`ui.startup`）：「新会话」（`new`，出厂）或「最近的会话」（`recent`）。已经在界面里了，敲 `/new` 开一个新的。

网页：

1. 点左栏「新会话」。
2. 输入框上面有「选择人格」「选择预设」「设置工作区」三个按钮，不点的照默认。
3. 敲第一句话。第一句话发出去时会话才建好。

命令行：`miyu ask "<话>"` 新开一个会话，说完这一句、印出回答就退出：

```bash
miyu ask "这个项目是做什么的"
cat 报错.log | miyu ask "为什么失败" -
miyu ask -C ~/src/app --preset full "跑一遍测试，修掉失败的"
```

```powershell
miyu ask "这个项目是做什么的"
miyu ask --file 报错.log "为什么失败"
miyu ask -C $HOME\src\app --preset full "跑一遍测试，修掉失败的"
```

不写话的，从标准输入读整段；话里有一个词正好是 `-` 的，读标准输入接在后面。`miyu ask` 的全部参数：

| 参数 | 做什么 | 能不能和 `-c`、`-s` 一起写 |
|---|---|---|
| `-c`、`--continue` | 接着上一次 `miyu ask` 开的会话说 | 不能和 `-s` 一起写 |
| `-s`、`--session <编号>` | 接着这个会话说 | 不能和 `-c` 一起写 |
| `-C`、`--cd <目录>` | 在这个目录里干活。目录要已经有。不写的是你敲命令时所在的目录 | 不能 |
| `--add-dir <目录>` | 把另一个目录也算进这个会话的工作区，可以写好几次 | 能。接着说时写了，原来加的那几个整份换成这次写的 |
| `--persona <人格>` | 用这个人格 | 不能；也不能和 `--no-persona` 一起写 |
| `--no-persona` | 不用人格 | 不能 |
| `--preset <预设>` | 用这个预设 | 不能 |
| `--permission <read-only\|full>` | 开局的权限级别：只读或开放权限，见 [权限和沙盒](permissions.md) | 不能 |
| `--model <模型>` | 用这个模型或 `@池`。接着说的会话从此换成它，见 [模型](models.md) | 能 |
| `--no-memory` | 这个会话不召回也不保存记忆，见 [记忆](memory.md) | 不能 |
| `--file <文件>` | 附上一个文件，可以写好几次，见下面「给 AI 文件和图片」 | 能 |
| `--format <text\|json\|jsonl>` | 输出格式。`text`（出厂）边收边打；`json` 最后一行印一个 JSON；`jsonl` 一行一个事件 | 能 |
| `--timeout <时长>` | 最多等多久，例如 `30s`、`10m`、`1h`，不写单位是秒。到了打断，退出码 `3` | 能 |
| `--from <名字>` | 别的 agent 调用时报自己的名字，例如 `claude-code`，这一句记成它说的 | 能 |

AI 派出了子代理的，`miyu ask` 等它们都回报、回答结束才退出。退出码：

| 退出码 | 意思 |
|---|---|
| `0` | 这一轮照常结束 |
| `1` | 出错，例如连不上核心、被拒绝、模型出错 |
| `2` | 参数不对 |
| `3` | 被打断（`Ctrl+C`），或到了 `--timeout` |
| `4` | 这一轮结束了，但有几步要你确认，没有做 |
| `5` | 没有可用的模型 |

## 接着以前的会话聊

终端：

- 敲 `/sessions`（别名 `/resume`）打开会话列表，能搜，`Enter` 切过去。列表里 `Ctrl+P` 置顶，空格勾选几个，`Ctrl+D` 删除。
- `/jump` 列出这个会话里你说过的话，选一句跳过去。
- `/status` 第一行「会话 ID」是完整的编号；侧边栏写着短编号 `#…`。
- 从 shell 直接打开某个会话：`miyu tui --resume <编号>`，打不开就报错退出。

网页：

- 左栏照时间分组列着会话。点「查看全部会话」进全部会话那一页，能筛、能搜。
- 敲 `/sessions <词>` 在输入框上面开会话列表，带着词搜。
- 每个会话右边「⋮」（会话操作）菜单里有「复制会话编号」。
- 从 shell 直接打开某个会话：`miyu web --session <编号>`。

命令行：

```sh
miyu ask -c "测试怎么跑"                                     # 接着上一次 miyu ask 开的
miyu ask -s 0198c2a4-7e1b-7c3d-9a2f-4b5c6d7e8f90 "接着改"    # 接着指定的
```

`-c` 只认 `miyu ask` 开的会话，终端、网页里开的要用 `-s` 写完整编号。一次都没用过 `miyu ask` 时 `-c` 报「没有可继续的 miyu ask 会话」。要在脚本里拿到编号，用 `--format json`，最后一行的 `session` 就是。

`miyu undo`、`restore`、`redo`、`compact`、`recap`、`rename`、`session export` 也都收 `-s <编号>`，不写的是上一次 `miyu ask` 开的那个会话。

## 会话在哪个目录干活

每个会话记着一个工作目录，AI 跑命令、写相对路径都从这里算。会话开好以后一直用它，你明着换了才变；一个界面里换了，别的界面跟着变。

新会话的工作目录：

| 从哪开 | 工作目录 |
|---|---|
| 终端 | 打开终端时所在的目录；开会话前用 `/workspace <路径>` 换过的照换过的 |
| 网页 | 没点「设置工作区」的，是这个会话自己的默认工作区 `~/.miyu/root/workspace/<会话编号>/`，界面上写「默认工作区」 |
| `miyu ask` | 敲命令时所在的目录，写了 `-C` 的照 `-C` |

换工作目录：

- 终端：`/workspace <路径>`，相对路径照终端所在的目录算。
- 网页：`/workspace <路径>`；不带路径的打开选目录的菜单。新会话还没开时点「设置工作区」。
- 命令行：`-C` 只管新开的会话，接着说的会话照它自己记的目录，和你所在的目录不一样时开头印一行「· 会话的工作目录：…」。

网页里路径要写绝对路径或 `~` 开头的：Linux、macOS 上写 `/…`、`~/…`；Windows 上写 `C:\…`、`C:/…`，`~/…`、`~\…` 也认。数据根里面只有 `~/.miyu/root/workspace/` 下面能当工作目录，别的报不能用；`miyu ask` 在数据根里敲的，改用这个会话的默认工作区，并说一句「工作目录 … 范围过大，改用 …」。

工作目录太宽的照样能用，命令从那里起；用 `/workspace` 换过去时回执写「工作区已切换到 …（范围较大）。」。根目录（Linux、macOS 上的 `/`，Windows 上 `C:\` 这样的盘根）在三个平台上都算太宽；Windows 上家目录本身、包住数据根的目录也算。Windows 上打开终端时一般就在家目录，要 AI 在某个项目里干活：先 `cd` 进项目目录再敲 `miyu`；`miyu ask` 写 `-C <目录>`；已经开着的会话敲 `/workspace <路径>` 换过去。

`--add-dir` 加的目录不能是 `~` 本身、家目录、根目录、装着数据根的目录，也不能在数据根里面，写了的整条命令不收。

## 撤销、恢复、重做

撤销只退对话，不把文件改回去。AI 在撤掉的那一轮里改过的文件、跑过的命令，照旧留在磁盘上。要找回文件，用 git 这类版本管理，或者自己备份；Miyu 没有改回文件的命令。终端敲 `/files`、网页右栏的文件修改那一块，能看这个会话改过哪些文件、每一步的差异，照着差异手动改回。

| | 终端、网页 | 命令行 |
|---|---|---|
| 撤销最后一轮 | `/undo`（别名 `/rewind`） | `miyu undo`（别名 `miyu rewind`） |
| 恢复刚撤销的 | `/restore` | `miyu restore` |
| 撤掉最后一轮、原话重来 | `/redo`；网页点 AI 那一轮末尾的「重做」 | `miyu redo` |
| 撤掉最后一轮、换一句话重来 | `/edit`；网页点你那句话下面的「编辑」 | `miyu redo <新的话>` |

撤销：

- 撤掉的是最后一轮：你的那句话和 AI 的回答，AI 从此看不到。别处来的东西留着，例如子代理的回报、定时触发、别的会话发来的消息，撤掉的只是 AI 对它们的回应。
- 那一轮派出去、还在跑的后台命令和子代理一起停下，回执写停了几个。
- 撤掉的几轮里压缩过、清空过的，上下文一起回到压缩前、清空前。
- 终端、网页里撤掉的那句话放回输入框。AI 正在回答、你又排着话没发出去的，`/undo` 先撤回排着的那一句。

恢复要在发下一句之前做。连着撤了几次的，能一次一次恢复回来。重做以后不能恢复。

重做和编辑只对最后一轮，而且这一轮要是你的话开的；AI 正在回答时不行。

## 上下文满了

AI 每次请求带着会话的上下文。上下文用到模型窗口的一定比例时，Miyu 自动把旧的部分压成一段摘要，最近的一段保留原文，接着干活。

看用了多少：

- 终端侧边栏写「上下文」：用了多少 / 窗口多大 · 百分比。`/context` 打开明细，看一块块各占多少。
- 网页输入框下面有上下文那一格，`/context` 打开同样的明细。
- `/status` 里也有。

手动压缩：

```sh
/compact                         # 终端、网页里
/compact 保留数据库迁移那部分的细节   # 后面写给摘要的要求
miyu compact -s <编号> 只留结论      # 命令行
```

自动压缩的两项配置，在设置页「高级 → 压缩」，或者用 `miyu config set`：

| 键 | 设置页上 | 出厂值 | 做什么 |
|---|---|---|---|
| `compaction.line` | 压缩触发线 | `85` | 上下文用到窗口的百分之几时自动压缩，能写 `20` 到 `95`。窗口小的模型要给回答留出地方，实际会更早压：20 万的窗口调到 85 以上不起作用，百万的窗口才到得了 95 |
| `compaction.prepare` | 提前压好 | `true` | 快到线时在后台先把旧的那一段压好，到线直接换上，不用停下来等。关掉的到线再压 |

两项都从下一轮起生效。只给当前会话改：

- `/compact-line 70`：这个会话到 70% 就压，能写 `20` 到 `95`；`/compact-line off` 回到跟着设置；只敲 `/compact-line` 说现在是多少、从哪来。
- `/context 128k`：给这个会话设上下文上限，数字后面可以接 `k`（千）、`m`（百万）；`/context off` 或 `/context unset` 去掉，照模型的窗口。上限太小、算不出压缩线的不收，网页提示「上下文上限至少要 …」。

不想要以前的内容了：

- `/clear`（别名 `/reset`）清空上下文，会话还是这个，回执「已清空上下文。」。清空以后敲 `/undo`，撤掉清空前的最后一轮，清空也跟着撤回。
- 或者 `/new` 开一个新会话。

## 回顾

`/recap` 或 `miyu recap` 让 AI 写一段回顾：在做什么、做完了什么、还剩什么。要请求一次模型，不开新的一轮。命令行只把这一段印到标准输出，可以接管道。

## 停下

- 终端：AI 回答时按两下 `Esc` 打断，排着的话接着发出去；按 `Ctrl+C` 打断，排着的话退回输入框。
- 网页：AI 回答时按两下 `Esc` 打断。
- 命令行：按 `Ctrl+C`，退出码 `3`。
- `/stop`：打断这一轮，排着的话留着不发，再停掉这个会话派出去的后台命令和子代理。回执「已全部停止。」。

## 改名

会话的标题出厂由 AI 照对话起。

- 终端、网页：`/rename <标题>` 改成这个；只敲 `/rename` 让 AI 照最近几轮重起一个；`/rename -` 去掉你起的标题。
- 网页：会话右边「⋮」菜单里「重命名」，在列表里直接改。
- 命令行：`miyu rename <标题>`，几个词用空格连起来；不写标题让 AI 重起。改好了什么都不印。

## 导出、导入

两种格式：

- 原始包（ZIP）：会话日志的原文、子代理的会话、分叉来源和附件都在里面，换机器、换数据根时搬会话用。包里另有一份 `transcript.md` 能直接看。导出的内容不打码，自己保管好。
- Markdown：给人看，或者贴给别的 AI。你配过的密钥在里面会被换掉。

Markdown 有三种用途：

| 命令行的 `--for` | 界面上 | 写成什么样 |
|---|---|---|
| `read`（出厂） | 仅导出对话为 Markdown 文件 | 带标题、时间段、模型和用量，思考、长输出折起来 |
| `agent` | 用于给别的 agent 继续 | 开头说明这是一段会话记录，工具写真名和参数原文，默认从最近一次压缩起，不带思考，全用英文 |
| `chat` | 用于网页端聊天对话 | 开头写 token 估算，工具一行写完，子代理只写回报，不带思考 |

命令行：

```bash
miyu session export                                   # 上一次 miyu ask 的会话，写到 ./miyu-session-<编号前 8 位>.zip
miyu session export 0198c2a4-7e1b-7c3d-9a2f-4b5c6d7e8f90 -o ~/备份/app.zip
miyu session export --md --for agent --last 20 -o -    # 最近 20 轮的 Markdown 打到标准输出
miyu session import ~/备份/app.zip                     # 印出新导入的会话编号
miyu session import 旧会话.zip --archive               # 导成只读存档
```

```powershell
miyu session export
miyu session export 0198c2a4-7e1b-7c3d-9a2f-4b5c6d7e8f90 -o $HOME\备份\app.zip
miyu session export --md --for agent --last 20 -o -
miyu session import $HOME\备份\app.zip
miyu session import 旧会话.zip --archive
```

| 参数 | 做什么 |
|---|---|
| `export [<编号>]` | 导出，不写编号的是上一次 `miyu ask` 的会话。写好了印出写到哪 |
| `-o`、`--output <文件>` | 写到这个文件。不写的是当前目录下的 `miyu-session-<编号前 8 位>.zip`，Markdown 是 `.md`。Markdown 写 `-` 打到标准输出 |
| `--md` | 导成 Markdown |
| `--for <read\|agent\|chat>` | Markdown 的用途，只能和 `--md` 一起写 |
| `--last <轮数>` | Markdown 只要最近几轮，只能和 `--md` 一起写 |
| `import <文件>` | 导入原始包，印出新导进来的会话编号；已经有、内容一样的不重复导 |
| `--archive` | 导成只读存档：能看、能搜，不能接着聊 |

导出的文件不能写进数据根里，已经有的同名文件不覆盖。

终端：敲 `/export`，先选用途（「完整存档」或三种 Markdown），再选「复制到剪贴板」或「存成文件」。存档只能存文件；超过 512 KiB 的 Markdown 也只能存文件。文件写在终端所在的目录。复制走终端的 OSC 52，终端不认 OSC 52 的复制不进去，也不报错，见 [终端](heads/tui.md)。

网页：会话右边「⋮」菜单里「导出…」。Markdown 能选范围（全部、现在的上下文、最近几轮）、带不带思考、工具写成什么样，然后「复制」或「下载」；「完整存档」只能下载。导入在「全部会话」那一页顶上的「导入会话…」，选一个 `.zip`。

存档在会话列表里单独一组「存档」。

## 给 AI 文件和图片

能给的：图片、PDF、文本和别的文件。图片 AI 直接看得到；模型看不了的种类，界面会提示。一个附件最大 20 MiB，图片最大 5 MiB、每边不超过 8000 像素。

终端：

- 把文件拖进终端窗口，或者敲 `@` 从列表里选。图片、PDF、音频、视频收成附件；别的文件和目录在话里写成路径，AI 要看自己去读。
- `Ctrl+V` 把剪贴板里的图贴成附件。Windows Terminal 里贴图用 `Alt+V`。
- 一段话超过 1 MB 的，自动转成文字附件发出去。
- 超过大小上限的文件只把路径交给 AI。

网页：

- 把文件拖进窗口、在输入框里粘贴，或者敲 `@` 从列表里选。用手指点的设备上输入框下面有回形针按钮。
- 一次最多 10 个。
- 超过上限的，网页在这台电脑上找到原文件、只把路径交给 AI；找不到的点它填完整路径。网页开在别的设备上的，超过上限的发不了。

命令行：`--file <文件>`，可以写好几次：

```sh
miyu ask --file 截图.png --file 日志.txt "这个报错和截图对得上吗"
```

数据根里的文件不能当附件。

## 待办

AI 做多步的活时会列一张待办。网页右栏能看；`/todo` 列出现在的待办和每一项的状态（未开始、进行中、已完成），`/todo clear` 清空。

## 删除会话

- 终端：`/delete` 删除当前会话，换到一个新会话。AI 正在回答时不能删，先打断。在 `/sessions` 列表里按两下 `Ctrl+D` 删选中的，空格勾选几个可以一起删。
- 网页：会话右边「⋮」菜单里「删除」；左栏「多选」勾几个一起删。

删一个会话，它派出去的子代理的会话一起删，在跑的先停下。删掉的会话挪到 `~/.miyu/root/trash/sessions/<会话编号>/`，留 7 天，核心下次启动时清掉满 7 天的。Miyu 没有把它找回会话列表的命令。

## 出了问题

| 看到的 | 怎么办 |
|---|---|
| 「没有可继续的 miyu ask 会话」 | `-c` 只认 `miyu ask` 开的会话。终端、网页里开的用 `-s <编号>` |
| 「工作目录 … 范围过大，改用 …」 | 在数据根里敲的 `miyu ask`。换到数据根外面，或者用 `-C` 指定目录 |
| 「没有可恢复的撤销」 | 撤销以后已经发了新的话，或者重做过，恢复不了 |
| 「无法重做」 | 最后一轮不是你的话开的，或者这个会话还没有一轮 |
| 「这是存档，不能接着说」 | 导入时写了 `--archive` 的会话只能看。要接着聊就不带 `--archive` 再导一次原始包 |
| 「上下文上限至少要 …」 | `/context` 设的上限太小，照提示的数往上调 |
