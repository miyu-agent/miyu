# 终端

> <sub>本文档由 Anthropic 的 Claude Fable 5.2 生成。</sub>

在终端里用 Miyu 的完整说明：屏幕上每一块是什么，每个键干什么，怎么调成自己顺手的样子，以及在 shell 提示符后面直接和 AI 说话。

## 打开

在终端里敲 `miyu` 或 `miyu tui`。直接敲 `miyu` 打开设置里「默认界面」（`ui.head`）指的界面，出厂就是终端。核心没在跑的，先把它拉起来。

```text
miyu tui [--resume <编号> | --page <页> | config]
```

| 写法 | 做什么 |
|---|---|
| 不带 | 照「启动时打开」（`ui.startup`）开新会话或接着最近的那个 |
| `--resume <编号>` | 打开这个会话，要写完整的编号；打不开就报错退出 |
| `--page config`、`config` | 只打开设置页，不进会话；在设置页的菜单上按 `Esc` 退出 |
| `--page oobe` | 重走一遍首次引导 |
| `-h`、`--help` | 印帮助 |

认不出的页名照常打开首页。终端界面是软件包 `tui`，卸掉了的用 `miyu pkg install tui` 装回来。

环境变量：

| 变量 | 做什么 |
|---|---|
| `MIYU_COLOR` | 强制色深：`truecolor`（或 `24bit`）、`256`、`16`、`none` |
| `NO_COLOR` | 设成非空的值就不上色，只留加粗、斜体这些 |
| `MIYU_TUI_IME=0` | 不替你切输入法（见下面「输入法」） |

只这一次带上环境变量打开：

```bash
MIYU_COLOR=truecolor miyu
```

```powershell
$env:MIYU_COLOR = 'truecolor'
miyu
```

PowerShell 里这样设的，在这个窗口里一直有效。

## 对终端的要求

| 要的 | 怎么认 | 缺了会怎样 |
|---|---|---|
| 真彩色 | `COLORTERM` 是 `truecolor` 或 `24bit`；`TERM` 里带 `kitty`、`wezterm`、`alacritty`、`ghostty`、`foot`；`TERM_PROGRAM` 是 `iTerm.app`、`WezTerm`、`ghostty`、`vscode`。Windows 上没设 `TERM` 的也算 | `TERM` 带 `256color` 的换成最近的 256 色，别的换成 16 色；`TERM` 空着或是 `dumb` 的不上色 |
| Nerd Font | 不自动认，首次引导里问你看到的是图标还是方块 | 图标是方块、问号。改用普通字符：`/icons`，或设置页「外观 → 图标」 |
| 鼠标 | 程序接管鼠标 | 终端自己的选区用不了，拖选、复制由 Miyu 自己做（见「鼠标」） |
| 图片 | 打开时问一次终端，最多等 2 秒，认 kitty、sixel、iTerm2 三种 | 图片、公式、Mermaid 图都显示成源码 |
| 键盘协议 | 认得 kitty 键盘协议的终端报得出 `Shift+Enter`、`Ctrl+Enter` | `Shift+Enter` 换行改用 `Alt+Enter` 或 `Ctrl+J` |
| 前台、后台 | 终端报窗口拿到、失去焦点 | 报不出的终端里，回答完不弹通知（kitty 除外） |

在 Linux 控制台（`TERM=linux`）里，没设过的图标默认用普通字符，没设过的主题默认用纯 ASCII 的那一套。界面是中文、日文的会提示一次「Linux 控制台显示不了中文：可在设置里把界面语言换成英文」。

在 Windows Terminal 里（认环境变量 `WT_SESSION`，在里面跑 WSL 也算），输入框空着时不写轮换的提示，首页那一行提示也不写。

### tmux、SSH、herdr

- 复制走终端的 OSC 52，经 SSH 也能复制到你手边的剪贴板。终端不认 OSC 52 的，复制不进去，也不报错。
- `Ctrl+V` 读的是跑着 Miyu 的那台机器的剪贴板。经 SSH 连过去时，要粘手边的东西，用终端自己的粘贴（kitty 是 `Ctrl+Shift+V`）。
- 在 tmux、herdr 里，通知交给系统弹（终端自己的通知过不去）。
- 在 tmux 里问不到终端的颜色：配色跟随终端时只用终端的 16 色。要真彩色的一套，打开 tmux 的透传。
- 同一个界面有时在能显示图的终端里看、有时在不能的里看（例如 herdr 里手机上连进来），敲 `/images off` 这一次运行先不显示图，`/images on` 恢复。不改配置。

## 首次引导

头一次打开终端时，连上核心后整屏是引导。走完写下 `ui.welcomed`，以后不再出现。中途按 `Ctrl+C` 退出程序，不记走完，下次从头来。要再走一遍：`miyu tui --page oobe`。

欢迎页写「欢迎使用 Miyu」「花一分钟配置模型和人格」，按 `Enter` 开始。上面一行是进度：语言、操作方式、图标、模型、货币、人格、配色方案、关于你、预设。每一步 `Esc` 回上一步。

1. 界面语言：第一行「跟随系统（…）」，下面中文、English、日本語。选了当场换。
2. 你喜欢的操作方式：「方向键」（↑↓ 上下，打字直接搜）或「Vim」（j/k 上下，按 / 搜索），写 `tui.keys`。
3. 图标：「你看到的是图标，还是方块或乱码？」选「图标」用 Nerd Font 图标，选「方块或乱码」用普通字符，写 `tui.icons`。
4. 选择模型供应商：选一家，填密钥，「测试连接」（会发一条测试请求，消耗少量额度），连上了选模型。列表里有「更多供应商…」和「自定义…」（填地址和接口：OpenAI 兼容、Anthropic、OpenAI Responses）。已经配过模型的，问你「使用」还是「更换」。这一步不能跳过。供应商、密钥、模型的细节见 [模型](../models.md)。
5. 希望金额以什么货币显示：列二十种常见的，最后一行「其他…」填三个字母的代码。写 `usage.currency`，花费照近期汇率换算成它。
6. 创建人格：名字（必填）、简单描述、头像、具体人格提示词、示范对话、人设提醒短语。长的几格按 `Enter` 进编辑窗，`Ctrl+G` 用外部编辑器写；Windows 上没有外部编辑器这一条，在编辑窗里写或者粘贴进去。「下一步」建好并设成默认人格；「跳过」不建。见 [人格和预设](../personas-presets.md)。
7. 配色方案：明暗（自动、深色、浅色）、配色（自动、跟随头像、跟随壁纸、终端配色），挪到哪一种界面当场变成哪一种。人格没有头像的多一格「形象」：显示、不显示吉祥物（「开启会提高 CPU 占用，拖慢启动速度」）。跟随头像、跟随壁纸时多一格「主色」。还有一格「铺底色」。上一步跳过了人格的，这一步也跳过。
8. AI 怎么认识你：「AI 用什么语言回复」「AI 怎么称呼你」「更多描述（可选）」，都可以不填，可以「跳过」。
9. 选择预设：一个预设一块，空格看详情，`Enter` 选定成默认预设；最后一块「自定义」，自己取名、勾功能。
10. 是否开启内置语义模型：只在软件源里有语义模型的软件包时出现。选「是」当场下载、装上，选「否」只用关键词检索。见 [记忆](../memory.md)。
11. 完成：写着「模型 … · 人格 … · 预设 …」，按 `Enter` 开始对话。紧接着的新会话直接用这里定的人格和预设。

以后改这些都在设置页（`/settings`）。

## 屏幕上有什么

空会话是首页：输入框在屏幕中间，上面是首页的那几样（打开了「首页显示形象」的有头像或吉祥物）。发出第一句以后变成下面这样：

```text
┌─────────────── 主列 ───────────────┐│┌── 侧边栏 ──┐
 正文顶上（往上翻时钉着你说的那句话）  ││ 头像
                                     ││ 会话名、#短编号
 时间线                               ││ 工作区
                                     ││ 上下文
 输入框上面（待办、运行状态、排队的话）  ││ 用量
 ╭ 输入框 ──────────────────────╮     ││ …
 ╰──────────────────────────────╯     ││
 底栏：权限级别 · 模型      用量        ││
```

| 一块 | 显示什么 |
|---|---|
| 时间线 | 你说的话、AI 的回答、AI 每一步做了什么（见「时间线怎么读」） |
| 正文顶上 | 往上翻过、你说的那句话已经滚出去时，顶上钉一行那句话，点一下跳回去 |
| 输入框上面 | 待办；AI 在回答时的运行状态行（「思考中」「回答中」、用时）；排着队的话；连不上核心时红字写原因；临时的提示 |
| 输入框 | 你敲的字。最多长到 8 行，再多的在框里滚 |
| 底栏 | 左边权限级别（「⏵⏵ 开放权限」「⏸ 只读」）、模型和供应商、思考程度；右边速度、用量那一格（例如 `◔ 128.4k · ¥0.42`）。有后台命令时中间多一个按钮「N 个后台命令」。窗口窄时右边的格子先丢，再把权限级别收成只剩图标、模型只写最后一段，最后收掉供应商名 |
| 侧边栏 | 窗口宽到 120 列以上、不在首页时出现在右边，宽 38 列。能滚，能拖选字 |

### 侧边栏的部件

出厂照这个先后：

| 部件名 | 显示什么 | 能点的 |
|---|---|---|
| `avatar` | 人格的头像，没有头像的显示吉祥物。受「侧边栏显示形象」（`tui.mascot_sidebar`，出厂关）管，关着时人格有头像的照样显示 | |
| `session` | 会话名，下面 `#短编号`，再下面人格、预设 | 点短编号复制完整的会话编号 |
| `cwd` | 「工作区」：这个会话的工作目录 | |
| `context` | 「上下文」：用了多少 / 窗口多大 · 百分比 | |
| `usage` | 「用量」：共多少 token、输入和输出各多少、缓存命中率、压缩了几次、缓存断裂几次、花费 | |
| `loops` | 这个会话挂着的循环（`/loop`） | |
| `jump` | 「跳转消息」：这个会话里你说的最近几句，新的在下，当前看的那句前面有箭头。条数照 `tui.sidebar_jumps`（出厂 `8`） | 点一句跳过去 |
| `files` | 「文件修改」：这个会话改过的文件，一行一个，后面写加减的行数，最多 8 个。没改过文件的不出现 | 点一行打开 `/files` 那一页，选着这个文件 |
| `recent` | 「最近会话」：一行一个。行首黄色 `?` 是在等你确认或回答，转圈是在跑，圆点是做完了还没看，箭头是当前这个。个数照 `tui.sidebar_sessions`（出厂 `8`） | 点一行切过去 |

装了带界面块的软件包的，它的块接在这几件后面。

### 调挂哪几件

侧边栏、底栏、输入框上面、正文顶上各是一项列表，设置页里没有，用 `miyu config edit` 手改系统配置 `~/.miyu/etc/config.toml`（数据根默认 `~/.miyu`，Windows 上是 `%USERPROFILE%\.miyu`）：

| 键 | 出厂的部件 |
|---|---|
| `tui.side` | 上表那九件 |
| `tui.footer` | 左段 `level`、`model`，右段 `usage` |
| `tui.above` | `todo` |
| `tui.top` | `prompt` |

一件写成一个行内表：`part` 是部件名，`hidden = true` 藏起来，`rows` 是最多几行（`0` 不限，底栏只有一行不看它）。写了的照写的先后排，没写到的照出厂的先后接在后面。认不出的部件名不画，提示一次「挂载位里有不认识的部件：…」。

```toml
[tui]
# 最近会话放最上面、最多 5 行；不要头像
side = [{ part = "recent", rows = 5 }, { part = "avatar", hidden = true }]
# 底栏不写模型
footer = [{ part = "model", hidden = true }]
```

存了当场照新的画。只想少列几个会话、几句话，改 `tui.sidebar_sessions`、`tui.sidebar_jumps` 就行，`0` 是不显示那一块。

## 按键

下面按情境分。哪个列表、框开着，按键先归它；`/help` 随时能看按键和全部命令。

### 输入框里

| 键 | 做什么 |
|---|---|
| `Enter` | 发送；是命令的执行。框里只有空白的不发 |
| `Shift+Enter`、`Alt+Enter`、`Ctrl+J` | 换行 |
| `↑`、`↓` | 在框里上下挪；在第一行再按 `↑`、最后一行再按 `↓`，翻输入历史。框里原来有字的，只翻以它开头的那几条 |
| `Ctrl+R` | 输入历史列表 |
| `←`、`→`、`Home`、`End` | 挪光标，`Home`、`End` 到这一行的头尾；按着 `Shift` 是选字 |
| `Ctrl+←`、`Ctrl+→` | 按词挪，按着 `Shift` 选 |
| `Ctrl+A` | 回到输入框开头 |
| `Ctrl+W`、`Alt+Backspace`、`Ctrl+Backspace` | 删掉前一个词 |
| `Backspace`、`Delete` | 删一个字 |
| `Ctrl+C` | 有选中的字复制；没选中、有字的清空输入框，提示「已清空 · ↑ 恢复」，空着按 `↑` 拿回来 |
| `Ctrl+S` | 暂存：框里的字存起来、框清空；再按一次取回。两边都有字的互换 |
| `Ctrl+V`、`Alt+V` | 读剪贴板粘贴，剪贴板里的图、复制的文件收成附件（见「输入框的几种写法」）。Windows Terminal 里贴图用 `Alt+V` |
| `Ctrl+Shift+V` | 终端自己的粘贴，粘进来的都是字 |
| `Ctrl+G` | 用外部编辑器写这一句：`$VISUAL`，没有的用 `$EDITOR`，都没有的用 `vi`。存了退出，字回到输入框。Windows 上没有：按了不起作用，长的话直接在输入框里写（换行用 `Shift+Enter`、`Alt+Enter`、`Ctrl+J`），或者粘贴进来 |
| `Esc` | 取消选中的字；在 `/edit` 编辑上一句时，取消编辑。不清空输入框 |
| `Ctrl+D` | 输入框空着时退出 |

### 时间线

| 键 | 做什么 |
|---|---|
| `PgUp`、`PgDn` | 往上、往下翻半屏。翻上去以后新来的字不会把你看的地方挤走 |
| `Ctrl+End` | 回到最底下，跟着最新的走。翻上去时右下有「跳转到底部（Ctrl+End）↓」，有新内容时它变亮 |
| `Ctrl+L` | 清屏：把屏幕顶空，往上翻内容还在。AI 在回答时不能清 |
| `/jump` | 列出你在这个会话里说过的话，`Enter` 跳过去，那一句顶到屏幕第一行 |
| `Ctrl+C` | 正文里拖选了字时，复制选中的。`Esc` 取消选区 |

展开、收起时间线上的一步要用鼠标点。

### AI 在回答时

| 键 | 做什么 |
|---|---|
| `Enter` | 照常发。这句排进队，这一轮结束后接着发。排着的话显示在输入框上面，点一条撤回到输入框 |
| `Esc` `Esc` | 按一下提示「再按一次 Esc 中断」，1.5 秒内再按一下打断这一轮，排着的话接着发。AI 还没开始做事、又没有排着的，打断后撤掉这一轮，你那句放回输入框 |
| `Ctrl+C`（输入框空着时） | 打断这一轮，排着的话不发，退回输入框 |
| `Ctrl+Enter` | 输入框有字的先排进队，然后当场打断，排着的马上发。没在回答时同 `Enter` |
| `Ctrl+L` | 不能清屏，提示「回答进行中，无法清屏」 |

AI 在整理记忆时，两下 `Esc` 停止整理。在看子代理、或者主会话闲着还有子代理在跑时，输入框空着按两下 `Esc` 停掉子代理，`Ctrl+C` 同样停掉它们。

### 确认框和提问框

AI 要你确认一步、或者向你提问时，输入框的位置换成一个框。按键全归它：

| 键 | 做什么 |
|---|---|
| `↑`、`↓`（`j`、`k`） | 选 |
| `1` 到 `9` | 直接选第几项 |
| `Enter` | 确定、提交 |
| 空格 | 能多选的题里勾上、取消 |
| `←`、`→`（`h`、`l`）、`Tab`、`Shift+Tab` | 几道题之间换题 |
| `n` | 提问里写补充；确认里光标挪到「不允许」，写理由 |
| `Ctrl+J`、`Ctrl+K`、`Ctrl+↑`、`Ctrl+↓` | 滚要跑的那条命令、预览 |
| `Ctrl+V` | 贴一张图：提问贴给这一道，确认只在「不允许」上收 |
| `Backspace` | 没在写字时删掉这一页最后一张图 |
| `Esc` `Esc` | 取消 |

在写字时，`Enter` 保存，`Shift+Enter`、`Alt+Enter`、`Ctrl+J` 换行，`Esc` 退出编辑。确认框上三个选择、等多久自动拒绝，见 [权限和沙盒](../permissions.md#确认框)。

### 列表和弹出的框

`/` 命令列表、`@` 文件列表、`$` 技能列表、输入历史、`/sessions`、`/model` 这些：

| 键 | 做什么 |
|---|---|
| `↑`、`↓`，`Ctrl+K`、`Ctrl+J` | 选 |
| `Enter` | 执行、选定 |
| `Esc` | 关掉 |
| 打字 | 命令列表、`@`、`$` 列表里接着打就是筛；输入历史、会话列表、模型列表里打字是搜 |
| `Tab` | 命令列表里补全命令名；`@` 列表里进这个目录 |

不能打字的框（`/help`、`/theme`、`/language`、`/effort`、`/usage`、`/status`、`/tool-list`、`/context`、`/export`、后台面板、选人格和预设的框）里直接按 `j`、`k` 也是上下。几个框自己的键：

| 框 | 键 |
|---|---|
| `/sessions` 会话列表 | 空格勾选，`Ctrl+A` 全选，`Ctrl+P` 置顶、取消置顶，`Ctrl+D` 删除（按两下） |
| `/status`、`/tool-list` | `c` 复制全部 |
| `/context` 上下文明细 | `Enter` 展开，`c` 复制 |
| `/usage` | `Tab`、`←`、`→` 换页，`t` 在 token 和花费之间换 |
| 后台面板 | `Enter` 展开、收起一条命令的输出，`x` 停掉它 |
| 新会话选人格、预设的框 | `e` 编辑选中的人格、预设；这个框开着时 `Ctrl+C`、`Ctrl+D` 退出程序 |
| `/files` 那一页 | `↑`、`↓`（`j`、`k`）换文件，`PgUp`、`PgDn`、空格滚差异，`Home`、`End` 到头尾，`Esc` 或 `q` 返回 |

### 全局

| 键 | 做什么 |
|---|---|
| `Tab`、`Shift+Tab` | 在开放权限和只读之间切。命令列表、`@`、`$` 列表开着时 `Tab` 归列表，`Shift+Tab` 照样切。权限级别见 [权限和沙盒](../permissions.md) |
| `↓`（输入框空着时） | 焦点挪到底栏的后台按钮、子代理状态行。再用 `↑`、`↓`、`←`、`→` 挪，`Enter` 打开后台面板或切进那个子代理的会话，`x` 停掉选中的子代理，`Esc` 回输入框 |
| `Ctrl+Z` | 挂起到后台，`fg` 恢复。Windows 上没有 |
| `Ctrl+D` | 输入框空着时退出；也可以敲 `/exit` |

在子代理的会话里看、它已经停了或报完了的，输入框空着时按 `Esc` 回主会话。

### Vim 按键模式

`tui.keys` 设成 `vim`（设置页「通用 → 交互 → 按键模式」，或首次引导第二步选「Vim」）以后，下面几处换一套键：

| 在哪 | 方向键（`arrows`，出厂） | Vim（`vim`） |
|---|---|---|
| 会话列表、模型列表、输入历史列表、`/jump` | 打字直接搜，`↑`、`↓` 选 | `j`、`k` 选；`/` 开始搜，搜的时候 `Ctrl+J`、`Ctrl+K` 选，`Enter` 收起（筛的留着），`Esc` 不搜了；没在搜时 `Esc` 先去掉留着的筛，再按才关 |
| `@` 文件列表、`$` 技能列表 | `Esc` 关掉列表 | `Esc` 进「在列表里选」：`j`、`k` 选，`h`、`l` 挪输入框里的光标，`/` 筛，`Enter` 插入，再按 `Esc` 关 |

别处的按键两种模式一样。

### 输入法

Linux 上用 fcitx5 的，在列表里按 `j`、`k` 这类不是打字的键时，Miyu 先把输入法切成英文，回到打字时切回来；终端不在前台时不切。不想要这个，打开时设 `MIYU_TUI_IME=0`。只认 fcitx5（环境变量 `XMODIFIERS`、`GTK_IM_MODULE`、`QT_IM_MODULE` 里写着 fcitx，用 `fcitx5-remote` 切），macOS、Windows 的输入法不替你切。

## 输入框的几种写法

| 写法 | 做什么 |
|---|---|
| `/命令` | 敲 `/` 弹出命令列表，边敲边筛 |
| `@` | 引用文件或目录：敲 `@` 加几个字弹出文件列表，`Tab` 进目录，`Enter` 收成一块。输入 `/` 按目录查找 |
| `$` | 点名技能：`$` 加名字弹出技能列表，一句话里能点几个 |
| `!` | 头一个字敲 `!` 进跑命令的模式，框里写「输入要跑的命令」，回车让核心直接跑这条命令，不经过 AI，最多跑 120 秒。不能带附件。框空着按 `Backspace` 或 `Esc` 回到平常 |
| 拖文件进终端 | 全是本机现成的文件、目录的，图片、PDF、音频、视频收成附件（`[图片 1]`），别的收成文件块（`[名字]`、`[目录/]`），发出去换成路径 |
| 贴图 | `Ctrl+V`（Windows Terminal 里 `Alt+V`）把剪贴板里的图收成附件；在文件管理器里复制的文件同拖进来的（macOS 上不收，见下） |
| 贴大段的字 | 超过 10 行或 800 个字的收成一块 `[已粘贴 N 行]`，发出去换回原文 |

附件最大 20 MiB。当前模型收不了这种附件的，改成写路径，提示「当前模型不支持…，已改为文件路径」。一句话超过 1 MB 的转成文字附件发出去。

`Ctrl+V` 读剪贴板用的命令：

| 系统 | 字 | 图 | 复制的文件 |
|---|---|---|---|
| Linux | Wayland 下先试 `wl-paste`，再试 `xclip`、`xsel` | Wayland 下装了 `wl-paste` 的问它，不然问 `xclip` | 同图 |
| macOS | 系统自带的 `pbpaste` | 系统自带的 `osascript` | 不收：访达里复制的文件收不进来 |
| Windows | Windows PowerShell（`powershell`） | 同字 | 同字 |

一个命令最多等 1 秒，Windows 上起 PowerShell 慢，最多等 3 秒。都读不到的提示「无法读取剪贴板：请使用终端的粘贴（kitty 为 Ctrl+Shift+V）」。

## 时间线怎么读

- AI 一轮里做的事一步一行：图标、工具名、简短的参数。命令、思考、编辑带几行预览：思考进行中滚着露最新的 `tui.timeline_thought_rows`（出厂 `15`）行，命令预览 `tui.timeline_preview_rows`（出厂 `10`）行。`tui.timeline_expand_thought`、`tui.timeline_expand_command`、`tui.timeline_expand_edit` 打开的那一种默认显示全文。
- 点一步展开看它的输出、编辑的差异；查记忆、知识库的结果点开是一条条的内容。再点收起。
- 一轮结束后，这一段的步骤折成一行，例如「执行了 2 条命令 · 3 次思考 · 48s」，编辑过的后面接加减的行数。点它展开。不想折，关掉 `tui.timeline_fold`。
- 一轮结束有一行收尾：时刻 · 供应商/模型 · 用时，后面接速度、这一轮的用量和缓存命中率。
- 差异：`/files` 打开「文件修改」那一页，一边是改过的文件（宽窗口在右边，窄窗口在上面），另一边是选中的文件的完整差异。
- 回答里的本机路径、网址能点，用系统给这种文件定的程序打开。AI 用 `show` 给你看的文件写着种类和「点击打开」。
- 图片、块级公式、Mermaid 图在认得图片协议的终端里画成图，点 Mermaid 图用程序打开大图；终端显示不了的写源码。`/images off` 这一次运行先不画。
- 子代理：底栏上面一行一个子代理的状态，`↓` 选中、`Enter` 切进它的会话看。
- 后台命令：底栏中间「N 个后台命令」，点它或选中按 `Enter` 打开后台面板，看输出、停掉。命令做完时间线上记一行「后台命令完成 · …」。
- 用量：底栏右边用量那一格是上下文环、累计 token（连子代理）、花费；侧边栏「上下文」「用量」更细。`/usage` 看这台机器上按天、按模型的用量。
- 别处来的消息（别的会话、子代理、你在别的界面发的）记一行「从 … 收到消息」。

## 外观

### 配色

`/theme` 打开配色框，挪到哪一种界面当场变成哪一种，`Enter` 写进 `tui.theme`，`Esc` 换回原来的。

| 选项 | 值 | 颜色从哪来 |
|---|---|---|
| 自动 | `auto`（出厂） | 依次看：人格有头像或主题色的跟随头像，找得到桌面壁纸的跟随壁纸，问得到终端颜色的终端配色，都没有的用 Tokyo Night |
| 跟随头像 | `persona` | 照看着的这个人格的头像取主色生成一套；人格自己设了主色的照它。人格交不出颜色的不列 |
| 跟随壁纸 | `wallpaper` | 先找 matugen 生成的那一份，没有的从桌面壁纸图取主色。换了壁纸自动跟着变。找不到壁纸的不列 |
| 终端配色 | `terminal` | 跟着终端自己的配色。真彩色、问得到终端颜色的从终端的 16 色里挑主色生成一套，不然直接用终端的 16 色。不铺底色 |

Tokyo Night 只在「自动」什么都找不到时兜底，配色框里不列，手写 `tui.theme = "tokyonight"` 也认。程序自带的四份配色文件：`tokyonight-night`、`tokyonight-day`（自带颜色），`terminal`、`terminal-light`（用终端的颜色）。

跟随头像、跟随壁纸、终端配色有几个候选主色时，设置页「外观 → 配色方案 → 主色」里挑。跟随壁纸、终端配色挑的写 `tui.theme_seed`；跟随头像挑的写回那个人格。

明暗（`tui.theme_mode`）：自动跟着终端的底色，问不到的当深色；或者一直深色、浅色。

铺底色（`tui.theme_background`，出厂开）：整个界面铺配色的底色。终端配色不铺，设置页里也不列这一项。

### 图标、主题、语言

- `/icons` 在 Nerd Font 图标和普通字符两套之间换，只管这一次运行。要一直用，设 `tui.icons`（设置页「外观 → 图标」）。
- 主题（`tui.look`）管框线、记号、字的修饰：不设是默认主题；写 `ascii` 是自带的纯 ASCII 那一套，界面上的符号、图标都换成 ASCII 字（汉字、字母不动），`tui.icons`、`/icons` 选的图标换回别的主题才用；装了别的终端主题包的写它的编号。主题包怎么装见 [软件包](../packages.md)。
- `/language`：第一行「自动（跟随系统：…）」，下面中文、English、日本語。选的写进 `ui.language`。换了以后新画的字照新语言，已经在时间线上的不变。

## shell 集成

装了以后，在 shell 的提示符后面敲一句话、回车，就是和 AI 说话。回答照时间线的样子印在 shell 里，不进全屏。

### 装、卸

```sh
miyu shellhook install            # 照你正在用的 shell 装
miyu shellhook install --shell zsh
miyu shellhook status             # 看装进了哪几个 shell
miyu shellhook doctor             # 查装好了没有、连不连得上核心、终端颜色、剪贴板
miyu shellhook uninstall          # 关掉：从 shell 里拿掉
```

`--shell` 能写 `fish`、`bash`、`zsh`、`pwsh`（PowerShell 7）、`powershell`（Windows 自带的 5.1）。不写的照这台机器认：

| 系统 | 不写 `--shell` 时怎么认 |
|---|---|
| Linux | 照上一层进程，认不出的照 `SHELL` |
| macOS | 只照 `SHELL` |
| Windows | 设了 `SHELL` 的照它；没有的照 PowerShell 加进 `PSModulePath` 的用户模块目录，分出 5.1 和 7 |

认不出的报「认不出是哪种 shell：用 --shell 加 fish、bash、zsh、pwsh 或 powershell 指定」。`--program <路径>` 是 shell 里调的程序，不写是这个程序旁边的 `miyu`。

装在哪：

| shell | 写进 |
|---|---|
| fish | `~/.config/fish/conf.d/miyu-shellhook.fish`（设了 `XDG_CONFIG_HOME` 的在它下面），整个文件 |
| bash | `~/.bashrc` 里带记号的一段 |
| zsh | `~/.zshrc`（设了 `ZDOTDIR` 的在它下面）里带记号的一段 |
| pwsh、powershell | 问 PowerShell 自己的 `$PROFILE.CurrentUserCurrentHost`，写进那个文件里带记号的一段。要 PSReadLine |

装进去的只有一行，每次 shell 起来时现印脚本，升级 Miyu 以后新开的 shell 自动用新的。已经开着的 shell 里会提示「这个终端里的集成还是旧的，重开终端用新的」。再装一次只换掉原来那一段。不是 shellhook 写的 fish 文件不动它。

PowerShell 的执行策略是 `Restricted`、`AllSigned` 的，PowerShell 不加载启动文件，装的时候印「PowerShell 的执行策略是 Restricted，不加载启动文件，装了也不生效：在 PowerShell 里执行 Set-ExecutionPolicy -Scope CurrentUser RemoteSigned 再开新窗口」（策略照实写）。照它执行：

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

### 怎么用

1. 新开一个 shell。
2. 敲一句话，回车。头一个词是普通的词、又不是任何命令的，这一行交给 AI；是命令的照常执行。多行的先看头一个命令在不在，判不出的交给 Miyu 判。找不到命令时也交给 AI。
3. 看回答。要确认、要回答问题时，提示符下面弹出和全屏一样的框。按 `Ctrl+C` 打断。

| 键 | 做什么 |
|---|---|
| `Ctrl+J` | 在命令行里换行，敲多行的话 |
| `Ctrl+V` | 读剪贴板：图、复制的文件收成块（`[图片 1]`），大段的字收成 `[已粘贴 14 行]`。PowerShell 里 `Alt+V` 也行 |

斜杠命令也能在 shell 里敲，或者写成 `miyu shellhook <名字>`（例如 `miyu shellhook model`）。`/model`、`/theme`、`/effort`、`/sessions`、`/persona`、`/preset` 在提示符下面开一个框选，`/model`、`/theme`、`/effort` 后面也能直接写名字。`/settings` 打开全屏的设置页。`/tui` 用全屏界面打开这个终端的会话。`/exit`、`/language` 在 shell 里不做。

AI 派出去的后台任务做完，回到提示符时印出来。停在提示符上等你敲的时候做完的：fish、zsh 里当场印；bash 里等你下一次回车，PowerShell 里等下一次画提示符（回车或 `Ctrl+C`）才印。

### 终端集成会话

每个终端窗口各有一个会话，叫终端集成会话，会话列表里标「终端集成」。开了终端不算，真说了话才建。设置页「通用 → 终端集成会话」里三项：

| 键 | 默认 | 管什么 |
|---|---|---|
| `terminal.persona` | 跟随 `persona.default` | 新开的终端集成会话用哪个人格 |
| `terminal.preset` | 跟随 `preset.default` | 新开的终端集成会话用哪个预设 |
| `terminal.idle_new_after` | `180` | 上一次说话以后闲置超过这么多分钟，下一句开一个新的，提示「上次说话是 … 前，为了防止缓存失效导致额外花费，已开启新会话」。`0` 是不开新的 |

在 shell 里敲 `/persona`、`/preset` 改的也是这两项。

## 通知

终端不在前台时，回答完了、出错了、在等你确认、在等你回答，Miyu 弹一条通知，响一声。通知的标题是这个会话的人格名字，有头像的带头像。别的会话做完、别的会话在问你，终端在前台也弹，不响。

| 在哪 | 怎么弹 |
|---|---|
| kitty | kitty 自己的通知，点一下跳回窗口；窗口在前台 kitty 自己不弹 |
| iTerm2、WezTerm、ghostty（认 `TERM_PROGRAM` 是 `iTerm.app`、`WezTerm`、`ghostty`） | 终端自己的通知 |
| 别的终端、tmux、herdr 里 | 系统通知，见下表 |

系统通知和响一声，三个平台各用：

| 系统 | 系统通知 | 响一声 |
|---|---|---|
| Linux | `notify-send` | 依次试 `pw-play`、`paplay`、`canberra-gtk-play`、`aplay` |
| macOS | `osascript` | `afplay` |
| Windows | 没有：走到系统通知这一路的什么都不弹 | 没有 Windows 的放音程序，不响 |

Windows 上弹得出通知的，只有上表头两行那种自己认通知序列的终端（例如 WezTerm）。Windows Terminal 不在这个名单里，Miyu 不给它发通知。

在 herdr 里由 herdr 响。通知和响声没有开关可设。

## 多个会话

- 打开时开新会话还是接着最近的，看「启动时打开」（`ui.startup`），见 [会话](../sessions.md)。
- 新会话开头先选人格、再选预设，选了才能打字。不想每次选，打开 `tui.skip_pick`。
- `/sessions` 打开会话列表，照「最近」「近 7 天」「近 30 天」「30 天前」「存档」分组。侧边栏「最近会话」点一行也能切。
- 别的会话在等你确认、回答时，不在这里弹框，提示「「标题」在问你 · /resume 切过去」，会话列表里那一项标「在问」，侧边栏行首是黄色 `?`。切过去框就弹出来。
- 别的会话一轮做完了，侧边栏那一行出一个圆点，切过去就消。

## 和 herdr 一起用

在 herdr 的窗格里开着终端时：

- Miyu 把在做、在等你、空闲报给 herdr，显示在它的侧栏上。
- 换会话时自动报恢复命令 `miyu tui --resume <编号>`。herdr 重启以后每个窗格接回各自的会话。`/new` 清掉旧的。只关 herdr 的客户端，Miyu 照旧在跑。
- 恢复命令要能在 PATH 上找到你敲的那个命令名，找不到的不报。写在命令前面的临时环境变量（bash 里的 `MIYU_HOME=… miyu`）herdr 不会存，要的话写一个固定这些变量的启动脚本放进 PATH。

## 缓存里的文件

终端的崩溃记录、交给编辑器的草稿这些放在缓存目录。缓存目录整台机器共用，不跟着 `MIYU_HOME` 变：

| 系统 | 缓存目录 |
|---|---|
| Linux | `$XDG_CACHE_HOME/miyu`（`XDG_CACHE_HOME` 没设、不是绝对路径的，`~/.cache/miyu`） |
| macOS | `~/Library/Caches/Miyu` |
| Windows | `%LOCALAPPDATA%\Miyu\cache` |

里面终端用的：

| 在哪 | 是什么 |
|---|---|
| `tui/crash.log` | 崩溃记录：时刻、版本、报错和调用栈，一次接一次往后写 |
| `tui/edit/` | `Ctrl+G`、改提示词时交给编辑器的临时文件 |
| `tui/pasted/<进程号>/` | 从剪贴板贴进来的图。界面退出时删掉；崩了留下的，Linux、macOS 上下次打开终端时清掉，Windows 上不清，要的话手删 |
| `tui/sounds/` | 提示音 |

## 出了问题

| 看到的 | 怎么办 |
|---|---|
| 图标是方块、问号 | 字体里没有 Nerd Font 的图标。装一个 Nerd Font，或者 `miyu config set tui.icons plain` |
| 框线、转圈是乱码 | `miyu config set tui.look ascii` 换成纯 ASCII 的主题 |
| 颜色发灰、不对 | 看 `COLORTERM`、`TERM` 是不是认得出真彩色，不是的设 `MIYU_COLOR=truecolor`；或者在设置页「外观 → 配色方案」换配色、明暗 |
| 图片、公式显示成源码 | 终端不认 kitty、sixel、iTerm2 图片协议，换一个认的终端；或者敲过 `/images off`，敲 `/images on` |
| `Shift+Enter` 发出去了 | 终端报不出 `Shift+Enter`，换行用 `Alt+Enter` 或 `Ctrl+J` |
| 「无法读取剪贴板：请使用终端的粘贴（kitty 为 Ctrl+Shift+V）」 | Linux：装上 `wl-paste`（Wayland 下）、`xclip`、`xsel` 中的一个；贴图、复制的文件要 `wl-paste` 或 `xclip`。macOS：读的是系统自带的 `pbpaste`，读不到的用终端自己的粘贴。Windows：要起 Windows PowerShell（`powershell`），3 秒没读完算读不到，用终端自己的粘贴 |
| 提示「已复制 … 个字符」，剪贴板里却没有 | 终端不认 OSC 52，复制不进去。换一个认 OSC 52 的终端 |
| 「核心未运行：设置 MIYU_CORE_BIN 指向 miyu」「连不上核心：…」 | 用 `miyu` 或 `miyu tui` 打开，不要直接跑 `miyu-tui`；还不行见 [排查问题](../troubleshooting.md#核心起不来连不上) |
| shell 里一句话交了两遍 | `miyu shellhook status` 会说旧版的 `conf.d/miyu.fish` 也在，删掉它 |
| 终端崩了，提示「调用栈已保存到 …」 | 崩溃记录在缓存目录下的 `tui/crash.log`，见上面「缓存里的文件」 |

装了 shell 集成的，先跑 `miyu shellhook doctor`，它一条条说哪里不对、怎么修。
