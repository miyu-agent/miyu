# 接入通讯平台

> <sub>本文档由 Anthropic 的 Claude Fable 5.2 生成。</sub>

把 Miyu 接到 QQ 或 Telegram 上，在私聊和群里跟 AI 说话：从装、接号，到管谁能叫 AI、AI 在群里能做什么、记录和用量。

## 是什么

软件包 `im`，界面上叫「接入通讯平台」。它是一个常驻的扩展，带一个自己的后台页（网页）。装了才有 `miyu im` 命令。能装在 `linux-x86_64`、`macos-aarch64`、`windows-x86_64` 上；没有 Linux aarch64 的，在那里 `miyu pkg install im` 报「不支持本机的系统。」。

| 平台 | 靠什么接 | 你要准备的 |
|---|---|---|
| QQ | OneBot v11 的反向 WebSocket：im 开一个端口，OneBot 实现连进来 | 另装一个 OneBot v11 实现，例如 NapCat、SnowLuma，登上 AI 要用的 QQ 号 |
| Telegram | 官方机器人接口（Bot API），im 往外连，不开端口 | 在 BotFather 建一个机器人，拿到令牌 |

一个 im 能同时接几个 QQ 号、几个 Telegram 机器人，一个号是一个「连接」。

## 装和打开

1. 装：

   ```sh
   miyu pkg install im
   ```

   确认屏上「需要的能力」列这几项，答 `Y` 一并批准：提供工具、操作会话、代平台用户发言、读取会话、写入会话记录、联网、调别的软件、往系统提示词里放内容、在界面上显示内容、替本机页面换登录票。能力是什么见 [软件包](../packages.md#能力)。

2. 问「现在启用 'im'？[Y/n]」时答 `Y`。答了不的，以后敲：

   ```sh
   miyu im start
   ```

   开了以后，核心每次起来都会拉起它。`miyu im stop` 关掉，之后核心不再拉起。

3. 打开后台页，三种办法任选：

   ```sh
   miyu im web        # 在浏览器里打开；im 没开的先开
   miyu pkg page im   # 同上；加 --print 只印网址
   ```

   或者在网页里敲 `/im`，在新标签页打开。

后台页默认开在 `http://127.0.0.1:8302/`。`miyu im web` 给的链接 1 分钟内有效。在这台电脑上打开、从网页、终端跳过来的，都不用登录。

后台页左边一列：「首页」「会话设置」「消息记录」「数据统计」「使用限制」；「AI」下面「人格」「预设」「模型」（和设置页里改的是同一份）；「软件」下面「已安装」「软件后台」「下载软件」；最下面「设置」。

## 接 QQ

先装好一个 OneBot v11 实现（NapCat、SnowLuma 这类），登上 AI 要用的 QQ 号。它要能建「WebSocket 客户端」，也就是反向 WebSocket：由它连到 im。im 不去连它。

1. 后台页首页点「新建连接」，选「QQ」（下面写着「OneBot（NapCat 等）」），点「下一步」。
2. 「在支持 OneBot 协议的软件里新建反向 WebSocket」：页面给一个地址，例如 `ws://127.0.0.1:8301/ws`。点「复制」，到 NapCat 的网络面板里新建 WebSocket 客户端，填这个地址。点「我已填写」。
   - NapCat 在别的机器上、在 Docker 里的，把 `127.0.0.1` 换成这台机器的地址。
   - 端口就在地址里改，要在 `1024` 到 `65535` 之间，不能和别的连接、后台页的端口重。头一个连接默认 `8301`，再建的往后顺延。
   - 路径写 `/ws` 或 `/onebot/v11/ws` 都行。
3. 「获取反向 WebSocket 验证 Token」：NapCat 建反向 WebSocket 时多半自动生成了一个 Token，粘贴过来，点「保存并连接」。没有 Token 的连接，NapCat 连进来会被拒。
4. 「你的 QQ 号」：填你自己的 QQ 号，AI 就认得出私聊和群里的你（见下面「谁是你本人」）。不填点「跳过」。
5. 「等它连上」：NapCat 那边保存以后几秒就好。连上了写「连接成功」，下面一行是机器人的号和连着的实现，例如「机器人 10001 · 连上的是 NapCat 4.8.0」。

连上以后，首页「连接」一栏一个机器人一张卡：头像、名字、「QQ · <实现> <版本>」、「<号> · 已连 N 分钟」。断开的卡留着，写「断开 N 分钟，在重连」。设了 Token、还没有号连进来过的，是一张「等 NapCat 连上」，写着端口。命令行里看：

```sh
miyu im status
```

连上了印「NapCat 已连接：<实现> <版本>，机器人 <号>」，没连上印「NapCat 未连接」和「NapCat 连接地址：ws://127.0.0.1:<端口>/ws」。

卡上的齿轮是「连接设置」：

| 格 | 说明 |
|---|---|
| 监听地址 | 默认 `0.0.0.0`：别的机器、Docker 里的也能连，外人靠 Token 挡。`127.0.0.1` 只收本机。要写成 IP |
| 反向 WebSocket 端口 | NapCat 连进来的端口 |
| 反向 WebSocket 验证 Token | 留空不改 |
| 填到 OneBot 实现里的地址 | 照上面几格拼好的地址，能复制 |

改了以后不用重启，NapCat 下次连进来就照新的认。连接不止一个时，下面多一个「删除这个连接」，点两次才删。

接几个 QQ 号：一个号一个 OneBot 实现、一个连接，各用各的端口和 Token。每个都照上面再走一遍「新建连接」。

## 接 Telegram

1. 在 Telegram 里找 `@BotFather`，发 `/newbot`，照提示起好名字和用户名，记下它给的令牌。
2. 后台页首页点「新建连接」，选「Telegram」（下面写着「机器人接口（Bot API）」），点「下一步」。
3. 「在 BotFather 新建机器人」：把令牌粘贴进「令牌」。「代理」三选一：
   - 「跟随联网设置」：照核心的环境变量 `HTTPS_PROXY`、`ALL_PROXY`、`NO_PROXY` 这些走，见 [联网搜索和抓网页](../web-search.md#代理)。
   - 「直连」：不走代理。
   - 「自定义」：写 `http://地址:端口` 或 `socks5://地址:端口`，`https://` 也认。

   国内网络连不上 Telegram 的，选一个能用的代理。点「检查并连接」。
4. 「检查结果」：令牌有效（写着机器人的名字、用户名、号）、连得上 Telegram、隐私模式开没开。点「下一步」。
5. 「你的 Telegram ID」：填你在 Telegram 上的数字编号，或者「跳过」。
6. 「连接成功」。

令牌存进密钥文件 `~/.miyu/etc/private/secrets.toml`（数据根默认 `~/.miyu`，Windows 上是 `%USERPROFILE%\.miyu`），配置里只写引用。连接卡的齿轮里能换令牌（「已设，留空不改；在 BotFather 换了令牌的填新的」）、改代理、看隐私模式。

### 隐私模式

BotFather 建的机器人默认开着隐私模式。开着时，群里只收得到回复 AI 的消息和发给它的命令，`@` 它也收不到。只在私聊里用的可以不管。要在群里叫它：

1. 在 Telegram 里给 `@BotFather` 发 `/setprivacy`。
2. 选这个机器人，再选 `Disable`。
3. 已经在群里的，把机器人移出群再拉回来才生效。

也可以把它设成群管理员，管理员收得到全部消息。改完在连接设置里点「重新检查」。隐私模式开着的群，会话卡上标着「隐私模式」。

### Telegram 上另外要知道的

- 一个令牌只能有一个程序在收消息。连接卡上写「别处也在收消息」的，是别的程序也在用这个令牌。
- 私聊里敲 `/`，列出 Miyu 的命令。命令名里的 `-` 换成了 `_`，例如 `/clear_memory`。
- 开了话题的群（会话卡上标「话题群」）整个群一个会话，AI 回在原来的话题里。
- 自建了 Bot API 服务的，把地址写进 `im.tg.api`。

## 谁是你本人

告诉 Miyu 平台上哪个号是你。写在核心的配置里，三处改的是同一份：

- 新建连接时的「你的 QQ 号」「你的 Telegram ID」那一步。
- 后台页「设置 → 绑定 → 本人的平台 ID」：「新绑定」先选平台，再填号；「解除绑定」去掉。QQ 号只写数字；别的平台不能有空格、冒号，最多 48 个字。
- 设置页（终端、网页里敲 `/settings`）「高级 → 平台账号」，或者手改 `~/.miyu/etc/config.toml`：

  ```toml
  [external.bindings]
  "qq:10001" = "owner"
  "tg:20002" = "owner"
  ```

填了以后，这个号：

- 私聊不是关起来的会话，和你在终端里开的会话一样照权限级别办；要确认的事不做，通讯平台上没有确认框。见 [权限和沙盒](../permissions.md#通讯平台上的会话)。
- 在群里叫 AI，不过主动回复判断，直接回。
- 不受限流、睡眠时间、用量上限的限制。
- 能用 `access` 是 `admin` 的命令，和群里的 `/model`、`/persona`、`/preset`、`/loop`。
- 加 AI 好友自动通过。
- 能叫 AI 去别的群、私聊发消息、搜所有会话的聊天记录。

改了最多 60 秒 im 就照新的认。

## 会话怎么分

一个连接下，一个群是一个会话，一个私聊是一个会话。群里同时有几个人叫 AI 时，会话里会多开几条支线并行回，最多几条看卡上的「会话内并行数量」。

每个会话一张卡，在后台页「会话设置」里。连接不止一个时，先在标题旁的下拉里选连接。墙上四段：

| 段 | 卡 | 管谁 |
|---|---|---|
| 默认 | 「群聊默认值」「私聊默认值」 | 群卡、私聊卡上没改的格照它们 |
| 名单以外 | 「陌生群」「陌生私聊」 | 不在名单里的群、人。出厂都不回，只记录 |
| 群聊名单 | 一个群一张 | 出厂回 |
| 私聊白名单 | 一个人一张 | 出厂回 |

点「新建」加一个群或一个人：先选「群聊」「私聊」，搜 AI 在的群、AI 的联系人，或者直接填号码，点「添加并设置」。QQ 上，加进私聊白名单的人加 AI 好友时自动通过。

一格没写的，往下照：群卡跟「群聊默认值」，私聊卡跟「私聊默认值」，默认值卡跟核心的设置（默认人格 `persona.default`、默认预设 `preset.default`、默认模型 `models.chat`）。格里写着「跟随群聊默认值（…）」这样的，括号里是现在照到的值。

出厂时群和私聊不一样：

| | 群 | 私聊 |
|---|---|---|
| 什么时候回 | 主动回复判断（见下一节） | 每条有字的都回；只有图、表情的只记录 |
| 限流 | 60 秒 30 轮；「陌生群」300 秒 5 轮 | 300 秒 5 轮；私聊白名单里的人出厂不受限流 |
| 会话内并行数量 | 3 | 一条一条来 |
| 回复时带多少条群聊记录 | 30 | — |
| 仅发送最终消息 | 开 | 关 |
| 让 AI 看到号码 | 开 | 开 |

### 卡上的几页

点一张卡打开它：

| 页 | 有什么 |
|---|---|
| 概况 | 「是否回复」开关（关掉以后只记录）；这个会话今天、7 天、30 天的统计；「最近判断」（群）、「最近处理」（私聊）：每条消息回没回、为什么；自主循环上次、下次几点；名单里的卡底下「移出群聊名单」「移出私聊白名单」 |
| 人格和模型 | 「AI 人格」「预设」「额外提示词」（只在这个会话生效）、「对话模型」「上下文窗口」「多模态模型」「主动回复判断模型」、「回复时带多少条群聊记录」、让不让 AI 看到发话人的号 |
| 触发方式 | 什么时候说话、主动回复判断、权限，见下面两节 |
| 定时任务 | 给这个会话建定时、循环的任务，见下面「定时任务」 |
| 限流与并发 | 「限流」（几条 / 几秒）、「睡眠时间」、三格「用量上限」、「会话内并行数量」 |
| 发送消息处理 | 说话方式、怎么发、长文，见「消息怎么显示」 |
| 管理插件 | 这个会话里开哪些插件 |
| 插件加的页 | 开着的插件在这个会话里带的页，例如「群管理面板」 |
| 实时日志 | AI 在这个会话里一行一件事：收到什么、怎么判断、想了什么、调了什么工具、发出了什么 |
| 查看会话 | 装了网页的才有：在新标签页里打开这个会话的时间线，只能看 |

人格、预设、模型改了，已有的会话也跟着换：模型当场换；人格、预设先压缩一次上下文，下一轮换上。卡上的人格、预设清掉的，已有的会话不变，要换回去在卡上选一个。

想让 AI 在一个群里从头来：后台页「消息记录」里点进这个群，右上角「删除 AI 会话」（点两次）。删的只是 AI 的上下文，聊天记录还在。

在聊天里也能换：你本人和卡上「允许使用管理员命令的用户」里的人，发 `/model`、`/persona`、`/preset`：

| 写法 | 做什么 |
|---|---|
| `/model` | 说现在用哪个，下面说怎么用 |
| `/model search [<关键词>]` | 列出能选的，带序号 |
| `/model <序号>`、`/model <名字>` | 换，写进这个会话的卡 |
| `/model 默认` | 改回跟随默认 |

`/persona`、`/preset` 一样。别人发的照普通的话交给 AI。

## AI 什么时候说话

### 私聊

私聊白名单里的人、你本人，每条有字的消息都回。陌生私聊出厂不回。

### 群里叫 AI

在群里，下面两种算叫了 AI：

- `@` 了 AI。
- 一句话以「额外触发关键词」里的某个词开头。区分大小写；要喊名字就叫的，把名字也写进去，不会自动加上人格的名字。

只回复 AI 的消息、没有 `@` 的，不算叫。

「是否开启主动回复判断」关着的群，叫了 AI 就回，不叫不回；开了「概率触发主动回复」的，抽中的也交给 AI。

### 主动回复判断

开着（群的出厂设置）时，一条消息碰上下面任意一条，就交给一个判断模型打分，过了门槛 AI 才回；一条都没碰上的只记录：

| 条件 | 什么时候算 |
|---|---|
| 叫了 AI | 见上 |
| 续聊 | AI 回了某人以后 30 秒内，这个人又说的 |
| 刚说过话 | AI 发完消息以后 30 秒内，谁说的都算 |
| 回复中跟进 | AI 正在回某人时，这个人又发的；过了就并进这一轮 |
| 概率抽中 | 别的都没碰上的，照概率抽。出厂关，开了默认 5% |
| 疑似违规 | 消息里有违规关键词，判断模型查一眼，严重程度到 7（0 到 10）就回 |

- 你本人、白名单成员、卡上「跳过主动回复判断的用户」里的人叫了 AI，直接回，不打分。
- 「被叫时也过主动回复判断」（出厂开）关掉的，谁叫了 AI 都直接回。
- 判断模型用轻量池里的模型；轻量池空着的用这个会话的对话模型。要指定，在卡上设「主动回复判断模型」。
- 门槛出厂 `0.8`。AI 刚说过话、同一个人叫得太勤、AI 在这个群最近回得多，门槛都会抬高；卡上「回复克制」管的是头一种。
- 门槛、五项权重、续聊和观察窗口的秒数、违规严重程度门槛，在「触发方式」页的「高级」里。
- 违规关键词在后台页「已安装 → 群管理 → 设置」里改；你本人发的不查。

AI 也能自己决定这一轮不说话（工具 `qq_skip_reply`、`tg_skip_reply`）。

### 自主循环

AI 时不时看一眼群聊，自己决定回什么、做什么。出厂关，只在名单里的群卡、私聊卡上有：

- 在「触发方式」页打开「自主循环」。
- 「多久看一眼」：AI 没自己定下一次的时候，隔多久看一次，出厂 7 分钟。AI 用 `qq_glance`、`tg_glance` 定了的照它的。
- 「看一眼带几条新消息」（群）：上次看过以后没回的消息最多交几条，出厂 50。
- 「自主循环的额外提示词」：看一眼时要做的事，比如留意什么、收集什么。

上次看过以后群里没有新消息的，不请求模型，照间隔再排。私聊到点不看有没有新消息，闲着就让 AI 决定要不要开口。睡眠时间里顺延到醒。

群里看一眼时，这一轮请求的最后接一句提示（不进会话历史）：没人叫 AI，它像一个平时多半只看不说的群友在往回翻；只为新东西开口：没人回的提问（开口时引用那一条）、跟进某个人、对话题真有补充；这里说过的不重复；不开口是常态。私聊到点那一轮带的提示只说没人叫 AI、是它自己在看，不劝它少说。卡上写了「自主循环的额外提示词」的，群里、私聊都照样带上。

在群里，你本人和「允许使用管理员命令的用户」里的人发：

| 写法 | 做什么 |
|---|---|
| `/loop` | 打开这个群的自主循环，回「这个群的自主循环开了」 |
| `/loop off` | 关上 |

群里的 `/loop` 只有这两种写法，带间隔、带话的回一句用法；它开关的是卡上的「自主循环」，不交给核心。私聊里的 `/loop` 交给核心，是核心的循环，写法同终端：光打 `/loop` 开的是核心的自主循环，跟着这个私聊的会话跑，和私聊卡上的「自主循环」是两样东西，开着它不会打开卡上那一格。核心的循环见 [让 AI 自己接着干](../automation.md#循环-loop)。

### 定时任务

名单里的群卡、私聊卡有「定时任务」页：「新建任务」写要做什么、什么时候（「每天几点」「每隔多久」「某一刻一次」「cron（高级）」）。到点 AI 在这个会话里做，睡眠时间里也做；「是否回复」关着时不做。能暂停、恢复、编辑、删除。定时任务别的用法见 [让 AI 自己接着干](../automation.md#定时任务)。

### 让 AI 在一个群里闭嘴

- 只是不说话：卡上「是否回复」关掉，AI 照样记录，不开口。
- 少说话：关掉主动回复判断，只有叫了才回；或者调低「限流」。
- 某段时间不说话：「睡眠时间」写成 `23:00-07:00` 这样，照本机的时间。这段时间里只回你本人和白名单成员。
- 整个不管这个群：「移出群聊名单」，这个群就照「陌生群」那张卡，出厂不回。

### 别的只记录、不回的情况

在卡的「最近判断」、实时日志里看得到原因：

- 「限流满了，只记录」「用量到了上限，只记录」：你本人和白名单成员不受这两条限制。
- 「睡眠时间，只记录」。
- 「AI 被禁言了，只记录」，或者「AI 被禁言着，解禁后回复」。
- 「几个人在复读同一句，只记录」：2 分钟内别人刚说过一模一样的话。
- 叫 AI 的那条被撤回了，这一轮停下。

## 谁能用

| 名单 | 在哪改 | 管什么 |
|---|---|---|
| 群聊名单 | 「会话设置」新建群聊；`miyu im access group add <群号>` | 名单里的群 AI 出厂会回 |
| 私聊白名单 | 「会话设置」新建私聊；`miyu im whitelist add <号>`；配置键 `im.whitelist` | 能私聊 AI；加 AI 好友自动通过；不受限流和睡眠时间影响；群里叫 AI 直接回 |
| 跳过主动回复判断的用户 | 群卡「触发方式」；`miyu im access skip <群号> add <号>` | 在这个群叫 AI 直接回 |
| 允许使用管理员命令的用户 | 群卡「触发方式 → 权限」 | 在这个群算管理员，见下 |

「陌生群」「陌生私聊」两张卡上打开「是否回复」，名单以外的群、人 AI 也回。

命令行里的 `whitelist`、`access` 只改 QQ 的名单，号写纯数字。

### 请求

- 加好友：白名单成员和你本人的，自动通过。别人的放着，去 QQ 里自己处理。
- 邀请 AI 进群：放着，去 QQ 里自己处理。
- 有人申请进一个群：AI 是那个群的管理员、群管理插件开着、那个群的「群管理面板」里写了「通过条件」的，AI 照条件审：通过、拒绝或留待人工，拿不准、出错的一律留待人工。没写条件的不管。

### 群里的管理员

群卡上「允许使用管理员命令的用户」里的人，在这个群里：

- 算 `access` 是 `admin` 的命令的管理员。QQ 的群主、群管理员不算，要写进这一格。
- 能用 `/model`、`/persona`、`/preset`、`/loop`。
- 命令被拒时听得到那一句；别人被拒什么都不回。
- 能叫 AI 删群文件。

通讯平台上发 `/` 开头的消息，先交核心当命令认，认不出的照普通的话交给 AI。谁能用哪条命令由 `commands.<命令名>.access` 定，见 [斜杠命令](../commands.md#谁能用)。

群里命令成功的回执，`im.recall_receipts` 里的那几条 3 秒后撤回，出厂是 `clear`、`clear-memory`；被拒的那一句都撤回；私聊的不撤。后台页「设置 → 通用 → 回执自动撤回的命令」里改。

## 群里的 AI 能做什么

群会话、不是你本人的私聊是关起来的会话，不看权限级别：

- 文件工具只碰得到这个会话的工作区，技能文件夹只能读。
- 命令在把读也关进工作区的沙盒里跑。Windows 上不能跑命令；Linux 上沙盒管不住 Unix 套接字的也不能。
- 不能装、卸软件包。
- 要确认的事一律不做。

详细见 [权限和沙盒](../permissions.md#通讯平台上的会话)。另外：

- 没有子代理、长期目标，不能向人提问，见 [让 AI 自己接着干](../automation.md)。
- MCP 服务出厂只给本机的会话，`mcp.<服务名>.venues` 里加 `private`、`group` 才给，见 [配置键全表](../config-keys.md)。脚本、技能照它们的 `Venues` 给，见 [扩展 Miyu](../extending.md)。
- 别人让 AI 抓网页有额外限制，见 [联网搜索和抓网页](../web-search.md#通讯平台上别人让-ai-抓的)。
- 设置里写的关于你的事（`profile.about`）群聊里不带。

### 记忆和知识库

群里的 AI 照样有记忆和知识库的工具：`remember`、`forget`、`memory_search` 用的是这个人格的那一份记忆，和你在终端里用的是同一份；`kb_save`、`kb_edit`、`kb_delete` 写的是你的知识库。群里的人说一句，AI 可能就记下、改掉、翻出来。

不想让群里碰到，给这些群一个关掉它们的预设，在「群聊默认值」或群卡上选它：

```toml
# ~/.miyu/root/presets/group.toml 里加上
[features]
memory = false

[tools]
kb_save = false
kb_edit = false
kb_delete = false
```

预设怎么写见 [人格和预设](../personas-presets.md)，记忆见 [记忆](../memory.md)，知识库见 [知识库](../knowledge.md)。

| 插件 | 做什么 |

## 消息怎么显示

「发送消息处理」页的几格：

| 格 | 出厂 | 做什么 |
|---|---|---|
| 去掉末尾句号 | 开 | 回话末尾的一个「。」去掉 |
| 智能引用 | 开 | 原消息后面别人又说了 2 条以上，引用原消息 |
| 智能艾特 | 开（群） | 引用对方时顺带 `@`；智能引用关着时，回复晚于 20 秒才 `@` |
| 确认主动回复后贴表情 | | 判断要回以后先给那条贴个表情，回完摘掉（群） |
| 分多条发送 | 开 | 照真人聊天的样子在句号处断，有时也在逗号处断；太长的、带换行的照旧一条 |
| 消息间停顿 | 开 | 每条之间照打字速度停一会儿 |
| 打字速度 | 120 字/分钟 | `20` 到 `600` |
| 按顺序发送 | 开 | 前一条发出去了才发下一条 |
| 仅发送最终消息 | 群开、私聊关 | AI 调工具时说的中间的话不发 |
| 长文处理 | 自动转图片 | 超过阈值的长文画成图；QQ 上还能选「合并转发」 |
| 长文处理阈值 | 300 字 | |
| 这个会话的说话方式 | | 写这里的人平时怎么说话，AI 每轮都看到（群） |

画成图要装 `render` 软件包，没装的拆成几段发，见 [附加软件](../addons.md)。发表情包要装 `memes` 软件包，装上就开着，会话卡「管理插件」里能按会话关掉。

AI 看得到的：

- 引用：被引用的那条。
- 图：叫 AI 的那条和它引用的那条，各最多 4 张，每张不超过 20 MB。别的图、视频、文件 AI 用 `qq_fetch_media` 去取。对话模型看不了图的，照「多模态模型」（卡上没设的用 `models.vision`）。
- 合并转发（QQ）：一条消息最多展开 4 个，套 3 层，一个最多 20 条，每条最多 500 字。

## 限额和用量

按 token 限，三条线：最近 5 小时、7 天、30 天。到了只记录不回，你本人和白名单成员不受限。

- 一个会话的：卡上「限流与并发」页的「5 小时用量上限」「每周用量上限」「每月用量上限」，不填不限。
- 一个人的：后台页「使用限制」。「所有人」三格对所有人生效，一个人在所有群和私聊里合起来算；「单独设置」里的人照自己的三格，整组替换「所有人」的。下面「最近 30 天」列用过的人，红的是到了上限。数字能写成 `200k`、`1.5m`。存在 `~/.miyu/etc/im/limits.toml`：

  ```toml
  [default]
  limit_5h = 2000000

  [[person]]
  id = "qq:10002"
  limit_month = 50000000
  ```

后台页「数据统计」看今天、7 天、30 天：token 和花费、请求构成、按会话、按人、按模型、每天的走势、按小时的消息，以及 im 自己的 CPU、内存、运行时间。CPU、内存照 `ps` 量，Windows 上量不出，这两格空着。连接不止一个时能按连接看。

## 聊天记录

im 把群和私聊的消息、群事件（禁言、踢人、进群、退群、撤回）和每条消息回没回、为什么，存在 `~/.miyu/var/lib/im/records.db`。图、文件只记占位和平台上的编号，不存内容。不会自己删，一直留到你清。

后台页「消息记录」：一个连接一组，组里列有记录的群和私聊，写着条数和大小。点进一个看记录，上面能按关键词、号码或名字、日期搜。

清理：点「清理记录」，选场所、范围（「保留近 7 天」「保留近 30 天」「保留近 90 天」「全部清空」「自定义」：哪段时间、谁发的），点两次「清理」。清了不能恢复，AI 的会话和记忆不受影响。AI 自己删不了记录。

把旧版 Miyu 迁移出来的 QQ 记录导进来：

```bash
miyu im records import ~/qq-records.jsonl
```

```powershell
miyu im records import "$HOME\qq-records.jsonl"
```

已有的不重复导；有一行不对就整个不导，印出哪几行。迁移见 [从 0.7 旧版迁过来](../migrate.md)。

## 插件

im 能装自己的插件：

- 「已安装」：装了的插件，开关、批能力、改设置、看「用在哪」。
- 「下载软件」：软件源里 im 的插件，能搜、能装。
- 「软件后台」：开着的插件带的后台页。

### 赞助记录

`im-sponsor`（「赞助记录」）是 im 的一个插件：你本人或群里的管理员叫 AI 记一笔赞助，谁都能问 AI 查某人累计了多少、排行榜。装：

```sh
miyu pkg install im-sponsor
```

装好就跑，出现在后台页「已安装」里，按会话开关。改、删记录在它的后台页里。别的币种照记账时的汇率换成默认币种，默认币种是配置键 `im-sponsor.currency`，出厂 `CNY`。

## `miyu im` 命令

| 命令 | 做什么 |
|---|---|
| `miyu im start` | 启动，之后核心每次启动都会启动它 |
| `miyu im stop` | 停止，之后核心不再启动它 |
| `miyu im restart` | 重启 |
| `miyu im status` | 运行状态和 NapCat 的连接 |
| `miyu im web` | 在浏览器里打开后台页（链接 1 分钟内有效）；没启动的先启动 |
| `miyu im logs` | 印运行日志，标准错误里有内容的先印它 |
| `miyu im logs -f` | 一直印新写入的日志 |
| `miyu im logs watch [<会话>]` | 实时看 AI 在会话里做什么。会话写 `qq:<群号或对方的号>`，不写看全部；一个号既是群又是私聊的写 `qq:group:<号>`、`qq:private:<号>`。`Ctrl+C` 退出 |
| `miyu im venue show <场所>` | 一个场所每一项设置的值和来源。场所写 `<平台>:<机器人号>:group:<群号>` 或 `<平台>:<机器人号>:private:<号>` |
| `miyu im records import <文件>` | 从 JSON Lines 文件导入聊天记录 |
| `miyu im whitelist [list \| add <号> \| remove <号>]` | 看、改私聊白名单，不写是 `list` |
| `miyu im access` | 列出私聊白名单、群聊名单、各群跳过判断的人 |
| `miyu im access whitelist [list \| add <号> \| remove <号>]` | 同 `miyu im whitelist` |
| `miyu im access group [list \| add <群号> \| remove <群号>]` | 看、改群聊名单 |
| `miyu im access skip <群号> [list \| add <号> \| remove <号>]` | 看、改这个群跳过主动回复判断的人；群要先在群聊名单里 |

每条命令后面加 `--help` 印它的用法。用法写错退出码 `2`，出错退出码 `1`。

```sh
miyu im venue show qq:10001:group:123456
miyu im access skip 123456 add 20017
```

## `im.*` 配置键

都写在系统配置 `~/.miyu/etc/config.toml`，改了当场生效。标「藏」的设置页上不列，在后台页上改；手改也行。

后台页和名单：

| 键 | 默认 | 做什么 |
|---|---|---|
| `im.web.port` | `8302` | 后台页的端口，`1024` 到 `65535`。后台页「设置 → 访问 → 端口」 |

| 键 | 默认 | 做什么 |
|---|---|---|

| `im.qq.ports` | — | 每个连接的端口 |
| `im.qq.tokens` | — | 每个连接的 Token（密钥） |
| `im.qq.host` | `0.0.0.0` | `im.qq.ports` 没写过时，头一个连接的监听地址 |
| `im.qq.listen` | `8301` | 同上，头一个连接的端口 |
| `im.qq.token` | — | 同上，头一个连接的 Token（密钥） |

Telegram 连接（藏，在连接设置里改）：

| 键 | 默认 | 做什么 |
|---|---|---|
| `im.tg.tokens` | — | 每个连接的机器人令牌（密钥） |
| `im.tg.proxies` | — | 每个连接的代理，和令牌一一对应：空的或 `env` 跟随联网设置，`direct` 直连，别的是代理地址 |
| `im.tg.api` | `https://api.telegram.org` | Bot API 的地址，自建 Bot API 服务时才改 |

识人术（藏，「已安装 → 识人术 → 设置」）：

| 键 | 默认 | 做什么 |
|---|---|---|
| `im.qq.identity_on` | `true` | 插件的总开关 |

| `im.qq.identity_card` | `true` | 有人把群名片改成和 AI 一样，提醒 AI |
| `im.qq.identity_people` | `[]` | 识人映射，一项写 `名字=QQ号`，例如 `老板=10001` |

查询信息（藏，「已安装」里开关）：

| 键 | 默认 | 做什么 |
|---|---|---|
| `im.qq.lookup_on` | `true` | 插件的总开关；关了这几件工具都没有 |

| 键 | 默认 | 做什么 |
|---|---|---|
| `im.qq.admin_on` | `true` | 插件的总开关 |

| 键 | 默认 | 做什么 |
|---|---|---|
| `im.strip_period` | `true` | 去掉回话末尾的一个「。」 |
| `im.humanlike` | `true` | 分多条发送 |

下面三个改在会话卡上了。配置里写着的，im 启动时挪进「群聊默认值」卡、从配置里去掉：

| 键 | 默认 | 做什么 |
|---|---|---|
| `im.sleep` | — | 睡眠时间，`HH:MM-HH:MM` |
| `im.keywords` | — | 群里的触发词 |
| `im.show_ids` | `false` | 让 AI 看到 QQ 号 |

## 后台页从别的设备打开

后台页「设置 → 访问」打开「向局域网开放」，同一个局域网里的手机、电脑就能打开，下面给网址和二维码。从别的设备打开要用网页里设的访问密码登录，见 [网页](web.md)。别把 im 放在反向代理后面，要从局域网用就开这个开关。macOS 上别的设备打不开的，到「系统设置 → 网络 → 防火墙 → 选项」里允许 `miyu-im` 的传入连接。

## 文件在哪

| 位置 | 是什么 |
|---|---|
| `~/.miyu/var/lib/im/` | 会话卡 `cards.json`、聊天记录 `records.db`，和各平台自己的状态 |
| `~/.miyu/var/log/im/miyu-im.log` | 运行日志 |
| `~/.miyu/var/log/im/stderr` | im 崩的时候说的话 |
| `~/.miyu/etc/im/limits.toml` | 每人的用量上限 |

## 出了问题

| 看到的 | 怎么办 |
|---|---|
| `miyu im status` 印「NapCat 未连接」 | 核对 NapCat 里填的地址和 `miyu im status` 印的一样，路径是 `/ws` 或 `/onebot/v11/ws`；NapCat 在别的机器上的，把 `127.0.0.1` 换成这台机器的地址，监听地址要是 `0.0.0.0` |
| 「没有设置 Token，NapCat 的连接会被拒绝」 | 敲 `miyu im web`，在连接设置里粘贴 NapCat 的 Token |
| 首页日志「有人连续猜错 NapCat 的口令（…），已拦下」 | 两边的 Token 不一样，照 NapCat 那边的改 |
| 「端口 … 已被占用」「这个端口已经被占用了」 | 在连接设置里换一个端口，NapCat 里的地址跟着改 |
| 连接卡上「令牌失效，在连接设置里换一个」「令牌不对」 | 到 BotFather 拿新的令牌，填进连接设置 |
| 「连不上 Telegram，在重连」「连不上 Telegram，检查代理」 | 在连接设置里换代理；选「跟随联网设置」的，核对核心的 `HTTPS_PROXY` |
| 「代理地址不对，在连接设置里改」 | 写成 `http://地址:端口` 或 `socks5://地址:端口` |
| 「别处也在收消息」 | 停掉别的用这个令牌的程序 |
| 「隐私模式开着，群里 @ 收不到」 | 照上面「隐私模式」关掉 |
| AI 在群里不回话 | 打开那个群的卡看「概况 → 最近判断」，或者 `miyu im logs watch qq:<群号>`：「没叫 AI」是没 `@`、也没以触发词开头；「关着，只记录」是这个群不在名单里或「是否回复」关着；「… 没过门槛 …」是判断模型觉得不该回；另有限流、用量、睡眠、被禁言几种 |
| 实时日志里「模型请求出错」 | 核对会话卡上的对话模型、核心的默认模型能用，见 [模型](../models.md) |
| 卡上的人格、预设写了不存在的，这个会话不回 | 在卡上重新选一个 |
| `miyu im web` 印「接入通讯平台未运行」 | `miyu im start`；还不行看 `miyu im status`、`miyu im logs` |
| 「管理页面的端口 … 已被占用，页面无法打开」 | `miyu config set im.web.port 8312` 换一个 |
| `miyu im status` 印「接入通讯平台已停止，不再自动启动：…」 | 照原因修好，敲 `miyu im restart` |
| 后台页「连不上接入通讯平台」 | im 停了，`miyu im start` |
