# 网页

> <sub>本文档由 Anthropic 的 Claude Fable 5.2 生成。</sub>

在浏览器里用 Miyu：页面上每一块是什么、能做什么，都在这一页。部署到服务器、反向代理见 [常驻和服务器](../service.md)。

## 打开

```sh
miyu web
```

网页软件 `miyu-web` 没在跑的，`miyu web` 先把它起来（核心没在跑的一并拉起），再交给系统的浏览器，终端里印一行「已在浏览器中打开：<网址>」。默认地址是 `http://127.0.0.1:8300`。

交给浏览器用的是：Linux `xdg-open`，macOS `open`，Windows `cmd /C start "" <网址>`。这个命令起不来、3 秒内就出错退出的，算没交出去，印「miyu: 无法打开浏览器，请手动打开上面的地址」，网址照样印在上面。

| 参数 | 做什么 |
|---|---|
| `--port <端口>` | 这一次听哪个端口，网页没在跑时才算，出厂 `8300` |
| `--print` | 不开浏览器，印出地址 |
| `--format <text\|json>` | 印的格式；`json` 也不开浏览器 |
| `--reset` | 带一次性码打开，重设访问密码 |
| `--logout` | 让所有浏览器都要重新登录 |
| `--package <编号>` | 直接打开「软件后台」里这个软件包的页 |
| `--session <编号>` | 直接打开这个会话 |
| `--settings [<分页>]` | 直接打开设置；写 `access` 打开「通用」里的「访问」 |
| `--stop` | 停掉网页，核心照常跑。只能单独写 |
| `-h`、`--help` | 印帮助 |

别的打开办法：

- 装了托盘的，点托盘菜单「打开网页界面」，Linux、Windows 上左键点托盘图标也行，见 [托盘](applet.md)。
- 浏览器地址栏里有「安装」的，能把网页装成单独的窗口，名字是 Miyu。

端口：

- 没写过端口的，8300 被占时依次试 8301 到 8309，用第一个空的。都被占、或者写了的端口被占，报「端口 8300 已被占用」，用 `--port` 换一个。
- 固定端口用 `web.port`，监听地址用 `web.listen`，见下面「访问和安全」。

网页软件没有浏览器连着、也没有在给图片视频这类文件，连续 `web.idle_seconds` 秒（默认 `600`）就自己退出，下次 `miyu web` 再起来。打开了局域网访问的不退。`0` 是一直不退，设置页上不显示这一项，用命令改：

```sh
miyu config set web.idle_seconds 0
```

只关网页、核心照常跑：`miyu web --stop`。网页软件在前台跑的（例如服务器上照 [常驻和服务器](../service.md) 起的 `miyu-web serve`），按 `Ctrl+C` 停；Linux、macOS 上收到 `SIGTERM` 也停。

### 手机和别的设备

打开局域网访问（见「访问和安全」）以后，手机、平板用这台电脑的地址打开，敲访问密码登录。窗口窄于 836 像素时页面换成窄屏的样子：

- 左栏收起，左上角一个菜单按钮「展开侧栏」，点了从左边滑出来，手指往左划收起。
- 右侧边栏盖在对话上，顶上有关闭按钮，往右划收起。
- 平时悬停才露的按钮（你的话下面的复制、编辑，一轮末尾的复制、重做，左栏的多选）一直露着。
- 经局域网 `http` 打开的页面，浏览器不给剪贴板的接口，复制不成的提示「复制不了，请长按选中文字后复制」。

## 第一次打开

第一次打开网页，整页盖上引导，一屏一步。顶上一排小格是步骤条，按 `Enter` 走下一步，「上一步」回去，右上角换明暗。

1. 欢迎：「Miyu」，点「开始」。
2. 界面语言：中文、English、日本語，或「跟随系统」。
3. 模型：「选择模型供应商」，选一家、填密钥，「测试连接」，选默认模型。怎么填见 [模型](../models.md)。
4. 人格：「创建人格」，填名称、头像、具体提示词，可以打开「推演人生」（见 [推演人生](../life.md)）。能「跳过」，跳过的不用人格。
5. 外观：「配置外观」，选明暗、主色、配色方案、主题。上一步跳过了人格的，这一步也跳过。
6. 关于你：「AI 怎么认识你」，填「AI 怎么称呼你」和「更多关于你的描述（可选）」。都空着的按钮是「跳过」。
7. 预设：「选择预设」，点一个；「自定义」自己勾功能。
8. 语义模型：「是否开启内置语义模型」，「是（推荐）」下载装上，「否」只用关键词检索。软件源里没有这个包、也没装的，没有这一步。
9. 别的设备：「在别的设备上用」，选「开放」要先设访问密码，设好显示别的设备用的地址和二维码；选「不开放」只有这台电脑能打开。不是经 `miyu web` 打开的页面没有这一步。
10. 完成：列出选好的模型、人格、预设，点「▶ 开始聊天」进一个新会话。

从别的设备登录、头一次设访问密码进来的，第一步是「密码」，后面从界面语言接着走。

走完写 `ui.welcomed = true`，终端、网页都不再出引导。换了界面语言页面会重新载入，从这一步接着走；中途关掉页面，下次从头来。要再走一遍：

```sh
miyu config set ui.welcomed false
```

再刷新页面。人格、预设、外观以后都能在设置页改。

## 页面的样子

宽屏是三列：左栏、对话区、右栏。

### 左栏

从上往下：

- 头像和名字：正在看的会话用的人格，名字下面写「在线」「连接中」「离线」。点头像打开这个人格的编辑卡片。
- 「新建会话」「全部会话」「项目」三行。有软件包挂了入口的，下面多一行「更多」，点了弹出菜单。出厂的「推演人生」挂在这里，点了列出各人格的人生会话，见 [推演人生](../life.md)。
- 「置顶」「项目」「会话」三栏，点栏头收起、展开。「会话」照时间分组：最近、近 7 天、近 30 天、30 天前；终端集成开的会话单成一组「终端集成」；导进来的存档单成一组「存档」。最多列 20 个，下面「查看全部」进全部会话那一页。人生会话不列在这里。
- 最底下一行：齿轮打开设置，旁边的按钮换浅色、深色。

一个会话一行，左边的记号说它现在怎样：在跑的转圈，「等你确认」，「已中断，等待输入」，没看过的一个圆点。子代理的会话挂在派它的会话下面，结束了的收成「已完成 N 个」。

悬停一行，右边出「⋮」，菜单里有：置顶（或取消置顶）、移到项目、移出项目（在项目里的才有）、复制会话编号、重命名、导出…、删除。删除点了就删，不再问。

- 多选：「会话」栏头悬停露出多选按钮，点了每行前面换成勾选框，`Shift` 点连着选，栏头换成「已选 N 个」和全选、删除、退出。`Esc` 退出多选。
- 拖：按住一个会话拖到「置顶」那一栏置顶，拖回下面取消置顶，拖到一个项目上移进去。拖的时候 `Esc` 取消。
- 宽：左栏右边沿按住拖改宽，双击回到出厂的宽，这台设备记着。
- 收起：左上角的按钮收起、展开左栏。收起以后指针移到窗口左边沿，左栏浮出来。

### 对话区

- 左上角是会话标题，在项目里的前面写项目名。点标题出一张卡片：会话编号（点了复制）、人格、预设、工作区。点人格、预设那一行换一个，换之前问一句，会先压缩上下文；人格那一行的笔打开它的编辑卡片；工作区那一行换工作目录。
- 子代理的会话，标题前面一颗颗写上面几层，点了进那一层；输入框正上方有「回到「…」」回派它的会话。
- 中间是时间线，见下面「时间线」。滚上去以后底下出「回到底部」。
- 对话区右边一条跳转条：你说的一句一条短横线，指针靠近列出每一句，点哪句滚到哪句。
- 右上角是右栏的开关「展开右栏」。
- 对话这一列左右两边沿能拖宽窄，双击回到出厂的宽。

空会话（还没说第一句）的输入框上面有「选择人格」「选择预设」「设置工作区」三个按钮，不点的照默认。默认的预设、人格用不了时输入框锁住，写「请选择预设」或「请选择人格」，选了才能打字。

选工作目录时（「设置工作区」、项目的「工作区目录」这类），网页在这台电脑上开系统的选目录对话框，同一时间只开一个：

| 系统 | 用什么 |
|---|---|
| Linux | 依次试 `zenity`、`kdialog`；都没有、或者连不上显示的，退回页面自己画的文件夹浏览器 |
| macOS | `osascript` 的选文件夹对话框；开不成的退回页面自己画的文件夹浏览器 |
| Windows | PowerShell 的选文件夹对话框，盖在别的窗口上面 |

### 右栏

点右上角的开关打开右侧边栏，一张张卡片：

| 卡片 | 列什么 | 点了 |
|---|---|---|
| 待办 | AI 列的待办，「已完成 N 项」收着 | |
| 后台任务 | 这个会话的后台命令、子代理，子代理再派的挂在下面；有「停止」「全部停止」 | 后台命令「看输出」；子代理在主区打开它的会话 |
| 文件修改 | 这个会话改过的文件，能搜 | 看这次改动的差异，「上一个文件」「下一个文件」，「放大看」 |
| 展示文件 | AI 用 `show` 给你看过的文件 | 在右栏里打开（预览工作区） |
| 定时任务 | 挂在这个会话上的定时任务 | |

窗口不够宽时右栏盖在对话上，点外面或按 `Esc` 收起。卡片的先后、开关、每张最多露几行，在设置页「软件包」里「网页」那一段的「右侧边栏」里改。右栏的左边沿能拖宽。

预览工作区是右栏里看文件的地方，头上一行：

- 「预览」「源码」切换（两样都有才露）。
- 标题，点开列出展示过的全部。
- 复制、下载、最大化、关闭；从右侧边栏点进来的，左上角是返回。

Markdown 照回答的排法画，代码带行号、上色，HTML 在隔离的框里直接跑、不联网，图片能滚轮缩放、拖动，PDF 用浏览器自己的阅读器。装了带界面块的扩展的，顶上多两个标签「工作区」「面板」，面板里是扩展放的内容。

右侧边栏在设置页「软件包」里停用以后，右上角换成「预览工作区」的开关，来了新的展示文件按钮上一个圆点。

## 输入框

| 键 | 做什么 |
|---|---|
| `Enter` | 发送。AI 回答时也能发，先排着，状态行上能「撤回」 |
| `Shift+Enter`、`Ctrl+J` | 换行 |
| `Esc` 两下（1.5 秒内） | AI 回答时打断；空闲时清空输入框，空着按 `↑` 拿回来。整理记忆的会话里是停止整理 |
| `↑`、`↓` | 翻发过的话 |
| `Ctrl+R` | 输入历史列表，能搜；列表里 `Tab` 看全文，`Enter` 填进输入框 |
| `Ctrl+S` | 先存起框里这句；框空着再按取回来。Mac 上也是 `Ctrl+S`，`⌘S` 不算 |
| `Tab`、`Shift+Tab` | 换权限级别。命令、`@`、`$` 列表开着时 `Tab` 归列表 |
| `/` | 焦点不在哪个输入框里时，把焦点放回输入框 |
| `Backspace` | 光标在最前面时，拿掉最后一个附件 |
| `Ctrl+,`（Mac 上 `⌘,`） | 打开设置 |

命令、文件、技能、会话、历史这几种列表都是 `↑` `↓` 选、`Enter` 选定、`Esc` 关。

`Ctrl+,` 和 `⌘,` 照打开网页的那台设备分：Mac、iPhone、iPad 上的浏览器认 `⌘,`，别的认 `Ctrl+,`。软件包整页里的表单，`Ctrl+S`、`⌘S` 都是保存。

### 斜杠命令

敲 `/` 弹出命令列表，边敲边筛，`Tab` 补全，`Enter` 执行。最常用的：

| 命令 | 做什么 |
|---|---|
| `/new` | 新建会话 |
| `/sessions` | 会话列表，可以带搜索词 |
| `/stop` | 打断这一轮，停掉这个会话的后台命令和子代理 |
| `/undo` | 撤销最后一轮 |
| `/redo` | 撤掉最后一轮，原话重来 |
| `/compact` | 现在就压缩上下文 |
| `/model` | 换这个会话的模型 |
| `/persona`、`/preset` | 换人格、预设 |
| `/workspace` | 换工作目录 |
| `/settings` | 打开设置页 |
| `/help` | 看按键和全部命令 |

全部命令见 [斜杠命令](../commands.md)。

### @ 文件和 $ 技能

- 敲 `@` 弹出文件列表，照会话的工作目录找。`Tab` 进目录，`Enter` 选定。图片这类收成附件，别的文件在框里写成一块 `[文件名]`，发出去换成路径。退格整块删。
- 敲 `$` 弹出技能列表，选了的技能跟着这句话交给 AI，一句话能点几个。

### 附件

- 把文件拖进窗口、在输入框里粘贴，或者用 `@` 选。用手指点的设备上，输入框里有回形针按钮「添加附件」。
- 一次最多 10 个；一个最大 20 MiB，图片最大 5 MiB、每边不超过 8000 像素。
- 超过上限的，网页在这台电脑上找原文件，找到了只把路径交给 AI，框里那张卡标「仅路径」；没找到的标「未找到」，点它填完整路径。
- 找原文件照名字、大小、修改时刻认：先翻会话的工作区，再翻家目录下的下载、桌面、文稿、影片、图片、音乐，最后整个家目录；点开头的文件夹、`node_modules`、`target`、macOS 的资源库、Windows 的 `AppData` 不进，翻到时限为止。Linux 上装了 `plocate` 的、macOS 上，先问系统现成的索引（`plocate`、Spotlight），一下就回，外接盘上的也找得到。Windows 上没有索引可问，只靠一层层翻，翻不到的就是「未找到」。
- 数据根（默认 `~/.miyu`，Windows 上是 `%USERPROFILE%\.miyu`）里的文件不能当附件。

详见 [会话](../sessions.md#给-ai-文件和图片)。

### 框下面那一行

| 位置 | 是什么 | 点了 |
|---|---|---|
| 左边 | 权限级别「⏵⏵ 开放权限」或「⏸ 只读」 | 换另一级，见 [权限和沙盒](../permissions.md) |
| 左边 | 模型名 | 换模型的菜单：「模型」「模型池」两页，`Tab` 换页；模型有思考程度的，指着它往右展开「思考程度」 |
| 中间 | 「N 个后台任务」，有在跑的才有 | 列出后台命令、子代理，能停 |
| 右边 | 一个环、累计 token（括号里是缓存命中率）、花费 | 一个浮窗分三段：上下文、累计消耗、花费 |

环是上下文占窗口多少。正在压缩、压缩失败、超出窗口时这一格变红，写「正在压缩上下文」「上下文压缩失败」「上下文超出窗口」。扩展的界面块也可能挂在右边。

输入框上面一行：左边是运行状态行（AI 在做什么、用了多久、重试），右边有长期目标、循环的下次时间。待办在它上面。

## 时间线

你的话是靠右的气泡。AI 的一轮一块：头上是人格的头像和名字，下面依次是过程、回答、收尾那一行。

- 过程：一步一行，思考写「正在思考」「已思考」，工具一行一个图标。正在做的这一轮展开着，做完收成一行摘要，点开看每一步。
- 点一步展开细节：参数、结果；命令写命令本身和输出；改文件的写差异，加的、删的分颜色。文件太大、不是文字文件的写「文件太大，不显示差异」「不是文字文件，不显示差异」。
- 脚本里调了工具的，那一步下面写「脚本调用的工具 · N 次」，点开逐个看。
- 子代理：派出去那一步带机器人图标；它交回报告时时间线上记一行「子代理已提交报告 · <标题>」，点开看报告。后台命令结束也记一行，点开看命令和输出。
- 压缩、清空上下文各记一行「上下文已压缩」「上下文已清空」。

回答：

- Markdown 排版：标题、列表、表格、公式、脚注。代码块上色，右上角「复制代码」。
- mermaid 代码画成图。
- 回答里单独一行的图片、视频、音频地址画成卡片。图片点开放大，下面有下载、复制图片、在右栏打开（AI 展示过的图才有）、在新标签页打开。
- 单独一行的网页链接画成链接卡片，一条回答最多三张。

按钮：

- 你的话：悬停时下面出「复制」「编辑」。编辑在气泡里直接改，`Enter` 发送、`Esc` 取消，这一轮照新的话重来。
- AI 的一轮：收尾那一行写时刻、端点/模型、用时、用量、出字速度，后面「复制」「重做」。
- 编辑、重做只在最新的那一轮有，AI 回答时没有。

### 确认和提问

AI 要你确认一件事、或者问你问题时，输入框整个变成一个抽屉，框里写的字留着，答完回来。

确认：头一行写要做什么（「运行命令」「写入 N 个文件」「安装或卸载软件包」这类），受保护的命令标「高危命令」，下面三个选择：

1. 「允许本次」
2. 「此目录不再询问」：读写某个目录要确认时才有
3. 「不允许」：下面「理由（可选）」写一句，AI 看得到

按键 `↑` `↓` 选、`Enter` 确定。超时的写「… 后自动拒绝」。

提问：标题「… 提问」，一题一页，`←` `→` 换题。单选的选了就答，能多选的 `Space` 勾，「输入其他答案」自己写，`N` 加「补充」。最后一页「确认」，`Enter`「提交」。

两下 `Esc` 或点「取消」：关上抽屉，打断这一轮。答过的留在时间线上。

## 项目

项目把会话分成一组，并给组里新建的会话定好工作目录、人格、预设和一段附加提示词。只在网页里有。

### 建项目

1. 点左栏「项目」栏头的「+」（或全部会话里「项目」那一页最后一张「新建项目」）。
2. 在「新建项目」里填：

   | 项 | 说明 |
   |---|---|
   | 名称 | 必填，最多 40 个字 |
   | 说明 | 最多 80 个字，显示在项目卡片上 |
   | 颜色 | 十二种里选，或「+」自选 |
   | 工作区目录 | 在项目里新建的会话在这里干活；不选是「默认工作区」 |
   | 人格、预设 | 「默认」照设置里的默认 |
   | 附加提示词 | 项目里的每个会话都会带上这段提示词，最多 8000 个字 |
   | 留言 | 开关「能和项目外的会话互相留言」，默认关 |

3. 点「创建」。

### 项目里的会话

- 新建：项目那一行悬停出「⋯」，点「在项目里新建会话」；或者进项目页点「在项目里新建」。新会话照项目的工作区、人格、预设，左上角写「项目名 / 新会话」。
- 已有的会话放进去：拖到左栏的项目上，或者「⋮」→「移到项目」。拿出来：「⋮」→「移出项目」，或拖回下面的会话里。只有你在本机开的主会话能放进项目，子代理、通讯平台上的会话不行。
- 移进项目的会话人格、预设、工作目录不变。附加提示词照会话现在在哪个项目，每一轮开始时带上；移出去就不带了。
- 项目里的会话敲 `/persona`、`/preset`，说「这个会话在项目里，人格和预设由项目定」。
- 留言关着时，项目里的会话只和同一个项目里的会话互相看得到、发得了消息。打开以后能和项目外的会话互相留言。

左栏里项目一行一个，点了就地展开它的全部会话。项目名前面收着、里面有在跑的写 `(N)`。

### 改和删

- 改：项目那一行的「⋯」→「项目设置」，或者项目页右上角「项目设置」。表和新建时一样，点「保存」。
- 删：「⋯」→「删除项目」，再点「确认删除」；或者在「项目设置」左下角「删除项目」点两下。项目里的会话一起删，找不回来。

项目页（左栏「项目」，再点一张项目卡片）：顶上「‹ 全部项目」返回，标题、说明，「此项目里新建会话的默认配置」一块列着工作区目录、人格、预设、附加提示词、留言，下面是项目里的会话。

## 全部会话

左栏「全部会话」或「查看全部」打开，占对话区那一块。核心支持项目的，顶上分「会话」「项目」两页。

「会话」那一页：

- 顶上：搜索、「多选」、「新会话」、「导入会话…」。
- 筛选：「全部」「运行中」「未读」。右边「按最近活动」，点了换「按创建时间」。
- 列表照时间分组。项目里的会话不在这里列，进项目页看。人生会话也不列，从左栏「更多 → 推演人生」打开。
- 多选同左栏：勾选、`Shift` 连选、全选、删除。
- 「导入会话…」选一个导出的 `.zip`，导进来的放在最后一段「存档」。存档只能看，打开写「这是存档，只能看，不能接着聊」。导出怎么做见 [会话](../sessions.md)。

`Esc` 关上这一页。

## 设置

设置页是页面正中的一个弹窗，打开：左栏底下的齿轮、`/settings`、`Ctrl+,`。`/config` 直接到「模型」，`/pkg` 到「软件包」，`/market` 到「下载软件」。顶上能搜设置项。改一项存一项。

| 页 | 管什么 |
|---|---|
| 通用 | 外观（主题、配色方案，见下面「外观」）；显示、新会话、会话、命令、终端集成会话；「访问」 |
| 用户 | 头像；「关于你」：AI 怎么称呼你、关于你的描述 |
| 隐私与安全 | 权限、受保护的命令、私密目录，见 [权限和沙盒](../permissions.md) |
| 模型 | 「供应商」「默认模型」「模型池」三个分页，见 [模型](../models.md) |
| 用量 | 用量和花费，按天、按模型、按会话、按用途；今天、7 天、30 天、全部、自定义 |
| 预设、人格 | 新建、改、删，见 [人格和预设](../personas-presets.md)；人格页的「推演人生」开关和它下面的「推演方法」「人生会话上下文窗口」见 [推演人生](../life.md#在网页的人格设置里开) |
| 记忆 | 看、改、整理 AI 记住的事，见 [记忆](../memory.md) |
| 知识库 | 搜、看原文、加文档、挂文件夹，见 [知识库](../knowledge.md) |
| 定时任务 | 看、建、停、删定时任务，见 [让 AI 自己接着干](../automation.md) |
| 技能、脚本、MCP | 列出装着的技能、脚本、MCP 服务；MCP 能「添加服务」。技能、脚本页的「打开目录」用这台电脑的文件管理器打开那个文件夹：Linux 用 `xdg-open`，macOS 用 `open -R`（在访达里选中它），Windows 用 `explorer`；开不了的改成复制路径 |
| 下载软件 | 软件源里的包，搜、装、升级，见 [软件包](../packages.md) |
| 软件包 | 装着的包，一行一个开关；最后一段「网页」是网页自己的组件 |
| 软件后台 | 带自己页面的软件，点了打开那一页 |
| 高级 | 压缩、核心、运行日志、模型目录、冷却、软件源这类，一组一行，点进去改 |

设置页「软件包」最后「网页」那一段列着网页自己的组件，例如「右侧边栏」「系统通知」「右边的跳转条」「mermaid 图」，各有开关，有设置项的点进去改。这些开关只记在这台设备的这个浏览器里。

## 外观

外观在设置页「通用」最上面，分两组：

- 主题：「吉祥物」一行选「无」「Deniro」或外观包带的。装了别的主题时多一行「主题」，下拉选形状和材质（圆角、阴影、边框、字体），出厂是「默认主题」。打开了别的时间线、回答画法的，多一行「AI 输出样式」。
- 配色方案：「明暗」选「跟随系统」「浅色」「深色」；下面一张卡片一个配色方案；「主色」从候选色里挑。

出厂的配色方案：

| 配色方案 | 颜色从哪来 |
|---|---|
| 自动（出厂） | 这个会话的人格有主色的照人格，没有的照桌面壁纸，都没有的用默认配色 |
| 跟随人格 | 人格自选的主色，没选的照头像取色 |
| 跟随壁纸 | 这台电脑的桌面壁纸，换壁纸当场跟着变。别的设备上打开的没有这一项 |

左栏底下的按钮也能换浅色、深色。

「跟随壁纸」先找 matugen 生成的那一份颜色（Linux `$XDG_CACHE_HOME/miyu/matugen.json`，没设的 `~/.cache/miyu/matugen.json`；macOS `~/Library/Caches/miyu/matugen.json`；Windows `%LOCALAPPDATA%\miyu\matugen.json`），没有的照这台电脑的桌面找壁纸图：

| 系统 | 从哪读壁纸 |
|---|---|
| Linux | KDE、GNOME、XFCE、Cinnamon、MATE 的桌面设置（照 `XDG_CURRENT_DESKTOP` 认，Unity、Budgie、Pantheon 照 GNOME 读）；awww、swww、hyprpaper（Hyprland 下）、swaybg、wpaperd、waypaper；X11 下另认 feh、nitrogen |
| macOS | 系统存壁纸设置的文件；读不到的问 System Events，第一次会弹窗问要不要允许，不允许的就是读不到。HEIC 的壁纸用系统的 `sips` 转成 JPEG |
| Windows | 注册表 `HKCU\Control Panel\Desktop` 的 `WallPaper`；读不到的（例如幻灯片放映）用 Windows 转好的那一张 `%APPDATA%\Microsoft\Windows\Themes\TranscodedWallpaper` |

视频壁纸读不到。换了壁纸怎么跟上：盯着壁纸图和存设置的文件，一改就重新取色（Linux 用 inotify，macOS 用 FSEvents，Windows 用 ReadDirectoryChangesW）。hyprpaper、swaybg 这类只经命令换、不写文件的盯不到，换了另一个壁纸程序的也盯不到，这两种等浏览器窗口重新拿到焦点时再找一次。

背景图跟着人格：在人格的编辑卡片里「背景图」选一张，用这个人格的会话对话区铺上它。

出厂的主题只有「默认主题」。另带一个「像素风」主题，默认停用，在设置页「软件包」的「网页」那一段打开，再到「主题」里选。软件源里有社区做的网页外观包（`webui-theme-` 开头），装上以后出现在「主题」「配色方案」里，怎么装见 [软件包](../packages.md)。装、卸外观包以后，页面提示「外观「…」有变化，刷新页面后生效」。

`/gallery` 打开「皮肤样张」：一个只在这一页的会话，把各种元素都摆出来，换主题时对着看。

## 访问和安全

在这台电脑上用 `miyu web` 打开的、直接开 `http://127.0.0.1:<端口>` 的，不用密码。从别的设备进来的，要访问密码。

设置页「通用」最下面「访问」那一张卡片（`miyu web --settings access` 直接到这里）：

- 「允许局域网访问」开关，旁边写「已开启」或「仅本机」。还没设访问密码就打开的，先弹「设置访问密码」，设好点「设置并打开」。
- 开着时下面几行：
  - 「监听地址和端口」：`0.0.0.0` 是这台电脑的所有地址，也可以只写其中一个。端口本机和局域网打开都用它。改了网页当场换过去，端口换了写「端口换成了 …，这个页面照旧连着」。
  - 「访问密码」：「设置」或「修改」。从别的设备上修改要先填「当前访问密码」。
  - 「在别的设备上打开」：二维码和地址，「复制」；别的网卡上还有地址的点「更多地址」。手机扫码、敲访问密码就能进。macOS 上别的设备打不开的，照提示到「系统设置 → 网络 → 防火墙 → 选项」里允许 `miyu-web` 的传入连接。

局域网访问是明文 HTTP，只在信得过的网络里打开。在别的设备上关掉局域网访问，那台设备当场断开。

别的设备上的登录页「登录 Miyu」：敲访问密码，勾「自动登录」的这台浏览器 30 天内不用再敲，不勾的关了标签页就要再敲。忘了访问密码，在装 Miyu 的电脑上敲 `miyu web --reset`；让所有浏览器重新登录，敲 `miyu web --logout`。

别的设备上用不了的（这些只给装 Miyu 的那台电脑）：

- `@` 选文件、给会话或项目选工作目录。
- 「打开文件夹」这类按钮，换成复制路径。
- 配色方案「跟随壁纸」。
- 超过附件上限、只交路径的文件。
- 知识库挂文件夹、添加本机命令的 MCP 服务。

托盘菜单的「局域网访问」「在手机上打开…」做的是同一件事，见 [托盘](applet.md)。监听地址、端口的配置键，SSH 端口转发、反向代理的限制，见 [常驻和服务器](../service.md#从别的机器手机打开网页)。

## 通知

AI 一轮做完、有问题等你回答、要你确认时，浏览器弹系统通知：

- 正在看的会话，这个标签页不在前台时才弹；别的会话前台也弹，不出声。
- 标题是会话人格的名字，没有人格的写「Miyu」；正文是「<会话标题> · 回答完了」「… · 等你回答」「… · 等你确认」。点了回到那个会话。
- 每次新开会话的定时任务跑完了，弹「定时任务跑完了」或「定时任务没跑完」。
- 子代理的会话、一次性的会话不弹。
- 托盘在跑的时候，没在网页里开着的会话由托盘弹，网页只弹这个标签页开着的会话。

第一次在输入框里发话时，浏览器问一次给不给通知的权限。不要通知：在浏览器里拒绝，或者在设置页「软件包」的「网页」那一段关掉「系统通知」。标签页关了以后网页不再弹，要收得到就装托盘。

## 软件包加进网页的东西

软件包能往网页里加几样东西，装上、启用就出现，停用就没了：

- 后台页：包自己的一整页，在设置页「软件后台」里列着，点了打开。页面顶上一条窄栏，左边「返回」，网址带 `#package=<编号>`，能收藏、能在新标签页打开。`miyu web --package <编号>` 直接打开它。
- 界面块：扩展放的一小块字和按钮（天气、构建状态这类），出现在新会话的首页、右栏的「面板」、输入框下面那一行的右边，或者单独一整页。程序没在跑的写「未运行」。
- 外观：主题、配色方案、吉祥物，见上面「外观」。

怎么做这些见 [往界面上放东西](../../dev/ui-surfaces.md)。

## 出了问题

| 看到的 | 怎么办 |
|---|---|
| 「端口 8300 已被占用」 | `miyu web --port <端口>` 换一个，或者改 `web.port` |
| 「miyu: 无法打开浏览器，请手动打开上面的地址」 | 照印出来的地址自己打开；没有桌面的机器用 `miyu web --print`。Linux 上交给浏览器靠 `xdg-open`，没装的装上 |
| 「连不上网页软件」「网页软件没在跑。」 | 网页软件空闲退出了，在终端里敲 `miyu web` |
| 「连了很久还没连上。…」 | 这台设备开着代理或 VPN 的，关掉或者把这个地址设成直连 |
| 「核心版本过旧」 | 升级核心，再刷新页面 |
| 「访问密码错误」 | 重敲；忘了在装 Miyu 的电脑上 `miyu web --reset` |
| 「尝试次数过多，N 秒后再试」 | 等它写的秒数 |
| 「还没设访问密码」 | 在装 Miyu 的电脑上 `miyu web --settings access` 设好，再从这里登录 |
| 「这个链接已用过或已过期：在终端里再运行一次 miyu web」 | 照做；带票的链接 60 秒内有效、只能用一次 |
| 「登录已失效，请重新输入访问密码」 | 重新敲访问密码 |
| 「在这台电脑上本来不用输入密码，这次没连上核心…」 | 在终端里敲 `miyu web` 看原因 |
| 「外观「…」有变化，刷新页面后生效」 | 刷新页面 |
| 「复制不了，请长按选中文字后复制」 | 经局域网 `http` 打开的页面不给剪贴板，长按选字复制 |

网页的日志在 `~/.miyu/var/log/webui/web.log`。别的见 [出了问题怎么查](../troubleshooting.md#网页打不开)。
