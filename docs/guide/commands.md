# 斜杠命令

> <sub>本文档由 Anthropic 的 Claude Fable 5.2 生成。</sub>

在输入框里敲 `/` 能用的命令，全在这一页查：每条做什么、带什么参数、在终端、网页、通讯平台哪里能用。怎么用会话的那几条（撤销、压缩、导出这些）详细讲在 [会话](sessions.md)。

## 怎么敲

- 在输入框里敲 `/`，上面弹出命令列表，边敲边筛，名字或别名开头对上的排前面。`↑` `↓` 选，`Tab` 补全，`Enter` 执行。
- 参数写在命令名后面，空一格：`/compact 保留接口的改动`。
- 列表里没有的名字，交给核心认。核心也不认的：终端说为什么不行；网页里后面带着字的当一句普通的话发给 AI。`/` 后面不像命令名的（命令名是英文字母开头，只有英文字母、数字、`-`、`_`），例如 `/你吃了吗`、`/home/me`，本来就当普通的话。
- `/help` 列出按键和全部命令。

命令有两类：

- 核心的命令：核心登记的、软件包和你自己加的。终端、网页、通讯平台上都能用，终端、网页的命令列表里都列着。
- 头自己的命令：只在那个界面里有，见下面「终端的命令」「网页的命令」。

两边重名的（`/clear`、`/stop`、`/context`、`/workspace` 这些），界面照自己的做法办，说明照核心的。

## 核心的命令

| 命令 | 别名 | 参数 | 做什么 | 详见 |
|---|---|---|---|---|
| `/clear` | `/reset` | | 清空上下文，会话不变 | [会话](sessions.md) |
| `/stop` | | | 打断这一轮，排着的话留着不发，停掉这个会话的后台命令和子代理 | [会话](sessions.md) |
| `/workspace` | | `<路径>` | 换这个会话的工作目录。不带路径的说现在是哪个。只有你本人能用 | [会话](sessions.md) |
| `/context` | | `[<数值> \| unset]` | 带数值设这个会话的上下文上限，例如 `128k`、`1m`；`unset` 或 `off` 去掉；不带的说现在的上限和压缩线 | [会话](sessions.md) |
| `/todo` | | `[clear]` | 列出待办；`clear` 清空 | [会话](sessions.md) |
| `/remember` | | `<内容>` | 记一条记忆 | [记忆](memory.md) |
| `/dream` | | `[stop]` | 现在就整理记忆；`stop` 停止整理 | [记忆](memory.md) |
| `/clear-memory` | `/reset-memory` | | 清掉这个会话记下的记忆 | [记忆](memory.md) |
| `/goal` | | `[[--rounds <轮数>] <目标> \| pause \| resume \| clear]` | 不带的看进度；带目标的设定长期目标，已经有的改它，`--rounds` 定最多跑几轮；`pause` 暂停、`resume` 继续、`clear` 清除 | [让 AI 自己接着干](automation.md) |
| `/loop` | | `[[<间隔>] <要说的话> \| off]` | 每隔一段时间说一次，间隔写 `5m`、`2h`；不写间隔的由 AI 定下一次什么时候；什么都不写的由 AI 自己定做什么、什么时候；`off` 停止这个会话的循环。只写了间隔没写话的回用法 | [让 AI 自己接着干](automation.md) |
| `/life` | | `[new \| pause \| resume \| kill]` | 不带的看人生会话；`new` 开始新的一段，有一个就先结束它；`pause` 暂停、`resume` 继续、`kill` 结束 | [推演人生](life.md) |

`/todo`、`/remember`、`/dream`、`/clear-memory`、`/goal`、`/loop` 跟着各自的软件包：包没装、会话的预设没开那个功能的，命令列表里不列。`/life` 一直列着，会话没有人格的敲了回「这个会话没有人格，没有人生会话。」；`/life new`、`/life kill` 在终端里不先问，在网页里先弹一张卡确认；结束的那一段人生的记忆清掉。

网页里，核心的命令在还没开的新会话里不去开会话，当场说一句；`/goal <目标>`、`/loop <要说的话>` 例外，照第一句话一样先开会话。光打 `/loop` 不开会话，提示「请输入要循环说的话」；要开自主循环，先说一句话开了会话再敲。

## 软件包和你自己加的命令

这几种也算核心的命令，在命令列表里和上面的排在一起：

| 从哪来 | 长什么样 | 敲了以后 |
|---|---|---|
| 命令模板：数据根（默认 `~/.miyu`，Windows 上是 `%USERPROFILE%\.miyu`）下的 `root/commands/<名字>.md`，即 `~/.miyu/root/commands/<名字>.md`，或者软件包的 `commands/` 下 | `/<名字> 参数` | 模板的正文当你说的一句发给 AI |
| 扩展声明的命令（清单里的 `[[slash]]`） | `/<名字> 参数` | 扩展的程序办，回一段话给你看 |
| MCP 服务的提示词 | `/<服务名>:<提示词名> 参数`，例如 `/github:review-pr 123` | 取回来的内容当你说的一句发给 AI。只在本机的会话里能用 |
| 扩展带的整页 | `/<名字>` | 打开那一页 |

`~/.miyu/root/commands/` 里的模板和软件包里的同名时，你的赢；和上面核心登记的同名时，核心的赢。每条模板、每个 MCP 服务在预设里各自开关，预设没开的敲了说「预设「…」未启用 /…。」。怎么写模板、扩展命令，见 [扩展 Miyu](extending.md)。

## 谁能用

通讯平台上谁能用一条核心的命令，由 `commands.<命令名>.access` 定。设置页上没有这一项，用 `miyu config set` 改：

| 值 | 谁能用 |
|---|---|
| `admin` | 你本人，以及你在通讯平台后台页的群卡上写进「允许使用管理员命令的用户」的人。平台自己的群主、群管理员不算，见 [接入通讯平台](heads/im.md) |
| `anyone` | 谁都行 |
| `off` | 停用，谁都不行，敲了说「/<名字> 已停用。」 |

没写的照命令自带的设置（扩展在 `[[slash]]` 里写的），都没有的是 `admin`。终端、网页里说话的都是你本人，只有 `off` 有影响。

```sh
miyu config set commands.clear.access anyone       # 群里谁都能 /clear
miyu config set commands.remember.access off       # 停用 /remember
```

改了当场生效。只管核心的命令，头自己的命令不受它管。

## 通讯平台里

在通讯平台上给 AI 发 `/` 开头的消息，先交核心当命令认，核心不认的照普通的话发给 AI。能用的只有核心的命令（上面「核心的命令」和模板、扩展的命令；MCP 的提示词不行），谁能用看 `commands.<命令名>.access`。终端、网页自己的命令（`/undo`、`/compact`、`/new` 这些）在这里没有。平台上的细节见 [接入通讯平台](heads/im.md)。

## 输入框里别的写法

| 写法 | 在哪 | 做什么 |
|---|---|---|
| `$<技能名>` | 终端、网页 | 点名一个技能：敲 `$` 弹出技能列表，选了的技能正文跟着这句话交给 AI。一句话能点几个 |
| `@<路径>` | 终端、网页 | 弹出文件列表选文件。图片这类收成附件，别的文件和目录在话里写成路径，见 [会话](sessions.md) |
| `!<命令>` | 终端 | 框里第一个字敲 `!` 进跑命令的模式，回车在会话的工作目录里直接跑这条命令，不经权限确认，不进沙盒；命令和输出一起交给 AI。最多跑 120 秒，不能带附件。框空着按 `Backspace` 或 `Esc` 回到平常 |
