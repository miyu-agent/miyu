# 人格和预设

> <sub>本文档由 Anthropic 的 Claude Fable 5.2 生成。</sub>

每个会话开着一个人格、一个预设。这一页讲两者各管什么，怎么选、怎么换、怎么设默认，怎么自己写。

## 各管什么

- **人格**管 AI 是谁、怎么说话：人设、示范对话、人设提醒短语，都拼进发给模型的系统提示词。也可以不用人格，这时 AI 只带 Miyu 自己的那段系统提示词。
- **预设**管这个会话开着哪些功能：哪些工具、技能、脚本、MCP 服务、斜杠命令模板能用，往对话里注入哪些环境信息。会话一定要有预设。

两样各选各的，随便搭。人格的记忆跟着人格走：同一个人格的会话共用一份记忆，不用人格的会话共用另一份，详见 [记忆](memory.md)。预设没开「人格记忆」的会话，不记也不想起。

## 出厂的预设

| 界面上叫 | 编号 | 开了什么 | 什么时候用 |
|---|---|---|---|
| 全部功能 | `full` | 装了的全开，以后新装的也开 | 默认就是它 |
| 常规开发 | `dev` | 基础系统、注入环境信息、任务和定时三组，联网搜索，人格记忆，写技能和软件包的两个技能。别的不开，以后新装的也不开 | 写代码，不要扩展、MCP 服务这些额外的东西 |
| 极简开发 | `minimal` | 只有读文件、新建文件、编辑文件、运行命令四件工具，和环境信息的八样 | 想让 AI 照模型自己会的做，工具越少越好 |
| 无功能 | `none` | 什么都不开，以后新装的也不开 | 只聊天；或者以它为底，自己打开几样 |
| 推演人生 | `life` | 注入环境信息、联网搜索、人格记忆、循环任务、结束人生、人设遵循提醒、翻查本会话。没有命令和文件 | 推演人生的会话用，见 [推演人生](life.md)。网页里选预设的地方（新会话、换预设、默认预设、项目、定时任务）不列它，设置的「预设」页照列；终端的选择框照列 |

出厂的默认预设是 `full`。

## 出厂的人格

出厂带一个人格「软件工程师」（编号 `software-engineer`），由出厂软件包「软件工程师人格」（`base-persona-engineer`）带来：写代码用，人设要求先用最简单的办法、用独立的依据验证、做完验过就收工、说话简洁。AI 派子代理时能选它。

出厂没设默认人格：不选的新会话不用人格。删掉这个人格就是卸掉那个软件包，想要回来，把 `base-persona-engineer` 装回来（见 [软件包](packages.md)）。

## 新会话选哪个

- 首次引导：「创建人格」一步建一个人格（可以跳过），建的成了默认人格；「选择预设」一步选的成了默认预设，也能在那里「自定义」一个新的。
- 终端：开新会话时，输入框的位置先出「请选择人格」，再出「请选择预设」，选完才能打字。人格框第一行是「无人格」。`↑`、`↓` 选，`Enter` 确定，`e` 编辑光标上那一个，`a` 新建；在预设框按 `Esc` 回到人格框重选。光标先停在上一个会话用的那一个。不想每次都问，打开设置页「通用 → 新会话 → 新会话不再询问人格预设」（`tui.skip_pick`），新会话直接用默认的。
- 网页：空会话的输入框上面有「选择人格」「选择预设」两个按钮，不点的照默认。默认的预设用不了（文件写错了、删了）时输入框锁住，写「请选择预设」，选一个才能打字。
- 命令行：`miyu ask --persona <人格>`、`--no-persona`、`--preset <预设>`，写的是编号，只管新开的会话，不能和 `-c`、`-s` 一起写：

  ```sh
  miyu ask --persona software-engineer --preset dev "看看这个仓库的测试为什么慢"
  ```

- 定时任务：`miyu schedule add` 同样收 `--persona`、`--no-persona`、`--preset`，管每次新开的会话；和 `--session` 不能一起写。见 [让 AI 自己接着干](automation.md)。
- 通讯平台上的会话用哪个人格、预设，照平台那边的规则定，见 [接入通讯平台](heads/im.md)。网页里在项目中新建的会话，照项目设的人格和预设。

## 给开着的会话换

- 终端：敲 `/persona` 或 `/preset`，在框里选。AI 正在回答时不开框，提示「回答进行中：先打断，或者等它做完」。
- 网页：点对话区左上角的会话标题，菜单里点「人格」或「预设」，选一个，再点「确认」（还没有能压缩的对话时不问，直接换）。也能敲 `/persona`、`/preset`。项目里的会话由项目定，敲了说「这个会话在项目里，人格和预设由项目定」。

换的时候 Miyu 先照旧人格把前面的对话压缩成摘要，下一轮起用新的。换人格以后，记忆从这一轮起记进新人格那一份，以前记的留在原来的人格那里。换预设不改记忆开不开：照开会话时的。子代理的会话不能换。

## 默认值

| 键 | 管什么 | 设置页上 |
|---|---|---|
| `persona.default` | 新会话默认用哪个人格。不设的新会话不用人格；指着已经没有的人格，也当没设 | 「通用 → 新会话 → 默认人格」 |
| `preset.default` | 新会话默认用哪个预设，出厂是 `full`。指着没有的预设，开新会话会报错，不会悄悄换成别的 | 「通用 → 新会话 → 默认预设」 |
| `terminal.persona` | 在 shell 里直接和 Miyu 说话时进的终端集成会话，新开时用哪个人格。不设的跟随 `persona.default` | 「通用 → 终端集成会话」 |
| `terminal.preset` | 同上，用哪个预设。不设的跟随 `preset.default` | 「通用 → 终端集成会话」 |

值写编号。改了对以后开的会话生效，开着的不变：

```sh
miyu config set persona.default software-engineer
miyu config set preset.default dev
```

## 自己写一个人格

人格是数据根（默认 `~/.miyu`，Windows 上是 `%USERPROFILE%\.miyu`）里的一个文件夹 `~/.miyu/root/personas/<编号>/`。编号就是文件夹名：小写字母开头，只有小写字母、数字、`-`、`_`，最长 64 个字符。Miyu 不拦 `con`、`nul`、`aux`、`prn`、`com1` 到 `com9`、`lpt1` 到 `lpt9` 这些 Windows 的保留名，Windows 上建不了这些名字的文件夹和文件，别用。

```text
~/.miyu/root/personas/captain/
├── persona.toml          # 名字、说明，还有几样设置
├── avatar.png            # 头像，可以没有
├── background.jpg        # 背景图，可以没有
└── prompts/
    ├── persona.md        # 人设
    ├── examples.md       # 示范对话
    ├── reminders.md      # 人设提醒短语
    └── life.md           # 推演人生时这条人生怎么过
```

每样都可以没有，空文件夹也算一个人格。放进去以后新开的会话就能选。

`persona.toml`：

```toml
[persona]
name = "老船长"                  # 名字，不能是空的
summary = "说话像老水手的助手"     # 简单描述，给你自己看，模型不看
subagent = true                 # AI 派子代理时能不能选它

[knowledge]
bases = ["sea-charts"]          # 用这个人格时只查得到这几个知识库

[appearance]
seed = "#2f6f9f"                # 主题色
background_opacity = 40         # 背景图露出多少，0 到 100
background_focus = [50, 30]     # 背景图对准哪一处，横、竖各 0 到 100
background_blur = 10            # 背景图模糊多少，1 到 100

[life]
context = 128000                # 推演人生时人生会话的上下文上限（token）
```

| 格 | 说明 |
|---|---|
| `persona.name` | 名字。也能写成 `{ zh = "…", en = "…", ja = "…" }`，界面照语言挑 |
| `persona.summary` | 一句简单描述，写法同 `name`，可以是空字 |
| `persona.subagent` | `true`：AI 派子代理时能选这个人格，名字和简单描述一起给模型看。不写是不能 |
| `knowledge.bases` | 一列知识库的编号，只查得到列着的；写 `[]` 一个都查不到。不写是全部查得到 |
| `appearance.seed` | `#rrggbb`，终端、网页照它取配色。不写的从头像取色 |
| `appearance.background_opacity` | 0 到 100 的整数 |
| `appearance.background_focus` | 两个 0 到 100 的整数 |
| `appearance.background_blur` | 1 到 100 的整数，不写是不模糊 |
| `life.context` | 正整数，人生会话的上下文上限（token）。不写是 `100000`。手改文件只管以后开的人生；在网页人格页改的，当场管这个人格没结束的人生会话。见 [推演人生](life.md#花费) |

只认这几张表、这几格，写了别的报错。

`prompts/` 里的几份：

- `persona.md`：人设，这个人格是谁、怎么说话、怎么待你。原样放进系统提示词最前面，什么语言都行。
- `examples.md`：示范对话，排在系统提示词后面、对话前面。`user:` 开头的是你说的，`assistant:` 开头的是 AI 答的；没有开头的行接在上一句后面，空行不算。要从 `user:` 开始、一问一答交替、`assistant:` 结束：

  ```text
  user: 今天天气怎么样？
  assistant: 风平浪静，适合出海。

  user: 帮我看看这段代码
  assistant: 拿来吧，老船长瞅瞅。
  ```

- `reminders.md`：人设提醒短语，一小段提醒 AI 别出戏的话。预设开着「人设遵循提醒」时，每 3 轮给 AI 再看一遍，系统提示词末尾另加一句要 AI 调完工具也保持人设的话。不想要的，删掉这个文件，或者在预设里关掉「人设遵循提醒」（出厂的「常规开发」「极简开发」就没开）。
- `life.md`：推演人生时这条人生怎么过，见 [推演人生](life.md)。网页人格页的「推演方法」写的就是它。

头像放 `avatar.png`、`avatar.jpg` 或 `avatar.webp`，背景图放 `background.png`、`background.jpg` 或 `background.webp`。在界面里换的，头像最大 1 MiB、宽高不超过 1024，背景图最大 5 MiB、宽高不超过 4096。

改了文件，新会话用新的；开着的会话在下一轮开始时换上新的人设、示范对话、提醒短语。写错的用 `miyu check` 查，会说哪个文件第几行错在哪；开着的会话碰上写错的，照旧用原来的。

## 自己写一个预设

预设是一个文件 `~/.miyu/root/presets/<编号>.toml`，编号就是文件名，写法同人格的编号。一个「只读代码审查」预设，只开读文件、找文件、搜内容，再告诉 AI 工作目录：

```toml
# ~/.miyu/root/presets/review.toml
[preset]
name = "代码审查"
summary = "只能读文件、找文件、搜内容"
icon = "search"
unlisted = "off"

[features]
read = true
glob = true
grep = true
env-workdir = true
```

`[preset]` 这一张：

| 格 | 说明 |
|---|---|
| `name` | 名字，写法同人格的 |
| `summary` | 一句说明，给你看，不发给模型 |
| `icon` | 图标，写 [Lucide](https://lucide.dev) 的图标名 |
| `unlisted` | 没写到的功能开不开：`on` 开，`off` 关。以后新装的也照它。不写是 `on` |
| `hidden` | `true`：不列进新会话选预设的列表，设置页里照样能改 |

别的几张：

| 表 | 写法 | 管什么 |
|---|---|---|
| `[features]` | `<功能编号> = true` 或 `false` | 一个功能开不开 |
| `[software]` | `<软件包编号或组名> = true` 或 `false` | 整个包、整个组开不开 |
| `[tools]` | `<工具名> = false` | 在开着的功能里单关一件工具。只能写 `false` |
| `[limits]` | `unattended_steps = <正整数>` | 没人看着时一轮最多请求几次模型，不写是 `500`。管通讯平台上的会话、定时新开的会话、`miyu ask`，和有人看着的会话里不是你开的那几轮（定时任务、长期目标接着跑这些） |

一个功能开不开，照这个先后：`[features]` 写了它；`[software]` 写了它所在的包；`[software]` 写了包所在的组；都没写的照 `unlisted`。写了没装的不报错。

功能编号：

| 什么 | 编号 |
|---|---|
| 出厂的工具 | 多数同工具名，例如 `read`、`shell`、`subagent`。不一样的：`web_search` 是 `web-search`，`web_fetch` 是 `web-fetch`，`send_message` 跟 `sessions` 一个功能 `sessions`，`remember`、`memory_search`、`forget` 是 `memory`，五件 `kb_*` 是 `knowledge`，三件 `cron_*` 是 `schedule`，`schedule_wakeup` 是 `loop`，`end_life` 是 `life`。全表见 [AI 能用的工具](tools.md) |
| 不带工具的出厂功能 | 环境信息 `env-time`、`env-workdir`、`env-permission`、`env-session`、`env-model`、`env-harness`、`env-machine`、`env-profile`；自动注入 AGENTS 文档 `project-docs`；命令行调用工具 `clicall`；人设遵循提醒 `roleplay` |
| 技能 | `skill-<技能名>` |
| 脚本 | `script-<工具名>` |
| MCP 服务 | `mcp-<服务名>` |
| 斜杠命令模板 | `command-<命令名>` |

`[software]` 能写的组：

| 组名 | 界面上叫 | 组里有 |
|---|---|---|
| `basesystem` | 基础系统 | 读文件、新建文件、编辑文件、找文件、搜内容、删到回收站、运行命令、后台运行、命令行调用工具、子代理、求助旗舰模型、提问、展示给用户、跨会话消息、翻查本会话、用量查询、软件包 |
| `tasks` | 任务和定时 | 待办清单、长期目标、定时任务、循环任务 |
| `environment` | 注入环境信息 | 环境信息的八样、自动注入 AGENTS 文档 |
| `persona` | 人格 | 人格记忆、人设遵循提醒、结束人生 |
| `research` | 查资料 | 联网搜索、知识库 |

在出厂的基础上改一点，只写改了的。例如全部功能里关掉联网搜索，文件叫 `full.toml`：

```toml
# ~/.miyu/root/presets/full.toml
[features]
web-search = false
```

改了文件，新会话用新的；开着的会话下一轮开始换上。用 `miyu check` 查写错没有。

### 设置页里的总开关

设置里技能、脚本、MCP 服务每一项有一个开关，记在 `features.<功能编号>`（例如 `features.mcp-github`）。它只对 `unlisted = "on"` 的预设起作用，而且预设里对这一项写了开或关的照预设。`unlisted = "off"` 的预设没写到的照旧关着。

## 在界面里建和改

- 终端：设置页（`/settings`）主菜单的「人格」「预设」两项。列表里 `a` 新建，填名字，编号可以留空让 Miyu 起；`Enter` 打开一个来改。人格能改名字、简单描述、子代理可选、头像、具体人格提示词、示范对话、人设提醒短语，提示词按 `Enter` 进编辑窗写，或者按 `Ctrl+G` 交给外部编辑器（`$VISUAL`，没有的用 `$EDITOR`，都没有的用 `vi`）；Windows 上没有外部编辑器这一条，在编辑窗里写或者粘贴进去。预设能改名字、描述和每个功能、每件工具的开关，`Space`、`Tab` 或 `Enter` 切，`Ctrl+A` 全切；改一项存一项。窗里按 `d` 删除；出厂的、软件包带的改过的，`d` 是恢复出厂设置。新会话的选择框里按 `e`、`a` 也进同样的窗。
- 网页：设置里的「人格」「预设」两页，能新建、改、删。人格页还有「推演人生」开关，开着时下面露出「推演方法」「人生会话上下文窗口」，见 [推演人生](life.md#在网页的人格设置里开)。开着的会话里，点左上角的会话标题，「人格」那一行的笔是「编辑这个人格」。

在界面里改出厂的、软件包带的，存进你那一层，只写你改了的。删掉的人格进回收站，留 7 天；删掉的预设找不回。

## 三层怎么叠

人格、预设都有三层，从下往上：

1. 出厂的：随 Miyu 装好的。
2. 软件包带的：装了的软件包里的 `personas/`、`presets/`。
3. 你的：`~/.miyu/root/personas/`、`~/.miyu/root/presets/`。

同一个编号几层都有，上面的盖下面的：人格的 `persona.toml`、预设的 `[preset]` 逐格盖，写了的那一格换掉，没写的照下面的；人格 `prompts/` 里的文件、头像、背景图同名的整份换掉；预设的 `[features]`、`[software]` 逐个盖。删掉你那一层，就回到下面的样子。软件包带的和出厂的同编号，用出厂的；几个软件包带了同编号的，只用其中一个，`miyu check` 会报出被盖住的那几份。

软件包也能带人格和预设，怎么做见 [放文件就能用的](../authors/scripts-skills.md)。

## 出了问题

| 看到的 | 怎么办 |
|---|---|
| 开不了新会话，`miyu check` 说「preset.default 写的预设 … 现在没有」 | 默认预设删了或者改了名。把 `preset.default` 改成在的，或者开会话时选一个 |
| 人格、预设在列表里标着错，选不了 | `miyu check` 看哪个文件第几行写错了 |
| 换人格、预设时「回答进行中：先打断，或者等它做完」 | 等这一轮做完，或者先打断 |
