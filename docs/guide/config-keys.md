# 配置键全表

> <sub>本文档由 Anthropic 的 Claude Fable 5.2 生成。</sub>

核心登记的每一个配置键，和随核心出厂的终端、网页的键，都在这一页。怎么改、改在哪、为什么没生效，见[配置](config.md)。

键都写在系统配置 `~/.miyu/etc/config.toml`（数据根默认 `~/.miyu`，Windows 上是 `%USERPROFILE%\.miyu`）里。只有 `permission.start_read_only` 还能写进项目配置。

## 怎么读这张表

「类型」一栏：

| 类型 | 写法 |
|---|---|
| 开关 | `true`、`false` |
| 整数、小数 | 数。小数的也能写整数 |
| 选项 | 「能写」那一栏里的一个，带引号 |
| 多选 | 「能写」那一栏里的几个，写成数组 |
| 字 | 带引号的一行字，不能是空的；「能写」写了最多几个字 |
| 几行字 | 能换行的字 |
| 英文字 | 一行字，中日韩的字不能占一半以上 |
| 时长 | 带引号的正整数，后面跟 `s`、`m`、`h`，不跟的是秒，例如 `"30m"` |
| 名字 | 小写字母开头，只有小写字母、数字、`-`、`_`，最长 64 个字符 |
| 网址 | `http://` 或 `https://` 开头；也能写 `{ env = "变量" }` |
| 模型引用 | `"供应商/模型"` 或 `"@池"` |
| 密钥引用 | `{ secret = "名字" }` 或 `{ env = "变量" }`，见[配置](config.md#密钥) |
| 列表 | 数组，每一项照括号里的类型 |

「默认」一栏的「—」是没有默认值：不写就是没有，说明里写了没有时怎么办。

「生效」一栏：

| 写的 | 意思 |
|---|---|
| 立即 | 改了马上照新的 |
| 下一轮 | 开着的会话从下一轮起照新的 |
| 新会话 | 以后开的会话照新的，开着的不变 |
| 头重启后 | 终端、网页下次启动时才读 |
| 核心重启后 | 核心下次起来时才读 |

键里尖括号那一段是你起的名字：`<编号>` 小写字母开头，只有小写字母、数字、`-`、`_`，最长 32 个字符；`<模型>` 照供应商那边的叫法，1 到 128 个字节；`<工具名>`、`<功能编号>` 1 到 128 个字符，不能有 `.`。名字里有 `.`、`:`、`/` 的，那一段加双引号：`[providers.ollama.models."qwen3:8b"]`。

## 权限

设置页「隐私与安全」。每一项的细节见[权限和沙盒](permissions.md)。`permission.confirm.git`、`delete`、`power`、`pipe_to_shell`、`container` 五个开关在 Windows 上不起作用：Windows 上 AI 用 PowerShell 跑命令，这些规则不查，见 [Windows 上不认](permissions.md#windows-上不认)。

| 键 | 类型 | 默认 | 能写 | 说明 | 生效 | 项目配置 |
|---|---|---|---|---|---|---|
| `permission.confirm.git` | 开关 | `true` | | 破坏性 git 操作先问你 | 下一轮 | 不能 |
| `permission.confirm.delete` | 开关 | `true` | | 递归删除先问你 | 下一轮 | 不能 |
| `permission.confirm.power` | 开关 | `true` | | 关机、重启先问你 | 下一轮 | 不能 |
| `permission.confirm.pipe_to_shell` | 开关 | `true` | | 下载下来直接执行先问你 | 下一轮 | 不能 |
| `permission.confirm.container` | 开关 | `true` | | 容器要宿主的设备、进程或网络命名空间先问你 | 下一轮 | 不能 |
| `permission.confirm.timeout` | 整数 | `300` | `0` 到 `86400`，秒 | 等你确认超过这么久就自动拒绝。`0` 是一直等 | 下一轮 | 不能 |
| `sandbox.private.enabled` | 开关 | `true` | | 私密目录整个开不开 | 下一轮 | 不能 |
| `sandbox.private.add` | 列表（字） | — | 每项 `~/…` 或绝对路径，最多 4096 个字；`~` 后面用 `/`，Windows 上也是；不能是家目录或它的上级 | 你加的私密目录 | 下一轮 | 不能 |
| `sandbox.private.remove` | 列表（字） | — | 只能写这台机器出厂的私密目录 | 去掉的出厂私密目录 | 下一轮 | 不能 |

| `models.cooldown.rate_limited.max` | 时长 | `"10m"` | `1s` 到 `24h` | 被限流，最多停多久 | 立即 | 不能 |

| `models.cooldown.auth.base` | 时长 | `"10m"` | `1s` 到 `1h` | 认证失败，第一次停多久 | 立即 | 不能 |
| `models.cooldown.auth.max` | 时长 | `"2h"` | `1s` 到 `24h` | 认证失败，最多停多久 | 立即 | 不能 |
| `models.cooldown.quota.base` | 时长 | `"30m"` | `1s` 到 `24h` | 额度用完、供应商没说什么时候恢复，第一次停多久 | 立即 | 不能 |
