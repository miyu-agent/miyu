# Config key reference

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

Every config key the core registers, and the keys of the terminal and web UI that ship with the core, are on this page. For how to change them, where, and why a change did not take effect, see [Configuration](config.en.md). Chinese version: [config-keys.md](config-keys.md).

All keys are written in the system config `~/.miyu/etc/config.toml` (the data root is `~/.miyu` by default, and `%USERPROFILE%\.miyu` on Windows). Only `permission.start_read_only` can also be written in the project config.

## How to read the tables

The "Type" column:

| Type | How to write it |
|---|---|
| Switch | `true`, `false` |
| Integer, decimal | A number. Where a decimal is allowed, an integer works too |
| Option | One of the values in the "Allowed values" column, in quotes |
| Multi-choice | Several of the values in the "Allowed values" column, written as an array |
| Text | A one-line quoted string, not empty; "Allowed values" gives the maximum number of characters |
| Multiline text | Text that can span lines |
| English text | One line of text; Chinese, Japanese and Korean characters cannot make up more than half of it |
| Duration | A quoted positive integer followed by `s`, `m` or `h`; with no suffix it is seconds, for example `"30m"` |
| Name | Starts with a lowercase letter; only lowercase letters, digits, `-` and `_`; at most 64 characters |
| URL | Starts with `http://` or `https://`; can also be written as `{ env = "VARIABLE" }` |
| Model reference | `"provider/model"` or `"@pool"` |
| Secret reference | `{ secret = "name" }` or `{ env = "VARIABLE" }`, see [Configuration](config.en.md#secrets) |
| List | An array; each item follows the type in parentheses |

A "—" in the "Default" column means there is no default: if you do not write it, it is not set. The description says what happens then.

The "Takes effect" column:

| Written | Meaning |
|---|---|
| Immediately | The new value is used right away |
| Next turn | Open sessions use the new value from the next turn |
| New sessions | Sessions opened from now on use the new value; open ones do not change |
| After head restart | The terminal and web UI read it only the next time they start |
| After core restart | The core reads it only the next time it starts |

The part of a key in angle brackets is a name you choose: `<id>` starts with a lowercase letter and has only lowercase letters, digits, `-` and `_`, at most 32 characters; `<model>` is the provider's own name for the model, 1 to 128 bytes; `<tool name>` and `<feature id>` are 1 to 128 characters and cannot contain `.`. If a name contains `.`, `:` or `/`, put that part in double quotes: `[providers.ollama.models."qwen3:8b"]`.

The last four are not on the settings page; edit the file by hand or use `miyu config set`. Each takes at most 100 parts, and one part is an inline table:

| Field | Type | Default | Description |
|---|---|---|---|
| `part` | Text, at most 100 characters | Required | The part name |
| `hidden` | Switch | `false` | Hide it |
| `rows` | Integer, `0` to `200` | `0` | The most lines it can take; `0` is no limit |

The shipped part names, in the shipped order:

| Key | Parts |
|---|---|
| `tui.side` | `avatar`, `session`, `cwd`, `context`, `usage`, `loops`, `jump`, `files`, `recent`. Interface blocks from packages are appended after them automatically; you do not need to write them |
| `tui.footer` | Left section `level`, `model`; right section `usage` |
| `tui.above` | `todo` |
| `tui.top` | `prompt` |

The parts you write go in the order you write them, and the ones you do not mention follow in the shipped order. A part that is not recognized is not drawn, and you are told once.

```toml
[tui]
side = [{ part = "recent", rows = 5 }, { part = "avatar", hidden = true }]
```

## Web UI

Settings for the web UI package, prefix `web`. To open the web UI from other devices, see [Keeping it running, and servers](service.en.md).

| Key | Type | Default | Allowed values | Description | Takes effect | Project config |
|---|---|---|---|---|---|---|
| `web.port` | Integer | `8300` | `1` to `65535` | The port the web UI listens on; opening it from this machine and from the local network both use it | Immediately | No |
| `web.listen` | Text | `"127.0.0.1"` | At most 64 characters | Which address to listen on. `127.0.0.1` can be opened only from this computer; `0.0.0.0` is all of this computer's addresses | Immediately | No |
| `web.idle_seconds` | Integer | `600` | `0` to `86400`, seconds | Exits after this long with no browser connected and no media file being served. `0` never exits. Not on the settings page | After head restart | No |
| `web.ticket_idle_seconds` | Integer | `43200` | `1` to `2592000`, seconds | A media file ticket expires after this long unused. Not on the settings page | After head restart | No |
| `web.most_tickets` | Integer | `4096` | `1` to `1000000` | How many media file tickets there can be at most; when full, the longest unused one is dropped. Not on the settings page | After head restart | No |
